## Summary

Ensure deployment artifacts embed resolved effective value-map bindings (including revisions, direction, match mode, fallback, and effective rows) so runtime executes deterministically without mutable library fetches.

---

## Scope

### In Scope

- Snapshot payload shape extensions for effective value-map bindings.
- Deployment relay/runtime guards to reject unresolved references.
- Promote/rollback compatibility with unchanged artifact identity.

### Out of Scope

- UI deploy page redesign.

## Change Requirements

- Snapshot must carry resolved effective lookup rows for each value-map usage.
- Runtime execute must not fetch global/project map storage.
- Integrity checks must fail deterministically when required effective rows are missing.
- Enforce deployment gate integration: new deployment must be blocked when dependency state is `needs-review` or `invalid`.

---

## Verification Requirements

- Deployment/runtime tests covering immutable behavior across deploy/edit/promote/rollback.
- Tests that runtime output remains stable despite post-deploy map edits.

---

## Acceptance Checks

- Runtime uses snapshot-only value-map data.
- Promote reuses same artifact identity and effective map payload.
- Rollback restores prior effective value-map behavior exactly.
- Deployment attempts are deterministically blocked for `needs-review`/`invalid` dependency states.

---

## Blockers / Risks

- Risk: accidental runtime fallback to live resolve endpoint.
