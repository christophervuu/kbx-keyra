## Summary

Implement project map promotion-to-global flow and extend project export/import/duplication so pinned global revisions, overlays, match mode, direction, and fallback preserve deterministic behavior across environments.

---

## Scope

### In Scope

- Promotion endpoint/logic for project-only map to global revision 1.
- Optional relink flow with behavior-equivalence validation.
- Export payload updates for linked global revision + overlay/effective portability.
- Import logic for relink-if-available or detached project-only fallback.
- Project duplication support preserving pinned revisions and overlays.

### Out of Scope

- UI workflow implementation details.

---

## Relevant Areas

- project import/export/duplication handlers and services
- value-map persistence and API modules
- adapter contracts and tests under backend and UI API layers

---

## Change Requirements

- Never silently relink to newer global revisions during import.
- Preserve deterministic behavior when destination lacks referenced global revision.
- When referenced global revision is unavailable, require explicit user resolution before import completion.
- Offer resolution actions:
  - Create project-only copy (recommended primary action),
  - Choose another global value mapping,
  - Cancel import.
- Detached project-only copy must be created from exported effective rows and reproduce original behavior exactly.
- Block unsafe unlink/delete operations when references exist.

---

## Verification Requirements

- Backend tests for promote, export/import fallback, duplication pin preservation.
- Contract tests for portable representation completeness.

---

## Acceptance Checks

- Promotion creates global revision 1 without breaking current project behavior.
- Import never silently relinks or silently detaches; explicit resolution is required when referenced revision is unavailable.
- Detached project-only fallback reproduces exported effective behavior exactly.
- Duplication preserves pinned global revisions and project overlays.

---

## Blockers / Risks

- Risk: portability payload omissions causing behavior drift post-import.

---

## Notes

- Keep payload shape explicit to avoid implicit version upgrades.
