## Summary

Recompose Project Overview into a desktop-first two-column workspace where mappings dominate the main column and secondary context moves to a right rail. Simplify the project header and remove legacy low-value surfaces from default view.

---

## Scope

### In Scope

- Update Project Overview page composition to:
  - breadcrumb (from T-01)
  - simplified project header
  - mappings-dominant main column
  - right rail container for deployment activity + schemas (cards may be stubbed for T-04 wiring)
- Keep fuller schema-management UI off the default compact surface and positioned for Manage schemas handoff (scroll target or collapsed-inline target).
- Simplify header fields to name, description, created/modified dates, compact summary line, and primary actions.
- Remove tag chip/add-tag UI from default overview surface.
- Remove legacy continue section and full-width summary-strip presentation from default layout.
- Remove duplicate Create Mapping affordances in favor of one clear primary location.
- Ensure responsive behavior stacks right rail under mappings at narrower widths.

### Out of Scope

- Mapping table deployment-state semantics and row action redesign (T-03).
- Detailed right-rail deployment activity and schemas card behavior (T-04).

- Header hierarchy must match spec intent with compact identity+metadata summary and clear primary actions.

- Narrow layout must preserve usability and action discoverability.
