## Summary

Build right-rail supporting context surfaces for Project Overview: Deployment Activity card (with polished empty state and View deployments CTA) and compact Schemas card (origin/format/field-count rows + Manage schemas handoff).

---

## Scope

### In Scope

- Add right-rail Deployment Activity card with:
  - empty-state title/body guidance
  - View deployments action linking to `/projects/:projectId/deployments`
  - placeholder-friendly presentation when activity data absent
- Add right-rail Schemas card with:
  - linked schema count + origin summary (e.g., CDM/local)
  - compact schema rows (name, origin, format label, field count)
  - format label normalization (`JSON` vs `JSON Schema`)
  - Manage schemas action routed using this priority:
    1. Scroll to existing full schema management section lower on Project Overview.
    2. If full section is not visible by default in compact redesign, expand it inline from Manage schemas.
    3. Do not introduce drawer/new route unless current codebase already uses that pattern.
- Ensure right-rail cards remain secondary visual weight to mappings panel.

### Out of Scope

- Backend deployment activity feed implementation.
- Full schema management redesign beyond handoff path.
- New project deployment dashboard route creation.
