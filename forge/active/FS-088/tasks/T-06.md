## Summary

Define and implement the non-UI contract needed for Create Mapping auto-map mode to trigger real suggestion generation and open Mapping Editor in a deterministic review-ready state without auto-accepting suggestions.

---

## Scope

### In Scope

- Audit existing adapter/backend callable paths for post-create auto-map trigger.
- Implement minimal contract additions (if needed) to support create-time trigger and editor handoff metadata.
- Ensure generated suggestions remain pending/review-only.
- Provide deterministic failure semantics when generation fails after create.

### Out of Scope

- Redesigning auto-map workspace UI.
- Any automatic accept/apply of generated suggestions.

## Change Requirements

- Create-time auto-map trigger must call an existing real backend/adapter path.
- Canonical handoff must be mappingId-based pending suggestion session state (re-entry safe), not navigation-state-only.
- Phase 0 may keep navigation-state fallback only as temporary local-only compatibility.
- No suggestion should be marked accepted by default during this flow.
- If backend path is unavailable in current mode, caller receives deterministic unsupported response for UI disabled/future handling.
