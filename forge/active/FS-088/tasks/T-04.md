## Summary

Connect `+ Add new source schema` and `+ Add new target schema` actions in schema cards to existing schema add/upload flows so users can create schemas inline and continue setup without leaving Create Mapping.

---

## Scope

### In Scope

- Add in-card source/target add buttons.
- Reuse existing schema modal/drawer behavior from projects feature (no new modal system).
- Track invocation context (source vs target).
- On successful schema create/link, refresh schema list and auto-select created schema for invoking card.
- Preserve existing user-entered form state after modal closes.

### Out of Scope

- New schema ingestion backend behavior.
- Start mode submission behavior.

## Change Requirements

- Add-schema action must not navigate away from Create Mapping route.
- Success path must auto-select new schema and update card/summary immediately.
- Failure path must show non-destructive error and preserve current selections.

## Verification Requirements

- Tests for auto-select + summary update after successful add.
