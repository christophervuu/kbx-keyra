## Summary

Implement condition/comparison authoring in Smart Builder, including operand slot focus behavior, compatible predicate sets by type, per-input transform integration, and deterministic condition expression generation.

---

## Scope

### In Scope

- New condition builder/editor UI surface.
- Predicate/operator availability by operand type.
- Focused-slot capture state and source-click fill integration.
- Then/else explicit branch output modeling.

### Out of Scope

- Non-condition action categories beyond integration hooks.
- Engine architecture changes.

---

## Relevant Areas

- `ui/src/features/mappings/components/ConditionBuilder.tsx`
- `ui/src/features/mappings/components/SmartBuilderPanel.tsx`
- `ui/src/features/mappings/lib/smart-builder-state.ts`
- `ui/src/features/mappings/lib/smart-builder-expression-generator.ts`
- `ui/src/features/mappings/**/*.test.ts(x)`

---

## Change Requirements

- Guided operator choices must only include DSL-valid operations.
- Unsupported/unregistered pseudo-operators are removed from guided condition controls (including `startsWith`).
- `isTruthy` / `isFalsy` are permitted only if compiled to valid registered DSL patterns with tests.
- User can add transforms before/after creating condition and expression remains deterministic.
- Engine diagnostics from invalid branch values/predicates are surfaced inline.

---

## Verification Requirements

- Component and generator tests for condition expression output.
- Tests for focused-slot fill behavior under condition editing.
- Validation integration tests for bad predicate/type scenarios.

---

## Acceptance Checks

- Condition slots can be filled via source clicks when focused.
- Compare/if expressions generate deterministically with per-input transforms.
- Guided operators align to registered DSL functions only.
- Any retained truthy/falsy guided operators compile to valid registered DSL and are test-covered.
- Validation diagnostics surface via engine integration.

---

## Blockers / Risks

- Legacy operator enums may be reused in other surfaces and require safe narrowing.

---

## Notes

- Preserve advanced raw editor escape hatch for unsupported custom logic.
