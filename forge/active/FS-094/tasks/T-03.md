## Summary

Integrate smart tray behavior with Mapping Editor selection events so source clicks add/fill inputs correctly and immediately update draft expressions, preview context, and unsaved state without persistence until global Save.

---

## Scope

### In Scope

- Source/input click handling for add/append/focused-slot fill.
- Source/input field-selection event contract integration (metadata payload, not path-only).
- Immediate draft rule expression update wiring.
- Mapping row and unsaved-count updates from draft changes.
- Undo trigger behavior for direct->compose recovery.

### Out of Scope

- Full action list UI.
- Deep condition/array editor UIs.
- Source panel visual redesign.

---

## Relevant Areas

- `ui/src/features/mappings/hooks/use-mapping-editor.ts`
- `ui/src/features/mappings/components/MappingEditorPage.tsx`
- `ui/src/features/mappings/components/SourceSchemaPanel.tsx` (or input-browser equivalent)
- `ui/src/features/mappings/hooks/*.test.ts(x)`

---

## Change Requirements

- First click on empty tray creates immediate `source("path")` draft.
- Additional clicks append by default (not replace).
- Focused slot click fills slot and does not append.
- Focused slot insertions create slot-scoped references that participate in type/sample/transform/expression generation.
- Draft changes propagate to row mapped state/preview/unsaved indicators.
- Global Save boundary remains unchanged.
- Input panel emits field-selection metadata contract (primary/enrichment kind + path + type/sample metadata), while SmartBuilder/MappingEditor owns append-vs-fill routing.

---

## Verification Requirements

- Hook/integration tests for click behavior permutations.
- Tests for draft autosave state and Save boundary.
- Tests for event-contract routing decisions (filled-focused-slot vs appended-to-tray vs created-direct-draft).
- Typecheck/lint for touched files.

---

## Acceptance Checks

- Input click behavior matches tray rules for empty, append, and focused slot flows.
- Source/input event contract is wired and path-only staging is no longer the sole insertion surface for smart-builder flows.
- Draft expression updates immediately with each valid input action.
- Undo restores prior direct mapping state after compose transition.
- Existing decomposable saved expressions hydrate to smart state; non-decomposable expressions route to Advanced mode banner path.
- No persistence occurs before global Save.
