## Summary

Implement the full set of inline schema editing operations for non-CDM JSON Schema schemas. This includes toggling required/optional, changing field types, renaming fields, adding/removing fields, adding descriptions, adding nested objects and arrays. Includes the save flow that reconstructs raw JSON Schema content from the modified tree and persists via `updateSchema`.

---

## Scope

### In Scope

- Editing operations on the local `SchemaTreeNode[]` tree:
  - Toggle `isRequired` on a field
  - Change `type` via dropdown (string, number, boolean, object, array)
  - Rename `fieldName` via inline input
  - Add/edit `description` via inline text input
  - Add new field to an object node (appended, default type: string)
  - Remove field (with confirmation dialog if node has children)
  - Add nested object (inserts object with placeholder child `newField: string`)
  - Add array field (inserts array with `items: { type: 'string' }`)
- Edit UI: inline controls that appear on tree nodes when in edit mode:
  - Required toggle (checkbox or switch)
  - Type dropdown
  - Rename input (double-click or edit icon)
  - Description input (expandable)
  - Add child button on object nodes
  - Delete button on each node
- Save flow:
  - Reconstruct raw JSON Schema object from modified `SchemaTreeNode[]` tree
  - Call `adapter.updateSchema(schemaId, { content, fieldCount })`
  - Update `parsedSchema` state with new parse result
  - Exit edit mode
  - If schema had GitHub source: mark as "Local changes" (for T-03 to display)
- Confirmation dialogs:
  - Remove field with children: "This field has {n} children that will also be removed. Continue?"
- Tree-to-JSON-Schema reconstruction utility

### Out of Scope

- XSD editing (not supported)
- Drag-and-drop reordering
- Undo/redo
- Schema validation of the edited result
- Visual styling of the overall page layout (established in T-02)

## Change Requirements

- Tree manipulation functions in `schema-editor-ops.ts`:
  - `toggleRequired(nodes, path): SchemaTreeNode[]`
  - `changeType(nodes, path, newType): SchemaTreeNode[]`
  - `renameField(nodes, path, newName): SchemaTreeNode[]`
  - `updateDescription(nodes, path, description): SchemaTreeNode[]`
  - `addField(nodes, parentPath, fieldName, type): SchemaTreeNode[]`
  - `removeField(nodes, path): SchemaTreeNode[]`
  - `addNestedObject(nodes, parentPath, objectName): SchemaTreeNode[]`
  - `addArrayField(nodes, parentPath, arrayName): SchemaTreeNode[]`
  - All functions return a new tree (immutable operations)
  - All functions correctly update `childCount`, `parentPath`, `depth`, and `path` on affected nodes

- Tree-to-JSON-Schema reconstruction (`tree-to-json-schema.ts`):
  - `treeToJsonSchema(nodes: SchemaTreeNode[], originalContent?: object): object`
  - Traverses tree and builds JSON Schema `properties`, `required`, `type`, `description` structure
  - Preserves unrecognized top-level properties from `originalContent` (e.g., `$schema`, `$id`, custom extensions)
  - Handles nested objects and arrays correctly

- `useSchemaEditor` hook extensions:
  - Expose operation dispatchers: `toggleRequired(path)`, `changeType(path, type)`, `renameField(path, name)`, etc.
  - `saveEdits()`: calls `treeToJsonSchema()`, then `adapter.updateSchema()`, then re-parses and updates state
  - Track `hasLocalChanges` (true after save if schema had a GitHub source)

- `EditableNodeControls` component:
  - Renders inline editing UI for a single tree node when in edit mode
  - Required toggle, type dropdown, rename input, description input, delete button
  - Add child button (only on object type nodes)

- Integration: `SchemaTreeNodeRow` or wrapper conditionally renders `EditableNodeControls` when `editable={true}`

## Notes

This is the most complex task in FS-015. The tree manipulation functions should be pure, well-tested utility functions. The reconstruction utility is the critical piece — it must produce valid JSON Schema that re-parses identically through `parseJsonSchema()`. Consider round-trip testing: edit → save → re-parse → verify tree structure matches expectations.
