## Summary

Integrate the existing `<SchemaTreeView />` component into the Schema Detail page, passing `editable={true}` when the user activates edit mode. Establish the edit-mode state toggle and visual indicators (editing banner, save/cancel buttons). The actual editing operations (field manipulation) are deferred to T-05.

---

## Scope

### In Scope

- Render `<SchemaTreeView schema={parsedSchema} variant="source" editable={isEditing} />` in the tree section
- Add edit-mode state management at page level: `isEditing: boolean`
- When `isEditing === true`:
  - Show editing banner/indicator ("Editing mode — changes are local until saved")
  - Show "Save" and "Cancel" buttons above or below tree
  - Pass `editable={true}` to `<SchemaTreeView />`
- When `isEditing === false`:
  - Tree renders in normal read-only mode
  - No editing controls visible
- "Cancel" discards local edits and exits edit mode
- "Save" placeholder (calls save handler — actual save logic wired in T-05)
- Edit mode is only available for non-CDM schemas with `format === 'json-schema'`
- The `<SchemaTreeView />` already handles the visual rendering; this task provides the page-level orchestration

### Out of Scope

- Actual field editing operations (T-05)
- The "Edit" action button (T-07 — for now, expose the toggle via a temporary dev button or wire to future action slot)
- Editing XSD schemas

## Change Requirements

- New hook: `useSchemaEditor(parsedSchema: ParsedSchema | null, schemaId: string)`
  - Returns: `{ isEditing, editedNodes, startEditing, cancelEditing, saveEdits, isDirty }`
  - `startEditing()`: copies `parsedSchema.nodes` into local mutable state, sets `isEditing = true`
  - `cancelEditing()`: discards local state, sets `isEditing = false`
  - `saveEdits()`: placeholder that returns the modified nodes (actual persistence wired in T-05)
  - `isDirty`: true if local nodes differ from original
- Tree section in `SchemaDetailPage`:
  - Renders `<SchemaTreeView />` with parsed schema
  - Passes `editable={isEditing}` prop
  - When editing: renders save/cancel toolbar above tree
  - When not editing: standard tree display
- Guard: edit mode only activatable when `origin !== 'cdm'` and `format === 'json-schema'`
