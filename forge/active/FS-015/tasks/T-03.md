## Summary

Add the Git Status section to the Schema Detail page. Displays sync status indicator, repository name, branch, file path, last synced commit SHA, and timestamp. All fields are read-only. Status is derived from schema source info and origin.

---

## Scope

### In Scope

- Create `ui/src/features/schemas/components/SchemaGitStatus.tsx` component
- Derive sync status from schema metadata:
  - `origin === 'cdm'` or `origin === 'published'` with `commitSha` present → "✓ Synced"
  - `origin === 'published'` without `commitSha` → "⚠ Not synced"
  - `source.type === 'upload'` → "Local only" (no git status section shown, or minimal display)
  - Schema has local modifications after last sync → "⚠ Local changes"
- Display: repo name, branch, file path, commit SHA (truncated to 7 chars), last synced timestamp
- Visual styling: status indicator (green check / amber warning), monospace for SHA/path
- Integrate into `SchemaDetailPage` layout

### Out of Scope

- Sync/re-sync actions (those are in T-07 Actions section)
- Actual GitHub communication
- Modifying the schema source info

- `ui/src/features/schemas/components/SchemaGitStatus.tsx` — new component
- `ui/src/features/schemas/components/SchemaDetailPage.tsx` — integration point

## Change Requirements

- `SchemaGitStatus` component:
  - Props: `source: SchemaSourceInfo`, `origin: SchemaOrigin`, `hasLocalChanges?: boolean`
  - If `source.type === 'upload'`: render minimal "Local schema — not connected to a repository" message
  - If `source.type === 'github'`: render full git status card with:
    - Status indicator icon + text
    - Repository: `source.repo`
    - Branch: `source.branch`
    - Path: `source.path`
    - Commit: `source.commitSha` (first 7 characters) or "—" if undefined
    - Last synced: derive from `updatedAt` or display "—" if never synced
  - Uses Tailwind for styling; Card or bordered section container
- Integrate into `SchemaDetailPage` below metadata section
