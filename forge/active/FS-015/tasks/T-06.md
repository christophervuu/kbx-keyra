## Summary

Build the Usage section of the Schema Detail page that displays which projects and mappings reference the current schema. Provides navigation links to Project Overview and Mapping Editor. Shows empty state when no references exist. This data is also consumed by the Remove action (T-07) to block deletion when mappings reference the schema.

---

## Scope

### In Scope

- Create `ui/src/features/schemas/components/SchemaUsageSection.tsx` component
- Create `ui/src/features/schemas/hooks/use-schema-usage.ts` hook
- Usage derivation logic:
  - Fetch all projects via `adapter.listProjects()`
  - For each project, check if `project.schemaRefs` contains the current `schemaId`
  - Fetch mappings for each referencing project via `adapter.listMappings(projectId)`
  - Check each mapping's `sourceSchemaId` and `targetSchemaId` against current `schemaId`
- Display:
  - "Projects using this schema:" — list with project names as links to `/projects/:projectId`
  - "Mappings referencing this schema:" — list with mapping names as links to `/projects/:projectId/mappings/:mappingId`, with role label (source/target)
- Empty state: "This schema is not currently used by any projects or mappings."
- Integrate into `SchemaDetailPage`

### Out of Scope

- Remove action blocking logic (T-07 consumes usage data)
- Modifying projects or mappings
- Deep-linking to specific schema references within those pages

## Change Requirements

- `useSchemaUsage(schemaId: string)` hook:
  - Returns: `{ projects: UsageProject[], mappings: UsageMapping[], isLoading: boolean }`
  - `UsageProject`: `{ projectId, name }`
  - `UsageMapping`: `{ mappingId, projectId, name, role: 'source' | 'target' }`
  - Fetches data on mount, derives references

- `SchemaUsageSection` component:
  - Props: `schemaId: string` (or receives pre-fetched data from hook)
  - Renders two sub-lists: projects and mappings
  - Project links navigate to `/projects/:projectId`
  - Mapping links navigate to `/projects/:projectId/mappings/:mappingId`
  - Role label shown next to mapping name (e.g., "(source)" or "(target)")
  - Empty state message when both lists are empty
  - Loading state (inline spinner or skeleton for the section)

- The hook should be designed so its output (`projects`, `mappings`) can also be consumed by the Remove action logic in T-07 (for blocking check)
