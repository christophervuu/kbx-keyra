## Summary

Replace the Schema Detail placeholder page with a full page component that loads schema data, displays metadata with inline editing for non-CDM schemas, and handles loading/error/not-found states. This establishes the page shell that subsequent tasks extend with additional sections.

---

## Scope

### In Scope

- Create `ui/src/features/schemas/components/SchemaDetailPage.tsx` — the feature-level page component
- Update `ui/src/routes/pages/SchemaDetail.tsx` to compose the feature page (route-level thin wrapper using `useParams`)
- Page layout with sections: metadata (header), git status placeholder slot, tree placeholder slot, usage placeholder slot, actions placeholder slot
- Metadata section displays: name, description, origin badge (CDM/Published/Local), scope badge (Global/Project-Level), format, field count, created/modified dates, updatedBy
- Inline editing for name and description (non-CDM only): click-to-edit, save on blur or Enter, calls `adapter.updateSchema()`
- Origin and scope badges using colored pill styles
- Loading state: skeleton layout (metadata skeleton blocks, tree area skeleton)
- Error state: "Failed to load schema" with retry button
- Not-found state: "Schema not found" with link back to Schema Library
- Breadcrumb rendering: Home > Schema Library > {Schema Name}
- Hook: `useSchemaDetail(schemaId)` — fetches schema, parses content, provides loading/error/data states
- Integration with `useAdapter()` for data fetching

## Change Requirements

- `useSchemaDetail(schemaId: string)` hook:
  - Calls `adapter.getSchema(schemaId)` on mount
  - Parses content using appropriate parser based on `metadata.format`
  - Returns `{ schema: SchemaDetail | null, parsedSchema: ParsedSchema | null, isLoading: boolean, error: AppError | null, notFound: boolean, retry: () => void, updateMetadata: (input: Partial<UpdateSchemaInput>) => Promise<void> }`
  - Handles race conditions (stale schemaId)
- `SchemaDetailPage` component:
  - Receives `schemaId` prop
  - Uses `useSchemaDetail` hook
  - Renders metadata section with:
    - Schema name (editable for non-CDM: renders as input on click, saves on blur/Enter)
    - Description (editable for non-CDM: click-to-edit textarea)
    - Origin badge: CDM (purple), Published (blue), Local (gray)
    - Scope badge: Global (green), Project-Level (amber)
    - Format display (JSON Schema / XSD)
    - Field count
    - Created date, Modified date, Updated by
  - Skeleton loading state covering all section areas
  - Error state with retry
  - Not-found state with back link
- Route page (`SchemaDetail.tsx`): extracts `schemaId` from `useParams()`, renders `<SchemaDetailPage schemaId={schemaId} />`
