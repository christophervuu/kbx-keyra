## Summary

Install Playwright and configure the E2E test infrastructure with dual-mode project support. This establishes the foundation: `tests/e2e/playwright.config.ts` with two Playwright projects (`localStorage` and `httpBackend`), appropriate Vite dev server startup per project, and the directory structure aligned with `e2e-testing.md`.

---

## Scope

### In Scope

- Set up `tests/e2e/` as a dedicated pnpm workspace package with its own `package.json`
- Add `@playwright/test` and `express` (for mock server, consumed by T-02) as workspace dev dependencies in the E2E package
- Create `tests/e2e/playwright.config.ts` with:
  - Two projects: `localStorage` (no `VITE_API_URL`) and `httpBackend` (`VITE_API_URL=http://localhost:4100`)
  - `webServer` array config starting both Vite dev server and mock server (Express via T-02) — Playwright manages both lifecycles
  - Chromium-only browser config
  - Reporter configuration (list for CI, html for local)
  - Test directory pointing to `tests/e2e/specs/`
  - Artifact/report output directories (gitignored)
- Create directory structure: `tests/e2e/{fixtures,pages,specs,mock-server}`
- Create `tests/e2e/fixtures/base.ts` with extended test fixture skeleton
- Add `.gitignore` entries for `test-results/` and `playwright-report/`
- Add `pnpm` scripts for running E2E tests (e.g., `test:e2e`, `test:e2e:local`, `test:e2e:backend`)
- Register `tests/e2e` in root `pnpm-workspace.yaml` (if applicable)

### Out of Scope

- Mock server implementation (T-02)
- Actual test specs (T-04)
- Page objects and seed utilities (T-03)
- CI pipeline configuration (T-05)

## Change Requirements

- Playwright must be configured for dual-project execution where the same spec files run against both adapter modes
- The `webServer` array must start both Vite dev server (with appropriate env per project) and the mock Express server on port 4100
- Playwright manages mock server lifecycle via `webServer` — no external process management needed
- Config must set reasonable timeouts: 10s per test action, 30s per test, 5min total suite
- Retries: 0 locally, 1 in CI (via `process.env.CI` detection)
- Single browser (Chromium) with viewport 1280x720

---

## Verification Requirements

- `npx playwright test --project=localStorage` starts without error (may have 0 specs initially)
- `npx playwright test --list` shows both projects configured
- Vite dev server starts successfully for each project
- TypeScript compiles cleanly in the E2E directory
- Directory structure matches `e2e-testing.md` conventions

---

## Acceptance Checks

- `tests/e2e/package.json` exists and declares `@playwright/test` and `express` as dependencies
- `tests/e2e/` is registered in workspace config
- `tests/e2e/playwright.config.ts` exists with two named projects and `webServer` array
- `tests/e2e/fixtures/base.ts` exports an extended `test` fixture
- Playwright CLI runs without configuration errors
- `pnpm test:e2e` (or equivalent) script exists and invokes Playwright
- `.gitignore` includes E2E artifact paths
- No changes to `ui/src/` source code

---

## Blockers / Risks

- Playwright version compatibility with the workspace pnpm setup
- `webServer` array config may need careful ordering (mock server must be ready before httpBackend Vite starts, or use health-check `url` waits)

## Notes

- The `httpBackend` project will not pass until mock server (T-02) is implemented; that's expected at this stage
- Use Playwright's `webServer[].url` health-check mechanism to wait for both servers before tests start
- Mock server `webServer` entry should use `GET /test/health` as the readiness URL
