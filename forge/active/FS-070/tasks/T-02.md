## Summary

Update API adapter contracts and shared domain types so the frontend can call the revised backend suggest-expression endpoint using identifier-based context inputs and consume validation-aware suggestion responses.

---

## Scope

### In Scope

- Update `ApiAdapter`/HTTP adapter request and response typing for suggest-expression.
- Align shared domain types for new input fields and validation metadata output.
- Ensure HTTP adapter error normalization remains compatible with existing UI error handling.
- Add adapter-level tests for request payload shape and response mapping.

### Out of Scope

- UI presentation and interaction behavior changes.
- Backend handler implementation details.
- Changes to unrelated AI adapter methods.

---

## Relevant Areas

- `ui/src/lib/api/types.ts`
- `ui/src/lib/api/http-adapter.ts`
- `ui/src/lib/types/domain.ts`
- `ui/src/lib/api/http-adapter.test.ts ?`

---

## Change Requirements

- SuggestExpression input type uses selection identifiers rather than raw prebuilt schema-context text.
- SuggestExpression result type includes validation status/diagnostics suitable for review-state UI decisions.
- HTTP adapter serializes request and deserializes response according to updated backend contract.
- Existing adapter error normalization semantics remain intact.

---

## Verification Requirements

- Unit tests for updated request payload construction.
- Unit tests for updated response parsing (valid and invalid suggestion payloads).
- Regression checks that error mapping path still produces normalized app errors.
- Typecheck for touched UI API/type modules.

---

## Acceptance Checks

- Adapter method signature and payload no longer require UI-built `sourceContext` blob.
- Adapter tests pass for both valid and invalid suggestion responses.
- Type definitions used by UI hooks/components compile without unsafe casting.

---

## Blockers / Risks

- Contract drift risk if backend response shape changes during T-01 completion.

## Notes

- Keep this task narrowly focused on contract alignment and transport-layer behavior.
