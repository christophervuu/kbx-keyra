## Summary

Apply reconciliation changes in backend/adapter-contract layers so retained AI features use canonical Phase 1 architecture paths and deprecated shortcut loops are removed or hard-retired. Preserve retained user-visible behavior while enforcing architecture-safe routing.

---

## Scope

### In Scope

- Canonicalize AI method routing in adapter/backend contract layers per approved matrix.
- Implement canonical `HttpAdapter` backend calls for `autoMap`, `suggestExpression`, `explainRule`, `smartFix`, and `validateMappings`.
- Remove/retire deprecated integration loops in non-UI backend/adapter-path code.
- Align lambda/runtime/error-envelope interactions with canonical conventions.
- Ensure deferred non-core/experimental methods return standardized `FEATURE_NOT_ENABLED` behind explicit gating.
- Align AI schema retrieval dependencies to OpenSearch-first with temporary PK-scoped gated/instrumented fallback.
- Update or add tests validating canonical routing and behavior parity.

### Out of Scope

- React component-level UI workflow changes (handled in T-05).
- New AI feature behavior not already in reconciliation scope.

## Change Requirements

- Retained AI methods must have a single canonical runtime path in backend mode.
- Deprecated shortcut paths must be removed or made unreachable in production mode.
- Error/retry semantics must remain compatible with Phase 1 UI expectations.
- No net-new AI capabilities introduced.
- No direct browser model calls or alternate adapter paths are permitted.

---

## Verification Requirements

- Automated tests cover canonical path behavior for retained methods.
- Regression checks prove retained behavior parity for explain/suggest/auto-map section flows.
- Typecheck/lint pass for all touched backend/adapter code.

---

## Acceptance Checks

- [ ] Retained AI methods route through canonical backend architecture without deprecated bypass loops.
- [ ] `HttpAdapter` implements backend calls for `autoMap`, `suggestExpression`, `explainRule`, `smartFix`, and `validateMappings`.
- [ ] Deprecated/retired backend/adapter shortcut paths are removed or explicitly blocked.
- [ ] Deferred non-core/experimental methods use standardized `FEATURE_NOT_ENABLED` gating.
- [ ] AI schema retrieval follows OpenSearch-first path with documented/instrumented PK-scoped degraded fallback only.
- [ ] Automated tests validate canonical routing and preserve retained user-visible behavior.
- [ ] No new AI capability surface is added.

---

## Blockers / Risks
