## Summary

Build the Project Metadata section (Section A) of the Project Overview page. Displays project name, description, tags, created date, modified date, and "updated by" fields. Name, description, and tags support inline editing — click to enter edit mode, save on blur or Enter.

---

## Scope

### In Scope

- New file `ui/src/features/projects/components/ProjectMetadataSection.tsx`
- Inline editable text field component (or sub-component) for name and description
- Inline editable tag list for tags
- Read-only date displays (created, modified)
- "Updated by" field (show "Local User" in Phase 0)
- Save on blur or Enter keypress
- Loading/saving states for edit operations

### Out of Scope

- Project actions (Section D — T-07)
- Full page layout assembly (T-08)
- Cancel/undo of inline edits

## Change Requirements

- `ProjectMetadataSection` receives: `project`, `onUpdateName`, `onUpdateDescription`, `onUpdateTags` props
- Name display: large heading text. On click → text input. On Enter/blur → call `onUpdateName(value)`. Show subtle save indicator.
- Description display: paragraph text (or "No description" placeholder). On click → textarea. On Enter/blur → call `onUpdateDescription(value)`.
- Tags display: rendered as tag pills. On click → editable input (comma-separated or backspace-to-delete pattern). On blur → call `onUpdateTags(tags)`.
- Dates: "Created: {date}" and "Last modified: {date}" in `text-sm text-gray-500`
- "Updated by: Local User" static in Phase 0
- Styling: Clean card-style container using `Card` primitive. Logical grouping of editable vs read-only fields.
- `InlineEditableText`: Reusable component that toggles between display text and input on click. Props: `value`, `onSave`, `placeholder`, `as` (h1/p), `multiline`.

## Notes

The inline edit pattern should feel lightweight — no modal, no dedicated "Edit" button needed. Visual cue that fields are editable (subtle hover underline or pencil icon on hover). Empty description shows italic placeholder text "Add a description..." that is itself clickable.
