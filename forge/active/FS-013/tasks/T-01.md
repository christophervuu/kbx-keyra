## Summary

Create the `ui/src/features/projects/` feature directory with component and hook barrels, feature-local types, and the folder structure needed by all subsequent tasks. This establishes the organizational pattern consistent with existing features like `mappings/` and `schemas/`.

---

## Scope

### In Scope

- Create directory structure: `features/projects/components/`, `features/projects/hooks/`, `features/projects/lib/`
- Create barrel files: `index.ts`, `components/index.ts`, `hooks/index.ts`, `lib/index.ts`
- Define feature-local types in `features/projects/types.ts`:
  - `SchemaScope` = `'global' | 'project-level'`
  - `ProjectLoadState` = `'loading' | 'loaded' | 'error' | 'not-found'`
  - `SchemaCardData` (derived view model for schema cards)
  - `MappingRowData` (derived view model for mapping table rows)
  - `CreateProjectFormData`
  - `CreateMappingFormData`
- Export types from feature barrel

### Out of Scope

- Hook implementations (T-03+)
- Component implementations (T-04+)
- Modifications to domain.ts or api/types.ts

## Change Requirements

Create the following structure:

```
features/projects/
  index.ts            Feature barrel — re-exports types, hooks, components
  types.ts            Feature-local types
  components/
    index.ts          Components barrel (empty initially)
  hooks/
    index.ts          Hooks barrel (empty initially)
  lib/
    index.ts          Lib barrel (empty initially)
```

Types to define in `types.ts`:

- `SchemaScope`: `'global' | 'project-level'`
- `ProjectLoadState`: discriminated by status
- `SchemaCardData`: `{ schemaId, name, format, origin, scope: SchemaScope, fieldCount, syncStatus, isInferred }`
- `MappingRowData`: `{ mappingId, name, sourceSchemaName, targetSchemaName, ruleCount, coverage, status, devDeploy, qaDeploy, prodDeploy, updatedAt }`
- `CreateProjectFormData`: `{ name: string, description: string, tags: string[] }`
- `CreateMappingFormData`: `{ name: string, sourceSchemaId: string | null, targetSchemaId: string | null }`
- `CreateMappingStep`: `'name' | 'source-schema' | 'target-schema' | 'confirm'`
