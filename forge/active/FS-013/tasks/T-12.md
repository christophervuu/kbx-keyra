## Summary

Ensure confirmation dialogs are available for all destructive actions: delete project, remove schema from project, and delete mapping. Either reuse the existing `ConfirmDialog` from `features/mappings/` (if API-compatible) or lift it to shared `components/` for cross-feature use.

---

## Scope

### In Scope

- Evaluate `features/mappings/components/ConfirmDialog.tsx` for reusability
- If reusable as-is: import from mappings feature (violates no-cross-feature-import rule) → must lift to `components/`
- Lift `ConfirmDialog` to `ui/src/components/ConfirmDialog.tsx` as a shared component
- Update `ui/src/components/index.ts` barrel
- Update `features/mappings/` imports to use shared component
- Ensure dialog supports:
  - Customizable title, message (with JSX), confirm/cancel labels
  - Danger variant (red confirm button)
  - Focus trapping and Escape to close

### Out of Scope

- New dialog designs beyond what already exists
- Toast notifications
- Undo functionality

---

## Relevant Areas

- `ui/src/features/mappings/components/ConfirmDialog.tsx` (source to lift)
- `ui/src/features/mappings/components/ConfirmDialog.test.tsx` (tests to move/keep)
- `ui/src/components/ConfirmDialog.tsx` (new shared location)
- `ui/src/components/index.ts` (barrel update)
- `ui/src/features/mappings/components/index.ts` (update imports)

---

## Change Requirements

- Move `ConfirmDialog.tsx` from `features/mappings/components/` to `ui/src/components/`
- Move or copy `ConfirmDialog.test.tsx` to appropriate test location
- Update `ui/src/components/index.ts` to export `ConfirmDialog`
- Update all imports in `features/mappings/` to import from `@/components` instead of local
- Verify `ConfirmDialog` props support:
  - `title: string`
  - `message: ReactNode` (allows JSX for rich warning messages)
  - `confirmLabel?: string` (default: "Confirm")
  - `cancelLabel?: string` (default: "Cancel")
  - `variant?: 'default' | 'danger'` (danger = red confirm button)
  - `onConfirm: () => void`
  - `onCancel: () => void`
  - `open: boolean`
- If existing component lacks any of the above, extend it minimally
