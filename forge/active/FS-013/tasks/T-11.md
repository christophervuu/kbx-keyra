## Summary

Build the Schema Upload flow: a modal/dialog triggered from Section B that accepts a file, detects its format using the utility from T-02, runs schema parsers (FS-009) for field count, allows scope selection (Global/Project-Level), and persists the schema via the adapter. Handles sample data inference with appropriate warnings.

---

## Scope

### In Scope

- New file `ui/src/features/projects/components/SchemaUploadDialog.tsx`
- File picker: accepts `.json`, `.xsd`, `.xml` extensions
- Read file content as text
- Call `detectSchemaFormat()` to determine format
- If JSON Schema: call `parseJsonSchema()` for field count
- If XSD: call `parseXsd()` for field count
- If sample data: call `parseInferredSchema()`, show "⚠ Inferred from sample data" warning
- Scope selection: radio buttons for "Global" or "Project-Level"
- Display detected format and field count before confirming
- On confirm: call `adapter.createSchema()` then `addSchemaRef()` to project
- Error handling: file read errors, parse failures (graceful — still save with fieldCount 0)
- Loading/progress state during upload

### Out of Scope

- Drag-and-drop upload
- Multi-file upload
- Schema editing after upload
- Schema validation beyond format detection

## Change Requirements

- Dialog layout:
  - Title: "Upload Schema"
  - File picker: `<input type="file" accept=".json,.xsd,.xml" />`
  - After file selected, show:
    - File name
    - Detected format badge ("JSON Schema", "XSD", "Sample Data")
    - If sample data: "⚠ This file will be treated as sample data. Schema structure will be inferred."
    - Field count (if parseable): "{n} fields detected"
    - If parse failed: "⚠ Could not parse schema structure. Field count will be estimated."
  - Scope selection: Radio group "Schema Scope" with options:
    - "Global — available to all projects"
    - "Project-Level — only available in this project"
  - Buttons: "Upload" (primary), "Cancel" (ghost)
- On Upload click:
  - Build `CreateSchemaInput`:
    - `name`: filename without extension
    - `format`: detected format ('json-schema' | 'xsd')
    - `origin`: 'local'
    - `content`: parsed JSON object or raw XML string
    - `source`: `{ type: 'upload' }`
  - For inferred schemas: format is 'json-schema', mark with metadata flag
  - Call `adapter.createSchema(input)` → returns `SchemaMetadata`
  - Update field count in metadata if parser succeeded
  - Add schema ref to project: `addSchemaRef({ schemaId, type: 'local' })`
  - Close dialog
- Error handling:
  - File read error: "Could not read file. Please try again."
  - Empty file: "File is empty"
  - Format detection returns 'unknown': "Could not determine file format. Supported: JSON Schema (.json), XSD (.xsd), sample JSON/XML."
