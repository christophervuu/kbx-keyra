## Summary

Build reusable loading skeleton, error state, and not-found state components for the Project Overview page. The skeleton mimics the page layout during loading. The error state shows a retry action. The not-found state shows a link back to the Home Dashboard.

---

## Scope

### In Scope

- New file `ui/src/features/projects/components/ProjectOverviewSkeleton.tsx` — loading placeholder
- New file `ui/src/features/projects/components/ProjectErrorState.tsx` — error with retry
- New file `ui/src/features/projects/components/ProjectNotFoundState.tsx` — not found with home link
- Skeleton: animated pulse placeholders mimicking sections A–D layout
- Error state: icon + "Failed to load project" + error detail + "Retry" button
- Not-found state: icon + "Project not found" + "The project you're looking for doesn't exist or was deleted." + "Go to Dashboard" link

### Out of Scope

- Generic skeleton primitives (build inline for this feature)
- Full page error boundaries (React error boundary)

## Change Requirements

- `ProjectOverviewSkeleton`:
  - Mimics the 4-section layout with gray animated `animate-pulse` blocks
  - Section A: title-height block + text-height block + tag pills
  - Section B: 2-3 card-sized blocks in a grid
  - Section C: table header + 3-4 row-height blocks
  - Section D: button-sized blocks
  - Use `bg-gray-200 dark:bg-gray-700 rounded animate-pulse` pattern
- `ProjectErrorState`:
  - Props: `error?: string`, `onRetry: () => void`
  - Alert icon (red/orange)
  - "Failed to load project" heading
  - Error detail text (if provided)
  - "Retry" button (primary variant) calling `onRetry`
  - Centered layout
- `ProjectNotFoundState`:
  - 404-style icon or illustration
  - "Project not found" heading
  - "The project you're looking for doesn't exist or was deleted." text
  - "Go to Dashboard" link (`<Link to={PATHS.HOME}>`)
  - Centered layout
