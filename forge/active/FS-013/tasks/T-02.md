## Summary

Implement a pure utility function that detects the format of uploaded schema content: JSON Schema, XSD, or sample data (for inference). This function is called during schema upload to determine how to process the content. No React dependencies — fully unit-testable.

---

## Scope

### In Scope

- New file `ui/src/features/projects/lib/detect-schema-format.ts`
- Detection logic:
  - JSON Schema: valid JSON with `"type"`, `"properties"`, or `"$schema"` top-level keys
  - XSD: XML content with `xs:schema` or `xsd:schema` root element
  - Sample data: everything else (valid JSON without schema markers, or non-XML text)
- Return type: `{ format: SchemaFormat | 'sample', content: unknown | string }`
- Full unit test coverage

### Out of Scope

- Actual schema parsing (done by FS-009 parsers downstream)
- File reading (caller provides content as string)
- UI components

## Change Requirements

Function signature:
```typescript
type DetectedFormat = 'json-schema' | 'xsd' | 'sample-json' | 'sample-xml' | 'unknown';

interface FormatDetectionResult {
  readonly format: DetectedFormat;
  readonly parsedContent: unknown; // parsed JSON object or raw XML string
  readonly confidence: 'high' | 'medium' | 'low';
}

function detectSchemaFormat(rawContent: string, fileName?: string): FormatDetectionResult;
```

Detection rules (in priority order):
1. Try `JSON.parse(rawContent)`:
   - If succeeds and result is an object with any of: `$schema`, `properties`, `type` (with value being a JSON Schema type) → `'json-schema'`, confidence high
   - If succeeds and has `$schema` only → `'json-schema'`, confidence high
   - If succeeds but none of the above → `'sample-json'`, confidence medium
2. If JSON parse fails:
   - Check if content starts with `<?xml` or `<xs:schema` or `<xsd:schema` or contains `xmlns:xs=` → `'xsd'`, confidence high
   - If it's XML-like but not schema → `'sample-xml'`, confidence low
3. Otherwise → `'unknown'`, confidence low

File extension hint (secondary):
- `.xsd` → boost XSD confidence
- `.json` → already handled by JSON parse
