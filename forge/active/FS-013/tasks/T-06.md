## Summary

Build the Mapping List section (Section C) of the Project Overview page. Displays all project mappings in a sortable table with columns for Name, Source→Target, Rules, Coverage%, Status, DEV/QA/PROD deploy badges, Last Modified, and row actions (Edit, Deploy, Duplicate, Delete).

---

## Scope

### In Scope

- New file `ui/src/features/projects/components/MappingListSection.tsx`
- New file `ui/src/features/projects/components/MappingRow.tsx`
- Table with all specified columns
- Status badges: "Ready" (green), "Has Errors" (red), "Draft" (gray)
- Coverage display: percentage or "—"
- Deploy badges: "○ Not deployed" for DEV/QA/PROD (static in Phase 0)
- Column sorting: click header to sort, default by Last Modified descending
- Row actions: Edit (→ Mapping Editor link), Deploy (→ placeholder route), Duplicate, Delete
- "Create Mapping" button in section header
- Empty state: "No mappings yet — create your first mapping"
- Delete confirmation dialog

### Out of Scope

- Actual deployment functionality
- Mapping status re-computation (use stored values)
- Pagination (Phase 0 — list is small)
- Column filtering

## Change Requirements

- `MappingListSection` receives: `mappings: MappingRowData[]`, `projectId`, `onCreateMapping`, `onDuplicate`, `onDelete`
- Table header row with sortable columns:
  - Name (text, sortable)
  - Source → Target (schema names, not sortable)
  - Rules (number, sortable)
  - Coverage (percentage, sortable)
  - Status (badge, sortable by status type)
  - DEV / QA / PROD (badges, not sortable)
  - Last Modified (date, sortable — default sort)
  - Actions (not sortable)
- Sort behavior: click column header toggles asc/desc. Active sort column has visual indicator (arrow).
- Each `MappingRow`:
  - Name as link to editor: `/projects/${projectId}/mappings/${mappingId}`
  - Source → Target: "{sourceSchemaName} → {targetSchemaName}" (show "No schema" when `MappingMetadata.sourceSchemaId` or `targetSchemaId` is undefined — per Q1 resolution, these are now optional)
  - Rules: count number
  - Coverage: "{n}%" or "—" if 0 and no rules
  - Status: colored badge (StatusBadge or custom)
  - DEV/QA/PROD: gray "○ Not deployed" text for each
  - Actions: Edit (link icon), Duplicate (copy icon), Delete (trash icon)
- "Create Mapping" button → calls `onCreateMapping` (navigates to create flow)
- Empty state when no mappings
- Delete → confirm dialog → calls `onDelete(id)`
- Duplicate → calls `onDuplicate(id)` (no confirmation needed)

## Notes

Use `<table>` semantic HTML for the mapping list — this is genuinely tabular data. Tailwind's table utilities (`table`, `table-header-group`, etc.) or standard `<table>/<thead>/<tbody>/<tr>/<td>` with Tailwind classes are both acceptable. The sort implementation can use local `useState` within the section component.
