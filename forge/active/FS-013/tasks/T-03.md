## Summary

Implement the `useProjectOverview` hook that orchestrates loading a project, its schemas, and its mappings, manages inline editing of project metadata, and provides action handlers for schema removal, mapping deletion/duplication, and project deletion. This is the primary data hook for the Project Overview page.

---

## Scope

### In Scope

- New file `ui/src/features/projects/hooks/use-project-overview.ts`
- Load project via `adapter.getProject(projectId)`
- Load schema details for all `project.schemaRefs` via `adapter.getSchema(id)`
- Derive `SchemaCardData[]` and `MappingRowData[]` view models
- Inline editing: `updateName()`, `updateDescription()`, `updateTags()`
- Schema management: `removeSchema(schemaId)`, `addSchemaRef(schemaRef)`
- Mapping actions: `deleteMappingAction(id)`, `duplicateMappingAction(id)`
- Project actions: `deleteProjectAction()`, `duplicateProjectAction()`
- Load state management: loading → loaded | error | not-found
- Re-load on `projectId` change
- Unit tests with mock adapter

### Out of Scope

- Schema upload logic (T-11)
- Create project/mapping flows (T-09, T-10)

## Change Requirements

Hook signature:
```typescript
function useProjectOverview(projectId: string): {
  // Load state
  loadState: ProjectLoadState;
  project: ProjectDetail | null;
  schemas: SchemaCardData[];
  mappings: MappingRowData[];

  // Inline editing
  updateName: (name: string) => Promise<void>;
  updateDescription: (description: string) => Promise<void>;
  updateTags: (tags: string[]) => Promise<void>;

  // Schema actions
  removeSchema: (schemaId: string) => Promise<void>;
  addSchemaRef: (ref: SchemaRef) => Promise<void>;

  // Mapping actions
  deleteMappingAction: (mappingId: string) => Promise<void>;
  duplicateMappingAction: (mappingId: string) => Promise<void>;

  // Project actions
  deleteProjectAction: () => Promise<void>;
  duplicateProjectAction: () => Promise<{ projectId: string }>;

  // Utility
  retry: () => void;
  schemasReferencingMapping: (schemaId: string) => string[]; // mapping names using this schema
}
```

Behavior:
- On mount: set state to loading, call `getProject(projectId)`. On success, load each schema detail, build view models. On not-found error, set not-found. On other error, set error state.
- `updateName/Description/Tags`: call `updateProject()` with partial input, update local state optimistically.
- `removeSchema`: remove from `project.schemaRefs`, call `updateProject()`.
- `addSchemaRef`: append to `project.schemaRefs`, call `updateProject()`.
- `deleteMappingAction`: call `deleteMapping()`, remove from local mappings list.
- `duplicateMappingAction`: call `duplicateMapping()`, add to local mappings list.
- `deleteProjectAction`: call `deleteProject()`, also delete all project mappings.
- `duplicateProjectAction`: create new project with same metadata + "(Copy)", duplicate all mappings, return new project ID.
- `schemasReferencingMapping`: check if any mapping's `sourceSchemaId` or `targetSchemaId` matches the given schemaId.

## Notes

The hook derives `MappingRowData` from `MappingMetadata` by resolving schema names from the loaded schemas. If a mapping references a schema not in the project's current set, show "Unknown Schema" as the name. Deploy badges are always "not-deployed" in Phase 0 — hardcode these values in the derivation.
