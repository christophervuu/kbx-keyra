## Summary

Create the foundational types, adapter interfaces, and configuration module for the shared AI runtime. This establishes `src/lib/ai/` as a new directory, defines all shared types (`PromptRecord`, `AIResult`, `AIError`, `AIResponse`), declares the adapter interfaces (`PromptRegistryAdapter`, `DslAssetLoader`), and implements the configuration module that reads environment variables with typed defaults.

---

## Scope

### In Scope

- Create `src/lib/ai/` directory
- Create `src/lib/ai/types.ts` with:
  - `PromptRecord` interface matching PRODUCT-TECHNICAL.md §15.1 PromptRegistry table schema
  - `AIResult<T>` interface (success response)
  - `AIError` interface (error response)
  - `AIResponse<T>` union type
  - `PromptRegistryAdapter` interface with `getLatestPrompt(promptId: string): Promise<PromptRecord | null>`
  - `DslAssetLoader` interface with `loadDslReference(): Promise<string>`
  - `InvokeAIOptions` interface with optional adapter overrides
  - Error code string literal union type for `AIError.error.code`
- Create `src/lib/ai/config.ts` with:
  - `AIRuntimeConfig` interface
  - `loadConfig()` function that reads environment variables
  - Typed defaults for all configuration values (table name, bucket, keys, endpoints)
  - `AI_RUNTIME_MODE` support (`local` | `aws`)
- Create `src/lib/ai/index.ts` barrel export (initially just re-exporting types and config)
- Add `openai`, `@aws-sdk/client-dynamodb`, `@aws-sdk/lib-dynamodb`, `@aws-sdk/client-s3` as dependencies in `package.json`
- Create `tests/lib/ai/` directory
- Add type-level tests confirming all interfaces are importable and assignable

### Out of Scope

- Implementing adapter logic (T-02, T-03)
- Prompt rendering logic (T-04)
- Model client logic (T-05)
- Orchestration logic (T-06)

## Change Requirements

### Types (`src/lib/ai/types.ts`)

Define the `PromptRecord` interface with all fields from the PromptRegistry table schema:
- `promptId: string`, `version: number`, `systemMessage: string`, `userMessageTemplate: string`, `model: string`, `temperature: number`, `responseSchema: string`, `maxTokens: number`, `updatedAt: string`, `updatedBy: string`, `notes?: string`

Define `AIResult<T>`:
- `success: true`, `data: T`, `promptId: string`, `model: string`, `usage?: { promptTokens: number; completionTokens: number; totalTokens: number }`

Define `AIError`:
- `success: false`, `error: { code: AIErrorCode; message: string; details?: unknown }`, `promptId: string`

Define `AIErrorCode` as a string literal union:
- `'PROMPT_NOT_FOUND' | 'REGISTRY_ERROR' | 'ASSET_NOT_FOUND' | 'ASSET_ERROR' | 'MODEL_ERROR' | 'MODEL_RATE_LIMITED' | 'PARSE_ERROR' | 'CONFIG_ERROR' | 'VALIDATION_ERROR'`

Define `AIResponse<T> = AIResult<T> | AIError`

Define adapter interfaces as specified in the architecture doc.

Define `InvokeAIOptions`:
- `promptRegistry?: PromptRegistryAdapter`, `dslAssetLoader?: DslAssetLoader`

### Configuration (`src/lib/ai/config.ts`)

Define `AIRuntimeConfig`:
- `mode: 'local' | 'aws'`
- `promptRegistryTable: string` (default: `'integrations-keyra-promptregistry'`)
- `promptRegistryLocalDir: string | undefined`
- `dslAssetBucket: string` (default: `'integrations-keyra'`)
- `dslAssetKey: string` (default: `'prompt-assets/dsl/keyra-dsl-reference.md'`)
- `dslAssetLocalPath: string | undefined`
- `githubModelsEndpoint: string` (default: `'https://models.inference.ai.azure.com'`)
- `githubToken: string | undefined`

`loadConfig()` reads from `process.env` and returns `AIRuntimeConfig`.

### Dependencies

Add to `package.json` `dependencies` (not `devDependencies`):
- `openai`
- `@aws-sdk/client-dynamodb`
- `@aws-sdk/lib-dynamodb`
- `@aws-sdk/client-s3`

Note: these are runtime dependencies needed by Lambda. The engine's `tsup` build already only bundles `src/engine/` — these packages will not leak into the engine output. If the task agent identifies a conflict with the engine package's zero-dependency constraint, surface it as a blocker referencing Q3 in the spec.
