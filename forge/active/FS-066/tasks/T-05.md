## Summary

Adopt the shared AI foundation in existing AI handlers and enforce the policy that prompt content is runtime/registry sourced, not hardcoded in handler implementations.

---

## Scope

### In Scope

- Refactor AI handlers to consume shared invocation entry points/contracts.
- Remove duplicated orchestration logic from handlers.
- Enforce no hardcoded prompt text in handler files.
- Add/adjust tests proving handlers remain thin and policy-compliant.

### Out of Scope

- New AI feature endpoint additions.
- UI-facing behavior redesign.

## Change Requirements

- Handlers must delegate to shared service and avoid bespoke model orchestration.
- Handler files must not define prompt templates or long prompt literals.
- Existing endpoint request/response behavior should remain compatible except for explicitly normalized improvements.

---

## Verification Requirements

- Handler unit tests for delegation and response behavior.
- Static checks/tests for absence of prompt literals in handler implementations.
- Regression checks for existing AI endpoints under canonical path.
