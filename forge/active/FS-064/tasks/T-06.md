## Summary

Add deployment history view, promote action (available only for version-backed deployments), rollback action, and an environment comparison view showing current deployments across DEV/QA/PROD with staleness indicators.

---

## Scope

### In Scope

- Deployment history list per environment (within deployment page)
- Promote button: visible only when current deployment is version-backed; targets next environment
- Rollback action: select a previous deployment from history and rollback
- Environment comparison panel: side-by-side DEV/QA/PROD with source type, number, and staleness badge
- Success/error feedback for promote and rollback

### Out of Scope

- Deploy action itself (T-05)
- Badges on project/home pages (T-07)

---

## Relevant Areas

- `ui/src/features/deployments/components/` (extend)
- `ui/src/features/deployments/hooks/` (extend)

---

## Change Requirements

- Deployment history section: call `listDeployments()`, render entries with source type, number, timestamp, promotedFrom, rollbackOf indicators
- Promote button: call `promoteDeployment()`; only enabled when `sourceType=version`
- Rollback button on history entries: call `rollbackDeployment()`; confirm action
- Environment comparison component: call `getCurrentDeployments()`, display per-env card with source info + staleness badge

---

## Verification Requirements

- Component tests: promote button hidden/disabled for revision-backed deployments
- Rollback action calls adapter with correct deployment reference
- Environment comparison renders three environment cards with correct status
- `tsc --noEmit` passes
