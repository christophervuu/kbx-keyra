## Summary

Create a shared staleness computation module that determines whether a deployment is current or stale by comparing the deployed source number against the mapping's latest revision/version number. Usable by both API handlers and the UI adapter layer.

---

## Scope

### In Scope

- `src/lib/deployment/staleness.ts` (new) — pure functions for staleness computation
- Types: `DeploymentStatus = 'current' | 'stale' | 'not-deployed'`
- `computeStaleness(deployment, mapping)` — compares `sourceNumber` against `mapping.revision` or `mapping.latestVersion` based on `sourceType`
- `computeAllEnvironments(currentDeployments, mapping)` — returns status per environment
- Unit tests with deterministic inputs

### Out of Scope

- Persistence reads (callers supply the data)
- UI rendering of badges (T-07)
- API endpoint modifications (staleness can be computed client-side or enriched server-side — either is valid)

- `src/lib/deployment/staleness.ts` (new)
- `src/lib/deployment/index.ts` (new barrel)
- `tests/lib/deployment/staleness.test.ts` (new)

## Change Requirements

- Pure function: given a current deployment record (`{ sourceType, sourceNumber }`) and mapping metadata (`{ revision, latestVersion }`), return `'current' | 'stale'`
- Revision-stale: `sourceType=revision` and `mapping.revision > sourceNumber`
- Version-stale: `sourceType=version` and `mapping.latestVersion > sourceNumber`
- Handle `not-deployed` case (null deployment)
- Batch helper for computing all three environments at once

---

## Verification Requirements

- Unit tests covering: current revision, stale revision, current version, stale version, not-deployed, edge cases (no latestVersion yet)
- `tsc --noEmit` passes

---

## Acceptance Checks

- `computeStaleness()` returns `'stale'` when deployed revision < current revision
- `computeStaleness()` returns `'current'` when deployed version = latest version
- `computeStaleness()` returns `'stale'` when deployed version < latest version
- Not-deployed case returns `'not-deployed'`
- All unit tests pass
- `tsc --noEmit` passes
