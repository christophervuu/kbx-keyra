## Summary

Create the `Deployments` and `DeploymentCurrent` DynamoDB tables and the `src/lib/persistence/deployments.ts` module with CRUD operations for deployment records, current-deployment tracking, and S3 snapshot storage at `deployments/{mappingId}/{ENV}/{timestamp}.json`.

- TypeScript types in `src/lib/persistence/types.ts` for deployment items
- `src/lib/persistence/deployments.ts` module: create deployment, get current, list history, update current
- S3 snapshot write helper in `src/lib/persistence/s3/deployment-snapshot.ts`
- Environment variable additions (`DEPLOYMENTS_TABLE`, `DEPLOYMENT_CURRENT_TABLE`)
- Unit tests for persistence module

## Change Requirements

- Define `DeploymentItem` and `DeploymentCurrentItem` TypeScript types matching the spec table schemas
- Implement `deployments.create(input)` — writes Deployments item + S3 snapshot + updates DeploymentCurrent
- Implement `deployments.getCurrent(mappingId, environment)` — reads DeploymentCurrent
- Implement `deployments.getCurrentAll(mappingId)` — reads all three environments for a mapping
- Implement `deployments.listHistory(mappingId, environment, limit?)` — queries Deployments by PK + SK prefix
- S3 snapshot helper: copies referenced config to `deployments/{mappingId}/{ENV}/{timestamp}.json`
- Add table names to `config.ts` and environment variable declarations
- Add DynamoDB table resources to SAM template
