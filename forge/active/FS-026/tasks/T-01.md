## Summary

Add a mode toggle (Upload File / Paste Content) to the `SchemaUploadDialog` and implement the paste content input path. When in paste mode, a textarea replaces the file input. Pasted content is run through the same `detectSchemaFormat` → parser pipeline as file uploads. Mode switching preserves state on both sides (file info is kept when switching to paste, paste content is kept when switching back to file).

---

## Scope

### In Scope

- Add a segmented toggle or tab control (Upload File / Paste Content) at the top of the dialog content area.
- Render a `<textarea>` in paste mode for pasting raw JSON/payload.
- On textarea blur (or explicit action), call `detectSchemaFormat` on the pasted text.
- Run the same parser pipeline (parseJsonSchema / parseInferredSchema) for field count extraction.
- Show info panel (format badge, field count, inferred warning) identical to file mode.
- Show error message for invalid/unparseable content.
- Preserve file state when switching to paste mode and vice versa (no data loss on toggle).
- Only support JSON-based pastes (JSON Schema, sample JSON) — not XSD/XML paste.
- Update the dialog title from "Upload Schema" to "Add Schema" (neutral for both modes).
- Ensure mode toggle is keyboard accessible (arrow keys or standard tab behavior).

### Out of Scope

- Schema name field (T-02).
- Test updates (T-03).
- XSD/XML paste detection.
- Drag-and-drop file upload.

## Change Requirements

The `SchemaUploadDialog` component must be updated to:

1. **Add mode state:** `inputMode: 'file' | 'paste'` (default: `'file'`).

2. **Add mode toggle UI:** A two-segment toggle rendered above the input area. Active segment styled with `bg-slate-700 text-white`, inactive with `text-slate-400`. Both clickable and keyboard-navigable.

3. **Conditional input rendering:**
   - `'file'` mode: existing file `<input>` and file info panel (unchanged behavior).
   - `'paste'` mode: `<textarea>` with placeholder "Paste JSON Schema or sample JSON data...", min-height ~120px, monospace font for code readability. Below the textarea, same info panel / error display as file mode.

4. **Paste analysis pipeline:**
   - Maintain `pasteText: string` state and `pasteInfo: ParsedFileInfo | null` state (mirroring `fileInfo`).
   - On textarea blur, if `pasteText.trim()` is non-empty, run `detectSchemaFormat(pasteText)`.
   - If format is `'unknown'` or an XSD/XML format, set error: "Could not determine format. Paste valid JSON Schema or sample JSON data."
   - If format is `'json-schema'` or `'sample-json'`, run the appropriate parser for field count. Set `pasteInfo`.
   - Also trigger analysis when the textarea changes and content is non-empty (debounce or on-blur is acceptable; on-blur is simpler and recommended).

5. **Mode switching state preservation:**
   - Switching modes does NOT clear the other mode's state.
   - The "active" content for upload purposes is determined by `inputMode` at the time of clicking "Add Schema".

6. **Upload button enablement:**
   - In file mode: enabled when `fileInfo` is non-null (existing behavior).
   - In paste mode: enabled when `pasteInfo` is non-null.

7. **Upload handler updates:**
   - When `inputMode === 'paste'`, the upload handler uses `pasteInfo` instead of `fileInfo`.
   - Source metadata for paste: `{ type: 'upload' }` (same as file).
   - Name derivation for paste (temporary until T-02): use `"Pasted Schema"` (T-02 will make this editable).

8. **Dialog reset:** When dialog closes (`open` becomes false), reset both `fileInfo` and `pasteInfo`, `pasteText`, errors, and `inputMode` back to defaults.

## Notes

- The mode toggle should use accessible semantics: either `role="tablist"` with `role="tab"` buttons, or a simple pair of buttons with `aria-pressed`. The tab pattern is more conventional for this kind of two-panel switch.
- `detectSchemaFormat` handles JSON parsing internally — it expects raw text. Ensure pasted content is passed as-is (not double-serialized).
- The `ParsedFileInfo` type currently includes a `filename` field. For paste mode, either extend the type to make `filename` optional, or create a parallel type/state. Recommend making `filename` optional: `filename?: string`.
