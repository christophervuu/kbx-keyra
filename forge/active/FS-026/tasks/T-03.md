## Change Requirements

Add the following test cases to the existing `SchemaUploadDialog.test.tsx` file:

1. **Mode toggle rendering:**
   - Dialog renders mode toggle with "Upload File" and "Paste Content" options.
   - "Upload File" is active by default.
   - Clicking "Paste Content" shows textarea, hides file input.
   - Clicking "Upload File" shows file input, hides textarea.

2. **AE-01 — Paste valid JSON Schema:**
   - Switch to paste mode.
   - Set textarea value to a valid JSON Schema object.
   - Fire blur event on textarea.
   - Assert format badge shows "JSON Schema".
   - Assert field count is displayed.
   - Assert name field shows "Pasted JSON Schema".
   - Assert "Add Schema" button is enabled.

3. **AE-02 — Paste sample JSON:**
   - Switch to paste mode.
   - Set textarea value to a plain JSON object (no `"type":"object"` + `"properties"` pattern).
   - Fire blur event.
   - Assert format badge shows "Sample JSON".
   - Assert inferred warning is displayed.
   - Assert name field shows "Pasted Sample JSON".

4. **AE-03 — Paste invalid content:**
   - Switch to paste mode.
   - Set textarea value to non-JSON text.
   - Fire blur event.
   - Assert error message is displayed.
   - Assert "Add Schema" button is disabled.

5. **AE-04 — Edit name in file mode:**
   - Upload a valid file.
   - Assert name field shows filename sans extension.
   - Clear and type a custom name.
   - Click "Add Schema".
   - Assert `adapter.createSchema` was called with the custom name.

6. **AE-05 — Edit name in paste mode:**
   - Switch to paste mode, paste valid content, blur.
   - Assert name field shows default.
   - Clear and type a custom name.
   - Click "Add Schema".
   - Assert `adapter.createSchema` was called with the custom name.

7. **AE-06 — Empty name disables button:**
   - Upload a valid file or paste valid content.
   - Clear the name field.
   - Assert "Add Schema" button is disabled.
   - Type whitespace only.
   - Assert button still disabled.

8. **AE-07 — Mode toggle preserves state:**
   - Upload a valid file in file mode.
   - Switch to paste mode.
   - Switch back to file mode.
   - Assert original file info is still displayed.

9. **AE-08 — Paste analysis on blur:**
   - Switch to paste mode.
   - Type JSON schema content in textarea (without blur).
   - Assert no info panel yet.
   - Fire blur event.
   - Assert info panel appears.

10. **Regression: existing file upload tests unchanged.**
