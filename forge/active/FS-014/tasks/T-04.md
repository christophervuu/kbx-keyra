## Summary

Build the project list container component with search input, sort selector, status filter, and view toggle. Handles client-side filtering, sorting, and delegates rendering to either the card grid or table view sub-components.

---

## Scope

### In Scope

- New file `ui/src/features/home/components/ProjectList.tsx`
- Search input: text field with icon, filters by project name and description
- Sort controls: dropdown for field (name, last modified, mapping count) + direction toggle
- Status filter: dropdown or button group (All, Ready, Draft, Has Errors, No Mappings)
- View toggle: grid/table icons, persists choice to localStorage
- Delegates to `ProjectCardGrid` or `ProjectTable` based on view mode
- Client-side filter/sort logic (pure functions in `features/home/lib/`)
- Count display: "Showing X of Y projects" when filtered

### Out of Scope

- Individual card/row rendering (T-05, T-06)
- Server-side filtering
- Pagination
- Virtualization

## Change Requirements

- `ProjectList` receives: `projects: ProjectListItem[]`, `onProjectClick: (id: string) => void`
- Internal state: `search: string`, `sortField: SortField`, `sortDir: SortDirection`, `statusFilter: StatusFilter`, `viewMode: ViewMode`
- View mode initialized from `localStorage.getItem('keyra:dashboard:viewMode')` ?? `'grid'`
- Controls layout (toolbar row above list):
  - Search input: left-aligned, `placeholder="Search projects..."`, with search icon
  - Sort: dropdown/select for field + clickable direction indicator (↑↓)
  - Filter: dropdown for status options (All | Ready | Draft | Has Errors | No Mappings)
  - View toggle: two icon buttons (grid icon, table/list icon), active one highlighted
- Filter logic (`filterProjects`):
  - Search: case-insensitive substring on `name` or `description`
  - Status: match `worstStatus` against selected filter (or pass all if 'all')
- Sort logic (`sortProjects`):
  - `name`: locale string compare
  - `updatedAt`: ISO string compare (lexicographic works for ISO)
  - `mappingCount`: numeric compare
  - Apply `sortDir` for ascending/descending
- Render: pass filtered+sorted list to either `ProjectCardGrid` or `ProjectTable` based on `viewMode`
- "Showing X of Y projects" text when filter reduces the count
- When filtered list is empty: inline message "No projects match your search/filter"
