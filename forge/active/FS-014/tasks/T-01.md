## Summary

Create the `ui/src/features/home/` feature directory with component and hook barrels, feature-local types (view models for dashboard data), and the folder structure needed by all subsequent tasks.

---

## Scope

### In Scope

- Create directory structure: `features/home/components/`, `features/home/hooks/`, `features/home/lib/`
- Create barrel files: `index.ts`, `components/index.ts`, `hooks/index.ts`, `lib/index.ts`
- Define feature-local types in `features/home/types.ts`:
  - `DashboardMetrics` — aggregated counts and status breakdown
  - `ProjectListItem` — view model for project in list (enriched ProjectMetadata)
  - `DashboardLoadState` — loading state discriminant
  - `ViewMode` — `'grid' | 'table'`
  - `SortField` — `'name' | 'updatedAt' | 'mappingCount'`
  - `SortDirection` — `'asc' | 'desc'`
  - `StatusFilter` — `MappingStatus | 'all' | 'no-mappings'`
- Export types from feature barrel

### Out of Scope

- Hook implementations
- Component implementations
- Modifications to shared domain types

## Change Requirements

Create the following structure:

```
features/home/
  index.ts            Feature barrel
  types.ts            Feature-local types
  components/
    index.ts          Components barrel (empty initially)
  hooks/
    index.ts          Hooks barrel (empty initially)
  lib/
    index.ts          Lib barrel (empty initially)
```

Types to define in `types.ts`:

```typescript
interface DashboardMetrics {
  readonly totalProjects: number;
  readonly totalMappings: number;
  readonly totalSchemas: number;
  readonly statusBreakdown: {
    readonly ready: number;
    readonly draft: number;
    readonly hasErrors: number;
  };
  readonly deployedCount: number; // always 0 in Phase 0
}

type ProjectWorstStatus = MappingStatus | 'no-mappings';

interface ProjectListItem {
  readonly projectId: string;
  readonly name: string;
  readonly description: string;
  readonly mappingCount: number;
  readonly updatedAt: string;
  readonly worstStatus: ProjectWorstStatus;
  readonly devDeploy: DeployStatus;
  readonly qaDeploy: DeployStatus;
  readonly prodDeploy: DeployStatus;
}

type DashboardLoadState = 'loading' | 'loaded' | 'error';

type ViewMode = 'grid' | 'table';

type SortField = 'name' | 'updatedAt' | 'mappingCount';
type SortDirection = 'asc' | 'desc';

type StatusFilter = MappingStatus | 'all' | 'no-mappings';
```
