## Summary

Build a tab structure for the Home Dashboard with three tabs: "Projects" (default, shows the project list), "Deployments" (placeholder), and "Activity" (placeholder). The Deployments and Activity tabs show non-functional empty states explaining they're available in future phases.

---

## Scope

### In Scope

- New file `ui/src/features/home/components/DashboardTabs.tsx`
- Tab bar with 3 tabs: Projects, Deployments, Activity
- Tab switching (local state)
- "Projects" tab: renders children (the actual project list content)
- "Deployments" tab: placeholder message "Deployment tracking available when backend is connected (Phase 4)."
- "Activity" tab: placeholder message "Activity feed available when backend is connected (Phase 1+)."
- Accessible tab pattern (ARIA roles: tablist, tab, tabpanel)

### Out of Scope

- Tab content for Deployments or Activity (future specs)
- Tab persistence (always starts on Projects)
- URL-based tab routing

---

## Relevant Areas

- `ui/src/features/home/components/DashboardTabs.tsx` (new)
- `ui/src/features/home/components/index.ts` (barrel update)

## Change Requirements

- `DashboardTabs` receives: `children: ReactNode` (the Projects tab content)
- Tab bar:
  - "Projects" tab (default active)
  - "Deployments" tab
  - "Activity" tab
  - Active tab: `border-b-2 border-blue-500 text-blue-600 font-medium`
  - Inactive tabs: `text-gray-500 hover:text-gray-700`
- Tab panels:
  - Projects: renders `children`
  - Deployments: centered placeholder
    - Icon: `Rocket` or `Cloud` from Lucide (gray)
    - "Deployment tracking available when backend is connected (Phase 4)."
  - Activity: centered placeholder
    - Icon: `Activity` from Lucide (gray)
    - "Activity feed available when backend is connected (Phase 1+)."
- ARIA:
  - Tab bar: `role="tablist"`
  - Each tab: `role="tab"`, `aria-selected`, `aria-controls`
  - Each panel: `role="tabpanel"`, `id` matching `aria-controls`
- Tab switch: `useState` managing active tab index/key
