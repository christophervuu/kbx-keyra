## Summary

Build the metrics bar component that displays summary cards at the top of the dashboard: total projects, total mappings, total schemas, and a mapping status breakdown (N Ready, N Draft, N Has Errors). Cards are color-coded for status values.

---

## Scope

### In Scope

- New file `ui/src/features/home/components/MetricsBar.tsx`
- Summary cards: Projects, Mappings, Schemas (total counts)
- Status breakdown card: Ready (green), Draft (gray), Has Errors (red) with counts
- Deploy metric: "0 deployed" (Phase 0 static)
- Skeleton/loading variant (pulse placeholders)
- Hidden or shows zeros gracefully when no data

### Out of Scope

- Clickable metrics (no drill-down navigation)
- Animated count transitions
- Responsive stacking (desktop-only)

---

## Relevant Areas

- `ui/src/features/home/components/MetricsBar.tsx` (new)
- `ui/src/features/home/components/index.ts` (barrel update)
- `ui/src/components/Card.tsx` (reuse)
- `ui/src/features/home/types.ts` (DashboardMetrics)

---

## Change Requirements

- `MetricsBar` receives: `metrics: DashboardMetrics | null`, `loading: boolean`
- Layout: Horizontal row of cards with gap, wrapping if needed
- Cards:
  - "Projects" card: large count number + "Projects" label
  - "Mappings" card: large count number + "Mappings" label
  - "Schemas" card: large count number + "Schemas" label
  - "Status" card: three sub-items in a row:
    - `{n} Ready` with green dot/text
    - `{n} Draft` with gray dot/text
    - `{n} Has Errors` with red dot/text
  - "Deployments" card: "0 deployed" (static, gray, Phase 0)
- Loading variant: When `loading` is true or `metrics` is null, show `animate-pulse` placeholder blocks matching card dimensions
- When all values are 0 (empty state), still render cards with "0" values — parent decides whether to hide the bar entirely
- Use `Card` primitive for each metric card (or a custom mini-card that's more compact)
- Styling: `text-2xl font-bold` for numbers, `text-sm text-gray-500` for labels
