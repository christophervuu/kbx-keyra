## Summary

Execute one-time migration/backfill for schema, mapping, and deployment historical artifacts to FS-105 immutable reference contracts and ensure deployment snapshots/runtime resolution remain reproducible and independent from mutable/latest schema state.

---

## Scope

### In Scope

- Migration/backfill for active + historical artifacts:
  - schema families/versions,
  - mapping schema refs,
  - deployment snapshots/manifests,
  - impacted audit/index metadata where required for parity.
- Preserve output parity and execution behavior pre/post migration.
- Add schema-version reference payloads to deployment snapshot generation.
- Ensure runtime executes from snapshot-resolved schema artifacts only.
- Preserve historical deployments and rollout behavior during migration.
- Remove non-CDM user-schema GitHub sync/publish dependencies while preserving CDM/AI flows.

### Out of Scope

- Net-new deployment UX redesign.

---

- `src/lib/persistence/deployments.ts`
- `src/lib/persistence/mappings.ts`
- `src/lib/persistence/schema-metadata.ts`

- `src/lambda/mapping/*`
- migration scripts/tools under `scripts/*` or designated migration modules

---

## Change Requirements

- Include schema identity bundle (`schemaId/schemaVersion/schemaVersionId/contentHash/artifactRef`) in snapshots.
- Do not read latest schema metadata at runtime execution path.
- Keep promote/rollback exact-data invariants.
- Produce migration dry-run report and parity evidence before cutover.

---

## Verification Requirements

- Integration tests proving later schema edits do not affect existing deployed artifact behavior.
- Snapshot integrity tests for source/target/enrichment refs.
- Migration parity tests comparing representative pre/post outputs for historical artifacts.

---

## Acceptance Checks

- Historical artifacts are migrated/backfilled per FS-105 rules.
- Deployment snapshot includes immutable schema-version reference bundle.
- Runtime execute path remains independent of mutable/latest schema state.
- Promote/rollback preserve identical schema artifact identity.
- Non-CDM user-schema GitHub behavior removal does not break CDM/AI paths.
