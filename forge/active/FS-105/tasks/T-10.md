## Summary

Add Mapping Editor and related UI flows for schema-version pin visibility, update-availability indicators, role-aware impact summaries, preview invalidation awareness, and explicit upgrade preview/apply interactions with suggestion review confirmation.

---

## Scope

### In Scope

- Show pinned schema version for source/target/enrichment refs.
- Show update-availability indicators without using deployment `stale` vocabulary.
- Add `Review update` flow with:
  - version diff summary,
  - affected rules listing,
  - suggestion acceptance UX,
  - explicit confirmation before upgrade apply.
- Surface preview-invalidated state and require refresh where applicable.
- Ensure save boundary semantics remain explicit and separate from deploy.

### Out of Scope

- Backend impact engine calculations.
- Deployment UI redesign.

---

## Relevant Areas

- `ui/src/features/mappings/components/*`
- `ui/src/features/mappings/hooks/*`
- `ui/src/routes/pages/MappingEditor.tsx`
- `ui/src/lib/query/*` (if needed for new query hooks)

---

## Change Requirements

- Prevent auto-apply/auto-rewrite behavior.
- Preserve ability to open and run existing pinned mappings unchanged.
- Ensure upgrade path results in explicit unsaved draft state until user saves.

---

## Verification Requirements

- UI tests for indicator labels/status transitions.
- Interaction tests for upgrade confirmation and suggestion acceptance requirements.
- Tests for archived-schema warning/blocked actions in mapping context.

---

## Acceptance Checks

- Mapping UI displays pinned version and update-available messaging.
- Upgrade flow requires explicit user confirmation and suggestion acceptance decisions.
- No automatic DSL rewrite or deployment action occurs from upgrade flow.
- Archived-schema behavior is surfaced per FS-105 contract.

---

## Blockers / Risks

- Potential UX confusion with deployment-state labels; wording must remain distinct.

---

## Notes

- Align status wording exactly to FS-105 contract (`Current`, `Update available`, `Review required`, `Upgrade blocked`).
