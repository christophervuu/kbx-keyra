## Change Requirements

Add the following architecture content to `ui-application.md`:

**Comparison Workflow Architecture (FS-037):**

1. Type model: document the `ComparisonMode` union, `ComparisonSideResult`, `ComparisonSideMetadata`, `ComparisonState`, and `ComparisonSnapshot` types and their relationships
2. Hook contracts:
   - `useServerPreview(mappingId, environment)` — adapter.previewOnServer wrapper with Phase 0 gating and timeout
   - `useDeploymentContext(mappingId)` — deployment context loader with per-mode availability derivation
   - `useEnvironmentComparison(...)` — two-sided orchestration with parallel execution, diff computation, progressive state updates
3. Component hierarchy:
   ```
   CompareTab
   ├── ComparisonModeSelector
   ├── ComparisonSidePanel (left)
   │   └── EnvironmentMetadataBar
   ├── ComparisonSidePanel (right)
   │   └── EnvironmentMetadataBar
    └── ComparisonDiffDisplay
   ```
4. Phase 0 gating: describe how `isModeAvailable` gates environment modes, `useServerPreview.isAvailable` catches adapter errors, and the UI shows appropriate messaging
5. Guardrails: document that Compare tab contains no deployment-modifying actions; comparison is observation-only
6. Snapshot storage: document the separate `ComparisonSnapshot` storage model — independent records in `keyra:comparison-snapshots:{mappingId}`, linked to test cases by `testCaseId`, with `useComparisonSnapshots` hook for CRUD

Update Module Structure to include:
- `ui/src/features/mappings/components/comparison/` directory with all new components
- `ui/src/features/mappings/hooks/use-server-preview.ts`
- `ui/src/features/mappings/hooks/use-deployment-context.ts`
- `ui/src/features/mappings/hooks/use-environment-comparison.ts`
- `ui/src/features/mappings/hooks/use-comparison-snapshots.ts`
