## Summary

Create the `ComparisonModeSelector` component that allows users to choose a comparison mode. The selector displays all available modes with deployment status information, disables modes that are unavailable (due to missing deployments or Phase 0), and shows informative tooltips explaining why modes are disabled.

---

## Scope

### In Scope

- Create `ui/src/features/mappings/components/comparison/ComparisonModeSelector.tsx`
- Render a dropdown or segmented control listing all 5 comparison modes
- Show deployment version info next to environment-dependent modes (e.g., "DEV: v5")
- Disable modes that are unavailable with reason tooltip
- Phase 0 messaging: "(requires backend connection)" for server-dependent modes
- Missing deployment messaging: "{ENV}: no deployment" for modes requiring undeployed environments
- Highlight the currently selected mode
- Add component tests

### Out of Scope

- Comparison execution (handled by the hook in T-04)
- Result display
- Comparison orchestration

## Change Requirements

Component props:

```ts

  selectedMode: ComparisonMode;
```

Rendering:

- Each mode option shows:
  - Mode label (e.g., "Current vs DEV")
  - Deployment status badge for environment sides (e.g., "v5" or "no deployment")
  - Disabled state with reason when unavailable
- Use a `<select>` or custom dropdown consistent with existing UI patterns
- Selected mode is visually distinguished
- Disabled options are grayed out with tooltip showing the reason
- Test IDs: `comparison-mode-selector`, `comparison-mode-option-{mode}`
