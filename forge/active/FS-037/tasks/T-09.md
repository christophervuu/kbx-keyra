## Summary

Extend the test case model and storage to support optional comparison result snapshots. Add a "Save Comparison" action in the CompareTab that captures the current comparison state (mode, both side results, diff) alongside the active test case. Add a read-only historical view for stored comparison snapshots in the TestCaseManager.

---

## Scope

### In Scope

- Extend `TestCase` type with optional `comparisonSnapshot?: TestCaseComparisonSnapshot` field
- Add "Save Comparison" button in CompareTab (visible after a comparison completes)
- Save flow: creates or updates the comparison snapshot on the current test case via `useTestCases` hook
- If no test case is loaded, prompt user to save the source data as a new test case first (or auto-create)
- Add a visual indicator in TestCaseManager for test cases that have stored comparisons
- Add a read-only view for stored comparison snapshots (expandable section or modal)
- Update `useTestCases` hook to support comparison snapshot CRUD
- Add tests for save flow and snapshot display

### Out of Scope

- Re-executing stored comparison snapshots (they are read-only historical records)
- Batch operations on comparison snapshots
- Comparison snapshot import/export

## Change Requirements

`TestCase` type extension:

```ts
export interface TestCase {
  // ... existing fields
  readonly comparisonSnapshot?: TestCaseComparisonSnapshot;
}
```

`useTestCases` hook extension:

- `saveComparisonSnapshot(testCaseId: string, snapshot: TestCaseComparisonSnapshot): void`
- `clearComparisonSnapshot(testCaseId: string): void`

CompareTab "Save Comparison" button:

- Visible after a comparison completes (status `'complete'` or `'partial-error'`)
- If a test case is loaded: saves the comparison snapshot to that test case
- If no test case is loaded: shows a mini-form to name and save a new test case with the current source data + comparison snapshot
- Success feedback: brief toast or inline success message

TestCaseManager indicator:

- Test cases with `comparisonSnapshot` defined show a small comparison icon (e.g., `GitCompare` from Lucide)
- Clicking the indicator expands or opens a read-only view of the stored comparison:
  - Mode, captured timestamp
  - Summary: "Outputs match" or "N differences"
  - Left/right labels and output excerpts (truncated)
