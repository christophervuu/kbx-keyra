## Summary

Add new `AutoMapSectionInput`, `AutoMapSectionResult`, and `AutoMapSuggestion` domain types for section-based Auto-Map with per-suggestion metadata (explanation, confidence, validation). Add an HTTP client function `autoMapSectionHttp()`, and add a new `autoMapSection()` method to `ApiAdapter`, `HybridAdapter`, and `LocalStorageAdapter`. The existing `autoMap()` method and `AutoMapInput`/`AutoMapResult` stubs remain untouched.

### `AutoMapSectionResult` type (new — does NOT modify existing `AutoMapResult`)

```ts
export interface AutoMapSectionResult {
  readonly suggestions: readonly AutoMapSuggestion[];
  readonly diagnostics?: readonly Diagnostic[];
```

Note: This uses `suggestions` (not `rules`) as the field name, since these are AI-generated suggestions, not committed mapping rules. The existing `AutoMapResult.rules: MappingRule[]` stub is not modified.

### HTTP client function

Follow the `suggestExpressionHttp` pattern:
- POST to `${apiUrl}/ai/auto-map-section`
- Timeout: 60,000ms (section-level operations are slower than single-field)
- Response parsing: expect `AIResult<{ suggestions: AutoMapSuggestion[] }>` envelope
- Error mapping: user-friendly error messages for network, timeout, rate limit, and server errors

### ApiAdapter interface addition

Add to `ApiAdapter` interface in `ui/src/lib/api/types.ts`:

```ts
autoMapSection(input: AutoMapSectionInput): Promise<AutoMapSectionResult>;
```

This is a new method alongside the existing `autoMap()` — it does not replace or modify `autoMap()`.

### HybridAdapter implementation

```ts
async autoMapSection(input: AutoMapSectionInput): Promise<AutoMapSectionResult> {
  return autoMapSectionHttp(this.apiUrl, input);
}
```

### LocalStorageAdapter stub

```ts
  throw new Error('Auto-Map Section is not available in offline mode');
```

## Notes

- The 60-second timeout for `autoMapSectionHttp` is intentionally longer than the 30-second timeout used for single-field AI operations. Section-level Auto-Map processes multiple fields and may require more time.
- The `sourceContext` field on `AutoMapSectionInput` follows the FS-042 showcase pattern — a pre-formatted text block of source fields as a temporary substitute for RAG retrieval. The hook (T-02) will derive this from the parsed source schema.
- The response envelope assumption (`AIResult<{ suggestions: AutoMapSuggestion[] }>`) matches the backend `ai-runtime.md` `AIResult<T>` pattern. If the actual backend endpoint uses a different shape, this function will need adjustment — flag in testing.
- The new `AutoMapSectionResult` uses `suggestions` (not `rules`) as its field name. This is intentional: the returned items are AI-generated suggestions, not committed mapping rules. The existing `AutoMapResult.rules: MappingRule[]` stub retains its original naming for the future full-schema Auto-Map use case.
