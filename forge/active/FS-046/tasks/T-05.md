## Summary

Wire the per-suggestion action callbacks (Accept, Edit, Dismiss, Undo Dismiss) and the bulk "Accept All Valid" action from `useAutoMapReview` into `AutoMapReviewDrawer` and `SuggestionReviewCard` components. This task connects the hook's action handlers to the UI, ensuring state transitions are visible and the editor draft model is updated correctly.

---

## Scope

### In Scope

1. Create a composition layer (likely within the drawer's parent or a dedicated container component) that:
   - Maps `useAutoMapReview.items` to `SuggestionReviewCard` instances
   - Passes `acceptSuggestion`, `editSuggestion`, `dismissSuggestion`, `undoDismiss` as callbacks to each card
   - Passes `acceptAllValid` to the `AutoMapReviewDrawer`'s bulk action button
2. Verify state transitions are correctly reflected in the UI:
   - Accept → card shows "Accepted ✓", expression was written to draft
   - Edit → card shows "Editing", expression was written to draft, editor navigated to field
   - Dismiss → card shows "Dismissed" with Undo button, no draft change
   - Undo Dismiss → card restores to full pending state, no draft change
   - Accept All Valid → multiple cards transition simultaneously
3. Completion detection: when `summary.pending === 0`, show completion summary in the drawer
4. Completion summary content: "All {total} suggestions reviewed. {accepted} accepted, {edited} edited, {dismissed} dismissed."

### Out of Scope

- Hook implementation (T-02)
- Drawer shell (T-03)
- Card component (T-04)
- MappingEditorPage integration and trigger (T-06)
- Loading/error states (T-07)

## Change Requirements

### Composition pattern

The parent component (likely in the route page or a dedicated wrapper) connects hook to drawer:

```tsx
// Conceptual structure
const autoMapReview = useAutoMapReview({ adapter, projectId, mappingId, rules, updateDraft, setSelectedTargetPath });

<AutoMapReviewDrawer
  isOpen={autoMapReview.isDrawerOpen}
  onClose={autoMapReview.closeDrawer}
  sectionPath={autoMapReview.sectionPath}
  summary={autoMapReview.summary}
  onAcceptAllValid={autoMapReview.acceptAllValid}
>
  {autoMapReview.items.map((item) => (
    <SuggestionReviewCard
      key={item.suggestion.target}
      item={item}
      onAccept={autoMapReview.acceptSuggestion}
      onEdit={autoMapReview.editSuggestion}
      onDismiss={autoMapReview.dismissSuggestion}
      onUndoDismiss={autoMapReview.undoDismiss}
    />
  ))}
</AutoMapReviewDrawer>
```

### Completion summary

When `summary.pending === 0` and `summary.total > 0`:

- Show a completion banner at the top of the scrollable area (above the cards)
- Content: checkmark icon + "All {total} suggestions reviewed"
- Breakdown: "{accepted} accepted, {edited} edited, {dismissed} dismissed" (omit categories with 0 count)
- The "Accept All Valid" button is disabled in this state

### State transition verification

For each action, verify the following side effects:

| Action | `updateDraft` called | `setSelectedTargetPath` called | `reviewStatus` change |
|--------|---------------------|-----------------------------|----------------------|
| Accept | Yes (target, expression) | No | `pending → accepted` |
| Edit   | Yes (target, expression) | Yes (target) | `pending → edited` |
| Dismiss | No | No | `pending → dismissed` |
| Undo Dismiss | No | No | `dismissed → pending` |
| Accept All Valid | Yes × N | No | `pending → accepted` × N |
