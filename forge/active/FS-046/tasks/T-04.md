## Summary

Create the `SuggestionReviewCard` component that renders a single Auto-Map suggestion with target path, new/replace badge, current vs suggested expression comparison, explanation, confidence badge, validation badge, optional diagnostics, and action buttons.

---

## Scope

### In Scope

1. New component at `ui/src/features/mappings/components/SuggestionReviewCard.tsx`
2. Card layout with:
   - Target field path (prominent)
   - "New rule" or "Replaces existing" badge
   - Current expression (or "No existing rule" placeholder)
   - Suggested expression (highlighted/distinct)
   - Explanation text
   - Confidence badge (High/Medium/Low with color)
   - Validation badge (Valid/Warning/Invalid with color)
   - Expandable diagnostics section when diagnostics exist
3. Action buttons: Accept, Edit, Dismiss (rendered but callback-only — action logic in T-05)
4. Visual states based on `reviewStatus`:
   - `pending` — full card, all actions available
   - `accepted` — collapsed, green "Accepted ✓" indicator, actions hidden
   - `edited` — collapsed, blue "Editing" indicator
   - `dismissed` — collapsed/faded, muted "Dismissed" indicator, **Undo button visible**
5. Component barrel export update

### Out of Scope

- Action handler logic (T-05 wires the callbacks)
- Integration into AutoMapReviewDrawer (done by parent composition)
- Loading/error states (T-07)

The dismissed card renders in a reduced, visually de-emphasized state with an **Undo** button that calls `onUndoDismiss(target)`. Clicking Undo restores the card to the full pending state.

### Expression comparison

- **Current expression**: show the existing rule expression in monospace font. If `currentExpression` is `null`, show "No existing rule" in muted italic.
- **Suggested expression**: show in monospace font with a distinct left border or background tint to visually distinguish from current. Truncate long expressions with expand toggle.

### Badges

**New/Replace badge:**
- `isNew === true` → "New rule" badge (blue outline)
- `isNew === false` → "Replaces existing" badge (amber outline)

**Confidence badge:**
- `high` → green dot + "High" label
- `medium` → amber dot + "Medium" label
- `low` → red dot + "Low" label

**Validation badge:**
- `valid === true` with no warning diagnostics → green "Valid ✓"
- `valid === true` with warning diagnostics → amber "Warning"
- `valid === false` → red "Invalid ✕"
- `validation` absent → no badge rendered (graceful degradation per AE-14)

### Diagnostics expansion

- If `suggestion.validation.diagnostics` is non-empty, show an expandable section
- Collapsed: "Diagnostics ({count})" toggle
- Expanded: list of diagnostic entries with severity icon + code + message
- Severity colors: error = red, warning = amber, info = blue

### Action buttons

- **Accept**: primary style (solid blue), text "Accept"
- **Edit**: secondary style (outline), text "Edit"
- **Dismiss**: ghost/subtle style, text "Dismiss"
- All buttons disabled/hidden when `reviewStatus !== 'pending'`
- Each button calls the corresponding callback with `item.suggestion.target`
