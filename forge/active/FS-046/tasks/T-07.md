## Summary

Implement all non-happy-path states for the Auto-Map review drawer: loading (in-flight request), empty (no suggestions returned), error (request failed or malformed response), and done (all suggestions resolved). These states ensure the drawer remains usable and trust-preserving across all scenarios.

---

## Scope

### In Scope

1. **Loading state**: Content within the drawer (or inline near the trigger) showing a spinner and contextual message: "Generating suggestions for {sectionPath}..."
2. **Empty state**: Drawer content when `items.length === 0` after a successful response: centered icon + message + close button
3. **Error state**: Drawer content when request fails: error icon + user-friendly message + "Try Again" button
4. **Done state**: Drawer content when all suggestions are resolved (`summary.pending === 0`): completion summary banner
5. **Malformed response**: Treated as error state with message "Received an unexpected response. Please try again."
6. Update `AutoMapReviewDrawer` to conditionally render these states based on hook status

### Out of Scope

- Happy-path suggestion rendering (T-04, T-05)
- Hook error handling implementation (T-02 — this task adds the UI for error states)
- Editor integration (T-06)

## Change Requirements

### Loading state

- Rendered inside the drawer body when `status === 'loading'`
- Centered vertically in the scroll area
- Content:
  - Animated spinner (use existing `Loader2` icon from Lucide React with `animate-spin`)
  - Text: "Generating suggestions for {sectionPath}..."
  - Muted subtext: "This may take a moment."
- No "Accept All Valid" button or summary badges during loading (bulk actions bar hidden or disabled)
- The drawer summary header still shows the section name

### Empty state

- Rendered when `status === 'success'` and `items.length === 0`
- Centered vertically in the scroll area
- Content:
  - Icon: `FileX2` or `Inbox` (muted gray)
  - Heading: "No suggestions generated"
  - Body: "All target fields in this section may already be mapped, or the AI could not determine appropriate mappings."
  - Close button: "Close" (secondary)

### Error state

- Rendered when `status === 'error'`
- Centered vertically in the scroll area
- Content:
  - Icon: `AlertTriangle` (amber)
  - Heading: "Failed to generate suggestions"
  - Body: `{error}` message from hook (user-friendly, e.g., "Network error. Check your connection and try again." or "The AI service is temporarily unavailable.")
  - Action: "Try Again" button (primary) — calls `triggerAutoMap(sectionPath)` to retry
  - Action: "Close" button (secondary)
- `role="alert"` on the error container for accessibility

### Done state (completion summary)

- Rendered as a banner at the top of the suggestion list when `summary.pending === 0` and `summary.total > 0`
- Content:
  - `CheckCircle2` icon (green)
  - "All {total} suggestions reviewed"
  - Breakdown line: "{accepted} accepted, {dismissed} dismissed" (omit zero categories)
- Does not replace the suggestion cards — they remain below with their final states visible
- "Accept All Valid" button disabled in this state

### Conditional rendering in drawer

The drawer body renders one of:
1. Loading state (`status === 'loading'`)
2. Error state (`status === 'error'`)
3. Content: empty state or cards + optional done banner (`status === 'success'`)

```tsx
<div className="flex-1 overflow-y-auto">
  {status === 'loading' && <DrawerLoadingState sectionPath={sectionPath} />}
  {status === 'error' && <DrawerErrorState error={error} onRetry={onRetry} onClose={onClose} />}
  {status === 'success' && items.length === 0 && <DrawerEmptyState onClose={onClose} />}
  {status === 'success' && items.length > 0 && (
    <>
      {summary.pending === 0 && <CompletionBanner summary={summary} />}
      {children}
    </>
  )}
</div>
```
