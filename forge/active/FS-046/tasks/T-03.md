## Summary

Create the `AutoMapReviewDrawer` component — a right-side fixed drawer that renders the Auto-Map suggestion review UI. This task covers the drawer container, summary header, bulk actions bar, scroll area, and basic drawer mechanics (open/close/keyboard/backdrop).

---

## Scope

### In Scope

1. New component at `ui/src/features/mappings/components/AutoMapReviewDrawer.tsx`
2. Right-side fixed drawer following `VersionHistoryDrawer` pattern:
   - `fixed right-0 top-0 z-50`, full height
   - Backdrop overlay with click-to-close
   - `role="dialog"`, `aria-modal="true"`, `aria-label="Auto-Map Review"`
   - Focus trap on mount
   - Escape key closes
3. Summary header:
   - Section name
   - Total suggestion count
   - Breakdown badges: valid (green), warnings (amber), invalid (red)
   - Confidence breakdown if space permits
4. Bulk actions bar:
   - "Accept All Valid" button (primary action)
   - Disabled when no pending valid suggestions remain
5. Scrollable body area for suggestion cards (children slot or render prop)
6. Drawer width: `w-[520px]` (wider than VersionHistoryDrawer's 440px to accommodate expression comparison)
7. Close button (X) in header
8. Component barrel export update

### Out of Scope

- Per-suggestion action logic (T-05)

## Change Requirements

### Component props

```tsx
interface AutoMapReviewDrawerProps {
  isOpen: boolean;
  onClose: () => void;
  sectionPath: string | null;
  summary: AutoMapReviewSummary;
  onAcceptAllValid: () => void;
  children: React.ReactNode; // suggestion cards rendered by parent
}
```

### Drawer structure

```
fixed backdrop (z-40, bg-black/50, click → onClose)
fixed drawer panel (z-50, right-0, top-0, h-full, w-[520px])
  ├── Header
  │   ├── Title: "Auto-Map Review"
  │   ├── Section path subtitle
  │   ├── Close button (X)
  │   └── Summary badges row
  ├── Bulk Actions Bar
  │   ├── "Accept All Valid" button
  │   └── Progress text: "{accepted} of {total} accepted"
  └── Scrollable body (flex-1, overflow-y-auto)
      └── {children} — suggestion cards
```

### Summary badges

Display as compact inline badges:
- `{validCount} valid` — green badge (only if validCount > 0)
- `{warningCount} warnings` — amber badge (only if warningCount > 0)
- `{invalidCount} invalid` — red badge (only if invalidCount > 0)

If all validation data is absent (validCount + warningCount + invalidCount === 0), show `{total} suggestions` without breakdown.

### Bulk actions bar

- "Accept All Valid" button:
  - Variant: primary (filled blue)
  - Disabled when `summary.pending === 0` or no valid/unvalidated pending suggestions
  - Text: "Accept All Valid" (or "Accept All" when no validation data exists)
- Progress text: `{summary.accepted} of {summary.total} accepted` — shown when at least 1 is accepted

### Accessibility

- `role="dialog"`, `aria-modal="true"`, `aria-label="Auto-Map Review"`
- Focus trap: focus first focusable element on mount
- Escape key: call `onClose`
- Backdrop click: call `onClose`
- Close button: `aria-label="Close Auto-Map review"`

### Conditional rendering

- Return `null` when `isOpen` is `false` (no DOM rendered)

## Notes

- The drawer width of 520px is wider than the 440px VersionHistoryDrawer because the content includes side-by-side expression comparison and multiple badges. If this feels too wide during implementation, 480px is acceptable as a minimum.
