## Summary

Create the foundational shared utilities and component that all source-field pickers will consume. This includes the `SOURCE_TYPE_BADGES` mapping, the `resolveFieldTestValue` utility, and the `SourceFieldOptionRow` React component that renders the standardized 4-zone option row layout.

---

## Scope

### In Scope

- Create `ui/src/features/mappings/lib/source-field-display.ts` with:
  - `SOURCE_TYPE_BADGES` constant: maps schema type strings to `{ code: string; className: string }` (3-letter uppercase code + Tailwind color classes)
  - `resolveFieldTestValue(sourceData: unknown, fieldPath: string): string | undefined` — navigates dot-path (supporting array bracket notation) into sourceData, returns truncated display string (~30 chars max) or undefined
  - `getTypeBadgeCode(type: string): string` — convenience accessor that falls back to `ANY`
- Create `ui/src/features/mappings/components/SourceFieldOptionRow.tsx`:
  - Props: `{ path: string; type: string; testValue?: string; scope?: string; isSelected?: boolean; className?: string }`
  - Renders: `[TYPE BADGE] [PATH] [TEST DATA] [SCOPE]` in a single flex row
  - TYPE BADGE: compact colored pill with 3-letter code
  - PATH: font-mono text-sm
  - TEST DATA: text-xs text-slate-500, truncated, only when non-null/undefined
  - SCOPE: ml-auto, uppercase, text-[10px], only when provided
  - Exports a `SourceFieldChipBadge` sub-component for use in selected chips/pills
- Create unit tests for `resolveFieldTestValue` covering: simple paths, nested paths, array bracket paths, null sourceData, missing intermediates, truncation of long values, object/array structural preview
- Create unit tests for `SOURCE_TYPE_BADGES` completeness (all known types mapped)
- Create component tests for `SourceFieldOptionRow`: all zones render correctly, missing test data hides zone, missing scope hides zone, unknown type shows ANY badge

### Out of Scope

- Integration into any existing picker (Tasks T-02 through T-05)
- Changes to SchemaPathEntry type
- Changes to PreviewContext

## Change Requirements

### SOURCE_TYPE_BADGES mapping

```ts
export const SOURCE_TYPE_BADGES: Record<string, { code: string; className: string }> = {
  string:  { code: 'STR', className: 'bg-blue-900/60 text-blue-300' },
  number:  { code: 'NUM', className: 'bg-purple-900/60 text-purple-300' },
  integer: { code: 'INT', className: 'bg-purple-900/60 text-purple-300' },
  boolean: { code: 'BOL', className: 'bg-emerald-900/60 text-emerald-300' },
  object:  { code: 'OBJ', className: 'bg-slate-700/60 text-slate-300' },
  array:   { code: 'ARR', className: 'bg-amber-900/60 text-amber-300' },
  null:    { code: 'NUL', className: 'bg-slate-700/60 text-slate-400' },
};
// Fallback: { code: 'ANY', className: 'bg-slate-700/60 text-slate-400' }
```

### resolveFieldTestValue

- Split path by `.` (handle `[]` bracket notation by stripping brackets for array traversal)
- Walk object, return undefined on any null/undefined intermediate
- If final value is a string: quote and truncate (max 30 chars including quotes and ellipsis)
- If final value is a number/boolean/null: return String(value)
- If final value is an array: return `[${value.length} items]`
- If final value is an object: return `{${Object.keys(value).length} keys}`

### SourceFieldOptionRow

Layout: single flex row with `items-center gap-2 px-2 py-1.5 min-w-0`

Zones:
1. Badge: `<span className="inline-flex items-center px-1.5 py-0.5 rounded text-[10px] font-bold font-mono uppercase tracking-wider shrink-0 ${badgeClassName}">{code}</span>`
2. Path: `<span className="text-sm font-mono text-slate-200 truncate">{path}</span>`
3. Test data: `{testValue && <span className="text-xs text-slate-500 truncate max-w-[120px] shrink-0">{testValue}</span>}`
4. Scope: `{scope && <span className="ml-auto text-[10px] font-medium text-slate-500 uppercase shrink-0">{scope}</span>}`

## Verification Requirements

- Unit tests for `resolveFieldTestValue`:
  - `resolveFieldTestValue({ name: "Alice" }, "name")` → `'"Alice"'`
  - `resolveFieldTestValue({ address: { city: "SF" } }, "address.city")` → `'"SF"'`
  - `resolveFieldTestValue(null, "name")` → `undefined`
  - `resolveFieldTestValue({ x: null }, "x.y")` → `undefined`
  - `resolveFieldTestValue({ d: "a".repeat(50) }, "d")` → truncated to ~30 chars with ellipsis
  - `resolveFieldTestValue({ arr: [1,2,3] }, "arr")` → `'[3 items]'`
  - `resolveFieldTestValue({ obj: { a: 1, b: 2 } }, "obj")` → `'{2 keys}'`
- Unit tests for `getTypeBadgeCode`: all 7 types + unknown fallback

  - Hides test value zone when undefined
  - Renders scope badge when provided

  - Unknown type renders ANY badge
- `tsc --noEmit` passes
- ESLint passes for all new files
