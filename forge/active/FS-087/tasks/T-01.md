## Summary

Perform a repository-grounded frontend audit to identify all user-facing and logic-level schema scope assumptions (global/project/local) across UI surfaces, adapters, and shared UI types. Publish a deterministic change list that drives implementation tasks without scope drift.

---

## Scope

### In Scope

- Audit `ui/src/features/schemas/**/*`, `ui/src/features/projects/**/*`, and mapping schema selector surfaces.
- Audit `ui/src/lib/types/domain.ts`, `ui/src/lib/api/types.ts`, and adapter code paths for scope usage.
- Identify all user-facing copy/labels/badges/filters using scope semantics.
- Produce a concrete list of affected files + required changes + risk notes.

### Out of Scope

- Implementing UI or adapter code changes.
- Backend/Lambda implementation changes.

---

## Relevant Areas

- `ui/src/features/schemas/**/*`
- `ui/src/features/projects/**/*`
- `ui/src/features/mappings/**/*`
- `ui/src/lib/types/domain.ts`
- `ui/src/lib/api/types.ts`
- `ui/src/lib/api/local-storage-adapter.ts`
- `ui/src/lib/api/http-adapter.ts`

---

## Change Requirements

- Deliver an audit artifact (task notes or dedicated markdown in FS-087 folder) that:
  - enumerates each scope assumption location,
  - classifies impact (type contract, UI copy, behavior, migration compatibility),
  - states whether change is required vs unaffected,
  - maps findings to follow-on tasks.
- Include explicit callouts for JSON label normalization (`JSON` vs `JSON Schema`).

---

## Verification Requirements

- Verify no major schema UI surface is omitted (library, detail, project linked schemas, add/link/upload flows, mapping selectors).
- Review findings against AE-07/AE-08/AE-10/AE-11 coverage needs.

---

## Acceptance Checks

- A complete frontend scope-assumption audit exists and is traceable to concrete file paths.
- Audit explicitly identifies all required UI/type/adapter updates for FS-087.
- Audit marks unaffected areas explicitly (no silent assumptions).

---

## Blockers / Risks

- Risk: hidden scope references in tests or copy snapshots may be missed without exhaustive search.
