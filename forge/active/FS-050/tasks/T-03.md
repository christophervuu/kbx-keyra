## Summary

Create a `ProjectSummaryRow` component that displays compact project health metrics in a horizontal row: total mappings, total schemas, mappings with errors, and scaffold placeholders for deployment-related counts. Wire it into the Project Overview page layout between the header and the mappings section. Include a "View Deployments" link.

---

## Scope

### In Scope

- New `ProjectSummaryRow` component in `ui/src/features/projects/components/`
- Metrics: total mappings count, total schemas count, error count (mappings with `status === 'has-errors'`), stale deployments (scaffold "—"), ready to deploy (scaffold "—")
- "View Deployments" link navigating to `/projects/:projectId/deployments`
- Visual treatment: compact horizontal card row or inline badges
- Error count red accent when > 0, neutral/green styling when 0
- Wire into `ProjectOverviewPage` layout in the summary row slot (created in T-02)

### Out of Scope

- Making metrics clickable/navigable to filtered views (future enhancement)
- Real deployment status data derivation (Phase 0 scaffold)
- Changes to `useProjectOverview` hook (metrics are derived in the component from existing data)

## Change Requirements

### ProjectSummaryRow Component

Props:
```typescript
interface ProjectSummaryRowProps {
  readonly mappingCount: number;
  readonly schemaCount: number;
  readonly errorCount: number;
  readonly projectId: string;
}
```

Rendering:
- Horizontal row of metric items, each showing a label and count
- Layout: flex row with gap, wrapping on narrow screens
- Each metric item: icon (optional) + count + label

| Metric | Label | Count Source | Visual Treatment |
|---|---|---|---|
| Mappings | "Mappings" | `mappingCount` | Neutral badge |
| Schemas | "Schemas" | `schemaCount` | Neutral badge |
| Errors | "Errors" | `errorCount` | Red accent when > 0, neutral when 0 |
| Stale Deployments | "Stale Deployments" | Scaffold | Muted "—" text |
| Ready to Deploy | "Ready to Deploy" | Scaffold | Muted "—" text |

- "View Deployments" link at the end of the row, navigating to `PATHS.PROJECT_DEPLOYMENTS.replace(':projectId', projectId)` (or equivalent)
- When all counts are 0 (new project), the row renders with zero values and neutral styling — the row is always visible

### Data Derivation

The `ProjectOverviewPage` already has access to `mappings` and `schemas` arrays from `useProjectOverview`. Derive:
- `mappingCount = mappings.length`
- `schemaCount = schemas.length`
- `errorCount = mappings.filter(m => m.status === 'has-errors').length`

Pass these as props to `ProjectSummaryRow`. No hook changes needed.

### Scaffold Treatment

Stale Deployments and Ready to Deploy metrics are scaffold placeholders:
- Show a muted dash ("—") or "0" with muted/disabled styling
- These are intentionally non-functional until backend deployment status wiring exists
- Use `aria-label` to indicate these are placeholder values (e.g., "Stale Deployments: not yet available")

### Accessibility

- `data-testid="project-summary-row"` on the root element
- Each metric item should have clear labeling (visible text or `aria-label`)
- "View Deployments" link should have descriptive text
