## Summary

## Scope

### In Scope

- Define/align re-sync result shape (status, reason, commit metadata, diff summary).
- Align schema sync status enums and serialization boundaries used by CDM re-sync.
- Ensure backward-safe mapping for existing schema records.

### Out of Scope

- Implementing dependency resolution logic.
- Implementing full re-ingestion orchestration.

## Change Requirements

- Re-sync contract must support deterministic response modes: `no-op`, `updated`, `failed`.
- Contract must include prior/current commit SHA fields when available.
- Diff summary shape must be representable for updated responses.

- Compatibility tests for existing records.
- Typecheck + lint in touched areas.
