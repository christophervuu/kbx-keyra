## Summary

Create the `ArgumentForm` React component that renders a function's parameter slots from catalog metadata. Each slot supports source mode, literal mode, and dropdown mode. Slots also support inline nested transforms (enabling compositions like `upper(source("a"))` within a single argument). For variadic functions, a `[+ Add value]` button appends additional slots.

---

## Scope

### In Scope

- New `ArgumentForm.tsx` component in `ui/src/features/mappings/components/`.
- New `ArgumentSlotInput.tsx` sub-component for individual slot rendering.
- Reads `DSL_FUNCTION_CATALOG` to determine parameter list, types, variadic flag.
- Each slot renders based on its mode:
  - **Source mode**: inline source field picker (mini-picker or chip input).
  - **Literal mode**: text/number input with placeholder from catalog example.
  - **Dropdown mode**: renders a dropdown with options from `PARAMETER_HINTS` (T-04).
- Mode toggle: each slot has a way to switch between source/literal (and dropdown when hints exist).
- Nested transforms: a slot in source mode can have an inline transform added (mini `[+ Transform]` action), producing nested `InlineTransform` state (AE-07).
- Variadic: `[+ Add value]` button visible when the function has a variadic parameter.
- Parameter labels, type badges, and hint text from catalog.
- Emits `ArgumentSlot[]` changes via callback.

### Out of Scope

- The SourceCard wrapper (T-02).
- The function picker (existing component reused).
- Expression generation from state (T-07).
- Connector prompt (T-05).

## Change Requirements

- `ArgumentForm` accepts: `functionName: string`, `slots: ArgumentSlot[]`, `onSlotsChange: (slots: ArgumentSlot[]) => void`.
- Looks up the function in `DSL_FUNCTION_CATALOG` to get parameters.
- Renders one `ArgumentSlotInput` per slot, plus variadic add button.
- Each `ArgumentSlotInput` renders:
  - Parameter name label (from catalog).
  - Type badge (from catalog `parameter.type`).
  - Mode-appropriate input control.
  - Hint/placeholder text (from catalog `entry.example` or `PARAMETER_HINTS`).
  - Optional inline nested transform action and display (AE-07).
- Dropdown mode is activated when `PARAMETER_HINTS` provides options for `(functionName, parameterName)` — otherwise defaults to literal text input.
- Validation indicator: required slots that are empty show subtle warning styling.
