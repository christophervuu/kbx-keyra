## Summary

Create the `ConnectorPrompt` React component that automatically appears when 2+ standalone source cards exist without a wrapping function. The prompt asks "How should these be combined?" and offers a dropdown of compatible combining functions. Upon selection, the source cards merge into a single `concat`/`coalesce`/etc. Argument Form.

---

## Scope

### In Scope

- New `ConnectorPrompt.tsx` component in `ui/src/features/mappings/components/`.
- Automatic appearance logic: renders when `ValueModeState` is in `PendingConnector` variant (2+ sources, no function selected).
- Shows prompt text: "How should these be combined?"
- Dropdown with combining function options: at minimum `concat`, `coalesce`, `add`, `subtract`.
- On function selection: emits state change transforming `PendingConnector` → `FunctionCall` with the sources pre-filled as argument slots.
- Visual placement: between/below the source cards.
- Dissolve logic: if the user removes a source reducing count to 1, the connector disappears (state transitions back to single SourceCard).

### Out of Scope

- The Source Card component itself (T-02).
- The Argument Form internals (T-03).
- Expression generation (T-07).

## Change Requirements

- Component accepts: `sources: string[]`, `onFunctionSelected: (functionName: string) => void`.
- Filters `DSL_FUNCTION_CATALOG` for functions with 2+ required parameters (or variadic) that are not in `SourceAccess` or `Array` categories — these are the connector candidates.
- Renders a compact prompt with a function dropdown.
- On selection, calls `onFunctionSelected` which the parent uses to transition state from `PendingConnector` to `FunctionCall`.
- The component should be visually distinct (connector line/bridge metaphor) to indicate it connects the cards above.
