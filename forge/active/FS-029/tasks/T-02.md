## Summary

Create the `SourceCard` React component that displays a selected source field path, provides an `[+ Add Transformation]` action, and expands to show an inline Argument Form when a transformation is selected. This component is the primary UX element for the single-source paths (direct copy and source-with-transform).

---

## Scope

### In Scope

- New `SourceCard.tsx` component in `ui/src/features/mappings/components/`.
- Renders the source field path as a chip/label.
- Shows `[+ Add Transformation]` button when no transform is applied.
- On transform selection: expands to show the Argument Form (delegates to `ArgumentForm` component from T-03).
- Pre-fills the first argument slot with the card's source (editable, not locked).
- Shows a remove/X action to clear the transformation (returns to base state per AE-06).
- Emits state change callbacks (`onStateChange`) producing the appropriate `ValueModeState` variant.
- Accessible: keyboard navigation, aria labels.

### Out of Scope

- The Argument Form internals (T-03).
- The function picker popover (reuse existing `TransformFunctionPicker`).
- Connector prompt logic (T-05).
- Expression generation (T-07).

## Change Requirements

- Component accepts props: `source: string`, `transform?: InlineTransform`, `onStateChange: (state) => void`, `onRemove?: () => void`.
- Base state: renders source path with `[+ Add Transformation]` action.
- Transform state: renders source path + expanded Argument Form for the selected function.
- First argument slot of the Argument Form is pre-filled with `{ mode: 'source', path: <card source> }` but remains editable.
- Removal action: calls `onStateChange` with the transform cleared.
- Uses Tailwind CSS 4 for styling consistent with existing builder components.
