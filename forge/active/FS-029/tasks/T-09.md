## Summary

Wire all new Source Card builder components (SourceCard, ArgumentForm, ConnectorPrompt, BuilderEntryActions) into the `UnifiedExpressionBuilder` Value mode, replacing the current `TransformPipeline` usage. Connect state management, expression generation, and decomposition to produce a fully functional end-to-end builder experience.

---

## Scope

### In Scope

- Update `UnifiedExpressionBuilder.tsx` Value mode rendering to use new components.
- State management: maintain the new `ValueModeState` and drive component rendering from it.
- Wire `BuilderEntryActions` for empty state.
- Wire `SourceCard` for single-source states.
- Wire `ConnectorPrompt` for multi-source pending state.
- Wire `ArgumentForm` for function-call states.
- Connect expression generation: call `generateExpressionFromSourceCardState` and pass result to `onExpressionChange`.
- Connect decomposition: when editing an existing expression, call `decomposeToSourceCardState` to hydrate the builder.
- Fallback: if decomposition returns null (unsupported expression), keep existing raw-mode behavior.
- Ensure the Apply/Preview button reflects the generated expression.
- Ensure source drag-and-drop (DnD) from SourceSchemaPanel still works for adding sources.

### Out of Scope

- Conditional mode (unchanged).
- Value Map mode (unchanged).
- Removal of old pipeline components (T-10).

## Change Requirements

- `UnifiedExpressionBuilder` Value mode switches from rendering `TransformPipeline` to rendering the new component tree.
- State lifecycle:
  - Initial empty → `BuilderEntryActions`
  - After source added → `SourceCard` (or multiple SourceCards + ConnectorPrompt)
  - After transform added → `SourceCard` with expanded ArgumentForm or standalone `ArgumentForm`
  - After connector resolved → `ArgumentForm` for the connector function
- Expression generation runs on every state change and updates the parent via `onExpressionChange`.
- Expression decomposition runs on mount/hydration when `initialExpression` is provided.
- The old `TransformPipeline` import can be conditionally retained but not rendered (removed in T-10).
