## Summary

Implement `src/lib/persistence/s3/schema-content.ts` and `src/lib/persistence/s3/mapping-config.ts` — typed S3 helpers for storing and retrieving schema content (original + processed) and mapping config objects. These are standalone utilities consumed by entity modules (T-03, T-04) and directly by FS-056/FS-057 handlers.

## Change Requirements

- Implement `schemaContent.putOriginal(schemaId: string, content: string, format: 'json' | 'xsd'): Promise<void>`:
  - S3 PutObject at key `schemas/{schemaId}/original.{format}`
  - Content-Type: `application/json` for json, `application/xml` for xsd
  - Body: raw content string

- Implement `schemaContent.putProcessed(schemaId: string, content: Record<string, unknown>): Promise<void>`:
  - S3 PutObject at key `schemas/{schemaId}/content.json`
  - Content-Type: `application/json`
  - Body: `JSON.stringify(content)`

- Implement `schemaContent.get(schemaId: string): Promise<Record<string, unknown> | null>`:
  - S3 GetObject at key `schemas/{schemaId}/content.json`
  - Parse JSON and return
  - Return `null` on `NoSuchKey` error

- Implement `schemaContent.getOriginal(schemaId: string, format: 'json' | 'xsd'): Promise<string | null>`:
  - S3 GetObject at key `schemas/{schemaId}/original.{format}`
  - Return raw string content
  - Return `null` on `NoSuchKey` error

- Implement `schemaContent.delete(schemaId: string): Promise<void>`:
  - Delete both `schemas/{schemaId}/original.*` and `schemas/{schemaId}/content.json`
  - Use S3 `DeleteObjects` (batch) or two `DeleteObject` calls
  - Idempotent (no error if objects don't exist)

- Implement `mappingConfig.put(mappingId: string, config: MappingConfig): Promise<void>`:
  - S3 PutObject at key `mappings/{mappingId}/config.json`
  - Body: `JSON.stringify(config)`

- Implement `mappingConfig.get(mappingId: string): Promise<MappingConfig | null>`:
  - S3 GetObject at key `mappings/{mappingId}/config.json`
  - Parse JSON and return typed `MappingConfig`
  - Return `null` on `NoSuchKey`

- Implement `mappingConfig.delete(mappingId: string): Promise<void>`:
  - S3 DeleteObject at key `mappings/{mappingId}/config.json`
  - Idempotent

## Notes

- The `NoSuchKey` error from S3 SDK v3 is thrown as an error with `name: 'NoSuchKey'`. Use a try/catch that specifically checks for this error name.
- `schemaContent.delete()` needs to handle the case where `original` might be `.json` or `.xsd`. Consider listing objects with prefix `schemas/{schemaId}/` and deleting all, or storing the format in metadata and passing it in.
- Alternative for delete: accept format parameter, or use `ListObjectsV2` with prefix then `DeleteObjects`. Simpler: accept format as param since caller (handler) knows the schema format from metadata.
