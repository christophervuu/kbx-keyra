## Summary

Implement `src/lib/persistence/projects.ts` with typed CRUD operations for the Projects DynamoDB table: create, get, list, update, and delete. This is the simplest entity module and validates the data-access patterns used by all subsequent modules.

## Change Requirements

- Implement `projects.create(input: CreateProjectInput): Promise<ProjectItem>`:
  - Generate UUID `projectId`
  - Set `createdAt` and `updatedAt` to current ISO timestamp
  - Use `PutCommand` to write to Projects table
  - Return the complete `ProjectItem`

- Implement `projects.get(projectId: string): Promise<ProjectItem | null>`:
  - Use `GetCommand` with `projectId` as key
  - Return item or `null` if not found

- Implement `projects.list(): Promise<ProjectItem[]>`:
  - Use `ScanCommand` on Projects table
  - Return all items (no pagination for Phase 1)

- Implement `projects.update(projectId: string, fields: UpdateProjectInput): Promise<ProjectItem>`:
  - Use `UpdateCommand` with dynamic `UpdateExpression` built from provided fields
  - Always update `updatedAt`
  - Return updated item (using `ReturnValues: 'ALL_NEW'`)

- Implement `projects.delete(projectId: string): Promise<void>`:
  - Use `DeleteCommand` with `projectId` as key
  - Idempotent (no error if item doesn't exist)

- Export all functions from the module
