## Summary

Implement `src/lib/persistence/mapping-versions.ts` with operations for the MappingVersions DynamoDB table: save a version entry (with S3 config snapshot and auto-prune at 50), list versions for a mapping (descending order), and get a specific version. The prune logic ensures no mapping accumulates more than 50 version snapshots.

## Change Requirements

- Implement `mappingVersions.save(mappingId: string, entry: { version: number; savedBy: string; ruleCount: number; config: MappingConfig }): Promise<MappingVersionItem>`:
  - Compute `configS3Key` using `mappingVersionKey(mappingId, entry.version)`
  - Write config JSON to S3 at that key
  - Set `savedAt` to current ISO timestamp
  - Write DynamoDB item: `mappingId` (PK), `version` (SK), `savedAt`, `savedBy`, `ruleCount`, `configS3Key`
  - After successful write, invoke prune logic
  - Return the saved `MappingVersionItem`

- Implement prune logic (internal):
  - Query all versions for mapping (just keys + version numbers), sorted ascending
  - If count > 50, identify excess items (oldest by version)
  - For each excess: delete DynamoDB item + delete S3 object
  - If prune fails, log warning but do not throw (save already succeeded)

- Implement `mappingVersions.list(mappingId: string): Promise<MappingVersionItem[]>`:
  - `QueryCommand` with PK=`mappingId`, `ScanIndexForward: false` (descending)
  - Return all items (max 50 by design)

- Implement `mappingVersions.get(mappingId: string, version: number): Promise<MappingVersionItem | null>`:
  - `GetCommand` with PK=`mappingId`, SK=`version`
  - Return item or null

- Implement `mappingVersions.getConfig(mappingId: string, version: number): Promise<MappingConfig | null>`:
  - Get version item to retrieve `configS3Key`
  - Read S3 object and parse JSON
  - Return parsed `MappingConfig` or null if not found

## Notes

- The `MappingVersionEntry` in `domain.ts` includes a full `config` field. In the persistence layer, `config` is stored in S3 and replaced by `configS3Key` in the DynamoDB item. The `getConfig()` method provides the full retrieval path. The FS-057 handler will need to hydrate the config from S3 when serving `getMappingVersion` responses.
- `MappingConfig` type from the engine types is the payload stored in S3.
