## Summary

Implement `GET /deployments` and `GET /projects/{projectId}/deployments` using DeploymentSummaries indexes with correct full-population filtering/sorting/pagination semantics.

---

## Scope

### In Scope

- Add aggregate global/project deployment GET routes.
- Implement filter semantics (`freshness`, `attention`, `status`, `version`, `search`, etc.).
- Implement default sort: `lastActivityAt DESC`, `projectName ASC`, `mappingName ASC`.
- Return rows for never-deployed mappings.

### Out of Scope

- Mutating APIs and operation polling endpoint.

---

- `src/lambda/deployment/list-deployments.ts` (global)

## Change Requirements

- Query projection indexes; do not pre-page mappings table then filter.
- Ensure status/attention filtering correctness across full population.
- Support cursor pagination with deterministic ordering.
