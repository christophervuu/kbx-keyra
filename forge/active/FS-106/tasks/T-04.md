## Summary

Implement concrete async mutation contracts for deploy/promote/rollback/retry and `GET /deployment-operations/{operationId}` including idempotency, reason rules, and operation field model.

---

## Scope

### In Scope

- Add/align routes:
  - `POST /mappings/{mappingId}/deployments`
  - `POST /mappings/{mappingId}/promotions`
  - `POST /mappings/{mappingId}/rollbacks`
  - `POST /deployment-operations/{operationId}/retry`
  - `GET /deployment-operations/{operationId}`
- Return `202 Accepted` operation envelope for accepted mutations.
- Enforce idempotency key behavior and retry linkage.
- Enforce reason requirements:
  - DEV deploy optional
  - PREPROD promote optional
  - PROD promote required
  - rollback required
  - retry optional

### Out of Scope

- Locking/reconciliation internals (T-05).
