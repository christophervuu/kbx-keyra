## Summary

Upgrade mapping deployment page to consume operation-status API, resume polling after refresh, enforce reason/validation rules, keep DEV version selection stable, and render immutable artifact/version diff summaries for deploy/promote/rollback.

---

## Scope

### In Scope

- Poll and display operation status/stage/outcome by operationId.
- Resume polling after browser refresh/navigation.
- Keep selected DEV version stable during data refresh.
- Enforce UI-side reason requirements and action disable reasons.
- Show immutable manifest-based diff summaries.

### Out of Scope

- Global/project page table implementation.

## Change Requirements

- Use operation resource as source for progress state.
- Distinguish operation failure from deployment freshness state in UI.
- Require reason for rollback and PROD promotion; optional for others per spec.
- Keep mapping page as sole action surface.
