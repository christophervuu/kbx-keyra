## Summary

Create a `devLogger` utility module that provides structured console output for API errors, retries, and diagnostic events during development. The logger is a no-op in production builds, uses `console.group` with color coding for visibility, and includes request correlation IDs and timing information.

---

## Scope

### In Scope

- New `ui/src/lib/api/dev-logger.ts` module
- Structured logging for: errors (non-retryable), warnings (retryable/transient), info (successful retries)
- Includes: endpoint, statusCode, errorCode, requestId, duration, attempt number, message
- Color-coded console.group output (red/amber/gray)
- No-op when `import.meta.env.DEV` is false (production)
- Integration points documented (HTTP client will call devLogger on errors and retries)
- Unit tests verifying logger calls and no-op behavior

### Out of Scope

- Remote error reporting (Sentry, DataDog, etc.)
- Backend logging infrastructure
- Log persistence or export
- UI-visible logging panel

## Relevant Areas

- `ui/src/lib/api/dev-logger.ts` — new module
- `ui/src/lib/api/http-client.ts` — integration point (caller)
- `ui/src/lib/api/retry.ts` — integration point (caller for retry diagnostics)

## Change Requirements

- Module exports:
  ```typescript
  interface DevLogEntry {
    endpoint: string;
    statusCode?: number;
    errorCode?: string;
    requestId?: string;
    duration?: number;
    attempt?: number;
    message: string;
  }

  const devLogger = {
    error(entry: DevLogEntry): void;    // Non-retryable failures (red)
    warn(entry: DevLogEntry): void;     // Retryable/transient failures (amber)
    info(entry: DevLogEntry): void;     // Successful retries (gray)
  };
  ```
- Implementation:
  - Check `import.meta.env.DEV` at module level; if false, export no-op functions
  - Use `console.groupCollapsed` with styled prefix:
    - `%c[API ERROR]` red for errors
    - `%c[API RETRY]` amber/orange for warnings
    - `%c[API OK]` gray for info (retry successes)
  - Log each field as key-value within the group
  - Include timestamp
  - `console.groupEnd()` to close
- Integration (documented, not necessarily wired in this task):
  - HTTP client calls `devLogger.error()` on non-retryable failures
  - HTTP client calls `devLogger.warn()` on retryable failures before retry
  - Retry utility calls `devLogger.info()` on successful retry completion
