## Summary

Extend the schema creation flow to handle 202 (Accepted) responses from the ingestion endpoint. When a schema upload returns 202 with `status: "ingesting"`, the UI enters a polling loop that checks schema status every 2 seconds until it resolves to `"ready"` or `"error"`, with a 5-minute timeout. Display progress state during polling and appropriate success/error outcomes.

---

## Scope

### In Scope

- Detect 202 response from `createSchema` (distinguish from 201 immediate success)
- Implement polling utility or hook (`useIngestionPolling` or integrated into schema creation flow)
- Poll `getSchema(id)` every 2 seconds
- Display "Processing schema..." with progress indicator during polling
- Transition to success on `status: "ready"`
- Transition to error on `status: "error"` with re-upload option
- Timeout after 5 minutes with timeout message
- Cleanup polling on component unmount
- Abort polling if user navigates away

### Out of Scope

- Backend changes to ingestion pipeline
- Real-time WebSocket/SSE (polling only)
- Retry logic for individual poll requests (HTTP client handles that)
- Schema detail page redesign

## Change Requirements

- HttpAdapter `createSchema` must handle both 201 (immediate success) and 202 (async ingestion) responses:
  - 201: return `SchemaMetadata` directly (current behavior)
  - 202: return `SchemaMetadata` with `status: "ingesting"` — caller detects and starts polling
- New hook or utility: `useIngestionPolling(schemaId, options?)`
  - Starts polling when `schemaId` is provided and initial status is `"ingesting"`
  - Polls `adapter.getSchema(schemaId)` every `intervalMs` (default: 2000)
  - Returns: `{ status: 'polling' | 'ready' | 'error' | 'timeout', schema?: SchemaDetail, error?: AppError }`
  - Stops on: `status === "ready"`, `status === "error"`, timeout (300s), unmount
  - Uses `setInterval` or `setTimeout` chain with cleanup
- UI integration in schema creation flow:
  - After `createSchema` returns with `status: "ingesting"`, show processing state
  - When polling resolves to "ready", navigate to schema detail or show success
  - When polling resolves to "error", show error with "Try uploading again" button
  - When timeout: show "Processing is taking longer than expected. Refresh to check status."
