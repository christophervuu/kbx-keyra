## Summary

Create `useAutoMapWorkspace` hook that evolves the FS-046 `useAutoMapReview` pattern with persistent suggestion state, extended lifecycle management, refresh/merge logic, and filter computation. This is the primary orchestration hook for the Auto-Map Review Workspace.

---

## Scope

### In Scope

- Create `ui/src/features/mappings/hooks/use-auto-map-workspace.ts`
- Implement the following hook contract:

```ts
interface UseAutoMapWorkspaceParams {
  adapter: ApiAdapter;
  mappingId: string;
  projectId: string;
  rules: readonly MappingRule[];
  updateDraft: (targetPath: string, expression: string) => void;
  setSelectedTargetPath: (path: string) => void;
  exitWorkspace: () => void;
  parsedSourceSchema?: ParsedSchema | null;
  parsedTargetSchema?: ParsedSchema | null;
}

interface UseAutoMapWorkspaceResult {
  // Lifecycle
  status: 'idle' | 'loading' | 'success' | 'error';
  error: string | null;

  // Data
  sectionPath: string | null;
  items: readonly SuggestionWorkspaceItem[];
  summary: AutoMapWorkspaceSummary;
  hasPersistedSuggestions: boolean;

  // Actions
  triggerAutoMap: (sectionPath: string) => void;
  acceptSuggestion: (targetPath: string) => void;
  editSuggestion: (targetPath: string) => void;
  dismissSuggestion: (targetPath: string) => void;
  undoDismiss: (targetPath: string) => void;
  bulkAcceptAllValid: () => void;

  // Refresh
  refreshAll: () => void;
  refreshUnmapped: () => void;
  refreshStale: () => void;

  // Filtering
  activeFilters: Set<SuggestionFilter>;
  toggleFilter: (filter: SuggestionFilter) => void;
  clearFilters: () => void;
  filteredItems: readonly SuggestionWorkspaceItem[];

  // Metadata
  generatedAt: string | null;
  previousSuggestionsAvailable: boolean;
  restorePreviousSuggestions: () => void;
}
```

- Persistence integration:
  - On successful generation: save to sessionStorage via persistence utilities
  - On `triggerAutoMap`: check for persisted suggestions first; load if available
  - On status change: update sessionStorage
  - On mount with `sectionPath`: hydrate from sessionStorage if available

- Summary computation:
  - total, suggested, accepted, edited, dismissed, stale counts
  - valid, invalid counts
  - replacing existing count
  - Last refreshed timestamp

- Refresh merge logic:
  - `refreshAll`: re-trigger `autoMapSection()`, merge new results with existing terminal states
  - `refreshUnmapped`: re-trigger and filter to unmapped targets
  - `refreshStale`: re-trigger and filter to stale targets
  - All refresh operations preserve `accepted` and `edited` items

- Filter computation:
  - Derive `filteredItems` from `items` based on `activeFilters`
  - Filter set supports: all, unmapped, replacing, valid, invalid, lowConfidence, accepted, dismissed, stale

- Error recovery:
  - On error during refresh: preserve previous suggestions; expose `previousSuggestionsAvailable`
  - `restorePreviousSuggestions()` re-hydrates from last known good state

- Abort semantics: abort-on-reinvoke, abort-on-unmount (consistent with FS-041/FS-042 hooks)

### Out of Scope

## Change Requirements

- Hook must call `adapter.autoMapSection()` for generation/refresh
- Hook must use `saveAutoMapSuggestions` / `loadAutoMapSuggestions` from T-01 persistence utilities
- Hook must derive source context from `parsedSourceSchema` (same pattern as FS-046: flattened field list, max 200 lines)
- Hook must compute `existingExpressionAtGeneration` by checking `rules` for matching target paths at generation time
- `acceptSuggestion` must call `updateDraft(targetPath, suggestedExpression)` and transition status to `accepted`
- `editSuggestion` must call `updateDraft(targetPath, suggestedExpression)`, call `setSelectedTargetPath(targetPath)`, call `exitWorkspace()`, and transition status to `edited`
- `dismissSuggestion` must transition status to `dismissed` with no draft change
- `undoDismiss` must transition status from `dismissed` back to `suggested`
- `bulkAcceptAllValid` must accept all items where status is `suggested` and validation is not explicitly `false`
- Refresh operations must:
  - Preserve accepted/edited items
  - Replace suggested/dismissed/stale items
  - Update sessionStorage after merge
  - Handle abort-on-reinvoke
- Filter state must be independent of suggestion data (filters survive refresh)
