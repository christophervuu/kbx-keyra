## Summary

Extend the `EditorView` type from `'target' | 'rules'` to `'target' | 'rules' | 'automap'` and update `MappingEditorPage` to conditionally render a workspace placeholder in the center panel slot when `view === 'automap'`. This establishes the mode-switch infrastructure that subsequent tasks will build upon.

---

## Scope

### In Scope

- Extend `EditorView` type in `ui/src/features/mappings/types.ts` to include `'automap'`
- Add `autoMapSectionPath: string | null` state to the Mapping Editor page composition level
- Update `MappingEditorPage` center panel slot: when `view === 'automap'`, render a placeholder for the workspace component (actual workspace component comes in T-05)
- Update view toggle behavior: the Target/Rules segmented toggle should not show `automap` as an option — it is entered via trigger only
- Add `enterAutoMapWorkspace(sectionPath)` and `exitAutoMapWorkspace()` handler functions at the composition level
- `exitAutoMapWorkspace()` sets `view` back to `'target'` and preserves `selectedTargetPath`
- Ensure source panel remains visible during automap mode
- Ensure bottom preview area remains visible during automap mode
- Hide TargetWorklist toolbar (sort, search, filters) during automap mode

### Out of Scope

- The actual `AutoMapWorkspace` component (T-05)
- Hook changes (T-03)
- Drawer removal (T-10)
- ObjectSummaryPanel trigger changes (T-10)

## Change Requirements

- `EditorView` must accept `'automap'` as a valid value
- When `view === 'automap'`:
  - Center panel renders a placeholder `<div>` with "Auto-Map Workspace" text (temporary until T-05)
  - Right panel continues to render the node-type-specific builder (or `BuilderEmptyState` if nothing selected), with **visually secondary treatment** (e.g., reduced opacity wrapper `opacity-60` or muted border `border-zinc-800` instead of the normal panel border) to keep review focus on the center workspace
  - Bottom content continues to render normally
  - Source panel continues to render normally
- The Target/Rules view toggle must not render an "automap" option — workspace entry is via explicit trigger only
- `enterAutoMapWorkspace(sectionPath)` must:
  - Set `view` to `'automap'`
  - Store `autoMapSectionPath` in state
- `exitAutoMapWorkspace()` must:
  - Set `view` to `'target'`
  - Preserve `selectedTargetPath` (do not clear selection)
  - Preserve `autoMapSectionPath` (so re-entry can restore)
- The view toggle should be hidden or disabled during automap mode (the user exits via "Back to Editor")
