## Summary

Define the extended suggestion lifecycle types (`SuggestionLifecycleStatus`, `PersistedSectionSuggestions`, `PersistedSuggestionItem`) and implement persistence utilities for saving/loading/clearing Auto-Map suggestion state in sessionStorage. This provides the foundation for suggestion persistence across view switches and navigation.

---

## Scope

### In Scope

- Add `SuggestionLifecycleStatus` type (`'suggested' | 'accepted' | 'edited' | 'dismissed' | 'stale'`) to domain types or feature types
- Add `PersistedSectionSuggestions` and `PersistedSuggestionItem` interfaces
- Add `AutoMapWorkspaceSummary` interface (extended from `AutoMapReviewSummary` with stale count and generation metadata)
- Create `ui/src/features/mappings/lib/auto-map-persistence.ts` with:
  - `saveAutoMapSuggestions(mappingId, sectionPath, items)` — writes to sessionStorage
  - `loadAutoMapSuggestions(mappingId, sectionPath)` — reads from sessionStorage with corruption recovery
  - `clearAutoMapSuggestions(mappingId, sectionPath?)` — clears one section or all
  - `hasPersistedSuggestions(mappingId, sectionPath)` — quick existence check
  - `listPersistedSections(mappingId)` — returns section paths with suggestion counts
- Storage key pattern: `keyra:automap-suggestions:{mappingId}`
- Corruption recovery: JSON parse failure resets to empty with `console.warn`

### Out of Scope

- Staleness detection logic (T-04)
- Hook implementation (T-03)
- UI components
- Modifying existing FS-046 types (the new types coexist)

## Change Requirements

- `SuggestionLifecycleStatus` must be a union type covering: `'suggested' | 'accepted' | 'edited' | 'dismissed' | 'stale'`
- `PersistedSectionSuggestions` must include: `sectionPath`, `generatedAt` (ISO string), `items` array, `generationContext` with optional `sourceContextHash`
- `PersistedSuggestionItem` must include: `targetPath`, `suggestedExpression`, `explanation`, `confidence`, `validation` (optional), `status` (lifecycle), `isNew`, `existingExpressionAtGeneration` (nullable)
- Persistence functions must handle:
  - sessionStorage quota exceeded: catch and log warning, do not crash
  - Corrupted JSON: reset to empty, log warning
  - Missing key: return `null` / empty
- Storage value is `Record<string, PersistedSectionSuggestions>` keyed by section path, stored under one key per mapping
- All functions must be pure/side-effect-contained and independently testable
