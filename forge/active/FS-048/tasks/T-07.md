## Summary

Create the `WorkspaceToolbar` component that provides filter chips for narrowing the suggestion list and bulk action buttons for batch operations. This toolbar renders in the workspace shell's toolbar slot between the header and the card list.

---

## Scope

### In Scope

- Create `ui/src/features/mappings/components/WorkspaceToolbar.tsx`:
  - **Filter chips row:**
    - All (default, clears filters)
    - Unmapped
    - Replacing
    - Valid
    - Invalid
    - Low Confidence
    - Accepted
    - Dismissed
    - Stale
  - **Bulk action buttons:**
    - "Accept All Valid" — primary action
    - "Refresh Unmapped" — secondary action
    - "Refresh Stale" — secondary action (hidden when no stale items)
    - "Refresh All" — secondary action
  - Active filter count indicator
  - Filter chips are toggleable (click to activate/deactivate)
  - Filters show count badges (e.g., "Unmapped (3)")

### Out of Scope

- Filter computation logic (owned by T-03 hook)
- Refresh backend call logic (T-08)
- Refresh confirmation dialog (T-08)

## Change Requirements

- `WorkspaceToolbar` props:
  - `activeFilters: Set<SuggestionFilter>`
  - `onToggleFilter: (filter: SuggestionFilter) => void`
  - `onClearFilters: () => void`
  - `summary: AutoMapWorkspaceSummary` (for count badges and disable logic)
  - `onAcceptAllValid: () => void`
  - `onRefreshUnmapped: () => void`
  - `onRefreshStale: () => void`
  - `onRefreshAll: () => void`
  - `isRefreshing: boolean` (disable buttons during refresh)

- Filter chip styling:
  - Inactive: `bg-zinc-800 text-zinc-400 hover:bg-zinc-700`
  - Active: `bg-blue-900/60 text-blue-300 ring-1 ring-blue-500/30`
  - Each chip shows its filter count: e.g., "Unmapped (3)"
  - "All" chip is visually distinct when no filters are active

- Bulk action button states:
  - "Accept All Valid": disabled when no pending valid suggestions
  - "Refresh Unmapped": disabled when no unmapped suggested/stale items
  - "Refresh Stale": hidden when stale count is 0; disabled during refresh
  - "Refresh All": disabled during refresh
  - All buttons disabled during `isRefreshing`

- Layout:
  - Filters on left, bulk actions on right (or wrapped to second row if space is tight)
  - Compact horizontal layout within the panel width
  - Toolbar should be sticky (not scroll with cards)
