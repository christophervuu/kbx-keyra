## Summary

Create the `AutoMapWorkspace` shell component and `WorkspaceHeader` that render in the center panel during automap mode. The workspace shell manages layout (header + toolbar slot + scrollable card list), loading/error/empty/done states, and provides the structural container for suggestion cards (T-06) and toolbar (T-07).

---

## Scope

### In Scope

- Create `ui/src/features/mappings/components/AutoMapWorkspace.tsx`:
  - Accepts workspace hook result as props
  - Renders: `WorkspaceHeader` + toolbar slot + scrollable suggestion card list + completion banner
  - Handles four body states:
    - `loading`: spinner + "Generating mapping suggestions for {sectionPath}..."
    - `error`: `role="alert"`, error message, "Try Again" button, optional "Show previous suggestions" link
    - `success` + empty items: empty state message + "Back to Editor" + "Refresh All"
    - `success` + items: card list + completion banner when all resolved
  - The card list area must be scrollable (overflow-y-auto) within the panel height
  - Replace the T-02 placeholder in `MappingEditorPage` center panel slot

- Create `ui/src/features/mappings/components/WorkspaceHeader.tsx`:
  - Section path display: "Auto-Map: {sectionPath}"
  - Suggestion count badges: total, valid, invalid, replacing existing
  - Status count badges: accepted, dismissed, stale
  - Last refreshed timestamp (relative: "2 minutes ago")
  - "Back to Editor" button (calls `exitWorkspace`)

- Completion banner:
  - Rendered when all items are in terminal states (accepted/edited/dismissed)
  - "All N suggestions reviewed. M accepted, K edited, J dismissed."
  - "Refresh All" remains available

### Out of Scope

- Suggestion card component (T-06)
- Toolbar component with filters and bulk actions (T-07)
- Refresh logic (T-08)
- Preview support (T-09)
