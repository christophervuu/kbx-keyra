## Summary

Ensure the Schema Name input is always rendered on the schema import screen (not conditionally shown after blur), and auto-populate it from the pasted JSON Schema's `title` property immediately on paste. Respect manual edits by not overwriting a user-modified name on subsequent pastes.

---

## Scope

### In Scope

- Make Schema Name input unconditionally rendered on the schema import/paste screen
- On paste of valid JSON Schema with a `title` field, auto-fill Schema Name immediately
- Track whether user has manually edited the Schema Name (dirty flag)
- If user has manually edited, do not overwrite on subsequent paste
- If user has not manually edited, update Schema Name on each paste that has a `title`

### Out of Scope

- Schema validation logic (already exists)
- XSD title extraction (JSON Schema only for now)
- Schema Name length validation or formatting constraints
- Changes to non-paste schema creation flows (e.g., file upload)

---

## Relevant Areas

- `ui/src/features/schemas/components/SchemaDetailPage.tsx`
- `ui/src/features/schemas/components/ReplaceFileDialog.tsx`
- `ui/src/features/schemas/hooks/use-schema-detail.ts`

---

## Change Requirements

- Schema Name input must render unconditionally (always visible), not gated behind a content validation or blur event.
- On change to the schema content textarea (including paste), parse the content as JSON; if valid and has a top-level `title` string, auto-fill Schema Name.
- Maintain a `userEditedName` flag (initially `false`). Set to `true` when the user directly types/edits in the Schema Name input.
- If `userEditedName` is `true`, do not overwrite Schema Name on paste.
- If `userEditedName` is `false` and paste has no `title`, leave Schema Name empty.
- Triggering auto-fill should not require blur/tab — it should fire synchronously on content change.

---

## Verification Requirements

- Component test: Schema Name input is visible before any paste action.
- Component test: Pasting JSON with `"title": "Patient"` fills Schema Name with "Patient" (AE-03).
- Component test: After manual edit to Schema Name, pasting JSON with a different title does not overwrite (AE-04).
- Component test: Pasting JSON without `title` leaves Schema Name empty.
- Component test: Pasting invalid JSON does not crash and leaves Schema Name unchanged.
- Typecheck passes.

## Notes

- The `title` extraction should be a simple `JSON.parse` + check for `typeof parsed.title === 'string'`. Wrap in try/catch for invalid JSON.
- There is no standalone schema import/paste dialog. The schema creation / Replace File flow is within `SchemaDetailPage` and `ReplaceFileDialog`. The Schema Name input and paste handling live in this area.
- If the current flow shows Schema Name conditionally (after content validation), change it to render unconditionally.
