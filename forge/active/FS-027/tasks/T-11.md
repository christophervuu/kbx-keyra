## Summary

Update diagnostics rendering so long description text wraps to multiple lines by default and includes an expand/collapse toggle for especially long content. No error text should be visually clipped without a way to inspect the full message.

---

## Scope

### In Scope

- Diagnostics description text wraps (no `truncate` / `text-ellipsis` / `overflow-hidden` without expansion)
- For short diagnostics (e.g., under 3 lines): show full text, no toggle needed
- For long diagnostics (e.g., over 3 lines): show collapsed preview with expand/collapse toggle
- Primary fix target: `InlinePreviewStrip` which uses CSS `truncate` class on diagnostics
- Apply to any other diagnostics surface if truncation is found there

### Out of Scope

- Changes to diagnostic content/messages produced by the engine
- Changes to validation logic
- Changes to diagnostic severity/categorization
- `BottomArea` diagnostics tab (does not currently truncate)

---

## Relevant Areas

- `ui/src/features/mappings/components/InlinePreviewStrip.tsx` (primary — uses `truncate` CSS class)
- `ui/src/features/mappings/components/BottomArea.tsx` (verify — confirmed no truncation currently)
- `ui/src/features/mappings/components/RuleList.tsx` (check for any diagnostics display)

---

## Change Requirements

- In `InlinePreviewStrip.tsx`: remove `truncate` CSS class from diagnostic description text.
- Replace with wrapping text (`whitespace-normal` or `break-words`).
- For long diagnostics (threshold: 3 lines or ~150 characters): render in a collapsed state showing first 3 lines with a "Show more" / "Show less" toggle.
- Expanded state shows full diagnostic text with no clipping.
- Toggle should be inline or immediately below the text (small, unobtrusive).
- Check `RuleList` for any similar truncation and apply the same fix if found.

---

## Verification Requirements

- Component test: clicking "Show more" reveals full text.
- Component test: clicking "Show less" collapses back to preview.
- Component test: short diagnostics show full text without toggle.
- Typecheck passes.

## Notes

- The truncation is specifically in `InlinePreviewStrip.tsx` using the Tailwind `truncate` class (which applies `overflow-hidden text-ellipsis whitespace-nowrap`).
- A reusable `ExpandableText` component (with `maxLines` prop and toggle) would be a clean pattern here if one doesn't already exist.
- Use `line-clamp-3` in Tailwind for the collapsed state with an explicit "Show more" button, rather than relying on CSS-only truncation.
