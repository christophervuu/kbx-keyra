## Summary

Fix `useTargetStatus` to compute object coverage ratios using child leaf fields (all leaf descendants) rather than just direct children. Object rows in the target worklist and any summary surface should display `mapped leaf fields / total leaf fields`.

---

## Scope

### In Scope

- Update `coverageMap` derivation in `useTargetStatus` to count leaf fields recursively
- Leaf fields = nodes that are not `object` or `array` type (scalar types: string, number, boolean, integer, null)
- `mapped` = leaf descendants that have a matching rule in the rules array
- `total` = all leaf descendants
- Update immediately when rules change (add, edit, clear, remove)
- Ensure consistency between Target Worklist row display and Object Summary panel

### Out of Scope

- Changes to non-leaf status (object/array nodes in `statusMap`)
- Changes to the overall validation result structure
- Changes to how `coverageMap` is consumed (consumers just read x/y)

---

## Relevant Areas

- `ui/src/features/mappings/hooks/use-target-status.ts`
- `ui/src/features/mappings/components/TargetFieldRow.tsx` (consumes coverage for display)
- `ui/src/features/mappings/components/ObjectSummaryPanel.tsx` (consumes coverage)

---

## Change Requirements

- In `useTargetStatus`, update the `coverageMap` computation:
  - For each object/array node, recursively collect all leaf descendants (nodes where type is a scalar: string, number, boolean, integer, null).
  - Count how many of those leaf paths have a matching rule in the rules array.
  - Store `{ mapped: N, total: M }` in `coverageMap` for that node's path.
- Ensure this is memoized efficiently (depends on `rules` and `nodes` inputs).
- Verify `TargetFieldRow` renders the ratio correctly for object rows.
- Ratio should update synchronously within the same React commit when rules change.

## Verification Requirements

- Unit test: nested object `address` with children `street` (string) + `location` (object with `lat`, `lng`) counts 3 leaf fields total (AE-13).

- Unit test: adding a rule for `address.location.lat` updates to `{ mapped: 2, total: 3 }`.
- Unit test: removing a rule decrements mapped count.
- Component test: `TargetFieldRow` for an object shows correct "x/y" ratio.

## Notes

- The current architecture doc says: "Object/array nodes derive coverage from their direct children's status." This task changes that to recursive leaf counting.
- A helper function `getLeafDescendants(node, nodes)` that returns all leaf-type descendant paths would be clean and testable.
- Array nodes should also count their leaf descendants for ratio display.
