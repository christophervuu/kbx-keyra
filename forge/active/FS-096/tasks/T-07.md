## Summary

Update Mapping Editor/Builder Map values method to support project-table vs inline scope, explicit direction selection with side labels, pinned revision display, newer-revision review/adoption, and inline-to-project conversion flows.

---

## Scope

### In Scope

- Add scope selector (`Project value table` vs `Inline value map`) in Map values method.
- Add project table picker with search, side labels, direction support, counts, usage, and create options.
- Add explicit lookup-direction selector with disabled invalid directions and reasons.
- Add compact metadata display (table name/scope/revision/entry count/side labels/direction/no-match behavior/preview rows).
- Add “Review newer revision” and explicit adopt flow with diff summary and changed-state handling.
- Add inline-to-project conversion and replacement with confirmation boundaries.

### Out of Scope

- Project-level table management page implementation details (handled in T-06).
- Backend route/persistence implementation.

---

## Relevant Areas

- `ui/src/features/mappings/components/*`
- `ui/src/features/mappings/lib/*`
- `ui/src/routes/pages/MappingEditor.tsx`
- mapping editor tests under `ui/src/features/mappings/**` and `ui/src/routes/pages/*.test.ts`

---

## Change Requirements

- Guided mode must disable invalid directions; raw-editor invalid cases still rely on engine validation.
- Builder panel must not embed full table grid.
- Adoption must be explicit and mark mapping unsaved.

---

## Verification Requirements

- Component/integration tests for selection, direction updates, no-match controls, and revision-adoption behavior.
- Tests for conversion flow from inline to project table with confirmation gate.
- Regression tests for existing inline map-values behavior.

---

## Acceptance Checks

- Builder supports project-table selection and explicit direction selection with side labels.
- Invalid directions are disabled and explained in guided mode.
- Pinned revision and newer-revision adoption UX are implemented with explicit confirmation.
- Inline maps remain available and convertible to project scope.
