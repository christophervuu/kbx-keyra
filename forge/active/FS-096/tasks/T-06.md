## Summary

Add a project-level Value Mappings area with list/editor/usage flows and integrate a compact Value Mappings summary section into Project Overview to improve discoverability and reusable-table management.

---

## Scope

### In Scope

- Add `/projects/:projectId/value-mappings` route and navigation entry points.
- Add Project Overview section showing active table count, mappings-using count, manage action, and empty state.
- Implement value-table list with search/sort/create/view/edit/duplicate/archive/export/view usage/review stale mappings.
- Implement table editor with side metadata, row grid, paste/import/export, duplicate detection, direction-validity summary, and explicit save.

### Out of Scope

- Mapping Builder table-selection integration details.
- Engine/parser/backend route implementation.
