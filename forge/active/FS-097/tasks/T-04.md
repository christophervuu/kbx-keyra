## Summary

Implement Direct mapping as explicit default for new unmapped scalar targets and remove legacy Fill-left/right/THEN/ELSE slot controls in Conditional, replacing them with directly selectable IF/THEN/OTHERWISE value editing and All/Any handling.

---

## Scope

### In Scope

- Default method behavior for new unmapped scalar target (`Direct mapping`).
- Direct method empty and assigned presentation states.
- Conditional section layout and labels (IF, THEN, OTHERWISE).
- Direct left/operator/right value editing for each condition row.
- `+ Add condition` and match mode selector (`All conditions` / `Any condition`).
- Conditional auto-fill priority when switching from Direct (representable direct value → first tray item → empty).

### Out of Scope

- Nested logical group authoring UI.
- Advanced DSL editor redesign.

## Change Requirements

- New unmapped scalar target must open in Direct mode by default with tray visible.
- Remove user-facing slot/operand/fill terminology in guided conditional UX.
- Keep one flat condition group with explicit All/Any mode.
- Auto-fill on Direct→Conditional must follow FS-097 priority order and run only for new conditional configuration (not reopen/restore/advanced-return paths).

## Verification Requirements
