## Summary

Apply query caching to canonical Mapping Editor server data while preserving unsaved draft ownership and ensuring background refresh never silently overwrites local draft state. Explicitly exclude sensitive payload categories from shared query retention.

---

## Scope

### In Scope

- Integrate canonical mapping/project/value-table fetches into shared query layer for Mapping Editor route.
- Preserve and prioritize unsaved draft/local editor state ownership (`draftRules`, local draft persistence).
- Add user-facing non-destructive notification when fresher server mapping exists while unsaved changes are present.
- Ensure sample payload bodies, preview outputs, trace outputs, and AI transient content are not stored as broadly retained shared query entries.

### Out of Scope

- Redesign Mapping Editor UX layout.
- Changing draft persistence strategy itself.

## Change Requirements

- Canonical saved mapping resource is query-cached.
- Mutation flows cancel relevant in-flight reads before optimistic/canonical cache writes.
- Unsaved local draft remains isolated from shared server cache values.
- Background refresh while dirty never auto-commits or overwrites draft.
- Sensitive/transient payload categories are excluded or set to non-shared, short-lived local handling.

---

## Verification Requirements

- Integration tests for unsaved-draft protection during background refresh.
- Tests confirming save updates canonical mapping cache.
- Tests/assertions that sensitive payload categories are not retained in shared query entries.
- Tests for metadata-only mutation handling in editor surfaces (invalidate/refetch, no speculative merge).

---

## Acceptance Checks

- Mapping Editor preserves unsaved changes during and after server refresh.
- Users are notified (non-destructively) when newer saved mapping exists while dirty.
- Successful save updates canonical mapping cache state.
- Sample payloads/preview results/AI transient outputs are not broadly retained in shared query cache.
- Metadata-only mutation responses in mapping/editor paths invalidate canonical detail queries rather than speculative local merge.

---

## Blockers / Risks

- High-complexity editor state graph may hide edge overwrite paths during migration.
