## Summary

Introduce limited high-probability prefetch triggers and lightweight refresh-status indicators across key pages, plus development-only diagnostics for request counts, cache hits, and background refresh behavior.

---

## Scope

### In Scope

- Add route-adjacent prefetch triggers on hover/focus for project/mapping/deployment navigation affordances.
- Ensure keyboard focus gets equivalent prefetch opportunities where practical.
- Add subtle background-refresh indicators (e.g., near last-updated metadata).
- Add development-only diagnostics using TanStack Query dev tooling and test request spies.

### Out of Scope

- Bulk prefetch of large collections.
- Production telemetry backend pipeline changes.
- Permanent noisy production cache hit/miss logging.

---

## Relevant Areas

- `ui/src/features/home/components/*`
- `ui/src/features/projects/components/*`
- `ui/src/features/deployments/components/*`
- `ui/src/lib/*` (query prefetch/instrumentation helpers)

---

## Change Requirements

- Prefetch uses canonical query key/query definition paths.
- Prefetch is bounded to avoid traffic spikes.
- Refresh indicator behavior does not block or hide content.
- Diagnostics are development-only and do not emit noisy production cache logs.

---

## Verification Requirements

- UI tests for hover/focus-triggered prefetch wiring.
- Request-count tests confirming prefetch warm usage by destination pages.
- Manual dev verification for instrumentation output clarity.

---

## Acceptance Checks

- High-probability navigation targets prefetch canonical destination queries on hover/focus.
- Cached destination navigation uses warmed cache without full skeleton fallback.
- Background refresh indicators are subtle and non-blocking.
- Request-count/cache-hit/background-refresh behavior is observable during testing via dev tooling and request spies.

---

## Blockers / Risks

- Over-prefetching may increase backend traffic if triggers are too broad.

---

## Notes

- Prefer conservative rollout and tune trigger coverage from observed usage.
