## Summary

## Change Requirements

### `ai-api-client.ts`

Create a module that exports:

```typescript
export async function explainRuleHttp(
  apiUrl: string,
  input: ExplainRuleInput,
): Promise<ExplainRuleResult>
```

Implementation requirements:

1. **Request construction:**
   - `POST ${apiUrl}/ai/explain-rule`
   - Headers: `{ 'Content-Type': 'application/json' }`
   - Body: `JSON.stringify({ targetPath: input.targetPath, expression: input.expression })`

2. **Timeout:**
   - Create an `AbortController`
   - Set a 15-second timeout via `setTimeout`
   - Pass `signal` to `fetch`
   - Clear timeout on response

3. **Response handling:**
   - If `!response.ok`:
     - `400` → throw with message "Invalid request — the rule may be malformed."
     - `429` → throw with message "The AI service is temporarily busy. Please try again in a moment."
     - `404` → throw with message "The Explain service is not configured on the server."
     - Other → throw with message "The Explain service encountered an error. Please try again."
   - Parse response body as JSON
   - If `result.success === true`:
     - Extract `result.data` as `ExplainRuleResult`
     - Validate `data` is an object with a `string` `explanation` field
     - If valid: return `{ explanation: data.explanation }`
     - If invalid: throw with "Received an unexpected response from the server."
   - If `result.success === false`:
     - Use error-code-specific messaging (same as HTTP status mapping above)

4. **Error handling:**
   - Catch `AbortError` → throw with "Could not reach the Explain service. Check your connection and try again."
   - Catch `TypeError` (network) → throw with same network error message
   - Catch JSON parse failure → throw with "Received an unexpected response from the server."

5. **Optional:** Export an `ExplainRuleError` class extending `Error` with a `code` field for programmatic error handling in the hook.

### Test file

Unit tests mocking `globalThis.fetch`:

- Happy path: 200 + `{ success: true, data: { explanation: "..." } }` → returns `ExplainRuleResult`
- Error 400 → throws with "Invalid request" message
- Error 429 → throws with "temporarily busy" message
- Error 500 → throws with "encountered an error" message
- Success false response (AIError envelope) → throws with error message
- Network failure → throws with "Could not reach" message
- Timeout → throws with "Could not reach" message
- Malformed JSON response → throws with "unexpected response" message
- Data missing `explanation` field → throws with "unexpected response" message
