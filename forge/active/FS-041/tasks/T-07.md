## Change Requirements

### ui-application.md — Adapter Pattern section

Update the existing Adapter Pattern section to include:

**Implementations** (update existing list):
- **Current (Phase 0):** `LocalStorageAdapter` — all operations use localStorage
- **Current (Showcase/Phase 0.5):** `HybridAdapter` — extends `LocalStorageAdapter`; overrides AI methods to call backend via HTTP; all CRUD operations remain localStorage-backed
- **Future (Phase 1+):** `HttpAdapter` — all operations via HTTP (intentionally not implemented)

**Bootstrap** (update existing description):
1. Read `import.meta.env.VITE_API_URL`
2. If unset/empty → return `new LocalStorageAdapter()`
3. If set → return `new HybridAdapter(apiUrl)` — provides localStorage CRUD + HTTP-backed AI calls

Note that the previous behavior (throw when set) has been replaced.

**Add AI API Client subsection:**

Document `ui/src/lib/api/ai-api-client.ts`:
- Purpose: Focused HTTP client functions for individual AI endpoints
- Current exports: `explainRuleHttp(apiUrl, input)` → `ExplainRuleResult`
- Pattern: one exported function per AI endpoint, each handling fetch + timeout + response parsing + error mapping
- Not an adapter — consumed by `HybridAdapter` (and potentially future `HttpAdapter`)

### ui-application.md — Module Structure

Add to the `lib/api/` section:
```
ai-api-client.ts        HTTP client functions for AI endpoints (explainRuleHttp)
hybrid-adapter.ts       HybridAdapter: LocalStorageAdapter + HTTP AI overrides
```

### INDEX.md

Update `ui-application.md` row `Last Updated` to `2026-05-11` (or current date at execution time).
