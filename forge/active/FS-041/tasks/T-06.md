## Change Requirements

### ChainBuilderShell.tsx

1. **Add props** for Explain context:
   - The `AiActionBar` needs access to `targetPath` and `expression` to construct the `ExplainRuleInput`. These must be threaded from the parent or derived from the chain builder state.
   - If the chain builder already exposes the generated expression, pass it to `AiActionBar`.
   - `targetPath` should be passed as a prop to `ChainBuilderShell` or derived from context.

2. **Update `AiActionBar`:**
   - Import and call `useExplainRule()` inside `AiActionBar` (or lift to `ChainBuilderShell` and pass down)
   - Enable the Explain button: remove `disabled`, update styling
   - Disable only when expression is empty
   - On click: `explain({ targetPath, expression })`
   - Show loading state on button when `status === 'loading'`
   - Update tooltip from "available in a future release" to "Explain this expression using AI"

3. **Render `ExplanationPanel`:**
   - Below the `AiActionBar` div
   - Show on success/error states
   - Pass `onDismiss` and `onRetry`

4. **Reset on field change:**
   - Call `dismissExplain()` when expression or targetPath changes

### Tests

Update `ChainBuilderShell.test.tsx`:

- **AE-02**: Mock adapter, click Explain → verify loading → result panel appears
- Explain disabled when no expression
- Error state renders correctly
- Dismiss works
