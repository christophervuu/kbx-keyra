## Summary

Define the shared prompt-registry data/runtime contracts used by all AI capabilities, including the canonical prompt ID set and compatibility alias policy.

---

## Scope

### In Scope

- Define/extend prompt record and runtime types needed for versioning and rollback-aware selection.
- Establish centralized prompt ID constants for explain-rule, natural-language-to-dsl, smart-fix, ai-validation, auto-map, and field-description.
- Define alias mapping behavior for backward compatibility (`nl-to-rule` alias to canonical `natural-language-to-dsl`) for one release cycle.

### Out of Scope

- Registry adapter query implementation.
- Output schema validation wiring.

---

## Relevant Areas

- `src/lib/ai/types.ts`
- `src/lib/ai/prompt-registry.ts`
- `src/lib/ai/index.ts`
- `tests/lib/ai/*`

## Change Requirements

- Prompt IDs must be declared once and reused by runtime/handlers.
- Unknown or unmapped IDs must follow deterministic not-found behavior.
- Canonical NL→DSL ID is `natural-language-to-dsl`; `nl-to-rule` compatibility alias has explicit sunset semantics.
- Contract shape must allow downstream deterministic latest/rollback selection.

---

## Verification Requirements

- Unit tests for prompt ID resolution and unknown-ID behavior.
- Type-level checks for updated prompt contracts.
- Typecheck/lint for touched modules.
