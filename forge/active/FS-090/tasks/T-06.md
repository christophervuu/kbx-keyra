## Summary

Implement backend pathways for adding sample payloads, generating schema-diff evidence, and applying schema updates only after explicit user confirmation.

---

## Scope

### In Scope

- Add endpoint/service behavior for add-sample payload operations.
- Validate sample format compatibility with schema data format.
- Produce diff payload (fields to add, type conflicts, required/optional evidence signals).
- Support non-mutating save-sample-only and confirm-mutate modes.

### Out of Scope

- UI rendering for sample list/diff modal.
- Full automated confidence scoring system.

## Change Requirements

- Add-sample flow returns deterministic diff structure suitable for sidebar modal workflows.
- Schema content changes occur only via explicit accept action.
- Save-sample-only path persists sample record without schema mutation.

---

## Verification Requirements

- Backend tests for add-sample format mismatch, diff generation, mutate-confirm, and save-sample-only behavior.
- Lint/typecheck/tests for touched backend modules.

---

## Acceptance Checks

- Adding a sample payload never mutates schema unless explicit confirmation flag/action is provided.
- Diff response includes additions and conflict/evidence sections when detectable.
- Save-sample-only path persists sample record and leaves schema unchanged.

---

## Blockers / Risks

- Current inference/parsing utilities may require extension to produce reliable diff evidence.
