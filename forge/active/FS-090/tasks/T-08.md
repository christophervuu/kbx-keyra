## Summary

Consolidate top-level and overflow actions on Schema Detail, remove legacy sync/publish actions, and enforce ownership-specific action availability (user vs CDM).

---

## Scope

### In Scope

- Top-level action model:
  - user schemas: `Edit Schema` + overflow,
  - CDM schemas: overflow only.
- Overflow menu content updates:
  - user: `View raw`, `Replace schema`, `Delete schema`,
  - CDM: `View raw` (+ optional duplicate only if already supported).
- Rename `Replace file` label to `Replace schema`.
- Remove Sync/Re-sync/Publish/Promote actions and related copy from Schema Detail.

### Out of Scope

- Implementing duplication if not already supported.
- Backend route additions unrelated to existing action contracts.

---

- `ui/src/features/schemas/components/SchemaActions.tsx`
- `ui/src/features/schemas/components/SchemaDetailPage.tsx`
- `ui/src/features/schemas/components/ReplaceFileDialog.tsx` (rename/update copy)

## Change Requirements

- Ownership and usage constraints determine enabled/disabled state for destructive actions.
- Action vocabulary aligns with FS-090 and removes deprecated lifecycle terms.

## Verification Requirements

## Acceptance Checks

- Overflow/menu actions match ownership-specific contract.

- Sync/Re-sync/Publish/Promote options are not rendered in Schema Detail.
