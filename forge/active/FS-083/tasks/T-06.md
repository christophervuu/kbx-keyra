## Summary

Align deployment UI surfaces with remote orchestration semantics by adding orchestration timeline/status presentation, artifact identity context per environment, and server-preview metadata rendering while preserving deliberate action flow and Save != Deploy UX.

---

## Scope

### In Scope

- Deployment Page model updates for action status (`queued/in_progress/retrying/succeeded/failed/timed_out`).
- Environment cards/badges showing active artifact identity metadata.
- Rollback modal/list behavior aligned to artifact-targeted rollback actions.
- Preview result UI metadata (environment + artifact identity).
- Environment source from backend config/model (DEV/PREPROD/PROD runtime only).

### Out of Scope

- Non-deployment editor IA changes.
- Auth/security UI for runtime API protection.

## Change Requirements

- Render orchestration state machine results clearly and deterministically.
- Ensure Save action paths remain deployment-side-effect free.
- Surface retry attempt/failure context from backend payloads where present.
- Display preview execution metadata with environment and artifact identity.
- Keep project-level deployment surfaces read-only for actions while reflecting richer status.
