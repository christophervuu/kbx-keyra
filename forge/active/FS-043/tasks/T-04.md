## Summary

Build the core Array Builder component shell, the mode selector entry point ("How do you want to build this array?"), and the Map Source Array collection mode UI. This replaces the existing `ArrayMappingBuilder.tsx` and `use-array-builder.ts` with the new chain-aligned two-layer builder model. The builder renders in the right panel when an array-type target field is selected.

---

## Scope

### In Scope

- `ArrayBuilder.tsx` — new component replacing `ArrayMappingBuilder.tsx`
- `useArrayBuilderState()` hook — manages `ArrayBuilderState`, exposes actions for mode selection, collection configuration, and draft integration
- `ArrayModeSelector.tsx` — mode picker component showing 5 mode options with descriptions
- `MapCollectionEditor.tsx` — source array picker for Map mode
- Builder shell layout: header (target path, type badge, status), pinned feedback area, scrollable collection + item layers
- Integration with `useMappingEditor.updateDraft()` for auto-drafting generated expression
- Integration with `BuilderFeedbackArea` for expression/result/validation display
- Source array selection from parsed source schema (list array-type fields)
- Progressive disclosure: mode selector → collection editor → item template placeholder (item template built in T-07)

## Change Requirements

- Create `ArrayBuilder.tsx` as the new right-panel component for array-type target fields
- The component must accept props matching the existing `ArrayMappingBuilder` integration contract (target path, schemas, draft API)
- Create `useArrayBuilderState(targetPath, schemas, getDraftExpression)` hook:
  - Initializes state from `createEmptyArrayBuilderState()` or hydrates from existing expression via decomposer (T-03 integration point — stub for now)
  - Exposes `selectMode(mode)`, `setSourceArrayPath(path)`, and other collection-level actions
  - Calls `generateArrayExpression(state)` on state changes and fires `onExpressionChange` callback
  - Manages `previousStructuredDraft` for custom expression return (placeholder for T-12)
- Create `ArrayModeSelector.tsx`:
  - Five selectable mode cards with title, description, and icon
  - Mode descriptions:
    - Map source array: "Transform each element of a source array"
    - Filter + map: "Filter, then transform a source array"
    - Build from values: "Construct array entries from individual fields"
    - Merge branches: "Combine multiple source arrays into one"
    - Custom expression: "Write raw DSL (advanced)" — visually separated as advanced
- Create `MapCollectionEditor.tsx`:
  - Lists source array fields from parsed source schema
  - User selects one source array
  - Shows selected source with field count and type summary
  - Compact summary after selection (collapsible)
- Wire `ArrayBuilder` into the right panel slot in `MappingEditorPage` (or the composition layer that selects panel by node type)
- Builder shell layout follows `ScalarFieldBuilder` patterns: header row, feedback area, scrollable content
