## Summary

Implement a pure function that generates a DSL expression string from `ArrayBuilderState`. The generator handles all five array modes (map, filter+map, build from values, merge branches, custom expression) and produces syntactically correct DSL aligned with the patterns defined in `specs/KEYRA-DSL-ARRAYS.md`. It delegates leaf-level field expression generation to the existing `generateChainExpression()` from the scalar chain builder.

---

## Scope

### In Scope

- `generateArrayExpression(state: ArrayBuilderState): string` main generator function
- Map mode: `map(source("path"), { "field": <chainExpr>, ... })`
- Filter + Map mode: `map(filter(source("path"), <predicate>), { "field": <chainExpr>, ... })`
- Build from Values mode: `array(...)` with optional `filter(array(...), not(isNull(item("field"))))` wrapping
- Merge Branches mode: `merge(map(source("a"), {...}), map(source("b"), {...}), ...)`
- Custom Expression mode: raw passthrough
- Object template generation from item template fields
- Scope-aware source reference generation: `item("field")` inside array contexts, `parent("field")` for nested arrays
- Nested array expression generation (recursive)
- Cross-array lookup expression generation: `default(get(find(...), "field"), fallback)`

### Out of Scope

- Expression decomposer (T-03)
- UI components
- Modifying `generateChainExpression()` in `chain-expression-generator.ts`
