## Summary

Implement the Merge Array Branches collection-layer UI component. This mode allows users to define multiple array branches (up to 10), each with its own source array and item template. The final result merges all branches into one target array using `merge()`. Branch summaries should remain compact and readable once configured. Users needing more than 10 branches use Custom Expression mode.

---

## Scope

### In Scope

- `MergeBranchesEditor.tsx` — branch list manager with add/remove/configure per branch
- `MergeBranchEditor.tsx` — single branch editor: source array selection + item template reference
- Branch summary display: compact one-line per branch when configured (source name, field count)
- `[+ Add Branch]` button for adding branches
- Per-branch remove button (minimum 2 branches)
- Wire Merge Branches mode into `ArrayBuilder.tsx` collection layer slot
- Update `useArrayBuilderState()` with branch management actions

### Out of Scope

- Item template layer per branch (T-07 — each branch's item template uses the shared item template model)
- Mode switching logic (T-08)
- Branch contribution preview summary (T-13)

## Change Requirements

- `MergeBranchesEditor.tsx`:
  - Renders a vertical list of branch editors
  - Each branch shows: branch number label, source array selection, item field count, expand/collapse toggle
  - `[+ Add Branch]` button appended to the list (disabled when 10 branches exist — maximum cap)
  - Remove button per branch (disabled when only 2 branches remain — minimum 2 required)
  - Collapsed branch summary: "Branch 1: orders[] → 4 fields mapped" style
- `MergeBranchEditor.tsx`:
  - Source array picker (same pattern as `MapCollectionEditor`)
  - Reference to the branch's item template (rendered by T-07's item template layer)
  - Each branch owns its own `MergeBranch` state with `sourceArrayPath` and `itemTemplate`
- Update `useArrayBuilderState()`:
  - `addBranch()` — adds a new empty `MergeBranch` (no-op if 10 branches exist)
  - `removeBranch(index)` — removes branch at index (no-op if only 2 branches)
  - `updateBranch(index, partial)` — updates branch source path or item template
  - Initialize with 2 empty branches when Merge mode is selected
