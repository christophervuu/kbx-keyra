## Summary

Implement the `useTestCases` hook that manages CRUD operations for test cases persisted in localStorage, scoped by mapping ID. Provides save, load, delete, and list operations with proper error handling for storage quota limits.

---

## Scope

### In Scope

- New file `ui/src/features/mappings/hooks/use-test-cases.ts`
- Save test case (name, sourceData, optional expectedOutput)
- Load test case by ID
- Delete test case by ID
- List all test cases for a mapping
- localStorage persistence with key `keyra:testcases:{mappingId}`
- Quota error handling
- Unit tests with mocked localStorage

### Out of Scope

## Change Requirements

Hook signature:
```typescript
function useTestCases(mappingId: string): {
  testCases: readonly TestCase[];
  saveTestCase: (params: { name: string; sourceData: string; expectedOutput?: string }) => { success: boolean; error?: string };
  loadTestCase: (id: string) => TestCase | null;
  deleteTestCase: (id: string) => void;
}
```

Behavior:
- On mount (or when `mappingId` changes), read test cases from `localStorage` key `keyra:testcases:{mappingId}`.
- `saveTestCase`: Generate unique ID (crypto.randomUUID or fallback), create TestCase with current ISO timestamp, append to array, persist. Return `{ success: false, error: "Storage full" }` if quota exceeded.
- `loadTestCase`: Find by ID in current list, return or null.
- `deleteTestCase`: Remove by ID, persist updated list.
- If localStorage value is corrupted (not valid JSON), reset to empty array with console warning.
- `testCases` state updates reactively after save/delete operations.

## Verification Requirements

- Unit tests:
  - Save creates a new test case with generated ID and timestamp
  - Save persists to localStorage under correct key
  - Load returns saved test case by ID
  - Load returns null for non-existent ID
  - Delete removes test case and persists
  - Changing mappingId reloads test cases for new mapping
  - Corrupted localStorage resets gracefully
  - Quota exceeded returns error object
- `tsc --noEmit` passes
- Tests pass via `vitest run`
