## Summary

Build the Output tab content component that displays the execution result as formatted, syntax-highlighted JSON. Shows appropriate empty/error/timeout states when execution has not produced output.

---

## Scope

### In Scope

- New file `ui/src/features/mappings/components/preview/OutputDisplay.tsx`
- Formatted JSON rendering of `ExecutionResult.output`
- Basic syntax highlighting (keys, strings, numbers, booleans, null in distinct colors via Tailwind)
- Empty state: "Run a mapping to see output"
- Error state: "Execution failed: {error message}"
- Timeout state: "Execution timed out — consider reducing rule count or simplifying expressions"
- Scrollable container for large output

### Out of Scope

- Diff comparison (T-11)
- Copy-to-clipboard functionality
- Collapsible JSON tree (plain formatted text is acceptable for Phase 0)

---

## Relevant Areas

- `ui/src/features/mappings/components/preview/OutputDisplay.tsx` (new)
- `ui/src/features/mappings/components/preview/PreviewPanel.tsx` (renders in Output tab)

---

## Change Requirements

- Component receives `state: PreviewExecutionState` as prop (or reads from context/hook)
- When `status === 'idle'`: show empty state message
- When `status === 'executing'`: show loading spinner or skeleton
- When `status === 'success'`: render `JSON.stringify(result.output, null, 2)` with syntax coloring
- When `status === 'error'`: show error message in red
- When `status === 'timeout'`: show timeout message with suggestion
- Syntax highlighting: Apply Tailwind color classes to JSON tokens via a simple tokenizer or pre-formatted spans:
  - Keys: `text-blue-400`
  - Strings: `text-green-400`
  - Numbers: `text-amber-400`
  - Booleans: `text-purple-400`
  - Null: `text-gray-400`
- Container: `overflow-auto`, `font-mono`, `text-sm`, `whitespace-pre`

## Notes

The syntax highlighting implementation can be a simple regex-based tokenizer that wraps JSON string parts in styled spans. No need for a full parser — `JSON.stringify` output is predictable and safe to tokenize with regex patterns for keys, string values, numbers, booleans, and null.
