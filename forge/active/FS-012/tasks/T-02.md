## Summary

Implement a pure-function structural JSON diff utility that recursively compares two JSON values and returns a `DiffResult` describing added, removed, and changed fields. This utility has no React dependencies and is fully unit-testable in isolation.

---

- Full unit test coverage in `ui/src/lib/utils/__tests__/json-diff.test.ts`

## Change Requirements

Implement `computeDiff(actual: unknown, expected: unknown): DiffResult`:

- If both values are primitives: compare with `===`. If different, emit a `changed` entry.
- If one is an object and the other is not: emit `changed` at that path.
- If both are objects: iterate all keys in both. Keys only in `actual` → `added`. Keys only in `expected` → `removed`. Keys in both → recurse.
- If both are arrays: compare by index up to the longer length. Extra indices in actual → `added`. Extra in expected → `removed`. Matching indices → recurse.
- `null` is a valid value (not equivalent to missing key).
- `DiffResult.isEqual` is `true` only when `entries` is empty.
- Path format: `"root.child.nested"` for objects, `"root.items[0].name"` for arrays.

## Notes

The diff is directional: `actual` is the left side (what execution produced), `expected` is the right side (what user defined). "Added" means present in actual but not expected. "Removed" means present in expected but not actual. This matches the mental model: "what did execution add/miss compared to expectations?"
