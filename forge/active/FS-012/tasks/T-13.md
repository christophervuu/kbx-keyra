## Summary

Connect the `sourceData` from PreviewContext to FS-011's `useExpressionPreview` hook, enabling expression-level preview to evaluate against the user's sample data in real time. This completes the integration contract between FS-011 and FS-012.

---

## Scope

### In Scope

- Modify the expression preview integration point to read `sourceData` from `PreviewContext`
- Pass `sourceData` to `useExpressionPreview` where it is currently receiving `null`
- Verify that expression preview updates when source data changes

### Out of Scope

- Changes to `useExpressionPreview` internal logic (it already accepts sourceData)
- PreviewContext implementation changes (already done in T-03)
- Source data input changes (already done in T-07)

---

## Relevant Areas

- `ui/src/features/mappings/components/` (expression builder integration point)
- `ui/src/features/mappings/hooks/use-expression-preview.ts` (if it exists from FS-011)
- `ui/src/features/mappings/context/preview-context.tsx` (reads from)

---

## Change Requirements

- In the component or hook that instantiates `useExpressionPreview`, import and call `usePreviewContext()`
- Pass `sourceData` from context to `useExpressionPreview`'s `sourceData` parameter (replacing the current `null` or placeholder)
- Ensure the expression preview re-evaluates when `sourceData` changes (should happen naturally via React reactivity)
- If FS-011 has not been implemented yet, add a TODO comment at the integration point with clear instructions for wiring

---

## Verification Requirements

- When valid source data is entered in Preview Panel, expression preview receives it
- When source data becomes invalid, expression preview receives null
- Expression preview shows evaluated result using source data
- `tsc --noEmit` passes
- Integration test or manual verification confirms data flows between panels

---

## Acceptance Checks

- `useExpressionPreview` receives non-null `sourceData` when Preview Panel has valid JSON input
- Expression `source.price * (1 + source.tax)` with sourceData `{price:100, tax:0.08}` previews as `108`
- `tsc --noEmit` passes
- No runtime errors when expression preview and preview panel are both active
