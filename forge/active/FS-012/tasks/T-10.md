## Summary

Build the Trace tab content component that displays execution trace entries — showing each rule's evaluation step with target path, expression, resolved value, and timing. Entries are presented as a collapsible/expandable list ordered by execution sequence.

---

## Scope

### In Scope

- New file `ui/src/features/mappings/components/preview/TraceDisplay.tsx`
- Render `TraceEntry[]` from `ExecutionResult.trace`
- Each entry shows: sequence number, target path, expression text, resolved value (formatted), duration
- Collapsible detail view for each entry (click to expand/collapse)
- Collapsed: shows target path + duration
- Expanded: shows expression + resolved value
- Empty state when trace is empty or trace not enabled
- "Enable trace in toolbar to see step-by-step execution" message when trace toggle is off

### Out of Scope

- Trace filtering or searching
- Performance flame graph visualization
- Clicking trace entry to navigate to rule

---

## Relevant Areas

- `ui/src/features/mappings/components/preview/TraceDisplay.tsx` (new)
- `ui/src/features/mappings/components/preview/PreviewPanel.tsx` (renders in Trace tab)
- `src/engine/types/results.ts` (TraceEntry type reference)

---

## Change Requirements

- Component receives `trace: TraceEntry[] | undefined` and `traceEnabled: boolean` as props
- When `traceEnabled` is false: show "Enable trace in toolbar to see step-by-step execution details"
- When `traceEnabled` is true but trace is empty/undefined: show "Run a mapping to see trace"
- When trace has entries, render ordered list:
  - Each item: clickable row showing `#{index} | {target} | {duration}ms`
  - Expanded state adds: `Expression: {expression}` and `Value: {JSON.stringify(value)}`
- Use `font-mono text-xs` for code-like content
- Alternate row background for readability
- Duration formatted to 2 decimal places
- Scrollable container for many entries
