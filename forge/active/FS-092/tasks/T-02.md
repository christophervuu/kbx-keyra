## Summary

Redesign Mapping Editor page composition to the new focused workspace model: context-rich header, search/filter toolbar, and target-field-first grid as primary navigation surface. Ensure the route removes in-page deployment/test-console emphasis and keeps Save Mapping as the primary action.

---

## Scope

### In Scope

- Recompose `MappingEditorPage` and related layout components to new shell hierarchy.
- Implement header elements: mapping context, coverage/issue summary, sample selector trigger, save state, actions.
- Implement toolbar search + filter chips and scope-aware auto-map trigger affordance.
- Build/read-only-first grid columns: status, type, target (+ required marker + muted output), source summary, mapping type, notes preview.
- Implement row selection behavior and clear active-row state.

### Out of Scope

- Full Source/Builder panel behavior internals beyond basic open/selection wiring.
- Complex array-builder internals.
- Architecture doc updates.

- `ui/src/features/mappings/hooks/use-mapping-editor.ts`

## Change Requirements

- Grid must be non-spreadsheet editing by default; clicking row opens detail context.
- Required target indicator and muted sample output must be visually distinct and consistent.
- Auto-map call-to-action must expose visible-scope count and filtered context prior to run.
- Remove default in-page deployment and full preview/test-console controls from primary workspace.

---

## Verification Requirements

- Component tests for header/toolbar/grid rendering and row selection behavior.
- Interaction tests for search/filter scope and auto-map scope labeling.
- Regression checks for save state and unsaved changes display.
- Typecheck/lint for touched UI modules.

---

## Acceptance Checks

- Mapping Editor route renders focused authoring shell with no inline deploy/full test console surfaces (AE-01).
- Row click selects target and opens detail area context (AE-02).
- Required marker + status model + muted sample output render in grid (AE-03, AE-08).
- Filter/search controls update visible set and auto-map scope affordance (AE-09).
- Save Mapping remains primary persistence action and no deploy action is triggered by save UI flow (AE-15).
