## Summary

Extend the redesigned grid/details model for array targets using expandable parent groups, child mapping coverage summaries, and large-array progressive disclosure behavior. Provide clear Array Builder entry points for complex scenarios.

---

## Scope

### In Scope

- Array parent row rendering with method/source summary and child coverage.
- Expand/collapse behavior for array children.
- Source panel list-selection behavior for array targets.
- Builder panel array summary behavior + “Open Array Builder” entry.
- Large-array threshold behavior with prioritized child subset and summary workspace.

### Out of Scope

- Full reimplementation of all Array Builder internals beyond integration points.
- Non-array scalar builder behavior.
- Architecture documentation updates.

---

## Relevant Areas

- `ui/src/features/mappings/components/*` (grid array rows, array details panels)
- `ui/src/features/mappings/components/ArrayBuilder.tsx` ?
- `ui/src/features/mappings/hooks/*` (array grouping/progressive disclosure state)

---

## Change Requirements

- UI language must remain business-friendly (no direct `map()/item()/parent()` jargon in default surface).
- Large arrays must not render all child rows by default once threshold exceeded.
- Prioritized child subset ordering must follow spec priority guidance.

---

## Verification Requirements

- Component tests for array parent summary rendering and expansion behavior.
- Tests for threshold-triggered large-array summary mode.
- Manual UX verification on small/medium/large array examples.

---

## Acceptance Checks

- Array parent rows summarize source list, method, item count, and child coverage (AE-11).
- Users can expand and map child fields with scoped context (AE-11).
- Large arrays show progressive disclosure summary with focused actions, not full child dumps (AE-12).

---

## Blockers / Risks

- Fixed threshold defaults may still require empirical tuning after initial implementation based on real schema sizes/performance.

---

## Notes

- Keep existing Array Builder capabilities accessible through clear handoff entry points.
