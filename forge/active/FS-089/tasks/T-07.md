## Summary

Update Schema Detail behavior to respect schema ownership: CDM records are read-only and expose only allowed actions, while detail metadata explicitly separates data format from source kind and includes inferred callout behavior.

---

## Scope

### In Scope

- Hide/disable edit/replace/delete actions for CDM schemas.
- Keep view/search/raw-schema behaviors for CDM.
- Ensure metadata section displays:
  - Data format (JSON/XML)
  - Schema source kind (JSON Schema/XSD/Inferred from JSON/Inferred from XML)
  - status/field counts/timestamps
- Show persistent inferred-schema callout for inferred source kinds.
- Add explicit inferred review completion control (`Mark as Reviewed`) that transitions `needs_review` to `ready` and records `reviewedAt` while preserving inferred source kind.

### Out of Scope

- New schema editing capabilities beyond existing feature set.
- CDM duplication implementation if not already present.

- `ui/src/features/schemas/components/SchemaDetailPage.tsx`

- `ui/src/features/schemas/hooks/use-schema-detail.ts`

---

## Change Requirements

- CDM detail pages must be read-only by action contract.
- Detail metadata must communicate both format and source-kind explicitly.
- Inferred warning copy must remain visible for inferred schemas.
- XSD-backed schemas must explicitly show both `Data format: XML` and `Schema source: XSD`.

---

## Verification Requirements

- Component tests for CDM vs user-created action visibility.
- Detail metadata rendering tests for source-kind/format combinations.
- Manual checks for inferred callout persistence.

---

## Acceptance Checks

- CDM schemas cannot be edited/replaced/deleted from detail actions.
- Detail metadata displays format and source kind as separate fields.
- Inferred schemas show persistent review callout.
- User-created schema detail actions remain available per existing permission model.

---

## Blockers / Risks

- Existing shared action components may assume legacy origin/scope fields.

---

## Notes

- Keep action gating centralized in ownership/read-only helpers to avoid drift across card/list/detail surfaces.
