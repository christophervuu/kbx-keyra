## Summary

Update Schema Library top controls to match the simplified model: ownership/format/status filters, explicit sort-direction options, and Card/List toggle with session persistence.

---

## Scope

### In Scope

- Replace legacy scope/sync filters with ownership, format, and status filters.
- Add explicit sort-direction labels for supported sort fields.
- Add Card/List view toggle and session persistence behavior.
- Update header/subtitle copy to schema management hub messaging.

### Out of Scope

- Schema card visual hierarchy changes.
- Add Schema modal changes.
- Backend query optimization.

---

## Relevant Areas

- `ui/src/features/schemas/**/*`
- `ui/src/lib/types/domain.ts`
- `ui/src/lib/api/types.ts`

---

## Change Requirements

- Controls must not expose Global/Local/Published/Synced terms.
- Sort UI must make direction explicit in text labels.
- Selected view mode must persist in localStorage using `keyra.schemas.viewMode`.

---

## Verification Requirements

- Component tests for filter/sort options and toggle persistence.
- Manual check for header copy and removal of legacy terms.
- Typecheck/lint for touched UI files.

---

## Acceptance Checks

- Toolbar displays ownership/format/status filters only.
- Sort options include explicit direction labels (e.g., Name A-Z, Name Z-A).
- Card/List toggle works and persists within session.
- No legacy scope/sync/publish terminology is present in toolbar controls.
