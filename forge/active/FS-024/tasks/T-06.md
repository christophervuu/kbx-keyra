## Summary

Wire all new props through `ConnectedInlinePreviewStrip` to the `InlinePreviewStrip` component: diagnostics and durationMs from `usePreviewExecution`, ruleCount from config, autoRun with localStorage persistence, onNavigateToRule from the composition layer, and onSaveTestCase from `useTestCases`. ## Notes

- The diagnostic mapping in `ConnectedInlinePreviewStrip` should be a `useMemo` — diagnostics can be expensive to re-derive on every render.
- For `durationMs`: if the engine `execute()` doesn't return timing, `ConnectedInlinePreviewStrip` can measure it locally using `performance.now()` around the `run()` call. This is acceptable for Phase 0.
- The `onNavigateToRule` flow: composition layer has access to `rules` (from `useMappingEditor`) and `setSelectedTargetPath`. The callback is: `(ruleIndex) => { const rule = rules[ruleIndex]; if (rule) setSelectedTargetPath(rule.target); }`.
- Auto-run localStorage read: use a try/catch around `JSON.parse(localStorage.getItem(...))` with fallback to `true`.
