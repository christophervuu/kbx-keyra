## Summary

Add a ⊕ "Save as test case" button to the toolbar row that opens a modal dialog. The modal contains: a name input (required, auto-populated with "Test case {N+1}"), a read-only JSON preview of the source data being saved (truncated if long), an optional "Set as expected output" checkbox, and Save/Cancel buttons. On successful save, the toolbar button briefly shows "Saved ✓" state for 1.5 seconds. Wire `onSaveTestCase` prop.

---

## Scope

### In Scope

- Add ⊕ button to toolbar row (between Clear and Auto-run toggle): `data-testid="strip-save-testcase-button"`.
- Implement `SaveTestCaseModal` sub-component (rendered within `InlinePreviewStrip`).
- Modal contains:
  - Name input (`data-testid="save-testcase-name-input"`), required, default value "Test case {existingCount + 1}".
  - Source JSON preview (read-only `<pre>`, truncated to ~10 lines with "..." if longer).
  - "Set as expected output" checkbox (`data-testid="save-testcase-expected-checkbox"`), disabled when output is null.
  - Save button (`data-testid="save-testcase-confirm"`), Cancel button (`data-testid="save-testcase-cancel"`).
- On Save: call `onSaveTestCase({ name, sourceData, expectedOutput? })`, close modal, show "Saved ✓" on toolbar button for 1.5s.
- Modal uses backdrop overlay (click outside or Cancel closes without saving).
- ⊕ button disabled when `sourceData` is empty.
- Update tests.

### Out of Scope

- Test case edit/delete functionality.
- Changing `useTestCases` hook interface (assume `saveTestCase` accepts the required shape).
- The test case selector dropdown (already exists from T-01/T-02).
