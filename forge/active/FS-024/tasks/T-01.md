## Summary

Rewrite the `InlinePreviewStrip` expanded layout from the current 4-column structure (Source ~30% | Run | Output ~45% | Status ~25%) into the new three-tier layout: full-width toolbar row (placeholder slots for controls added in later tasks), single-line status bar with state-dependent display, and three-pane content area (Source JSON ~35% | Output ~40% | Diagnostics ~25%). Define the updated `InlinePreviewStripProps` interface with all new fields. Implement status bar state logic and pane placeholder states.

---

## Scope

### In Scope

- Rewrite `InlinePreviewStrip` expanded layout structure (toolbar → status bar → three panes).
- Define updated `InlinePreviewStripProps` interface adding: `diagnostics`, `ruleCount`, `durationMs`, `onNavigateToRule`, `onSaveTestCase`, `onClearSource`, `autoRun`, `onAutoRunChange`.
- Implement status bar component with six states: Idle, Ready, Running, Success, Success with warnings, Error.
- Implement three-pane content area with fixed widths (~35% / ~40% / ~25%).
- Add pane headers with uppercase labels (SOURCE JSON, OUTPUT, DIAGNOSTICS).
- Implement placeholder states: Output → "No output yet — run the mapping to see results"; Diagnostics → "Run to see diagnostics."
- Remove the old `line-clamp-3` restriction on output (make scrollable).
- Keep existing collapsed bar behavior intact.
- Keep existing `TestCaseSelector` sub-component (relocated into toolbar in T-02).
- Temporarily render the Run button inline (T-02 moves it to toolbar).
- Update `InlinePreviewStrip.test.tsx` for new layout structure.

### Out of Scope

- Toolbar control implementations (Clear, Auto-run toggle, Save button) — those are T-02, T-03.
- Diagnostics entry rendering/clickability — that is T-04.
- Format/Copy buttons — that is T-05.
- `ConnectedInlinePreviewStrip` wiring changes — that is T-06.
