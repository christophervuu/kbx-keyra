## Summary

Build the Diagnostics pane (~25% width) content: a scrollable list of diagnostic entries with severity icon, error code, message, and affected rule name. Each entry is clickable and fires `onNavigateToRule(ruleIndex)`. The pane shows a placeholder when no diagnostics exist. Define the `PreviewDiagnostic` type if not already defined.

---

## Scope

### In Scope

- Define `PreviewDiagnostic` type in `ui/src/features/mappings/types.ts`:
  ```ts
  interface PreviewDiagnostic {
    severity: 'error' | 'warning' | 'info';
    code: string;
    message: string;
    ruleIndex: number;
    ruleName: string; // target path or rule label
  }
  ```
- Implement diagnostics entry rendering within the Diagnostics pane:
  - Severity icon: ✗ (red) for error, ⚠ (amber) for warning, ℹ (blue) for info.
  - Error code (monospace, muted).
  - Message text.
  - Rule name (muted, smaller).
- Make each entry a clickable `<button>` that fires `onNavigateToRule(entry.ruleIndex)`.
- Hover state: background highlight on entry.
- Pane is scrollable (`overflow-y-auto`) when entries exceed pane height.
- Pane header shows count badge (e.g., "3") next to "DIAGNOSTICS" label when diagnostics are present.
- Placeholder state: "Run to see diagnostics." when `diagnostics` array is empty.
- Update tests.

### Out of Scope

- Wiring `onNavigateToRule` to the composition layer (that is T-06).
- Filtering diagnostics by severity.
- Diagnostics from engine validation (only preview execution diagnostics).
