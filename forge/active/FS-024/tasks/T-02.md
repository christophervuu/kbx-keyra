## Summary

Populate the toolbar row with all control elements: relocate the test case selector dropdown, add × Clear button, add Auto-run toggle (green/gray dot with on/off visual states), relocate ▶ Run button into the toolbar, and add right-aligned "Open Advanced Testing ↗" link. Wire `autoRun` and `onAutoRunChange` props. Update `ConnectedInlinePreviewStrip` to own `autoRun` state with localStorage persistence and gate the `lastApplyTimestamp` auto-run effect on it.

## Scope

### In Scope

- Move `TestCaseSelector` rendering from the source pane into the toolbar row (after PREVIEW label).
- Add × Clear button that calls `onClearSource()`.
- Add Auto-run toggle component: pill/dot with green (on) and gray (off) states, aria-label, test ID.
- Move ▶ Run button from inline position into the toolbar row.
- Add "Open Advanced Testing ↗" link at the far right of the toolbar (using `testingPageUrl` prop).
- Update `ConnectedInlinePreviewStrip`:
  - Add `autoRun` state (default: `true`), persisted to localStorage key `keyra:preview-autorun`.
  - Gate the `lastApplyTimestamp` effect: only fire `onRun()` when `autoRun === true && sourceData.trim()`.
  - Add `onClearSource` callback that sets `sourceData` to `''`.
- Update tests for toolbar rendering, auto-run toggle behavior, clear button.

- Format/Copy ghost buttons — that is T-05.
