## Summary

Make DiffDisplay interactive by adding click handlers on diff entries to fire linked selection and adding highlight styling when entries match the current external selection. This enables the diff panel to participate in the cross-panel debugging workflow.

---

## Scope

### In Scope

- Add `onSelect` callback prop to DiffDisplay for firing `DebugSelection` on diff entry click
- Add `selectedTargetPath` prop for receiving external highlight state
- Add visual highlight styling on diff entries whose `path` matches `selectedTargetPath`
- Add click handler on each diff entry row
- Auto-scroll highlighted diff entry into view when selected from another panel
- Update existing tests and add new tests

### Out of Scope

- Adding filtering or search to DiffDisplay (diagnostics and trace get filters; diff entries are typically few and color-coded)
- Modifying the expected output textarea or diff computation logic
- Changing the `DiffEntry` or `DiffResult` types

## Change Requirements

Extend `DiffDisplayProps`:

```typescript
interface DiffDisplayProps {
  state: PreviewExecutionState;
  expectedOutput: string;
  onExpectedOutputChange: (value: string) => void;
  // New props:
  onSelect?: (selection: DebugSelection) => void;
  selectedTargetPath?: string | null;
}
```

Each diff entry `<li>` becomes clickable:
- On click: call `onSelect({ targetPath: entry.path, ruleIndex: undefined, source: 'diff' })`. Note: `DiffEntry` does not carry `ruleIndex`, so it is `undefined`.
- Apply highlight class when `selectedTargetPath === entry.path`
- Highlight style: ring/outline overlay on top of the existing color-coding (e.g., `ring-2 ring-white/30` to show selection without hiding the added/removed/changed color)
- When highlighted from external selection, scroll into view: `scrollIntoView({ behavior: 'smooth', block: 'nearest' })`

Backward compatibility:
- When `onSelect` is undefined, diff entries are not clickable (no cursor change, no click handler)
- When `selectedTargetPath` is null/undefined, no highlight applied

## Notes

Since `DiffEntry` doesn't carry `ruleIndex`, the linked selection from a diff click will match other panels by `targetPath` only. The orchestration layer (T-06) handles the lack of `ruleIndex` gracefully.
