## Summary

Wire the `useLinkedDebugSelection` hook into AdvancedTestingPage (and PreviewPanel if applicable) to orchestrate cross-panel linked selection. Pass selection state and callbacks to all four display components (DiagnosticsDisplay, TraceDisplay, OutputDisplay, DiffDisplay). Also extend InlinePreviewStrip to use the linked selection for its subset of panels (diagnostics + output).

---

## Scope

### In Scope

- Instantiate `useLinkedDebugSelection` in `AdvancedTestingInner` component
- Pass `onSelect`, `selectedTargetPath`, `selectedRuleIndex` props to DiagnosticsDisplay, TraceDisplay, DiffDisplay
- Pass `highlightPath`, `onPathClick` to OutputDisplay
- Wire auto-clear on new execution (pass execution status to the hook)
- Extend InlinePreviewStrip to pass linked selection state to its output pane (AE-12)
- Update ConnectedInlinePreviewStrip to instantiate linked debug selection for the strip context
- Integration tests verifying cross-panel selection flow in AdvancedTestingPage

### Out of Scope

- Jump-to-rule navigation (T-07)
- Failure explainer wiring (T-08)
- PreviewPanel in BottomArea for Rules View (this can be a follow-up; the Rules View bottom area is less frequently used for debugging)

## Change Requirements

**AdvancedTestingPage:**

In `AdvancedTestingInner`, add:

```typescript
const debugSelection = useLinkedDebugSelection(state.status);
```

Pass to display components:
- `DiagnosticsDisplay`: `onSelect={debugSelection.select}`, `selectedTargetPath={debugSelection.selection?.targetPath}`, `selectedRuleIndex={debugSelection.selection?.ruleIndex}`, `traceEntries={state.status === 'success' ? state.result.trace : undefined}`
- `TraceDisplay`: `onSelect={debugSelection.select}`, `selectedRuleIndex={debugSelection.selection?.ruleIndex}`, `selectedTargetPath={debugSelection.selection?.targetPath}`
- `OutputDisplay`: `highlightPath={debugSelection.selection?.targetPath}`, `onPathClick={(path) => debugSelection.select({ targetPath: path, ruleIndex: undefined, source: 'output' })}`
- `DiffDisplay`: `onSelect={debugSelection.select}`, `selectedTargetPath={debugSelection.selection?.targetPath}`

**InlinePreviewStrip:**

- Add internal `useLinkedDebugSelection` instance (scoped to the strip)
- When a diagnostic is clicked, fire both the existing `onNavigateToRule` AND the linked selection
- Pass `highlightPath` to the output pane's rendering to highlight the matching path
- The strip does not have trace or diff panels, so linked selection only applies to diagnostics ↔ output

**ConnectedInlinePreviewStrip:**

- No changes needed if InlinePreviewStrip handles its own selection state internally
