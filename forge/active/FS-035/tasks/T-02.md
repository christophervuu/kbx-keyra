## Summary

Update the DiffDisplay component to render the new categorized mismatch types from T-01 with distinct labels, icons, and color coding. Each diff entry should clearly indicate why the mismatch occurred (missing field, extra field, type mismatch, value mismatch, null mismatch, structural mismatch).

---

## Scope

### In Scope

- Update `DiffDisplay` to render category-specific labels and styling for each `DiffChangeType`
- Add mismatch type badge/label per diff entry row (e.g., "Type Mismatch", "Missing Field")
- Show `actualType` / `expectedType` context for type-related mismatches
- Add a diff summary section at the top of DiffDisplay showing category counts (e.g., "1 missing, 2 type, 1 value")
- Maintain existing diff entry layout (path, actual value, expected value) with the new category overlay

### Out of Scope

- Changes to `computeDiff()` or diff types (completed in T-01)
- Auto-tab-switching behavior (that is T-04)
- Execution summary bar (that is T-03)
- Batch execution or suite summary

## Change Requirements

### Category Labels and Colors

| Category | Label | Color | Icon hint |
|---|---|---|---|
| `missing_field` | Missing Field | Red (text-red-400) | minus-circle |
| `extra_field` | Extra Field | Amber (text-amber-400) | plus-circle |
| `value_mismatch` | Value Mismatch | Amber (text-amber-400) | arrow-right-left |
| `type_mismatch` | Type Mismatch | Red (text-red-400) | type icon or braces |
| `null_mismatch` | Null Mismatch | Amber (text-amber-400) | circle-slash |
| `structural_mismatch` | Structural Mismatch | Red (text-red-400) | layers or boxes |

Icons are from Lucide React (project standard).

### Per-Entry Rendering

Each diff entry row should show:
1. Category badge (label + color) — left-aligned
2. Path — `font-mono`, truncated if needed
3. Value comparison:
   - For `missing_field`: show expected value only with "expected" label
   - For `extra_field`: show actual value only with "actual" label
   - For value/type/null/structural mismatches: show both actual and expected with labels
   - For `type_mismatch` and `structural_mismatch`: additionally show `actualType → expectedType` annotation

### Diff Summary Header

At the top of the diff entries list (below the expected output textarea), add a compact summary line:

- When `isEqual`: green check + "Output matches expected"
- When not equal: summary like "4 mismatches: 1 missing, 2 type, 1 value" derived from `DiffResult.summary.byCategory`

### Backward Compatibility

The existing "Output matches expected" green checkmark state is preserved and uses `DiffResult.isEqual`.
