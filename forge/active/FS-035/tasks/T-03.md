## Summary

Create an `ExecutionSummaryBar` component and integrate it into the Advanced Testing page. The summary bar provides at-a-glance execution feedback: pass/fail status, duration, diagnostics counts by severity, rules summary, and version/environment context. It appears after execution completes and persists until the next execution or page change.

## Change Requirements

### Pass/Fail Derivation

Create `deriveExecutionVerdict(state, diffResult?)` utility:

```typescript
type ExecutionVerdict = 'pass' | 'fail' | 'error' | 'idle' | 'executing';

function deriveExecutionVerdict(
  state: PreviewExecutionState,
  diffResult?: DiffResult | null
): ExecutionVerdict;
```

Logic:
- `state.status === 'idle'` → `'idle'`
- `state.status === 'executing'` → `'executing'`
- `state.status === 'error' || state.status === 'timeout'` → `'error'`
- `state.status === 'success'`:
  - if any diagnostic has `severity === 'error'` → `'fail'`
  - if `diffResult` is provided and `!diffResult.isEqual` → `'fail'`
  - otherwise → `'pass'`

### ExecutionSummaryBar Component

Props:
```typescript
interface ExecutionSummaryBarProps {
  state: PreviewExecutionState;
  diffResult?: DiffResult | null;
  diffSummaryLabel?: string;  // e.g., "2 mismatches: 1 type, 1 value" — wired by T-04
  mappingVersion?: number;
  environmentLabel?: string;   // defaults to "Local"
}
```

Rendering:
- **Hidden** when `verdict === 'idle'`
- **Loading state** when `verdict === 'executing'`: subtle pulsing bar with "Executing..."
- **Result state** (pass/fail/error):
  - Left: verdict icon + label
    - pass: green check + "Passed"
    - fail: red X + "Failed"
    - error: red alert + "Error" (with error message)
  - Center: stats group
    - Duration badge: clock icon + `${durationMs}ms`
    - Diagnostics: severity badges (red for errors, amber for warnings, blue for info) with counts
    - Rules: `${succeeded}/${evaluated} rules` (green if all succeeded, amber otherwise)
  - Right: context group
    - Version badge: `v${version}`
    - Environment badge: "Local"
  - Optional: `diffSummaryLabel` rendered as an additional badge when provided (for T-04)

Layout: horizontal flex row with `items-center`, `gap-3`, appropriate padding. Background color reflects verdict: green-tinted for pass, red-tinted for fail, amber-tinted for error.

- `diffResult` and `diffSummaryLabel` are wired in T-04; for now pass `undefined`.
