## Summary

Define the OpenSearch Serverless collection, encryption policy, network policy, and data access policy resources in the SAM template (or as a separately-managed prerequisite if provisioning friction is too high). Create a setup script for the index mapping that will be run after collection creation. The target is IaC-managed, but Phase 1 allows separate provisioning if needed.

---

## Scope

### In Scope

- `AWS::OpenSearchServerless::Collection` resource
- `AWS::OpenSearchServerless::SecurityPolicy` (encryption)
- `AWS::OpenSearchServerless::SecurityPolicy` (network — public access for Phase 1)
- `AWS::OpenSearchServerless::AccessPolicy` (data access — Lambda role permissions)
- Index mapping setup script (`scripts/create-opensearch-index.ts`)
- OpenSearch endpoint passed to Lambda functions via environment variable

### Out of Scope

- VPC endpoint configuration (Phase 1 uses public access)
- OpenSearch Dashboards configuration
- Vector index configuration (future AI/RAG spec)
- OpenSearch query logic (FS-056)
- Cost optimization (OCU min/max scaling)

## Change Requirements

Add to `template.yaml` Resources section:

1. **SchemaNodesCollection** (`AWS::OpenSearchServerless::Collection`)
   - Name: `!Sub '${Stage}-keyra-schema-nodes'`
   - Type: SEARCH
   - Description: Schema node index for keyword and structural queries

2. **SchemaNodesEncryptionPolicy** (`AWS::OpenSearchServerless::SecurityPolicy`)
   - Type: encryption
   - Policy: AWS-owned key for the collection

3. **SchemaNodesNetworkPolicy** (`AWS::OpenSearchServerless::SecurityPolicy`)
   - Type: network
   - Policy: Allow public access (AllPublic) to collection and dashboards

4. **SchemaNodesAccessPolicy** (`AWS::OpenSearchServerless::AccessPolicy`)
   - Type: data
   - Policy: Grant Lambda execution role(s) permissions for:
     - `aoss:CreateIndex`, `aoss:UpdateIndex`, `aoss:DescribeIndex`
     - `aoss:ReadDocument`, `aoss:WriteDocument`, `aoss:DeleteDocument`
   - Resource: `collection/{Stage}-keyra-schema-nodes`, `index/{Stage}-keyra-schema-nodes/*`

Add to Outputs:
- `OpenSearchCollectionEndpoint`: `!GetAtt SchemaNodesCollection.CollectionEndpoint`

Create `scripts/create-opensearch-index.ts`:
- Accepts `--endpoint` and `--index-name` arguments
- Creates index with mapping per schema-ingestion.md Section 4:
  - `schemaId`: keyword
  - `path`: text + keyword (multi-field)
  - `fieldName`: text + keyword (multi-field)
  - `embeddingText`: text
  - `embedding`: knn_vector (dimension 1536, engine nmslib, space_type cosinesimil) — defined but unused
  - `type`: keyword
  - `depth`: integer
  - `parentPath`: keyword
  - `isArray`: boolean

## Blockers / Risks

- OpenSearch Serverless collection creation takes 5–10 minutes. CloudFormation handles this via normal resource creation wait, but it makes stack creation slow.
- OpenSearch Serverless has minimum billing (2 OCUs = ~$700/month). This should be noted in documentation. Development may use a shared collection or skip OpenSearch for purely local testing.
- IAM policy syntax for OpenSearch Serverless data access is non-trivial — uses JSON policy documents with principal/resource/permission arrays, not standard IAM statements.

## Notes

- The index mapping includes a `knn_vector` field for future embeddings but it's not populated in Phase 1. This avoids re-indexing when embeddings are introduced.
- OpenSearch Serverless uses AOSS (Amazon OpenSearch Serverless) SDK client, not the standard OpenSearch client. The index setup script should use `@aws-sdk/client-opensearchserverless` for collection management and the OpenSearch client for index operations.
- Per the resolved Q1 decision: target IaC (SAM/CloudFormation resources) but allow OpenSearch to be provisioned separately as a prerequisite if that simplifies Phase 1 delivery. If managed separately, document the manual provisioning steps and ensure the `OpenSearchEndpoint` parameter is passed to the stack. The SAM template should handle both cases gracefully (use a `Condition` to skip OpenSearch resources when endpoint is provided externally).
- OpenSearch Serverless has minimum billing (2 OCUs ~$700/month). Consider whether a shared dev collection is acceptable for cost management.
