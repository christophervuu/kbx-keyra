## Summary

Create a local test event fixture (`tests/lambda/ai/fixtures/auto-map-event.json`) containing a realistic API Gateway proxy event for the auto-map Lambda, enabling local invocation and manual testing against GitHub Models. This fixture follows the same approach used for local testing of explain-rule and suggest-expression.

## Change Requirements

1. **Create** `tests/lambda/ai/fixtures/` directory if it does not exist

2. **Create** `tests/lambda/ai/fixtures/auto-map-event.json` with contents:

```json
{
  "body": "{\"targetSection\":\"- Order.Header.DocumentType (string)\\n- Order.Header.DocumentDate (string)\\n- Order.Header.CurrencyCode (string)\",\"sourceContext\":\"- InvoiceAmount (number)\\n- InvDate (string, MM/DD/YYYY)\\n- InvoiceCurrency (string)\\n- Header.Currency (string)\",\"businessContext\":\"This mapping converts AP invoice data into the ShipmentOrder target model.\"}",
  "headers": {
    "Content-Type": "application/json"
  }
}
```

The `body` field is a JSON-stringified version of the request payload, matching the API Gateway proxy integration format where `event.body` is a string.

3. **Document** (in a comment block at the top of the fixture or in a companion README) the local invocation approach:

   - Set environment variables:
     ```
     AI_RUNTIME_MODE=local
     PROMPT_REGISTRY_LOCAL_DIR=./path/to/local/prompts
     DSL_ASSET_LOCAL_PATH=./path/to/dsl-reference.md
     GITHUB_TOKEN=<your-token>
     ```
   - Invoke the handler directly in a test script or REPL:
     ```typescript
     import { handler } from './src/lambda/ai/auto-map.js';
     import event from './tests/lambda/ai/fixtures/auto-map-event.json';
     const result = await handler(event);
     console.log(JSON.stringify(JSON.parse(result.body), null, 2));
     ```
