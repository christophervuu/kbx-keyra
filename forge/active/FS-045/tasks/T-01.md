## Summary

Create `src/lambda/ai/auto-map.ts` — the Auto-Map Lambda handler following the same thin-handler pattern used by `explain-rule.ts` and `suggest-expression.ts`. This task implements request parsing, input validation, `invokeAI('auto-map', variables)` invocation, and the standard response envelope. Expression validation post-processing is handled in T-02.

---

## Scope

### In Scope

- New file `src/lambda/ai/auto-map.ts`
- `APIGatewayProxyEvent` and `APIGatewayProxyResult` interface declarations (matching existing pattern)
- `JSON_HEADERS` constant, `jsonResponse()`, `statusCodeForAIError()`, `parseRequestBody()` utilities (following established pattern)
- Input validation: `targetSection` (required, non-empty string), `sourceContext` (required, non-empty string), `businessContext` (optional, defaults to empty string)

- On AI error: map error code to HTTP status using `statusCodeForAIError()`

## Change Requirements

The handler must:

1. **Import** `invokeAI` and `AIErrorCode` from `../../lib/ai/index.js`
2. **Define** the same `APIGatewayProxyEvent`, `APIGatewayProxyResult`, `JSON_HEADERS`, `jsonResponse`, `statusCodeForAIError`, and `parseRequestBody` utilities matching the existing Lambda pattern exactly
3. **Export** an `async function handler(event: APIGatewayProxyEvent): Promise<APIGatewayProxyResult>` that:
   - Calls `parseRequestBody(event.body)` — returns 400 on null
   - Validates `targetSection` is a non-empty string — returns 400 with `"Missing required field: targetSection"`
   - Validates `sourceContext` is a non-empty string — returns 400 with `"Missing required field: sourceContext"`
   - Extracts `businessContext` — defaults to `""` if not a string
   - Calls `invokeAI('auto-map', { targetSection, sourceContext, businessContext })`
   - On `result.success === true`: returns `jsonResponse(200, result)`
   - On `result.success === false`: returns `jsonResponse(statusCodeForAIError(result.error.code), result)`
   - Catches unexpected exceptions and returns `jsonResponse(500, { success: false, error: { code: 'MODEL_ERROR', message: 'Unexpected error while handling request' }, promptId: 'auto-map' })`

The handler at this stage passes through the `invokeAI` result directly. T-02 will add validation enrichment between the `invokeAI` call and the response.
