## Summary

Create the `UnifiedExpressionBuilder` component that replaces `GuidedBuilder`. This task builds the outer shell (mode tabs, mode switch confirmation, layout) and the Value mode source section (chip-based multi-select with search, static value toggle, Direct Copy shortcut button). The transform pipeline, conditional, and value map UIs are built in subsequent tasks.

---

## Scope

### In Scope

- Create `UnifiedExpressionBuilder.tsx` component with:
  - Mode segmented control (Value | Conditional | Value Map).
  - Mode switch confirmation dialog when in-progress expression exists.
  - Slot/section layout: Source section -> Transform section (placeholder for T-04) -> Live Expression (placeholder for T-07) -> Live Result (placeholder for T-07).
- Create `SourceChipPicker.tsx` component:
  - Chip-based multi-select for source fields from `parsedSourceSchema`.
  - Search input to filter available source fields.
  - Chips are removable (x button on each chip).
  - "Use a static value instead" toggle that shows a text input (with type selector: string/number/boolean/null).
- "Direct Copy" shortcut button: visible when exactly 1 source is selected and no transforms are present. Clicking it generates `source("path")` expression and fires `onExpressionGenerated`.
- Wire `generateExpressionFromState()` from T-01 for source-only expressions.
- Component tests for mode tabs, source chip picking, static value toggle, Direct Copy, and mode switch confirmation.

### Out of Scope

- Transform pipeline UI (T-04).
- Conditional mode UI (T-05).
- Value Map mode UI (T-06).
- Live Expression / Live Result display (T-07).
- Integration into ScalarFieldBuilder/ExpressionBuilderPanel (T-07).
- Raw Editor mode toggle (T-07).

## Change Requirements

**`UnifiedExpressionBuilder.tsx`:**

- Props:
  - `expression: string` — current expression (for loading existing rules)
  - `onExpressionChange: (expr: string) => void` — fires on every expression update
  - `onApply: (targetPath: string, expression: string) => void` — passed through for Direct Copy auto-apply
  - `selectedTargetPath: string` — current target path (for Direct Copy auto-apply)
  - `parsedSourceSchema: ParsedSchema | null` — source schema for field picking
  - `sourceData?: unknown` — test data for live result evaluation (passed through)
  - `className?: string`
- Internal state:
  - `activeMode: 'value' | 'conditional' | 'valueMap'` — controlled by mode tabs
  - `builderState: ExpressionBuilderState` — the current form state
  - `showModeConfirmation: boolean` — for mode switch dialog
  - `pendingMode: string | null` — the mode user wants to switch to
- Mode tabs: segmented control at the top. Clicking a different mode when `builderState` has non-empty content triggers confirmation dialog.
- Confirmation dialog: "Switching modes will reset the current expression. Continue?" with Confirm/Cancel buttons. On confirm, resets state and switches mode. On cancel, stays.
- Section layout: renders mode-specific content based on `activeMode`. For this task, only Value mode source section is implemented; other modes render a placeholder.

**`SourceChipPicker.tsx`:**

- Props:
  - `parsedSourceSchema: ParsedSchema | null`
  - `selectedSources: SourceSelection[]`
  - `onSourcesChange: (sources: SourceSelection[]) => void`
  - `staticMode: boolean`
  - `onStaticModeChange: (enabled: boolean) => void`
  - `staticValue?: StaticValue`
  - `onStaticValueChange?: (value: StaticValue) => void`
- Renders:
  - Search input that filters source schema tree fields.
  - Available fields list (from schema) — clicking a field adds it as a chip.
  - Selected fields displayed as chips with remove (x) button.
  - "Use a static value instead" toggle link/button.
  - When static mode is active: hides the field picker, shows a text input with type selector dropdown (String, Number, Boolean, Null).
- Field suggestions: flatten the schema tree into leaf paths and display in a scrollable list filtered by search text.

**Direct Copy button:**

- Conditionally rendered when `selectedSources.length === 1` and transform pipeline is empty (no transforms added yet from T-04).
- On click: **auto-applies** — calls `onApply(selectedTargetPath, 'source("path")')` immediately. Does NOT just call `onExpressionChange`.
- After auto-apply: shows a brief toast/flash confirmation ("Direct copy applied"). The parent component handles focus advance to next unmapped field (existing FS-021 behavior triggered by `onApply`).
- Styled as a prominent shortcut button (e.g., blue "Direct Copy" with a zap/copy icon).
