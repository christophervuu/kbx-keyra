## Change Requirements

**Module Structure updates:**

Replace the listed components/lib files in the `features/mappings/` tree to accurately reflect what exists after T-07 completes.

**Expression Builder Architecture section rewrite:**

Replace the existing section (currently titled "Expression Builder Architecture (FS-011)") with an updated section (titled "Expression Builder Architecture (FS-011, FS-023)") that documents:

1. **Component hierarchy (both views):**
   - `ScalarFieldBuilder` (Target View) and `ExpressionBuilderPanel` (Rules View) both render `UnifiedExpressionBuilder`.
   - `UnifiedExpressionBuilder` contains: mode tabs, mode-specific content (Value/Conditional/ValueMap), `LiveExpressionDisplay`, `LiveResultDisplay`.
   - Value mode contains: `SourceChipPicker`, `TransformPipeline` (with `TransformPipelineStep[]` and `TransformFunctionPicker`).
   - Conditional mode contains: `ConditionalModeBuilder` (with `ConditionRow[]`, `BranchValueSelector`).
   - Value Map mode contains: `ValueMapModeBuilder`.

2. **State model:**
   - `ExpressionBuilderState` discriminated union with mode-specific shapes.
   - State is owned at the `UnifiedExpressionBuilder` level.
   - Expression string is derived (generated) from state on every change.

3. **Expression generation:**
   - `generateExpressionFromState()` — pure function, state -> DSL string.
   - Pipeline nesting model: innermost = source, each transform wraps the previous.

4. **Expression decomposition:**
   - `decomposeExpression()` — DSL string -> state (or failure).
   - Mode auto-detection from AST structure.
   - Failure path: "Complex expression -- edit in Editor mode."

5. **Mode-toggle rules (updated):**
   - Builder -> Editor: direct projection (generate expression string).
   - Editor -> Builder: decomposition attempt. Success: hydrate state + switch. Failure: stay in editor + warning banner.

6. **Cross-panel integration (updated):**
   - Source Panel DnD/click adds a chip to `SourceChipPicker` in the active builder.
   - Works across all modes (adds to appropriate operand/input).

**INDEX.md update:**

- Update `Last Updated` date for `ui-application.md` row to the completion date.
