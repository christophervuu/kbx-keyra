## Summary

Implement the Value Map mode of the `UnifiedExpressionBuilder`. This provides a source field picker, an editable key-value mapping table ("When value is..." -> "Map to..."), and a fallback value selector. The form generates `valueMap(source("field"), {...}, fallback)` DSL expressions.

---

## Scope

### In Scope

- Create `ValueMapModeBuilder.tsx` component rendered when `activeMode === 'valueMap'` in `UnifiedExpressionBuilder`.
- Input source section: single-select source field picker.
- Mapping table: editable rows with "When value is..." (input) and "Map to..." (input) columns. [+ Add row] button. Rows removable with x button.
- Fallback section: value input or "return null" toggle/checkbox.
- Wire expression generation via `generateExpressionFromState()`.
- Component tests.

### Out of Scope

- Value mode (T-03/T-04).
- Conditional mode (T-05).
- Live Expression/Result (T-07).
- Import/export of mapping tables from CSV or external sources.

## Change Requirements

**`ValueMapModeBuilder.tsx`:**

- Props:
  - `state: ValueMapModeState` (the valueMap portion of `ExpressionBuilderState`)
  - `onStateChange: (state: ValueMapModeState) => void`
  - `parsedSourceSchema: ParsedSchema | null`
- Renders:
  - **Input Source** section:
    - Label: "Input Value"
    - Single-select source field picker (dropdown or searchable select).
    - Shows selected field as a chip/badge.
  - **Mapping Table** section:
    - Table header row: "When value is..." | "Map to..." | (remove)
    - Data rows: each `ValueMapEntry` renders as a row with two text inputs and a remove (x) button.
    - [+ Add row] button below the table.
    - Empty state: "Add mapping rows to define value transformations."
  - **Fallback** section:
    - Label: "Default / Fallback"
    - Toggle or radio: "Return specific value" (shows text input) | "Return null"
    - Default: "Return null" selected.

**State management:**

- `inputSource: string` — the selected source field path.
- `mappings: ValueMapEntry[]` — array of `{ whenValue: string; mapTo: string }`.
- `fallback: FallbackValue` — `{ kind: 'value' | 'null'; value?: string }`.
- On any change, call `onStateChange` with updated state.

**Expression generation wiring:**

- On state change in `UnifiedExpressionBuilder`, generate expression:
  - `valueMap(source("inputField"), {"key1": "val1", "key2": "val2"}, fallback)`
  - If fallback is null: third argument is `null`.
  - If fallback is value: third argument is the quoted string.
- Fire `onExpressionChange` with generated expression.

**Row interactions:**

- Adding a row appends `{ whenValue: '', mapTo: '' }` to mappings array.
- Removing a row splices it from the array.
- Editing a cell updates the corresponding field in-place.
- Rows with empty `whenValue` are included in state but the generated expression omits them (or marks them as incomplete — see Notes).

**Integration into `UnifiedExpressionBuilder`:**

- When `activeMode === 'valueMap'`, render `ValueMapModeBuilder` in the main content area.
- On state change, generate expression and fire `onExpressionChange`.

## Notes

- The mapping table should feel like a lightweight spreadsheet: tabular, easy to scan, quick to edit. Two-column layout with clear headers.
- For rows with empty `whenValue`, the generated expression should skip them (don't include empty-string keys in the DSL output). Show a visual indicator that the row is incomplete (e.g., light red background or warning icon).
- The source field picker here is single-select (unlike the multi-select in Value mode). Reuse the field search pattern from `SourceChipPicker` but as a single-select dropdown.
- `data-testid` pattern: `value-map-builder`, `value-map-source-picker`, `value-map-row-{index}`, `value-map-when-{index}`, `value-map-to-{index}`, `value-map-add-row-btn`, `value-map-fallback-input`, `value-map-fallback-null`.
