## Summary

Implement the Options mode rendering within `ParameterValueInput`. When a parameter has `PARAMETER_HINTS`, the Options mode shows predefined values as selectable chips (small sets ≤ 6) or a searchable dropdown (larger sets). Handles both strict enum hints (no freeform allowed) and token hints (freeform via Static mode). Preserves custom values when switching between Options and Static modes.

---

## Scope

### In Scope

- Wire `PARAMETER_HINTS` resolution into `ParameterValueInput` via the `options` prop
- Create a helper function that converts `ParameterHint` to `ParameterOptions` shape
- Implement chip list rendering for small option sets (≤ 6 items): horizontally wrapped chips with active/selected state
- Implement dropdown rendering for larger option sets: searchable listbox
- For strict enum (`allowCustom: false`): hide Static mode from toggle; only show Options
- For token hints (`allowCustom: true`): show both Static and Options in toggle; switching to Static allows freeform entry
- Handle "custom value in options context": when current slot literal value is not in the options list, show it with a "Custom" badge and the option to switch to preset
- Preserve custom Static value when switching Options→Static→Options→Static
- Chip visual styling: `rounded-md border px-2.5 py-1.5 text-xs cursor-pointer` with selected state `bg-blue-700 border-blue-600 text-white` and unselected `bg-zinc-800 border-zinc-700 text-zinc-300 hover:bg-zinc-700`
- Add tests for chip rendering, selection, dropdown behavior, enum-only mode, and value persistence

### Out of Scope

- Changes to `parameter-hints.ts` registry (existing entries are sufficient)
- Adding new parameter hints for additional functions
- Integration with `ArgumentForm` (T-04)
- Empty string handling details (T-03)

## Change Requirements

- Add `resolveParameterOptions(functionName: string, paramName: string): ParameterOptions | undefined` helper (either in `ParameterValueInput.tsx` or a co-located utility)
- When `options` prop is provided to `ParameterValueInput`:
  - If `options.allowCustom === false`: mode toggle shows ONLY "Options" (no Source, no Static)
  - If `options.allowCustom === true`: mode toggle shows the standard modes PLUS "Options"
  - If `options.values.length <= 6`: render chips layout
  - If `options.values.length > 6`: render searchable dropdown (role="listbox")
- Chip list: flex-wrap container, each chip is a button with selected/unselected styling
- Clicking a chip: set slot to `makeLiteralSlot(chipValue)`, mark chip as selected
- Custom value indicator: if current literal value is not in `options.values`, show it above the chips with a "Custom: {value}" badge and a "Use a preset instead" link
- Value persistence: maintain internal `customStaticValue` state separate from options selection so switching between Options and Static preserves the user's custom text
