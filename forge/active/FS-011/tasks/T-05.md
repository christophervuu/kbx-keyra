## Summary

Build the first two steps of the guided expression builder: Step 1 (source field selection with inline picker, multi-field support, and shortcuts) and Step 2 (categorized function picker). These steps allow users to begin constructing DSL expressions without knowing raw syntax.

---

## Scope

### In Scope

- **Step 1 — Source Field Selection:**
  - Inline source field picker with text input + autocomplete
  - Accepts clicks from source schema tree (Panel 1) via callback prop
  - Shows selected field as a pill/chip (e.g., `source("order.customer.name")`)
  - "Add another field" action for multi-field selection (for functions like concat)
  - Remove selected field action
  - Shows field type indicator next to selected field
  - "Direct Copy" shortcut: if user selects one field and proceeds without choosing a transform, expression is `source("path")`
  - "Static Value" toggle: switches to a literal value input, generates `static("value")`
  - Static value input accepts string, number, boolean, null with type selector
- **Step 2 — Transform Function Picker:**
  - Categorized grid/list of DSL functions from `DSL_FUNCTION_CATALOG`
  - Categories: String, Date, Math, Conditional, Lookup, Array, Null Handling, Type Conversion
  - Each function shows: name, one-line description, parameter count
  - Category tabs or accordion for navigation
  - Search/filter input to find functions by name
  - Selecting a function advances to Step 3 (argument configuration)
  - Visual indication of which functions work with the selected source field type
- **Builder step navigation:**
  - Step indicator (1 → 2 → 3 → 4)
  - Back button to return to previous step
  - Step 1 is always accessible; later steps depend on prior selections
- **Builder state management:**
  - Track selected source fields, selected function, current step
  - Generate partial DSL expression as user progresses
  - Integrate with `useExpressionBuilder` hook for expression state

### Out of Scope

- Step 3: Argument configuration (T-06)
- Step 4: Preview/evaluation (T-06)
- Array-specific builder patterns (T-07)
- Mode toggle logic (T-08)
- Integration with Panel 1 click events (T-11 — this task provides the callback interface)

## Change Requirements

- Create `ui/src/features/mappings/components/GuidedBuilder.tsx`:
  - Orchestrates the step flow (Step 1 → Step 2 → placeholder for Step 3/4)
  - Manages builder-specific local state: `currentStep`, `selectedSourceFields`, `selectedFunction`
  - Renders step indicator and navigation (back/next)
  - Generates partial expression from builder state
  - Calls expression update when a complete expression is formed (direct copy/static value shortcuts)
  - Props: `expression`, `onExpressionChange`, `parsedSourceSchema`, `onSourceFieldInsert` (callback from schema tree clicks)

- Create `ui/src/features/mappings/components/SourceFieldPicker.tsx`:
  - Props: `parsedSourceSchema: ParsedSchema | null`, `selectedFields: string[]`, `onFieldSelect: (path: string) => void`, `onFieldRemove: (path: string) => void`
  - Text input with autocomplete showing schema field paths (reuse `flattenSchemaPaths` from T-03 utils)
  - Selected fields shown as removable pills/chips
  - "Add another field" button (enabled after first selection)
  - Field type indicator (icon + label) for each selected field
  - Empty state: "No source schema loaded" when parsedSourceSchema is null
  - "Static Value" toggle at the bottom of Step 1

- Create `ui/src/features/mappings/components/TransformPicker.tsx`:
  - Props: `selectedSourceFields: string[]`, `onFunctionSelect: (functionName: string) => void`, `catalog: FunctionCatalogEntry[]`
  - Category-organized display (tabs or collapsible sections)
  - Each function entry: name (bold), description (muted), parameter count badge
  - Search input at top for filtering by function name
  - Highlight/suggest functions compatible with selected source field types (soft guidance, not strict filtering)
  - Click handler fires `onFunctionSelect`

- Create `ui/src/features/mappings/components/BuilderStepIndicator.tsx`:
  - Props: `currentStep: number`, `totalSteps: number`, `stepLabels: string[]`
  - Horizontal step indicator with active/completed/pending states
  - Clickable completed steps for navigation back

- Static value input in `SourceFieldPicker`:
  - Toggle between "Source Field" and "Static Value" modes
  - Static value mode shows: type dropdown (string, number, boolean, null) + value input
  - Generates `static("value")` or `static(123)` or `static(true)` or `static(null)` based on type
