## Summary

Extend the guided builder to support constructing array expressions: `map()` with object template scaffolding, `filter()` with condition sub-expression, and `item()`/`parent()` as source options when inside an array context. Add visual indicators for array context awareness.

---

## Scope

### In Scope

- **Array context detection:**
  - When selected source field is an array type (`SchemaTreeNode.isArray === true`), suggest `map()` as primary transform
  - When `map()` or `filter()` is selected as the transform, enter "array context mode"
  - Track array context in builder state (for item/parent availability)
- **`map()` with object template:**
  - When map() is selected, Step 3 scaffolds an object template builder
  - Object template builder: add key-value pairs
  - Each key: text input for target field name
  - Each value: a sub-expression builder (source field via `item()`, literal, or nested function)
  - "Add field" button to add more key-value pairs
  - "Remove field" button per pair
  - Generates: `map(source("arrayField"), { "key1": item("childField"), "key2": item("other") })`
- **`filter()` with condition:**
  - When filter() is selected, Step 3 scaffolds a condition sub-expression slot
  - Condition slot: mini guided builder for boolean expressions (eq, neq, gt, lt, etc.)
  - Generates: `filter(source("arrayField"), eq(item("status"), "active"))`
- **`item()` and `parent()` in array context:**
  - When inside an array context (map/filter Step 3), source field picker shows:
    - `item("path")` options (fields of array element type from schema)
    - `parent("path")` options (fields from parent scope)
    - Regular `source("path")` still available for root data
  - Visual label: "You are inside a map() — use item() to access array element fields"
- **Array context visual indicator:**
  - Banner/badge at top of Step 3 when in array context
  - Different icon/color for item() vs source() selections
  - Breadcrumb showing context depth (e.g., "map(items) > template")
- **Expression generation for array patterns:**
  - Object template: `{ "key": value, ... }` syntax generation
  - Proper quoting of keys
  - Nested item/parent function calls within template values

### Out of Scope

- Nested map() within map() (too complex for guided builder — use raw editor)
- `find()` support in guided builder (lower priority, defer to raw editor)
- Drag-and-drop reordering of template fields
- Live evaluation preview of array expressions (T-10)

## Change Requirements

- Create `ui/src/features/mappings/components/ObjectTemplateBuilder.tsx`:
  - Props: `fields: Array<{ key: string; value: BuilderArgument }>`, `onChange`, `parsedSourceSchema`, `arrayItemSchema: SchemaTreeNode | null`
  - Renders a list of key-value pair editors
  - Key: text input for field name
  - Value: `ArgumentSlot` configured in array context (item/parent available)
  - "Add field" button to append new pair
  - "Remove" button per pair
  - Generates `{ "key1": expr1, "key2": expr2 }` object template syntax

- Create `ui/src/features/mappings/components/ConditionBuilder.tsx`:
  - Props: `condition: BuilderState | null`, `onChange`, `parsedSourceSchema`, `arrayItemSchema`
  - Mini builder for boolean expressions: comparison function picker (eq, neq, gt, gte, lt, lte) + two argument slots
  - Left side: typically `item("field")`, right side: literal or source value
  - Generates: `eq(item("field"), value)` or similar

- Create `ui/src/features/mappings/components/ArrayContextBanner.tsx`:
  - Props: `functionName: string` (e.g., "map"), `sourceField: string`
  - Renders info banner: "You are inside a map() — use item() to access array element fields"
  - Uses info icon + blue/indigo background

- Update `SourceFieldPicker.tsx` / `ArgumentSlot.tsx`:
  - Accept `arrayContext?: { inArrayContext: boolean; arrayItemSchema: SchemaTreeNode | null }`
  - When in array context, show three sections in field picker:
    1. `item("...")` — fields from array element (from arrayItemSchema children)
    2. `parent("...")` — fields from parent context (if nested)
    3. `source("...")` — root source fields (always available)
  - Different icons for each section

- Update `expression-generator.ts`:
  - Add object template generation: `{ "key1": expr, "key2": expr }`
  - Add `item("path")` and `parent("path")` generation
  - Handle map expression: `map(source("array"), { ... })`
  - Handle filter expression: `filter(source("array"), condition)`

- Update `GuidedBuilder.tsx`:
  - Detect when selected source field is array type
  - When map() or filter() is selected, switch Step 3 to array-specific UI
  - Pass array context state down to child components
  - Derive `arrayItemSchema` from the selected array field's children in ParsedSchema

## Blockers / Risks

---

## Notes

- The array context support is limited to single-level map/filter in the guided builder. Nested map() within map() should be authored in raw editor mode.
- `find()` is structurally similar to `filter()` but returns a single value — could be added later with minimal effort, but is explicitly out of scope for this task.
- The `arrayItemSchema` is derived by finding the selected array field in the ParsedSchema and accessing its `children` (which represent the array element's fields).
