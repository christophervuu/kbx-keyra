## Summary

Build the raw DSL text editor component with syntax highlighting, bracket matching, and multi-line support. This is the power-user editing surface that renders DSL expressions with colored token classes using a lightweight custom approach (textarea + overlay or contenteditable).

---

## Scope

### In Scope

- `RawDslEditor` component:
  - Text input area for DSL expression editing
  - Syntax highlighting overlay rendering colored tokens
  - Bracket/parenthesis matching (highlight matching pairs on cursor position)
  - Multi-line expression support (textarea with auto-grow or fixed height with scroll)
  - Cursor position tracking (needed for autocomplete context in T-03)
  - `onChange` callback for expression text changes
  - `onCursorChange` callback for cursor position updates
  - Placeholder text when expression is empty
  - Read-only mode (for when panel is in non-editing state)
  - Keyboard shortcut stubs (Ctrl+Space, Ctrl+Enter, Escape — handlers wired in T-03/T-04/T-11)
- `dslTokenizer` utility:
  - Regex-based tokenizer that classifies DSL expression text into visual token spans
  - Token types: `function-name`, `string-literal`, `number-literal`, `boolean-literal`, `null-literal`, `punctuation` (parens), `comma`, `whitespace`
  - Returns array of `{ type, text, start, end }` for rendering
  - Handles edge cases: escaped quotes in strings, multi-line expressions, incomplete expressions
- Bracket matching logic:
  - Given cursor position, find matching opening/closing parenthesis
  - Return positions of both brackets for highlight rendering
- Tailwind CSS 4 styling with distinct colors per token type
- Standard text editing behavior (undo, redo, select all via native browser)

### Out of Scope

- Autocomplete dropdown (T-03)
- Inline validation error rendering (T-04)
- Mode toggle integration (T-08)
- Expression state management (handled by T-01's hook)
- Line numbers (implementer's judgment — not required)

## Change Requirements

- Create `ui/src/features/mappings/lib/dsl-tokenizer.ts`:
  - Export `tokenizeDsl(expression: string): DslToken[]`
  - `DslToken` = `{ type: DslTokenType; text: string; start: number; end: number }`
  - `DslTokenType` = `'function-name' | 'string-literal' | 'number-literal' | 'boolean-literal' | 'null-literal' | 'punctuation' | 'comma' | 'brace' | 'colon' | 'whitespace' | 'unknown'`
  - Tokenization rules:
    - Identifiers followed by `(` → `function-name`
    - Double-quoted strings (handle escaped quotes) → `string-literal`
    - Numbers (integers and decimals) → `number-literal`
    - `true` / `false` → `boolean-literal`
    - `null` → `null-literal`
    - `(` / `)` → `punctuation`
    - `,` → `comma`
    - `{` / `}` → `brace`
    - `:` → `colon`
    - Whitespace → `whitespace`
    - Anything else → `unknown`

- Create `ui/src/features/mappings/components/RawDslEditor.tsx`:
  - Props: `value: string`, `onChange: (value: string) => void`, `onCursorChange?: (position: number) => void`, `placeholder?: string`, `readOnly?: boolean`, `className?: string`
  - Implementation approach (recommended): hidden textarea for input + overlaid div with colored spans for highlighting
    - Textarea handles all native editing (undo/redo/selection/IME)
    - Overlay div renders same text but with colored spans per token
    - Textarea has transparent text color; overlay is pointer-events-none
    - Both scroll together (synced scroll position)
  - Bracket matching: on cursor position change, compute matching bracket and apply highlight class to both bracket tokens in overlay
  - Expose `ref` for imperative access (insert text at cursor — needed by T-03 and T-09)
  - Handle resize gracefully (flex within panel)

- Token color scheme (Tailwind classes):
  - `function-name`: `text-blue-400`
  - `string-literal`: `text-green-400`
  - `number-literal`: `text-orange-400`
  - `boolean-literal`: `text-purple-400`
  - `null-literal`: `text-gray-400`
  - `punctuation`: `text-slate-300`
  - `comma`: `text-slate-400`
  - `brace`/`colon`: `text-yellow-300`
  - `whitespace`: inherited
  - `unknown`: `text-red-400`
  - Matched brackets: `bg-slate-700 rounded`

## Blockers / Risks
