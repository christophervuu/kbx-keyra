## Summary

Implement the context-aware autocomplete system for the raw DSL editor. The system detects the cursor context (inside source path, at function position, inside constant/external reference) and generates appropriate suggestions from the source schema, mapping config, and function registry. Includes dropdown UI, keyboard navigation, and selection behavior.

---

## Scope

### In Scope

- `useDslAutocomplete()` hook:
  - Accept expression string, cursor position, ParsedSchema, mapping config constants/externals
  - Detect cursor context by scanning characters around cursor
  - Generate filtered suggestion list based on context
  - Handle trigger conditions (typing, Ctrl+Space)
  - Track dropdown open/closed state, selected item index
- Context detection logic:
  - Inside `source("...` → suggest source field paths (dot-notation from ParsedSchema)
  - Inside `constant("...` → suggest constant names from mapping config
  - Inside `external("...` → suggest external source names
  - At top-level or function argument position → suggest function names with signatures
  - Prefix filtering as user types
- `AutocompleteDropdown` component:
  - Positioned relative to cursor in the editor
  - Shows filtered suggestions with icons per kind (function, field, constant)
  - Keyboard navigation: up/down arrows, Enter to select, Escape to close, Tab to select
  - Click to select
  - Max height with scroll for long lists
  - Shows parameter hint for function suggestions
- Integration with `RawDslEditor`:
  - Trigger on Ctrl+Space (explicit) and on typing (automatic when context is detected)
  - On selection: insert the suggestion text at cursor position, adjust cursor
  - For source paths: insert path and closing quote
  - For functions: insert `functionName()` with cursor inside parens
- `flattenSchemaPathsForAutocomplete()` utility:
  - Convert `ParsedSchema` tree to flat list of dot-notation paths with type info
  - Cache result (memoize on ParsedSchema reference)

### Out of Scope

- Inline validation error display (T-04)
- Function reference panel (T-09)
- Guided builder autocomplete (T-05 handles its own field picker)
- Autocomplete for object template keys

## Change Requirements

- Create `ui/src/features/mappings/lib/autocomplete-utils.ts`:
  - `detectAutocompleteContext(expression: string, cursorPos: number): AutocompleteContext`
    - Returns: `{ kind: 'source-path' | 'constant' | 'external' | 'function' | 'none'; prefix: string; insertStart: number; insertEnd: number }`
    - Logic: scan backwards from cursor to find enclosing `source("`, `constant("`, `external("`, or detect top-level/argument position
  - `flattenSchemaPaths(schema: ParsedSchema): Array<{ path: string; type: string; description?: string }>`
    - Recursively flatten tree nodes into dot-notation paths
    - Include leaf and intermediate nodes
  - `filterSuggestions(items: AutocompleteItem[], prefix: string): AutocompleteItem[]`
    - Case-insensitive prefix match

- Create `ui/src/features/mappings/hooks/use-dsl-autocomplete.ts`:
  - Hook accepts: `{ expression, cursorPosition, parsedSourceSchema, constants, externalSources }`
  - Computes context on cursor/expression change
  - Generates suggestions based on context kind
  - Manages open/close state of dropdown
  - Manages selected index for keyboard nav
  - Returns: `{ isOpen, suggestions, selectedIndex, open(), close(), selectNext(), selectPrev(), confirm(), context }`

- Create `ui/src/features/mappings/components/AutocompleteDropdown.tsx`:
  - Props: `suggestions: AutocompleteItem[]`, `selectedIndex: number`, `onSelect: (item: AutocompleteItem) => void`, `onClose: () => void`, `position: { top: number; left: number }`
  - Renders suggestion list with scroll
  - Highlights selected item
  - Shows item icon (function: `ƒ`, field: `□`, constant: `C`)
  - Shows detail text (type for fields, signature for functions)
  - Max 8 visible items with overflow scroll
  - Portal-rendered to avoid overflow clipping

- Update `RawDslEditor.tsx`:
  - Accept autocomplete props/children or compose with hook
  - On Ctrl+Space: trigger autocomplete open
  - On typing inside detected context: auto-open
  - On Escape: close dropdown
  - On Enter/Tab when dropdown open: insert selected suggestion
  - On selection: call insert handler with suggestion text and cursor adjustment
  - Position dropdown relative to cursor character position in editor

## Blockers / Risks

- Cursor position in textarea→character offset mapping can be complex for multi-line — ensure consistent calculation
- Dropdown positioning relative to cursor character requires measuring text width up to cursor — consider using a hidden measurement span

## Notes

- The autocomplete system is intentionally simple for Phase 0 — no fuzzy matching, just prefix filtering
- Source field path suggestions should be the full dot-notation path (e.g., `order.customer.name`), not just the leaf field name
- For functions, show the function name + parameter count hint (e.g., `concat (2+ args)`)
