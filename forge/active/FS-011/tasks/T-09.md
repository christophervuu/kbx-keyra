## Summary

Build a collapsible, searchable function reference panel that displays all available DSL functions with their signatures, descriptions, and example usage. Clicking a function inserts it at the cursor (raw editor mode) or selects it as the transform (guided builder mode). Data sourced from the shared `DSL_FUNCTION_CATALOG` in `ui/src/lib/data/dsl-functions.ts`.

---

## Scope

### In Scope

- `FunctionReferencePanel` component:
  - Collapsible panel (toggle open/closed)
  - Search input at top for filtering functions by name or description
  - Categorized display (same categories as TransformPicker: String, Date, Math, Conditional, Lookup, Array, Null Handling, Type Conversion)
  - Each function entry shows:
    - Function name (bold, monospace)
    - Signature: `functionName(param1: type, param2: type, ...): returnType`
    - One-line description
    - Example usage (monospace, syntax-colored)
  - Click handler: inserts function into expression
  - Keyboard accessible (focusable entries, Enter to insert)
- **Insert behavior:**
  - In Editor mode: insert `functionName()` at cursor position, place cursor inside parens
  - In Builder mode: select the function as the current transform (equivalent to picking in Step 2)
  - Insert callback provided via prop (actual insertion logic lives in parent/integration layer)
- **Collapse behavior:**
  - Default: collapsed (not taking panel space)
  - Toggle button labeled "Function Reference" or icon button
  - When open: renders below or beside the editor/builder area (implementer's layout choice)
  - Remembers open/closed state within session (local state)
- **Search:**
  - Debounced input (200ms)
  - Filters by function name and description text
  - Shows "No matching functions" when filter produces no results
  - Clear button to reset filter

### Out of Scope

- Editing the function catalog
- Function documentation beyond one-line descriptions + example
- Deep linking to external DSL documentation
- Syntax validation of examples

## Change Requirements

- Create `ui/src/features/mappings/components/FunctionReferencePanel.tsx`:
  - Props: `onInsertFunction: (functionName: string) => void`, `mode: 'builder' | 'editor'`
  - Local state: `isOpen: boolean`, `searchQuery: string`
  - Renders toggle button when collapsed
  - When open: search input + categorized function list
  - Filters catalog by search query (debounced)
  - Groups entries by category with section headers
  - Click on entry calls `onInsertFunction(entry.name)`

- Create `ui/src/features/mappings/components/FunctionReferenceEntry.tsx`:
  - Props: `entry: FunctionCatalogEntry`, `onInsert: () => void`
  - Renders single function reference card:
    - Name in monospace bold
    - Signature line: `name(param1: type, param2?: type, ...rest: type): returnType`
    - Description in muted text
    - Example in monospace (optional syntax highlighting via tokenizer)
  - Clickable (entire entry) — calls onInsert
  - Focusable for keyboard access
  - Hover state visual feedback

- Add example usage strings to `DSL_FUNCTION_CATALOG` entries in `ui/src/lib/data/dsl-functions.ts` (if not already present from T-01):
  - Each entry gets an `example: string` field
  - Examples: `concat("Hello", " ", "World")`, `formatDate(source("date"), "YYYY-MM-DD")`, etc.

- Update `ExpressionBuilderPanel.tsx`:
  - Add `FunctionReferencePanel` in the panel layout (below mode-specific content area)
  - Wire `onInsertFunction` callback:
    - Editor mode: insert function at cursor via `RawDslEditor` ref
    - Builder mode: trigger function selection (equivalent to TransformPicker select)
