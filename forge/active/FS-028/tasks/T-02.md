## Summary

Consolidate the Schema Name auto-fill logic so that title inference happens reliably through the debounced `analyzePasteContent` path introduced in T-01, while preserving the fast-path immediate extraction for responsive UX. Verify that `nameManuallyEdited` correctly prevents overwriting user-entered names.

---

## Scope

### In Scope

- Ensure the debounced `analyzePasteContent` path (T-01) correctly sets Schema Name from `title` when `nameManuallyEdited` is false
- Keep the immediate `title` extraction in `handlePasteTextChange` as a fast-path (already exists)
- Ensure the two paths do not conflict (debounced analysis should not overwrite a name already set by the fast-path with a different value)
- Verify `nameManuallyEdited` flag is set on any manual Schema Name input change and prevents auto-fill
- Add test coverage for the preservation behavior (AE-03)

### Out of Scope

- Changes to the debounce mechanism itself (T-01 owns that)
- Changes to file upload mode name inference (file mode uses filename, not title)
- UI changes to the Schema Name input visual

## Change Requirements

- In the `analyzePasteContent` function or its call site, after `pasteInfo` is set, update `schemaName` from title if `nameManuallyEdited` is false. This mirrors the existing logic in lines 334-348 but ensures it fires as part of the debounced analysis.
- Ensure the fast-path title extraction (lines 361-372 in `handlePasteTextChange`) and the debounced analysis path produce consistent results. If both fire, the later one (debounced) should not reset a name that was already correctly set by the fast-path.
- Verify that the `onChange` handler on the Schema Name input (line 574-577) correctly sets `nameManuallyEdited = true`.
- Verify that `nameManuallyEdited` is reset to `false` only on dialog close (via the `useEffect` at line 213-227).

## Notes

- The fast-path extraction exists because a single paste event delivers the full text in one `onChange`. For typed input, the JSON will be invalid until the user finishes typing — the debounced analysis handles that case by attempting full `parseContentInfo`.
- The `defaultPasteName` function provides fallback names like "Pasted JSON Schema" when no title exists. This fallback should only apply via the analysis path, not the fast-path (which sets empty string on failed parse).
