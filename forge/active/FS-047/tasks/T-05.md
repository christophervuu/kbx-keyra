## Summary

Update the `useAutoMapReview` hook to derive an eligible target listing from `parsedTargetSchema` using `deriveEligibleTargets`, include it as `targetSection` in the `autoMapSection` request input, and support header mode where `sectionPath` is null (full-schema auto-map). Add a guard that prevents sending the request when no eligible targets are found.

---

## Scope

### In Scope

- Import and call `deriveEligibleTargets` in `triggerAutoMap`
- Pass `targetSection` in the `AutoMapSectionInput` object
- Accept `parsedTargetSchema` as a new parameter to the hook
- Support `null` as `sectionPath` for header mode (triggers full-schema targeting)
- Update `triggerAutoMap` signature to accept `string | null` for `sectionPath`
- Guard: if `deriveEligibleTargets` returns empty string, set error state with message instead of sending request
- Update tests to verify new behavior

### Out of Scope

- Creating the `deriveEligibleTargets` utility (T-03)
- Modifying `AutoMapSectionInput` type (T-04)
- UI trigger components (T-06)
- Backend changes

## Change Requirements

1. **New param**: Add `parsedTargetSchema?: ParsedSchema | null` to `UseAutoMapReviewParams`.

2. **Derive target listing** in `triggerAutoMap`:
   ```typescript
   const targetSection = deriveEligibleTargets(
     parsedTargetSchemaRef.current,
     path, // null for header mode, sectionPath for section mode
   );
   ```

3. **Empty guard**: If `targetSection` is empty string:
   - Set `status` to `'error'`
   - Set `error` to `'No eligible target fields found in this section'`
   - Do not send request to adapter
   - Return early

4. **Include in input**:
   ```typescript
   const input: AutoMapSectionInput = {
     projectId,
     mappingId,
     sectionPath: path ?? undefined,
     targetSection,
     sourceContext: deriveSourceContext(parsedSourceSchemaRef.current),
   };
   ```

5. **Update `triggerAutoMap` signature**: Accept `string | null` instead of just `string`.
   - `null` means header mode (all eligible targets in schema)
   - Update `UseAutoMapReviewResult.triggerAutoMap` type accordingly

6. **Update tests**:
   - Test: triggerAutoMap with sectionPath → `targetSection` is derived for that section
   - Test: triggerAutoMap with null → `targetSection` covers full schema
   - Test: empty eligible targets → error state, no request sent
   - Mock or import `deriveEligibleTargets` as needed
