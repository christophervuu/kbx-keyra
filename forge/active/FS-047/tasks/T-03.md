## Summary

Create a pure utility function `deriveEligibleTargets` that takes a `ParsedSchema` and an optional `sectionPath` prefix, filters to eligible target fields (non-object types + arrays), and returns a formatted listing string suitable for the AI prompt's `{{targetSection}}` placeholder.

---

## Scope

### In Scope

- New file `ui/src/features/mappings/lib/derive-eligible-targets.ts` (or co-located in existing lib directory)
- Pure function: `deriveEligibleTargets(schema: ParsedSchema, sectionPath?: string | null): string`
- Filtering logic: exclude nodes where `type === 'object'`; include all other types (string, number, integer, boolean, array, null, any)
- Section prefix filtering: when `sectionPath` is provided, only include descendants (path starts with `sectionPath + '.'`)
- Output format: `"- {path} ({type})"` per line, newline-separated
- Line limit: cap at 200 lines (match existing `SOURCE_CONTEXT_LINE_LIMIT`)
- Unit tests with full coverage of filtering, prefix, cap, and edge cases
- Barrel export from the appropriate index

### Out of Scope

- Modifying the HTTP client (T-04)
- Backend changes

## Change Requirements

1. Create `deriveEligibleTargets(schema: ParsedSchema, sectionPath?: string | null): string`
   - Iterate `schema.nodes`
   - If `sectionPath` is provided and non-empty, filter to nodes where `node.path.startsWith(sectionPath + '.')`
   - Exclude nodes where `node.type === 'object'`
   - Format each remaining node as `"- {node.path} ({node.type})"`
   - Join with `'\n'`
   - Cap output at 200 lines
   - Return the joined string, or empty string if no eligible targets

2. Export from the feature barrel

3. Write unit tests covering:
   - Basic: schema with mix of types → only non-object types in output
   - Section filter: only descendants of sectionPath included
   - Array inclusion: array nodes are included
   - Object exclusion: object nodes are excluded at all levels
   - Empty result: all descendants are objects → returns empty string
   - Cap: 250 eligible nodes → output contains exactly 200 lines
   - No sectionPath: all eligible nodes in entire schema included
