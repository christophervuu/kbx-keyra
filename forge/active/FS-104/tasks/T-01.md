## Summary

Add `objectFields` as a first-class `ArrayBuilderMode` and define canonical `ObjectFieldsCollectionState` in Array Builder state/hook types, including parent object path, ordered selected child keys, default missing behavior, and optional inclusion predicate state.

---

## Scope

### In Scope

- Add new discriminated union members/types in `array-builder-state.ts`.
- Update compatibility helpers (`isCompatibleModeSwitch`, preservation rules, completion derivation, factories).
- Extend `use-array-builder-state.ts` actions/state wiring for objectFields state transitions.
- Keep existing modes and customExpression behavior unchanged.

### Out of Scope

- UI collection editor implementation.
- DSL generation/decomposition logic for objectFields.

## Change Requirements

- `ArrayBuilderMode` includes `objectFields`.
- New `ObjectFieldsCollectionState` captures:
  - `parentObjectPath`
  - `orderedChildKeys`
  - `missingBehavior` (default skip null/absent)
  - optional `inclusionPredicate`
- Completion/validation baseline must treat empty parent path or empty selected keys as incomplete.
- Existing mode behavior and tests remain green.

- Hook tests for objectFields action wiring and no regressions in existing modes.
- Typecheck/lint pass.
