## Summary

Implement the guided collection-layer UX for **Build from object fields**: parent object selection, schema child discovery, multi-select/select-all, remove, and deterministic ordering controls, integrated into `ArrayModeSelector` and `ArrayBuilder` mode-specific rendering.

---

## Scope

### In Scope

- Add mode card label/description in `ArrayModeSelector`.
- Create `ObjectFieldsCollectionEditor` component for:
  - parent object path picker,
  - child key list (schema-defined only),
  - add/remove/select-all controls,
  - drag/keyboard reorder with deterministic ordering.
- Wire editor into `ArrayBuilder` mode switch rendering and callbacks.
- Ensure UI state updates drive draft expression refresh via existing hook flow.

### Out of Scope

- Final DSL generation logic.
- Decomposer/reopen behavior.

## Change Requirements

- Mode card appears alongside existing collection methods.
- Parent picker only allows schema-defined object paths for this phase.
- Child list only includes schema-defined direct children of selected parent object.
- Configured order is explicit and stable; runtime JSON property order is not used.
- Empty/missing selection states present clear inline guidance.

---

## Verification Requirements

- Component tests for mode selection and objectFields editor interactions.
- Tests for select/deselect/select-all/reorder flows.
- Tests confirming deterministic configured order persistence in state.

---

## Acceptance Checks

- User can select `objectFields` mode from mode selector.
- User can select parent object and child keys.
- User can reorder selected keys and ordering persists in draft state.
- Existing mode selector tests continue to pass.
