## Summary

Create the repository root `package.json`, TypeScript strict-mode configuration, ESM + CJS build output via tsup, ESLint configuration, and the `src/engine/` directory structure. This is the foundational task that all other FS-001 tasks depend on.

---

## Scope

### In Scope

- Root `package.json` with:
  - Package name (e.g., `@keyra/engine` or project-level name)
  - Zero `dependencies` (only `devDependencies`)
  - Scripts: `build`, `typecheck`, `lint`, `test`
  - ESM primary with CJS fallback (dual package exports)
- Root `tsconfig.json`:
  - `strict: true`
  - `noUncheckedIndexedAccess: true`
  - Target: ES2022 or later (modern enough for both browser and Node 18+)
  - Module: ESNext / NodeNext
  - `src/` included, `tests/` excluded from build but included for checking
- Build tool configuration (tsup or equivalent):
  - Entry: `src/engine/index.ts`
  - Output formats: ESM (`.mjs`) and CJS (`.cjs`)
  - Declaration files (`.d.ts`) generated
  - Source maps enabled
- ESLint configuration:
  - TypeScript-aware rules
  - No `any` in public API (enforced via rule or convention)
  - Flat config format (eslint.config.js)
- Directory structure:
  - `src/engine/index.ts` (empty export file for now)
  - `src/engine/types/` (empty directory with index.ts)
  - `src/engine/diagnostics/` (empty directory with index.ts)
  - `src/engine/registry/` (directory for function registry)
- `.gitignore` updates for `node_modules/`, `dist/`, build output

### Out of Scope

- Writing any type definitions (T-02)
- Writing error codes (T-03)
- Writing function registry logic (T-04)
- Writing public API stubs (T-05)
- Vitest configuration (T-06)

## Change Requirements

After this task completes:

- `npm install` succeeds (all devDependencies resolve)
- `src/engine/` directory exists with the correct subfolder structure
- `tsconfig.json` has strict mode enabled and targets modern JS
- Build configuration exists and targets `src/engine/index.ts` as the entry point
- ESLint is configured with TypeScript support
- The `dependencies` field in `package.json` is empty or absent
- All tooling packages (typescript, tsup, eslint, @typescript-eslint/*) are in `devDependencies`
