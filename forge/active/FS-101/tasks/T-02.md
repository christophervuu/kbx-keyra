## Summary

Add infrastructure resources for persistent Auto-Map sessions/runs, including DynamoDB table/indexes, Step Functions and worker wiring, IAM policy boundaries, and environment configuration.

---

## Scope

### In Scope

- Dedicated Auto-Map table with TTL `expiresAt`.
- Sparse `GSI1` history and `GSI2` open-session indexes.
- State machine and/or async worker resources.
- Env configuration for execution mode and orchestration settings.

### Out of Scope

- Handler business logic.
- UI integration.

---

## Relevant Areas

- `template.yaml`
- infra scripts/validation

---

## Change Requirements

- Add on-demand billing and PITR (except disposable local environments).
- Add least-privilege IAM for Auto-Map table/state-machine/worker access.
- Add `AUTO_MAP_EXECUTION_MODE` env support and required outputs/parameters.

---

## Verification Requirements

- `sam validate` passes.
- State machine/worker definitions validate.
- Infra tests updated and passing where present.

---

## Acceptance Checks

- Template defines required table, indexes, TTL, and orchestration resources.
- IAM scopes are resource-specific and non-wildcard where feasible.
- Validation/build checks pass for infra changes.

---

## Blockers / Risks

- Risk: incomplete permissions causing orchestration runtime failures.
