## Summary

Implement canonical refresh/retry merge behavior inside a single open session, preserving out-of-scope review decisions and ensuring retry/refresh runs update only intended suggestion subsets.

---

## Scope

### In Scope

- Refresh/retry scope normalization and run creation.
- In-session suggestion replacement/retention rules.
- Session resolution state derivation.
- Open-session GSI2 attribute lifecycle handling.

### Out of Scope

- UI layout concerns.

---

## Relevant Areas

- backend run merge services
- persistence session summary updaters
- merge/session integration tests

---

## Change Requirements

- Preserve accepted/dismissed/kept-current outside refresh scope.
- Do not delete out-of-scope suggestions on refresh omission.
- Remove GSI2 open attributes only when session reaches resolved/superseded/expired conditions.

---

## Verification Requirements

- Integration tests for scoped refresh/retry with mixed states.
- Tests for session `resolved` transition criteria.

---

## Acceptance Checks

- Refresh of stale subset leaves unrelated rows unchanged.
- Retry-failed runs update only failed-unit-related suggestions.
- Session leaves open index only when completion criteria are met.

---

## Blockers / Risks

- Risk: merge race when overlapping runs complete near-simultaneously.

---

## Notes

- Ensure merge logic is deterministic and target-path keyed.
