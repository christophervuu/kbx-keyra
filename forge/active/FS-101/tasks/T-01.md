## Summary

Establish canonical backend domain contracts for `AutoMapSession`, `AutoMapRun`, `AutoMapWorkUnit`, and `AutoMapSuggestion`, including status transitions, optimistic concurrency versioning, and accepted-unsaved metadata needed for rehydration.

---

## Scope

### In Scope

- Domain enums/types and transition guards.
- Session/run/work-unit/suggestion metadata shapes.
- Suggestion versioning and acceptance/materialization metadata.
- Persistence key builders for session-partition model and sparse GSIs.

### Out of Scope

- API route wiring.
- Orchestration implementation.
- UI behavior.

---

## Relevant Areas

- `src/lib/persistence/*`
- `src/lib/ai/*`
- `src/lib/types/*`
- `tests/*` (unit)

---

## Change Requirements

- Implement session-partition key helpers:
  - `SESSION#{sessionId}/META`
  - `SESSION#{sessionId}/RUN#{createdAt}#{runId}`
  - `SESSION#{sessionId}/WORK_UNIT#{runId}#{order}#{workUnitId}`
  - `SESSION#{sessionId}/SUGGESTION#{sectionOrder}#{targetOrder}#{suggestionId}`
- Implement transition guards for session/run/work-unit/suggestion statuses.
- Include generation/request fingerprint fields and enrichment source-reference metadata contracts.
- Add conditional-write helpers for idempotency and superseded-write protection primitives.

---

## Verification Requirements

- Unit tests for valid/invalid status transitions.
- Unit tests for key builders and sparse GSI projections.
- Unit tests for suggestion version increment and optimistic-concurrency checks.

---

## Acceptance Checks

- Domain contracts compile under strict TypeScript.
- Invalid transitions are rejected deterministically.
- Persistence helpers produce deterministic keys and index attributes.
- Versioned suggestion mutation tests pass.

---

## Blockers / Risks

- Risk: transition drift between API handlers and persistence guards.
