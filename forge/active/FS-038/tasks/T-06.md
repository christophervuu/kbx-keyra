## Summary

Implement the Static entry flow: a literal value input with target-type validation. When the user selects the Static entry point, they see a text input, the entered value is validated against the target field's schema type, and the mapping is complete once a valid value is entered. Optionally, the user can add logic via the same "+ Add logic" mechanism.

---

## Scope

### In Scope

- Static value input component with text field
- Target-type validation: compare entered value against target field type (string, number, boolean, integer, null)
- Visual validation feedback: green checkmark for valid, red error for type mismatch (AE-17)
- Inline error message when type doesn't match (e.g., "Expected number")
- Static value sets `ChainBuilderState.staticValue` with correct `StaticValue` type
- DSL generation for static: string → `"value"`, number → `42`, boolean → `true`/`false`, null → `null` (reuses existing patterns from FS-027)
- "+ Add logic" button visible for static values (same as source flow)

### Out of Scope

- Source entry flow (T-05)
- "+ Add logic" picker content (T-07)
- Complex type validation (arrays, objects, enums)

## Change Requirements

- Create a `StaticValueInput` component (or similar name):
  - Text input field for entering literal values
  - Target type display next to input
  - Type inference from input: detect string (quoted), number (numeric), boolean (`true`/`false`), null (`null`)
  - Validation against target type:
    - If target is `string`: any input valid (auto-quoted if user enters unquoted text)
    - If target is `number` or `integer`: input must parse as number
    - If target is `boolean`: input must be `true` or `false`
    - If target type is unknown: accept any input
  - Validation indicator: checkmark icon (green) for valid, X icon (red) for mismatch
  - Error message below input when invalid: "Expected {targetType}"
  - Fires `onValueChange(value: StaticValue)` callback
- Update `ChainBuilderState.staticValue` on input change
- Disable Apply button when static value is invalid for target type
- Render "+ Add logic" button below the static value input
