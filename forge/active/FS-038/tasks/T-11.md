## Summary

Implement the collapsible summary system for logic steps in the chain. Completed steps collapse to readable one-line summaries. Only one step can be expanded for editing at a time. Clicking a collapsed summary expands it and collapses any other expanded step. Expression and Result sections remain pinned regardless of expansion state.

---

## Scope

### In Scope

- Collapsible step container: wraps each logic step (transform, condition, value map)
- Collapsed state: renders one-line summary from `summarizeLogicStep` (T-01)
- Expanded state: renders the full form (from T-08, T-09, T-10)
- Single-expansion constraint: only one step expanded at a time; expanding one collapses others
- Click-to-expand: clicking collapsed summary expands that step
- Click-to-collapse: clicking expanded step header collapses it (or auto-collapse when another step opens)
- `expandedStepIndex` state management in `ChainBuilderState`
- Visual indicators: chevron icon (right when collapsed, down when expanded), step number badge
- Transition: smooth expand/collapse animation (CSS transition on height or max-height)
- Step connector visuals: vertical line or arrow between steps indicating chain flow

### Out of Scope

- Step reordering via drag-and-drop (stretch goal)
- Keyboard navigation between steps (stretch goal)

## Change Requirements

- Create `CollapsibleStepContainer` component:
  - Props: `step: LogicStep`, `index: number`, `isExpanded: boolean`, `onToggle: (index: number) => void`, `onStepChange`, `onRemoveStep`, `renderForm: (step, callbacks) => ReactNode`
  - Collapsed rendering:
    - Step number badge (e.g., "Step 1")
    - Summary text from `summarizeLogicStep(step)`
    - Chevron icon (right →)
    - Remove button (subtle, visible on hover)
  - Expanded rendering:
    - Step number badge
    - Step kind label (e.g., "Transformation", "Condition", "Value map")
    - Chevron icon (down ↓)
    - Full form content via `renderForm` render prop
    - Remove button
  - Click on collapsed container → fires `onToggle(index)`
  - Animation: CSS `transition` on `max-height` or `grid-template-rows` for smooth expand/collapse
- Create `LogicStepList` component:
  - Renders ordered list of `CollapsibleStepContainer` items
  - Manages `expandedStepIndex` — updates `ChainBuilderState.expandedStepIndex`
  - Renders step connectors (vertical line/arrow) between steps
  - Renders "+ Add step" / "+ Add logic" at the bottom
- Step connectors: thin vertical line or arrow between collapsed summaries to indicate chain flow direction

## Notes

- The collapsible system is critical for managing vertical space in the builder. Without it, a chain of 3+ steps would push Expression/Result out of view (which they can't be — they're pinned).
- Step summaries should be human-readable, not DSL-readable. "uppercase the current value" not "upper(source(...))".
