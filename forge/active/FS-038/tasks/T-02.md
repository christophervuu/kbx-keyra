## Summary

Implement a pure function `generateExpressionFromChain(state: ChainBuilderState): string` that converts the new chain builder state into a valid DSL expression string. This is the forward path from state → DSL.

---

## Scope

### In Scope

- New generator function: `generateExpressionFromChain(state: ChainBuilderState): string`
- Generation for all entry types: source, static, external (external returns empty string or placeholder)
- Generation for all logic step kinds: transform, condition, value map
- Chain composition: base → step 1 → step 2 → ... → final expression
- Transform step: `functionName(previousExpression, ...additionalArgs)`
- Condition step: `if(conditionExpr, thenExpr, elseExpr)`
- Value map step: `valueMap(previousExpression, { mappings }, defaultExpr)`
- ChainBranch generation: static → literal, source → source+transforms, expression → raw string
- Empty/incomplete state handling: return empty string for incomplete states

### Out of Scope

- Decomposition (DSL → state) — that is T-03
- UI components
- Modifying existing generators (`pipeline-expression-generator.ts`, `source-card-expression-generator.ts`)

## Change Requirements

- Create `chain-expression-generator.ts` with the public function `generateExpressionFromChain`
- The function must be pure (no side effects, no hooks, no state)
- Reuse `ArgumentSlot` serialization patterns from existing generators where applicable
- Handle all `LogicStep` kinds in the chain:
  - `TransformLogicStep`: wrap previous expression as first arg: `fn(prev, arg2, arg3, ...)`
  - `ConditionLogicStep`: generate `if(conditionExpr, thenBranchExpr, elseBranchExpr)` — reuse condition generation patterns from existing `pipeline-expression-generator.ts`
  - `ValueMapLogicStep`: generate `valueMap(prev, { key: value, ... }, defaultExpr)`
- Handle `ChainBranch` generation:
  - `kind: 'static'` → literal DSL (string quoted, number/boolean/null raw)
  - `kind: 'source'` → `source("path")` optionally wrapped in transform steps
  - `kind: 'expression'` → raw string passthrough
- Return empty string when state is incomplete (no sourcePath for source entry, no staticValue for static entry)
- Export from feature barrel
