## Summary

Implement the redesigned inline Value Map builder for the chain model. The value map behaves like a user-friendly switch statement: "When the current value equals X, output Y." It has a required default case, renders inline with the chain, and collapses to a compact summary when complete.

---

## Scope

### In Scope

- Inline value map form: header + mapping rows + default row
- Header: "When {source/current value} equals:" context label
- Mapping rows: `[input value] → [output value]` with remove button per row
- `[+ Add case]` button to add mapping rows
- Default row: always present, required, labeled "Default →"
- Input values: literal text input (string, number, boolean)
- Output values: literal text input or source picker
- Collapsed summary: `map {field}: A→Active, B→Inactive, ... (default: Unknown)`
- Click-to-expand from collapsed summary
- Ordering: mapping rows in user-defined order, default always last
- State mapping: `ValueMapLogicStep` → mappings array + default `ChainBranch`

### Out of Scope

- Complex output values (expressions, transforms in output) — plain literals and source fields only
- Condition or nested value map in output branches
- Reordering mapping rows via drag (stretch goal)

## Change Requirements

- Create `ChainValueMapForm` component (or similar name):
  - Context header: "When {currentValueLabel} equals:"
    - `currentValueLabel` is derived from sourcePath or "the current value"
  - Mapping rows:
    - Left column: input value (editable text)
    - Arrow indicator: `→`
    - Right column: output value (editable text or source picker)
    - Remove button (X) per row
  - `[+ Add case]` button appends new empty mapping row
  - Default row:
    - "Default →" label (non-removable)
    - Output value input
    - Always rendered at the bottom
  - Empty state: one empty mapping row + default row on first render
- Collapsed summary rendering:
  - `summarizeValueMapStep(step: ValueMapLogicStep): string`
  - Format: `map {field}: A→Active, B→Inactive (default: Unknown)`
  - Truncate if > 3 mappings: show first 2 + "... (+N more)"
- Fires `onStepChange(index, step: ValueMapLogicStep)` on any change
- Fires `onRemoveStep(index)` on step removal
- Default validation: Apply disabled when default value is empty

## Notes

- The switch-statement metaphor is intentional: it should feel like a lookup table, not a programming construct. Labels like "When X equals" instead of "Map input to output" help achieve this.
- The default case being always present and required eliminates a common BA mistake (forgetting the fallback).
