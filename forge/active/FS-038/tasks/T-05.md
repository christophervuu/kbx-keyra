## Summary

Implement the Source entry flow: the default and most prominent entry point in the redesigned Builder. This includes the entry-point selector (Source/Static/External), the Source Card component that shows the selected source field with "Direct copy" label, the "+ Add logic" button, and integration with the source panel's click-to-stage and drag-and-drop.

---

## Scope

### In Scope

- Entry-point selector component: segmented control with Source (default, selected), Static, External (disabled)
- Source Card for direct copy: `[Source: path] [Direct copy] [+ Add logic]`
- Source field selection via source panel click-to-stage callback
- Source field selection via drag-and-drop (reuse existing `useDropZone`)
- Empty state when no source is selected: prompt to select a source field
- Entry-type switching with confirmation dialog when logic steps exist (AE-13)
- External entry point: disabled, muted, tooltip "External data sources — available in a future release" (AE-19)

### Out of Scope

- Static entry flow content (T-06)
- "+ Add logic" refinement picker content (T-07)
- Transform steps, condition, or value map builders (T-08–T-10)
- Expression generation (T-02 handles this)

## Change Requirements

- Create entry-point selector component (e.g., `EntryPointSelector`):
  - Three options: Source (default), Static, External
  - Source has primary visual weight (e.g., selected state, bold)
  - External is disabled with tooltip
  - Switching from Source to Static (or vice versa) when `logicSteps.length > 0` shows confirmation dialog
  - Fires `onEntryTypeChange(type: BuilderEntryType)` callback
- Create redesigned Source Card component as a **new component** `ChainSourceCard.tsx` (Q2 resolved at Rev 2: the mental model shift justifies a clean break; do NOT evolve existing `SourceCard.tsx`):
  - Header: source field path in a chip/badge
  - "Direct copy" label when no logic steps
  - "[+ Add logic]" button (fires callback to T-07's picker)
  - When source is set and no logic: mapping is shown as complete (visual indicator)
- Source selection integration:
  - When a source field is clicked/staged from the source panel, update `ChainBuilderState.sourcePath`
  - When a source field is dropped on the builder (DnD), same behavior
  - Selecting a different source field updates the path in the existing state (preserves logic steps if any)
- Empty source state: render guidance text "Select a source field from the panel or drag one here"
