## Summary

Wire the new chain builder components into `ScalarFieldBuilder`, replacing the current `UnifiedExpressionBuilder` usage in Target View. This is the main integration task that assembles the new shell (T-04), entry flows (T-05, T-06), progressive disclosure (T-07), step forms (T-08–T-10), collapsible summaries (T-11), generator (T-02), and decomposer (T-03) into the production builder surface.

---

## Scope

### In Scope

- Replace `UnifiedExpressionBuilder` usage in `ScalarFieldBuilder` with the new `ChainBuilderShell` + chain builder content
- Wire `ChainBuilderState` management: initialize on target selection, update on user interaction, generate expression on state change
- Wire `generateExpressionFromChain` (T-02) to produce DSL on every state change → feed to `onExpressionChange`
- Wire `decomposeToChainState` (T-03) for builder hydration when selecting a target with existing expression
- Preserve existing integration points:
  - `onApply(targetPath, expression)` callback
  - `onExpressionChange(expression)` callback
  - `onClearMapping()` callback
  - `onAdvanceToNext()` callback
  - Drop zone for source field DnD
  - Builder/Editor mode toggle
  - "Next unmapped →" button
  - Apply button with validation gating
  - Dirty detection (current expression vs applied expression)
- State hydration flow:
  1. Target selected → look up existing rule expression
  2. If expression exists → `decomposeToChainState(expression)` → success → hydrate chain state, builder mode
  3. If decomposition fails → fall back to Editor mode with warning (same as current)
  4. If no expression → empty chain state (source entry, no source)
- Key the chain builder on `selectedTargetPath` for full reset between targets
- Live preview: wire `useExpressionPreview` to the generated expression → feed result to `ChainBuilderShell`

### Out of Scope

- Rules View integration (T-13)
- Removing old `UnifiedExpressionBuilder` component (keep it for Rules View until T-13)
- Removing legacy decomposers/generators (keep for backward compat until Rules View migrated)

## Change Requirements

- Modify `ScalarFieldBuilder` to render `ChainBuilderShell` instead of the current header + UnifiedExpressionBuilder:
  - Remove suggested-sources section
  - Remove mode tabs (Value/Conditional/ValueMap)
  - Replace with: `ChainBuilderShell` (header + AI bar + Expression + Result + content slot)
  - Content slot: entry-point selector + source card OR static input + logic steps
- Add local state management for `ChainBuilderState`:
  - `useState<ChainBuilderState>` initialized from decomposition result or empty state
  - `useEffect` to call `generateExpressionFromChain(state)` on state change and propagate via `onExpressionChange`
  - `useEffect` to run decomposition when `selectedTargetPath` or `currentExpression` changes
- Preserve all existing ScalarFieldBuilder external contract (props, callbacks)
- When in Editor mode: continue rendering `RawDslEditor` (unchanged)
- When in Builder mode: render the new chain builder surface
- Drop zone: when a source field is dropped/staged, update `chainState.sourcePath` and set entry type to 'source'
- Apply button: enabled when `isChainComplete(state)` returns true AND expression is non-empty
