## Summary

Define the new `ChainBuilderState` type system that replaces the current 3-mode `ExpressionBuilderState` model. This introduces the `BuilderEntryType` enum, `LogicStep` discriminated union, `TransformLogicStep`, `ConditionLogicStep`, `ValueMapLogicStep`, `ChainBranch`, and related types. These types are the foundation for all subsequent tasks.

---

## Scope

### In Scope

- New type definitions for the chain-based builder model
- `BuilderEntryType = 'source' | 'static' | 'external'`
- `ChainBuilderState` interface with entryType, sourcePath, staticValue, logicSteps, expandedStepIndex
- `LogicStep` discriminated union (transform / condition / valueMap)
- `TransformLogicStep` with implicit first arg + additional `ArgumentSlot[]`
- `ConditionLogicStep` with required then/else `ChainBranch`
- `ValueMapLogicStep` with mappings + required default `ChainBranch`
- `ChainBranch` discriminated union (static / source+steps / expression)
- Factory functions for creating default states: `createEmptyChainState`, `createSourceCopyState`, `createStaticState`
- Helper functions: `isChainComplete` (validates all required fields are filled), `summarizeLogicStep` (returns one-line summary string)

### Out of Scope

- Modifying or removing existing `ExpressionBuilderState` types (they remain for backward compatibility during migration)
- UI components
- Expression generation or decomposition logic
- Removing legacy Source Card types

## Change Requirements

- Create the new type definitions in `chain-builder-state.ts` (confirmed at Rev 2: new file, not extending existing `expression-builder-state.ts`)
- Reuse existing `ArgumentSlot`, `StaticValue`, `ConditionGroup`, `ConditionRow`, `ComparisonOperator`, `ValueMapEntry` types where they are compatible with the new model
- Where existing types are incompatible, define new types with clear names that don't collide
- Export all new types from the feature barrel (`ui/src/features/mappings/index.ts`)
- Factory functions must return valid default states:
  - `createEmptyChainState()` → source entry, no sourcePath, empty logicSteps
  - `createSourceCopyState(path: string)` → source entry, sourcePath set, empty logicSteps
  - `createStaticState(value?: StaticValue)` → static entry, optional staticValue, empty logicSteps
- `isChainComplete(state: ChainBuilderState): boolean` checks:
  - source entry: sourcePath must be non-empty
  - static entry: staticValue must be defined
  - all logic steps must have required fields filled
  - condition steps: both then and else branches must be non-empty
  - value map steps: at least one mapping + default must be non-empty
- `summarizeLogicStep(step: LogicStep): string` returns a human-readable one-line summary
