## Summary

Create the new Builder shell component that establishes the redesigned layout: header row (target type + name + required + Builder/Editor toggle), AI action bar (Suggest/Explain/Fix + Clear), pinned Expression section, pinned Result section, and a scrollable content area for the entry-point-specific builder surface. Remove the suggested-sources row.

---

## Scope

### In Scope

- New shell component: `ChainBuilderShell` (or similar name)
- Header row: `[type badge] [target path] [required/optional tag] | [Builder/Editor toggle]`
- AI action bar row: `[Suggest] [Explain] [Fix]` (disabled/placeholder) | `[Clear]` (functional)
- Pinned Expression section: always-visible, live-updating, click-to-edit
- Pinned Result section: always-visible, live-updating, placeholder when no source data
- Scrollable content slot below pinned sections for entry-point builder content
- Remove suggested-sources row from the builder flow
- Tooltip on Suggest: "AI-powered expression suggestion — available in a future release"
- Clear button: visible when target has a mapping, fires `onClearMapping` callback

### Out of Scope

- Entry-point selector (T-05, T-06)
- Source Card, Static input, or any builder content (T-05–T-11)
- Expression generation/decomposition logic
- Changes to RawDslEditor
- Implementing AI Suggest/Explain/Fix functionality

## Change Requirements

- Create `ChainBuilderShell` component with the following layout structure:
  ```
  ┌──────────────────────────────────────────────────────┐
  │ Header: [type] [path] [required]    [Builder|Editor] │
  ├──────────────────────────────────────────────────────┤
  │ AI: [Suggest] [Explain] [Fix]              [Clear]   │
  ├──────────────────────────────────────────────────────┤
  │ Expression: {live DSL string}                        │
  │ Result: {live evaluated value}                       │
  ├──────────────────────────────────────────────────────┤
  │ (scrollable content area — children prop)            │
  │                                                      │
  │                                                      │
  └──────────────────────────────────────────────────────┘
  ```
- Props contract:
  - `targetPath: string`
  - `targetType: string`
  - `isRequired: boolean`
  - `expression: string` — current generated expression
  - `result: unknown | null` — current evaluated result
  - `isEvaluating: boolean` — result loading state
  - `sourceDataAvailable: boolean` — whether source data is loaded
  - `isMapped: boolean` — whether target has an existing mapping
  - `isBuilderMode: boolean` — Builder vs Editor toggle state
  - `onToggleMode: () => void`
  - `onClearMapping: () => void`
  - `onExpressionClick: () => void` — switch to editor mode
  - `children: React.ReactNode` — builder content slot
- Suggest/Explain/Fix buttons: render as disabled `Button` components with appropriate icons and tooltips
- Expression section: reuse or adapt `LiveExpressionDisplay` — make it a pinned (non-scrolling) section
- Result section: reuse or adapt `LiveResultDisplay` — make it a pinned (non-scrolling) section
- The content area below the pinned sections should be scrollable independently
- Ensure the layout works at minimum builder panel width (~300px)
