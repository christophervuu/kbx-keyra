## Summary

Implement the "+ Add logic" progressive disclosure mechanism. When clicked, it reveals three refinement options — Transformation, Condition, Value map — as a horizontal picker. Selecting one adds the appropriate `LogicStep` to the chain state and renders the corresponding builder surface (built in T-08, T-09, T-10).

---

## Scope

### In Scope

- "+ Add logic" button: appears on Source Card and Static value input when no logic steps exist
- Refinement picker: horizontal button group with three options: `[Transformation]` `[Condition]` `[Value map]`
- Each option has a brief description or icon
- Selecting an option:
  - Transformation → appends a `TransformLogicStep` (empty, ready for function selection) to `logicSteps`
  - Condition → appends a `ConditionLogicStep` (empty condition, empty then/else) to `logicSteps`
  - Value map → appends a `ValueMapLogicStep` (empty mappings, empty default) to `logicSteps`
- "+ Add step" button: appears after existing transform steps to add another transform to the chain
- Dismissal: clicking outside the picker or pressing Escape closes it without action

### Out of Scope

- Transform step form content (T-08)
- Condition builder form content (T-09)
- Value map builder form content (T-10)
- Collapsible summaries (T-11)

## Change Requirements

- Create `AddLogicPicker` component (or similar name):
  - Renders as a horizontal row of three option cards/buttons
  - Each option: icon + label + brief description
    - Transformation: "Apply a function to the current value" (e.g., uppercase, trim, concatenate)
    - Condition: "Add if/then/else logic" (e.g., different value based on a condition)
    - Value map: "Map specific values to outputs" (e.g., A→Active, B→Inactive)
  - Fires `onSelectLogicKind(kind: 'transform' | 'condition' | 'valueMap')` callback
- Create `AddStepButton` component for chain extension:
  - Appears below existing transform steps
  - Opens the `TransformFunctionPicker` (existing) to select the next transform
  - Filtered by type compatibility (reuse `getCompatibleChainableTransforms` from FS-030)
- State management:
  - When Transformation is selected: if this is the first logic step, show `TransformFunctionPicker` immediately for function selection
  - When Condition or Value map is selected: add the step to `logicSteps` and expand it for editing
  - Set `expandedStepIndex` to the new step's index

## Notes

- The picker is intentionally a flat horizontal layout, not a dropdown or modal. It should feel like expanding a set of choices, not opening a separate surface.
- Plain-language descriptions on each option are key to the BA-first UX principle. Avoid implementation terminology like "if() function" or "valueMap() DSL call."
