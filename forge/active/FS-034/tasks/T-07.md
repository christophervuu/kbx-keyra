## Summary
Replace the existing `TestCaseManager` in `AdvancedTestingPage` with the new `TestCaseListPanel` and wire all hooks together (`useTestCases`, `useTestRunResults`, `useBatchExecution`). This is the integration task that brings the full test case management experience to life on the Advanced Testing page.

---

## Scope

### In Scope
- Replace `TestCaseManager` with `TestCaseListPanel` in the left panel
- Wire `useTestCases` (with new rename/duplicate/update methods) into list callbacks
- Wire `useTestRunResults` into list status badges and batch result recording
- Wire `useBatchExecution` into Run All / Rerun Failed buttons
- Implement scratchpad vs saved-case selection model at composition level
- Selection state: `selectedTestCaseId: string | null` (null = scratchpad)
- On select: load test case sourceData into textarea; on select scratchpad: clear source data (scratchpad is ephemeral — always starts empty)
- On Add New: save blank case, select it, clear textarea
- On Save Current: save case from current source data, select it
- On batch case complete: call `recordResult` on `useTestRunResults`
- Disable source textarea and Run button during batch execution
- Ensure existing functionality (tabs, trace toggle, auto-run, diff tab) continues to work

### Out of Scope
- Changes to the right-panel tab content (Output, Diagnostics, Trace, Diff)
- Changes to the ConnectedInlinePreviewStrip (T-08)
- Changes to the engine

## Change Requirements
- `AdvancedTestingInner` gains `selectedTestCaseId` state (null = scratchpad)
- On test case selection: `setSourceDataRaw(tc.sourceData)`, update `loadedSourceData` and `loadKey`
- On scratchpad selection: clear source data state
- On Add New: call `saveTestCase({ name: 'Test Case N', sourceData: '' })`, select the returned case
- On Save Current: call `saveTestCase({ name, sourceData: sourceDataRaw })`, select the returned case
- On rename/duplicate/delete: delegate to `useTestCases` methods
- Batch execution wiring: `useBatchExecution({ config, sourceSchema, targetSchema, onCaseComplete })` where `onCaseComplete` calls `recordResult`
- `runAll` passes all `testCases`; `rerunFailed` passes failed subset
- Left panel layout change: `TestCaseListPanel` replaces `TestCaseManager`, may need layout adjustment for vertical list height
- Remove import/usage of old `TestCaseManager` from this file (or keep it if used elsewhere — check)
