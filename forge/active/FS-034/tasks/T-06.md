## Summary
Add "Run All" and "Rerun Failed" action buttons to the `TestCaseListPanel` toolbar area, along with a progress indicator during batch execution. These buttons wire into the `useBatchExecution` hook via callbacks.

---

## Scope

### In Scope
- Add "Run All" button to toolbar — disabled when no saved test cases or batch is running
- Add "Rerun Failed" button to toolbar — disabled when no test cases have `fail` status or batch is running
- Progress indicator during batch: "Running N/M..." text with a subtle animation or spinner
- Summary after batch completion: "N passed, M failed" inline text
- Disable individual Run and source editing during batch execution (via prop)
- Cancel button during batch execution

### Out of Scope
- Batch execution hook logic (T-05)
- Wiring into AdvancedTestingPage (T-07)

---

## Relevant Areas
- `ui/src/features/mappings/components/preview/TestCaseListPanel.tsx`
- `ui/src/features/mappings/components/preview/TestCaseListPanel.test.tsx`

## Change Requirements
- Props additions to `TestCaseListPanel`: `onRunAll()`, `onRerunFailed()`, `onCancel()`, `batchState: { isRunning: boolean; progress: { current: number; total: number } | null; summary: { passed: number; failed: number } | null }`
- "Run All" button: play icon, disabled when `testCases.length === 0` or `batchState.isRunning`
- "Rerun Failed" button: refresh icon, disabled when no failed cases in `runResults` or `batchState.isRunning`
- Progress: replaces buttons during execution, shows "Running {current}/{total}..." with Cancel button
- Summary: shown after batch completion for ~5 seconds, then fades or can be dismissed
- During batch: individual test case rows show a subtle loading indicator for the currently executing case
