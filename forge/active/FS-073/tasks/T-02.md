## Summary

Implement section/chunk generation orchestration so Auto-Map can process broad and very large scopes safely, invoking shared AI runtime per chunk and aggregating chunk outcomes into one response envelope.

- Chunk planning strategy and limits for Auto-Map generation (50–100 target fields per chunk default).
- Per-chunk invokeAI orchestration and bounded concurrency (max 4 parallel generations per request in Lambda path).

- Tests for large-scope behavior and chunk execution correctness.
