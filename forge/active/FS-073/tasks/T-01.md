## Summary

Refactor Auto-Map backend request handling so source context is assembled through existing schema retrieval infrastructure (OpenSearch + schema node metadata) based on mapping/schema/scope identifiers, replacing prompt-time dependency on UI-constructed full context strings.

---

## Scope

### In Scope

- Request contract updates needed for backend-owned retrieval inputs.
- Retrieval query wiring against existing schema query/index modules.
- Source-context shaping for Auto-Map prompt variables.
- Explicit no-context success response metadata.
- Backend tests for retrieval success/no-context paths.

### Out of Scope

- Chunk orchestration merge/dedup implementation details.
- UI workspace rendering behavior.
- Prompt authoring changes.

---

## Relevant Areas

- `src/lambda/ai/auto-map.ts`
- `src/lib/schema/opensearch/query.ts`
- `src/lib/schema/dynamo/node-reader.ts`
- `src/lambda/schema/query-schema-nodes.ts`
- `ui/src/lib/types/domain.ts`
- `tests/lambda/ai/auto-map.test.ts`

---

## Change Requirements

- Auto-Map endpoint accepts retrieval-identifying inputs (mapping/source schema/section scope) plus `mode: "section" | "whole"` sufficient for backend context assembly.
- Backend builds source context from schema index/query results using weighted hybrid lexical retrieval (BM25 on `fieldName`/`path`/`description` + heuristics) and applies deterministic bounds/filters before prompt rendering.
- Endpoint returns explicit empty-result metadata when retrieval yields no relevant source context.
- No direct full-schema prompt assembly path is introduced.
- Retrieval telemetry includes at minimum `retrievalCandidatesCount` and `retrievalSelectedCount` tied to `requestId` and `mappingId`.

---

## Verification Requirements

- Unit tests for retrieval invocation and query-parameter shaping.
- Unit tests for no-context success behavior and metadata shape.
- Unit tests for `mode`-specific retrieval behavior (`section` vs `whole`).
- Regression tests for invalid request and not-found behavior.
- Typecheck for touched backend files.

---

## Acceptance Checks

- Auto-Map generation no longer depends on UI sending full source context blobs for primary flow.
- Retrieval path uses existing schema query/index architecture.
- No-context requests return deterministic, non-error empty suggestion responses.
- Tests mapped to `AE-01` and `AE-06` pass.
