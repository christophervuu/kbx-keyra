## Summary

Connect UI CDM-related adapter methods to backend endpoints and implement/update Project Overview CDM library picker behavior so users can browse CommonDataModels-only entries and link schemas to the project.

---

## Scope

### In Scope

- Implement `HttpAdapter` mappings for `listCdmSchemas` and `linkCdmSchema`.
- Update CDM picker integration in project schema link flow.
- Ensure picker renders only CDM library entries and supports user selection/confirm.
- Surface clear, non-technical errors for listing/link failures.

### Out of Scope

- Re-sync UI behavior and status badges.
- Schema Detail action gating changes.
- Backend endpoint logic.

## Change Requirements

- UI must call backend CDM list/link operations in backend mode.
- Link-from-CDM experience must show only CommonDataModels entries.
- Linking success must attach schema to project and refresh relevant project view state.
- Error copy must be actionable and user-friendly.
