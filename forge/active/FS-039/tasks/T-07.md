## Summary
Implement accordion-style collapse/expand behavior for chain steps in the Builder. Each step can be expanded (full editor) or collapsed (summary text). Only one step can be expanded at a time. Newly added steps start expanded. Incomplete steps cannot collapse. Implement summary text renderers for all step types.

---

## Scope

### In Scope
- Accordion state management: `expandedStepIndex: number | null` in the builder
- Collapse toggle on each step header
- Auto-collapse previous step when new step is added
- Auto-expand new steps on creation
- Block collapse for structurally incomplete steps
- Summary text renderer for TransformStep: `functionName(args summary)`
- Summary text renderer for ConditionStep: `If {predicate} then {summary} else {summary}`
- Summary text renderer for ValueMapStep: `Map {N} values, default: {summary}`
- Summary text renderer for ChainSource: `source("path")` or literal value
- Truncation at ~80 chars with ellipsis
- Click summary to re-expand

### Out of Scope
- Condition step full editor (T-08)
- Value map step full editor (T-09)

## Change Requirements
Add `expandedStepIndex` state to the builder. Each step renders as a `ChainStepCard` with a header (summary + expand/collapse toggle) and a body (full editor). When collapsed, only the header is visible. When expanded, both header and body are visible. Clicking a collapsed step's header expands it and collapses the currently expanded step. New steps auto-expand. The `isStructurallyValid(step)` check determines whether a step can collapse — invalid steps stay expanded. Create `chain-summary.ts` with `summarizeStep(step): string` and `summarizeChain(chain): string` pure functions.
