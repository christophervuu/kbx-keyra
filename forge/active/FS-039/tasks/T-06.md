## Change Requirements
`UnifiedExpressionBuilder` manages a `ChainState` internally. On mount/prop change, it hydrates via `decomposeToChain(initialExpression)`. On every state change, it calls `generateExpressionFromChain(chain)` and propagates the result. The component renders: (1) source selector, (2) ordered step list, (3) `[+ Add Step]` button when last step is valid. The step picker shows transform functions filtered by `getCompatibleChainableTransforms(outputType)`, plus "Add condition" and "Add value map" entries. Mode tabs (Value/Conditional/ValueMap) are removed — the chain model subsumes them.
