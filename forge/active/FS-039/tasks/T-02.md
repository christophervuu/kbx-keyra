## Summary
Implement a new `generateExpressionFromChain(chain: ChainState): string` function that walks a `ChainState` tree and produces the equivalent DSL expression string. This replaces the role of `pipeline-expression-generator.ts` and `source-card-expression-generator.ts` for the new chain model.

- Handle all ChainSource variants (field → `source("path")`, static → literal DSL, none → empty string)
- Handle TransformStep: wrap previous expression as first arg, additional args appended
- Handle ConditionStep: generate `if(predicate, thenExpr, elseExpr)` with nested `if()` for else-if chains
- Handle ValueMapStep: generate `valueMap(currentExpr, { mappings }, defaultExpr)`
- Handle nested chains within condition branches and value map outputs
- Unit tests for all step types and nesting combinations

## Change Requirements
Create `chain-expression-generator.ts` with `generateExpressionFromChain()`. The function must recursively walk the chain: start with source expression, then for each step in order, wrap the accumulator. TransformSteps produce `functionName(accumulator, ...args)`. ConditionSteps produce `if(predicateExpr, thenChainExpr, elseChainExpr)` where predicate expressions use comparison operators (eq, neq, gt, lt, etc.). ValueMapSteps produce `valueMap(accumulator, { "input1": output1, ... }, defaultExpr)`. Empty chains (source kind: none, no steps) return empty string.
