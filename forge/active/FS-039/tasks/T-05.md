## Change Requirements
`ScalarFieldBuilder` no longer has an Apply button. Every expression change (from `ChainBuilder` or raw Editor) calls `updateDraft(targetPath, expression)` through the parent hook. On target field selection, hydration checks `getDraftExpression()` first (for in-progress edits from previous navigation), then falls back to saved rule decomposition, then to empty state. A "Discard changes" button appears when the current field's draft differs from saved. Clicking it calls `revertDraft(targetPath)` and re-hydrates from saved.
