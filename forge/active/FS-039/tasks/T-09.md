## Summary
Implement the full value map step editor UI within the chain-based Builder. Value maps have required default cases that cannot be removed. Each mapping row has an input value and an output chain. Completed value maps collapse into readable summaries.

- Summary rendering for collapsed value map steps

## Change Requirements
Create `ValueMapStepEditor.tsx` that renders the value map editing UI. The editor shows: (1) mapping rows table with input value text field and output chain mini-builder per row, (2) `[+ Add Mapping]` button, (3) default case row (always present, non-removable) with its own output chain. The value map implicitly operates on the current chain value (no separate source selector needed — it maps from whatever the previous step produced). When complete (default filled, all rows have values), it can collapse to summary: `Map N values, default: {summary}`.
