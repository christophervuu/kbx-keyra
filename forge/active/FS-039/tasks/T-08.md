## Summary
Implement the full condition step editor UI within the chain-based Builder. Conditions are total (else is required and cannot be removed). Both Then and Else branches support full chains (source + steps). Completed conditions collapse into readable summaries. Supports else-if by adding additional condition clauses.

- Else branch: full chain editor (always present, cannot be removed)
- "Add else-if" action

## Change Requirements
Create `ConditionStepEditor.tsx` that renders the full condition editing UI. The editor shows: (1) IF clause with predicate rows (AND-combined), (2) THEN branch as an embedded chain builder, (3) ELSE branch as an embedded chain builder (always present, structural requirement). Add "Add else-if" to insert additional clauses. The else branch label is always "ELSE" — it is never omitted. Branch chain editors are mini-chain builders that recursively use the same chain rendering components. When the condition step is complete (all predicates filled, both branches valid), it can collapse to its summary. Expression generation for conditions produces `if(predExpr, thenChainExpr, elseChainExpr)` with nested `if()` for else-if.
