## Objective

Install Playwright and create the base configuration for running E2E tests against the KeyRa UI.

## Context

The project currently has no E2E testing infrastructure. This task bootstraps Playwright with TypeScript, configures it to start the Vite dev server automatically, and adds the necessary scripts to run tests.

## Requirements

- Install `@playwright/test` as a dev dependency at workspace root
- Install Chromium browser via `npx playwright install chromium`
- Create `tests/e2e/playwright.config.ts` with:
  - `testDir`: `./specs`
  - `baseURL`: `http://localhost:5173`
  - `webServer.command`: `pnpm --filter @keyra/ui dev`
  - `webServer.port`: `5173`
  - `webServer.reuseExistingServer`: `!process.env.CI`
  - Single project: Chromium desktop
  - `timeout`: 30000
  - `actionTimeout`: 5000
  - `reporter`: `html` (CI reporter deferred to follow-up spec)
  - `retries`: 0 (CI retries deferred to follow-up spec)
- Add `"test:e2e": "playwright test --config tests/e2e/playwright.config.ts"` script to root `package.json`
- Create empty `tests/e2e/specs/` directory with a `.gitkeep` or trivial placeholder
- Verify `pnpm test:e2e` starts the dev server and exits cleanly (no tests to run yet is OK)

## Acceptance Criteria

- [ ] `@playwright/test` is in root `devDependencies`
- [ ] `tests/e2e/playwright.config.ts` exists and is valid TypeScript
- [ ] Config targets Chromium only
- [ ] `webServer` block starts Vite dev server on port 5173
- [ ] `pnpm test:e2e` command is available and executes Playwright
- [ ] No changes to `ui/package.json` — Playwright is workspace-root level

## Notes

- Use `defineConfig` from `@playwright/test` for type safety
- CI-specific config (retries, reporter, Docker) deferred to a follow-up spec
- Don't install Firefox/WebKit — Chromium only for Phase 0
- Output directory for test results: `tests/e2e/test-results/` (gitignored)
- HTML report directory: `tests/e2e/playwright-report/` (gitignored)
- Add both directories to root `.gitignore`
