## Summary

Add a footer action row to the ArrayBuilder with the same structural container as ScalarFieldBuilder's. Both builders share consistent action row container styling, but contents are capability-driven: the scalar builder shows AI action buttons (Suggest, Explain) alongside Reset/Discard, while the array builder shows only Reset/Discard — no AI buttons until array-level AI features exist. The guiding principle is: use consistent structure for real affordances, but do not add disabled controls purely for visual symmetry.

---

## Scope

### In Scope

- Add a footer action row to ArrayBuilder with `shrink-0 border-t border-slate-700 px-4 py-2`
- Include Reset draft action (with inline confirmation for non-trivial expressions) in array builder action row
- Include Discard changes action (visible when field is dirty) in array builder action row
- Do **not** include AI action buttons (Suggest, Explain) in array builder — omit until array-level AI features exist
- Ensure ScalarFieldBuilder's action row uses the same container styling (same padding, border, positioning)
- Normalize both action rows to use the same structural container component or consistent inline structure; contents differ based on available capabilities

### Out of Scope

- AI feature implementation for arrays
- Adding AI buttons (Suggest, Explain) to array builder — they are intentionally omitted, not disabled
- Functional changes to existing scalar builder AI buttons
- Changes to Reset/Discard behavior (existing logic is reused)
- Visual frame or header changes
