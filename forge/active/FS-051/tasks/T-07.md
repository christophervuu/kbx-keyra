## Summary

Update `forge/architecture/ui-application.md` to document the unified builder visual system established by FS-051. This includes documenting the shared visual shell pattern, the Builder/Editor toggle pattern for both builders, the overflow menu (⋮) in both builder headers, the retirement of Custom Expression as a mode card in ArrayBuilder, the capability-driven action row contents, and the intentional-differences-only principle for builder-specific content.
