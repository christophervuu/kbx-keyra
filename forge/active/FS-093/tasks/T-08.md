## Summary

Update Mapping Editor authoring surfaces to present primary and enrichment inputs together, rename source-oriented terminology, and enable guided rule authoring from enrichment fields that generates correct DSL expressions.

---

## Scope

### In Scope

- Rename Source Fields/Browse Source terminology to Input Fields/Browse Inputs in guided surfaces.
- Input browser grouping by Primary Source + Enrichment Inputs aliases.
- Selection behavior:
  - primary field -> `source("path")`
  - enrichment field -> `get(external("alias"), "path")`
- Builder value-source options include Enrichment input.
- Rule summary labels distinguish primary-only, enrichment-only, mixed/expression forms.
- Include minimal guided mixed primary/enrichment conditional builder support (Phase 1 baseline).

### Out of Scope

- Advanced/nested conditional builder enhancements beyond minimal mixed support (Phase 2).
- Advanced mode raw DSL redesign beyond naming adjustments.

---

## Relevant Areas

- `ui/src/features/mappings/components/MappingEditorPage.tsx`
- `ui/src/features/mappings/components/*Builder*`
- `ui/src/features/mappings/components/SourceSchemaPanel.tsx` and related input tree components
- mapping editor hooks/tests

---

## Change Requirements

- Guided UX must avoid forcing users to author raw DSL for enrichment field mapping.
- Advanced mode still shows raw DSL for power users.
- Mixed expressions combining primary + enrichment remain supported.
- Guided terminology uses “Enrichment input”; “external(...)” wording is confined to Advanced Mode/raw DSL/technical details.

---

## Verification Requirements

- Component/integration tests for grouped input rendering and selection DSL generation.
- Tests for rule summary labels and value source option behavior.
- UI lint/typecheck/tests for touched modules.

---

## Acceptance Checks

- Mapping Editor shows primary + enrichment input groups.
- Builder can create enrichment-based rules and mixed rules.
- Generated DSL for enrichment selection uses `get(external("alias"), "path")`.
- Minimal guided mixed conditional flow is available in Phase 1 (advanced/nested deferred).
