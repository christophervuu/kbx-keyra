## Summary

Deliver Smart Fix suggestion review UI that clearly shows original vs corrected expression and before/after explanation, supports explicit accept/edit/dismiss actions, and triggers immediate rule re-validation on apply.

---

## Scope

### In Scope

- Add/update Smart Fix suggestion UI in mapping rule/diagnostic surfaces.
- Display original expression, suggested expression, explanation, and validation status.
- Implement explicit Accept, Edit, and Dismiss interactions.
- Gate one-click Accept on validation-valid suggestions; no “Apply anyway” path for invalid suggestions (edit-to-valid required).
- Trigger and render immediate re-validation outcome after apply.
- Enforce hard stale-check apply gating using rule hash/version snapshot; on mismatch, block direct apply and offer re-run on latest rule.
- Add/update UI tests for interaction and non-mutation behavior.

### Out of Scope

- Backend endpoint/runtime changes.
- New AI capabilities beyond Smart Fix suggestion review.
- Full mapping editor redesign.

## Change Requirements

- Smart Fix UI clearly indicates AI-generated assistance and non-persistent nature.
- Before/after expression context and explanation are readable and deterministic.
- Accept/apply updates draft expression and triggers immediate validation refresh.
- Edit allows user modifications prior to apply.
- Dismiss closes Smart Fix suggestion without modifying rule expression.

---

## Verification Requirements

- Component tests for valid suggestion accept/apply path with re-validation trigger.
- Component tests for edit-then-apply behavior (including edit-to-valid requirement for previously invalid suggestion).
- Component tests for invalid suggestion acceptance gating and diagnostics display.
- Component tests for stale mismatch behavior (apply blocked + re-run CTA) and dismiss behavior/no-change guarantee.
- Typecheck for touched UI files.

---

## Acceptance Checks

- UI exposes explicit accept/edit/dismiss actions for Smart Fix suggestions.
- Re-validation is triggered and reflected immediately after apply.
- Invalid suggestions are not silently one-click accepted; edit-to-valid is required.
- Stale hash/version mismatch blocks direct apply and offers re-run on latest rule.
- Dismiss/failure paths preserve rule/draft state.

---

## Blockers / Risks

- Interaction placement in existing diagnostic surfaces may require minor UX harmonization with Explain/Suggest patterns.

---

## Notes

- Reuse existing AI suggestion interaction conventions where possible for consistency.
