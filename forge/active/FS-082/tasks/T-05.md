## Summary

Implement runtime execution and observability-facing status endpoints so mappings execute strictly from local runtime state and operators can verify environment readiness.

---

## Scope

### In Scope

- Implement `POST /internal/execute` runtime handler.
- Implement `GET /internal/health` and `GET /internal/status/{mappingId}` handlers.
- Active-pointer lookup and local artifact fetch path.
- Deterministic not-deployed behavior when pointer is missing.
- Structured logging fields for deploy/rollback/execute/status requests.

### Out of Scope

- Control-plane orchestration endpoints.
- UI surfaces.

## Change Requirements

- Execute handler resolves snapshot strictly from local DynamoDB/S3.
- Execute handler never reads deployment state from sandbox/control plane.
- Health/status handlers report runtime readiness and pointer/deployment summary.
- Logs include requestId, mappingId, snapshotId (if present), outcome, duration.
