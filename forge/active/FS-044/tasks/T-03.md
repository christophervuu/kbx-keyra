## Summary

Create local test fixture files for the suggest-expression Lambda and a local prompt record fixture for the `nl-to-rule` prompt. These fixtures serve two purposes: (1) documenting the expected request/response contract for the Lambda, and (2) enabling local-mode testing of the full AI pipeline when `AI_RUNTIME_MODE=local`. The fixtures follow the exact pattern established by the explain-rule fixtures.

### Local Prompt Record Fixture

Create `tests/lib/ai/fixtures/local-runtime/nl-to-rule.json`:

```json
{
  "promptId": "nl-to-rule",
  "version": 1,
  "systemMessage": "You are a DSL expression generator.\n{{dslReference}}",
  "userMessageTemplate": "Generate a DSL expression for target={{targetPath}} (type={{targetType}}, description={{targetDescription}}).\nInstruction: {{instruction}}\nAvailable source fields:\n{{sourceFields}}",
  "model": "openai/gpt-4.1-mini",
  "temperature": 0,
  "responseSchema": "{\"type\":\"object\",\"properties\":{\"expression\":{\"type\":\"string\"},\"explanation\":{\"type\":\"string\"},\"confidence\":{\"type\":\"string\"},\"assumptions\":{\"type\":\"array\",\"items\":{\"type\":\"string\"}}},\"required\":[\"expression\",\"explanation\",\"confidence\",\"assumptions\"],\"additionalProperties\":false}",
  "maxTokens": 500,
  "updatedAt": "2026-05-11T00:00:00.000Z",
  "updatedBy": "fixture"
}
```

Key characteristics of this fixture:
- `promptId`: `nl-to-rule` (matches the Lambda's promptId)
- `model`: `openai/gpt-4.1-mini` (Tier 1 per spec)
- `temperature`: 0 (deterministic)
- `systemMessage` includes `{{dslReference}}` placeholder
- `userMessageTemplate` includes all expected placeholders: `{{targetPath}}`, `{{targetType}}`, `{{targetDescription}}`, `{{instruction}}`, `{{sourceFields}}`
- `responseSchema` defines: `expression` (string, required), `explanation` (string, required), `confidence` (string, required), `assumptions` (array of strings, required), `additionalProperties: false`
- `maxTokens`: 500 (reasonable for a single expression + explanation)

## Notes

- The `nl-to-rule.json` prompt fixture is intentionally simplified for local testing. The real production prompt in the Prompt Registry will have a much more detailed system message and user message template. The fixture only needs to be structurally valid so the local adapter can load it and the prompt renderer can substitute placeholders.
- The `responseSchema` in the fixture must match what the model is expected to return. The schema includes `additionalProperties: false` to enforce strict structured output per the OpenAI SDK's `json_schema` mode.
- The `valid-concat-fields` fixture demonstrates a different use case (string concatenation vs. default value) to show the Lambda handles varied instruction types.
