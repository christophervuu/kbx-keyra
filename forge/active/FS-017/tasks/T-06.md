## Summary

Implement the "External Sources" section within the ConfigurationPanel. This section manages `config.externalSources` — an array of declared external source names that rules reference via `external("sourceName")`. Users can add and remove source names. The section includes a note explaining that external sources are resolved at runtime and return null in client-side preview.

---

## Scope

### In Scope

- `ExternalSourcesSection` component
- Display: list of declared external source names
- Add: text input for source name + add button
- Remove: X button on each entry with confirmation dialog
- Duplicate prevention: inline error "Source already declared" if name exists
- Empty name prevention: add button disabled until name is non-empty
- Runtime note displayed in the section: "External sources are resolved at runtime. In client-side preview, external sources return null."
- Empty state: "No external sources declared" message
- Calls `onUpdateConfig({ externalSources: updatedArray })` on add/remove

### Out of Scope

- Actually resolving external sources at runtime (engine/preview responsibility)
- Configuring external source endpoints or data (Phase 1+)
- Validating source name format (any non-empty string is valid)
