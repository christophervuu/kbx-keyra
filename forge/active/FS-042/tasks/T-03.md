## Summary

Add a `suggestExpression` override to the existing `HybridAdapter` class so that when `VITE_API_URL` is configured, suggest-expression calls go through the HTTP client instead of throwing "Not available in offline mode." This mirrors the existing `explainRule` override pattern.

- Import `suggestExpressionHttp` from `./ai-api-client`
- Add unit test verifying the override delegates to HTTP

### Out of Scope

## Change Requirements

### `hybrid-adapter.ts`

Add the import and override:

```typescript
import { explainRuleHttp, suggestExpressionHttp } from './ai-api-client';
// ...existing code...

export class HybridAdapter extends LocalStorageAdapter {
  private readonly apiUrl: string;

  constructor(apiUrl: string) {
    super();
    this.apiUrl = apiUrl;
  }

  override async explainRule(input: ExplainRuleInput): Promise<ExplainRuleResult> {
    return explainRuleHttp(this.apiUrl, input);
  }

  override async suggestExpression(input: SuggestExpressionInput): Promise<SuggestExpressionResult> {
    return suggestExpressionHttp(this.apiUrl, input);
  }
}
```

### Tests

Add a test case:

- Verify CRUD methods still delegate to `LocalStorageAdapter` (existing tests)
