### Hook and component integration

The ChainBuilderShell will need access to:
- `useSuggestExpression()` hook state
- The current target path and type
- The parsed source schema (for source field extraction)
- A way to update the draft expression on Accept

The integration approach depends on ChainBuilderShell's prop interface. If the shell receives the expression via props and updates it via a callback (e.g., `onExpressionChange`), then Accept should call that callback with the suggested expression.

### SuggestExpressionInline placement

Render below the `AiActionBar`, before the main chain builder content:

```tsx
<SuggestExpressionInline
  state={suggestState}
  targetPath={targetPath}
  targetType={targetType}
  onGenerate={handleGenerate}
  onAccept={handleAcceptSuggestion}
  onDismiss={dismiss}
/>
```

### Accept handler

The Accept action should update the field's expression. In ChainBuilderShell context, this likely means:
- If the shell has an `onExpressionChange` or `updateDraft` prop: call it with the suggested expression
- The chain builder may then need to re-hydrate/decompose the expression (existing behavior when expression changes externally)
