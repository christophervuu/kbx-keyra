## Summary

Create the `useSchemaLibrary` data hook and pure filter/sort utility functions that power the Schema Library page. The hook loads all schemas and projects from `LocalStorageAdapter`, derives an enriched display model (including project usage counts and sync status), and exposes state + actions for search, filter, and sort. The pure utilities handle the combinatorial filter/sort logic and are unit-testable independently.

---

## Scope

### In Scope

- `use-schema-library.ts` hook: loads schemas via `listSchemas()`, loads projects via `listProjects()`, derives enriched `SchemaLibraryItem[]` model.
- Enrichment logic: project usage count derivation, sync status derivation, display format derivation (including "Inferred" detection).
- `schema-filters.ts` pure utility: `filterSchemas()` function implementing search + multi-select filter logic (AND between categories, OR within).
- `schema-filters.ts` pure utility: `sortSchemas()` function implementing sort by name/fieldCount/updatedAt/origin.
- Types: `SchemaLibraryItem`, `SchemaLibraryFilters`, `SchemaLibrarySort`, `SyncStatus`, `DisplayFormat`.
- Unit tests for filter/sort utilities.
- Unit tests for the hook (loading states, enrichment, retry).

### Out of Scope

- Card component rendering (T-02).
- Filter/sort UI controls (T-03).
- Page-level composition (T-04).
- Any mutation operations on schemas.

## Change Requirements

**Types (in `ui/src/features/schemas/types.ts`):**

```ts
export type SyncStatus = 'synced' | 'not-synced' | 'local-changes' | 'local' | 'inferred';
export type DisplayFormat = 'JSON Schema' | 'XSD' | 'Inferred';

export interface SchemaLibraryItem {
  schemaId: string;
  name: string;
  description?: string;
  origin: SchemaOrigin;
  scope: 'global' | 'project';
  format: SchemaFormat;
  displayFormat: DisplayFormat;
  fieldCount: number;
  syncStatus: SyncStatus;
  projectCount: number;
  projectNames: string[];
  updatedAt: string;
  createdAt: string;
}

export interface SchemaLibraryFilters {
  search: string;
  origins: SchemaOrigin[];
  formats: DisplayFormat[];
  scopes: Array<'global' | 'project'>;
}

export type SortField = 'name' | 'fieldCount' | 'updatedAt' | 'origin';
export type SortDirection = 'asc' | 'desc';

export interface SchemaLibrarySort {
  field: SortField;
  direction: SortDirection;
}
```

**Filter/sort utilities (in `schema-filters.ts`):**

- `filterSchemas(items: SchemaLibraryItem[], filters: SchemaLibraryFilters): SchemaLibraryItem[]`
  - Search: case-insensitive substring match on `name` and `description`
  - Origin filter: OR within (empty = all pass)
  - Format filter: OR within (empty = all pass)
  - Scope filter: OR within (empty = all pass)
  - Categories combine with AND

- `sortSchemas(items: SchemaLibraryItem[], sort: SchemaLibrarySort): SchemaLibraryItem[]`
  - Name: locale-aware alphabetical
  - Field count: numeric
  - Updated at: ISO date string comparison
  - Origin: defined order (cdm=0, published=1, local=2) for consistent sort

**Hook (`use-schema-library.ts`):**

- Uses `useAdapter()` to get adapter instance.
- On mount: calls `listSchemas()` and `listProjects()` in parallel.
- Derives `SchemaLibraryItem[]` from raw data (cross-references projects for usage counts).
- Exposes:
  - `items: SchemaLibraryItem[]` (the full enriched list, before filtering)
  - `filteredItems: SchemaLibraryItem[]` (after search/filter/sort applied)
  - `status: 'loading' | 'success' | 'error'`
  - `error: string | null`
  - `totalCount: number`
  - `filters: SchemaLibraryFilters`
  - `sort: SchemaLibrarySort`
  - `setSearch(term: string): void`
  - `toggleOriginFilter(origin: SchemaOrigin): void`
  - `toggleFormatFilter(format: DisplayFormat): void`
  - `toggleScopeFilter(scope: 'global' | 'project'): void`
  - `setSort(field: SortField, direction?: SortDirection): void`
  - `clearFilters(): void`
  - `retry(): void`

**Sync status derivation logic:**
- `source.type === 'github'` + `commitSha` present → `'synced'`
- `source.type === 'github'` + no `commitSha` → `'not-synced'`
- `source.type === 'upload'` → `'local'`
- If schema metadata indicates inferred → `'inferred'`

**Display format derivation:**
- `format === 'json-schema'` and not inferred → `'JSON Schema'`
- `format === 'xsd'` → `'XSD'`
- Inferred → `'Inferred'`
