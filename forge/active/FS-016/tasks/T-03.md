## Summary

Create the UI control components for the Schema Library: a search text input, multi-select filter toggles (origin, format, scope), a sort dropdown/selector, active filter chips with remove capability, and a "Clear all filters" action. These components are stateless presentational controls that receive values and callbacks from the parent page.

---

## Scope

### In Scope

- `SchemaLibrarySearch` component: text input for search filtering.
- `SchemaLibraryFilters` component: multi-select toggles/checkboxes for origin, format, and scope.
- `SchemaLibrarySortControl` component: sort field selector + direction toggle.
- `ActiveFilterChips` component: displays active filters as removable chips with × buttons.
- "Clear all filters" button.
- "No schemas match the current filters" empty-filter-results message.
- Component tests for all controls.

### Out of Scope

- Data loading or state management (hook provides values/callbacks).
- Card rendering (T-02).
- Page-level layout composition (T-04).
- Skeleton/loading states for controls.

## Change Requirements

**SchemaLibrarySearch:**
```ts
interface SchemaLibrarySearchProps {
  value: string;
  onChange: (value: string) => void;
  resultCount?: number;
  totalCount?: number;
}
```
- Text input with placeholder "Search schemas..."
- Optional "Showing X of Y" count display
- Clear button (×) when input has value
- `aria-label="Search schemas"`
- No debounce needed (< 100 items)

**SchemaLibraryFilters:**
```ts
interface SchemaLibraryFiltersProps {
  origins: SchemaOrigin[];
  formats: DisplayFormat[];
  scopes: Array<'global' | 'project'>;
  onToggleOrigin: (origin: SchemaOrigin) => void;
  onToggleFormat: (format: DisplayFormat) => void;
  onToggleScope: (scope: 'global' | 'project') => void;
}
```
- Three filter groups, each with labeled checkboxes or toggle buttons:
  - Origin: CDM, Published, Local
  - Format: JSON Schema, XSD, Inferred
  - Scope: Global, Project-Level
- Selected state visually distinct (filled/highlighted)
- `aria-label` on each group (e.g., "Filter by origin")
- Compact horizontal layout

**SchemaLibrarySortControl:**
```ts
interface SchemaLibrarySortControlProps {
  field: SortField;
  direction: SortDirection;
  onSort: (field: SortField, direction?: SortDirection) => void;
}
```
- Dropdown or button group for sort field selection
- Direction toggle (ascending/descending arrow icon)
- Currently active sort visually indicated
- `aria-label="Sort schemas"`

**ActiveFilterChips:**
```ts
interface ActiveFilterChipsProps {
  origins: SchemaOrigin[];
  formats: DisplayFormat[];
  scopes: Array<'global' | 'project'>;
  onRemoveOrigin: (origin: SchemaOrigin) => void;
  onRemoveFormat: (format: DisplayFormat) => void;
  onRemoveScope: (scope: 'global' | 'project') => void;
  onClearAll: () => void;
}
```
- Renders one chip per active filter value
- Each chip has label text + × remove button
- "Clear all" button shown when any filter is active
- Hidden entirely when no filters active
- Chips use same color coding as filter badges (origin colors, etc.)

**SchemaLibraryNoResults:**
- Message: "No schemas match the current filters"
- "Clear filters" button/link
- Centered layout
- Only shown when schemas exist but current filters yield zero results

## Notes

- These components are presentational only — they receive controlled values and fire callbacks. State lives in the hook (T-01) and is wired at page level (T-04).
- For the filter toggle style, consider small pill-buttons that fill/highlight when active, similar to tag-selection UIs.
- Keep components small and focused. If the test file grows too large, split into per-component test files.
- Follow the pattern in `ProjectList.tsx` (FS-014) which has similar search/sort/filter controls.
