## Summary

Build the `VersionHistoryDrawer` component — a slide-in drawer from the right side that displays the version list. Each version entry (`VersionListItem`) shows the version number, relative timestamp, rule count, and change summary. The drawer includes loading skeleton state, empty state messaging, and smooth open/close transitions.

## Notes

For relative time formatting, implement a simple utility:
```typescript
function formatRelativeTime(isoString: string): string {
  const diff = Date.now() - new Date(isoString).getTime();
  if (diff < 60_000) return 'just now';
  if (diff < 3_600_000) return `${Math.floor(diff / 60_000)} min ago`;
  if (diff < 86_400_000) return `${Math.floor(diff / 3_600_000)} hours ago`;
  return new Date(isoString).toLocaleDateString(undefined, { month: 'short', day: 'numeric', hour: 'numeric', minute: '2-digit' });
}
```

No need for a date library (date-fns, dayjs) in Phase 0. This simple helper covers the use cases.

The `children` slot in the drawer props is for T-06 to inject the diff view. Initially, the drawer just shows the list. T-06 will add diff + restore UI that appears when a version is selected.
