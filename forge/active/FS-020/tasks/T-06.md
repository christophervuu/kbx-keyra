## Summary

Build the `ObjectSummaryPanel` component that renders in the right panel when an object node is selected in the Target Worklist. It displays section-level coverage, lists child field statuses, and offers section-level actions (auto-map section, map required fields first, validate section).

---

## Scope

### In Scope

- `ObjectSummaryPanel` component with sections:
  - **Header:** Object path, "object" type badge, coverage indicator ("N/M mapped")
  - **Child Status List:** Compact list of direct children with their name, type, and mapping status (icon + label)
  - **Section Actions:**
    - "Auto-map section" button — **disabled**, muted style (grayed icon + label), tooltip: "AI-powered auto-mapping — available in a future release"
    - "Map required fields first" button (fires callback to filter worklist to required fields in this section)
    - "Validate section" button (fires callback to trigger section-level validation display)
- Accepts coverage data from `useTargetStatus` (T-02)
- Emits callbacks for section actions

### Out of Scope

- Auto-map implementation (placeholder)
- Modifying the Target Worklist filter state directly (emits callbacks to parent)
- Scalar field builder (T-05)
- Array builder (T-07)
