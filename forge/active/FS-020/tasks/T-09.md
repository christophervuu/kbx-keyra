## Summary

Implement drag-and-drop from source schema fields (left panel) into the Builder/Editor panel's expression builder slots, and click-to-stage as an alternative interaction. Source fields must be draggable and the builder must have designated drop zones that accept source path insertion.

---

## Scope

### In Scope

- Make source schema tree fields draggable (HTML5 Drag API)
- Drag data payload: source field path string (e.g., `data.contactEmail`)
- Drop zones in `ScalarFieldBuilder` (T-05): source field slot in expression builder
- On drop: insert `source("path")` expression into the active expression slot
- **Click-to-stage** alternative: clicking a source field when builder is active inserts it into the expression
- Visual feedback: drag ghost, drop zone highlight when dragging over
- Visual indicator on source fields that they are draggable (grip handle or cursor change)
- Source panel component (`SourceSchemaPanel`) that renders the source schema tree with draggable fields

### Out of Scope

- Array builder Step 3 DnD (internal to T-07, separate DnD context)
- Source schema parsing (already handled by `useMappingEditor`)
- Modifying engine behavior

## Change Requirements

After this task is complete:

- `SourceSchemaPanel` renders source schema as a browsable tree (similar to existing Panel 1 but with draggable fields)
- Each leaf field in the source tree is draggable (`draggable="true"`, `onDragStart` sets data transfer with path)
- Object/array nodes in source tree are expandable/collapsible but not themselves draggable
- `ScalarFieldBuilder` has a designated drop zone in the source field section
- When a source field is dropped on the drop zone:
  - `source("dropped.path")` expression is inserted into the active expression
  - Drop zone shows visual confirmation
- **Click-to-stage:** when builder is active and user clicks a source field, the same insertion occurs
- `useDragSource` hook: manages drag state, provides `onDragStart`/`onDragEnd` handlers
- `useDropZone` hook: manages drop zone state (isDragOver, onDrop), provides ref and event handlers
- Visual: drop zone highlights (border color change) when valid drag hovers over it
