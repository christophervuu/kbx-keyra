## Summary

Build the `ScalarFieldBuilder` component for the right panel that appears when a scalar target field is selected. It displays target context (path, type, required status, mapping status), suggested source fields, a guided expression builder (source → transform → preview expression), a raw DSL toggle, plain-English explanation placeholder, and AI action buttons. This reuses and composes existing expression authoring components.

---

## Scope

### In Scope

- `ScalarFieldBuilder` component with sections:
  - **Header:** Target path, type badge, required/optional label, current mapping status
  - **Suggested Sources:** Client-side heuristic-based suggestions derived from parsed source schema. Matching rules (priority order): (1) exact name match, (2) case-insensitive match, (3) contains match, (4) type compatibility filter. Returns up to 5 suggestions ordered by match strength.
  - **Expression Builder:** Reuse/compose `GuidedBuilder` + `SourceFieldPicker` + `TransformPicker` components. Source field slot accepts drag-and-drop (T-09) or click-to-stage.
  - **Raw DSL Toggle:** Switch to `RawDslEditor` mode for power users
  - **Expression Explanation:** Plain-English description of current expression (placeholder text or simple template)
  - **AI Actions:** "Suggest", "Explain", "Fix" buttons (placeholders — show tooltip or log)
  - **Save button:** Commits the expression as a rule targeting this field
- Integrates with `useExpressionBuilder` hook for expression state
- Emits `onSave(targetPath, expression)` callback
- No preview in this panel — preview is in the bottom area

### Out of Scope

- Preview rendering (T-08 — bottom area)
- Drag-and-drop implementation (T-09 — source panel)
- Object node summary (T-06)
- Array builder (T-07)
- AI model integration (buttons are UI placeholders)

## Change Requirements

After this task is complete:

- `ScalarFieldBuilder` renders a vertical layout with all specified sections
- Header section shows target path, type badge (reuse `TargetFieldRow` badge styling), required indicator, and mapping status
- Suggested sources section computes suggestions using client-side heuristic:
  1. Exact name match (last path segment): `firstName` → `firstName`
  2. Case-insensitive match: `FirstName` → `firstName`
  3. Contains match: target `fullName` suggests source fields containing "name"
  4. Type compatibility: only suggest source fields whose type matches target field's type
  - Returns up to 5 suggestions, ordered by match strength
  - If no matches, show "No suggestions — select a source field manually"
  - Heuristic logic extracted to utility: `suggestSourceFields(targetPath, targetType, parsedSourceSchema): SuggestedField[]`
- Expression builder section composes existing `GuidedBuilder` or `RawDslEditor` based on mode toggle
- Mode toggle (Builder/Editor) reuses existing pattern from `ExpressionBuilderPanel`
- AI action buttons render but show "Coming soon" tooltip on click
- Save button is enabled only when expression is non-empty and syntactically valid
- `onSave` callback fires with target path and finalized expression string
- Component accepts `selectedTargetPath`, `selectedTargetType`, `selectedTargetRequired`, `currentStatus`, `parsedSourceSchema` as props

## Notes

- The `suggestSourceFields` utility runs entirely client-side against the parsed source schema tree. No backend call. This is consistent with Phase 0 constraints.
- Heuristic matching priority: exact > case-insensitive > contains. Type compatibility is a filter applied on top of name matching (not a standalone ranking signal).
- Phase 2 will layer AI suggestions alongside heuristic suggestions with a sparkle (✨) badge. Design the suggestions list to accommodate an additional "AI suggested" group in the future.
- This component essentially replaces Panel 4 for scalar target fields in the new layout. The composition is similar but the context (target field info) is new.
- Existing `GuidedBuilder` and `RawDslEditor` may need minor refactoring to extract them as standalone composable units outside their current `ExpressionBuilderPanel` wrapper.
