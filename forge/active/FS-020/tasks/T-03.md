## Summary

Build the `TargetFieldRow` component that renders a single target field within the Target Worklist. Each row shows: field name, type badge, required indicator, mapping status icon, and an optional truncated expression summary. This is the atomic visual unit of the target-driven worklist.

---

## Scope

### In Scope

- `TargetFieldRow` component with props:
  - `fieldName: string`
  - `fieldPath: string`
  - `fieldType: 'string' | 'number' | 'boolean' | 'object' | 'array' | 'null' | 'integer'`
  - `required: boolean`
  - `status: 'unmapped' | 'mapped' | 'warning' | 'error'`
  - `expressionSummary?: string` (truncated DSL expression or empty)
  - `isSelected: boolean`
  - `depth: number` (indentation level)
  - `isExpandable: boolean` (true for object/array nodes)
  - `isExpanded: boolean`
  - `coverageText?: string` (e.g., "3/5 mapped" — for object nodes)
  - `onClick: () => void`
  - `onToggleExpand?: () => void`
- Visual elements:
  - Indentation based on depth (left padding)
  - Expand/collapse chevron for expandable nodes
  - Field name text
  - Type badge (small colored pill: different color per type)
  - Required indicator (red asterisk or "required" micro-badge)
  - Status icon: empty circle (unmapped), green check (mapped), yellow triangle (warning), red circle (error)
  - Expression summary (gray, truncated to ~40 chars)
  - Coverage text for object nodes (muted, after field name)
- Selected state: highlighted background
- Hover state: subtle background change

### Out of Scope

- Tree expand/collapse state management (owned by parent `TargetWorklist`)
- Mapping status computation (owned by `useTargetStatus` hook in T-02)
- Click behavior beyond firing `onClick` callback
- Drag-and-drop target (T-09)

## Change Requirements

After this task is complete:

- `TargetFieldRow` renders all visual elements as described
- Indentation is `depth * 16px` (or similar spacing unit) left padding
- Type badge uses distinct colors: string=blue, number=green, boolean=purple, object=slate, array=amber, integer=green, null=gray
- Status icon uses Lucide icons: `Circle` (unmapped), `CheckCircle2` (mapped), `AlertTriangle` (warning), `XCircle` (error)
- Required indicator shown as red asterisk next to field name when `required=true`
- Expression summary truncated with ellipsis at max 60 characters. Formatting rules:
  - Always show the outermost function name
  - Always show the first argument (primary source path) if it fits
  - Truncate remaining arguments with `…`
  - Object templates inside `map()` show as `{…}`
  - If the full expression is ≤ 60 characters, show in full (no truncation)
  - Full expression visible on hover (tooltip)
  - Examples: `source("firstName")` → full; `concat(source("firstName"), …)` → truncated
- Coverage text displayed in muted style for object/array nodes
- Component uses Tailwind classes consistent with existing dark theme (slate-950 backgrounds)
- Accessible: row is keyboard-focusable, has appropriate aria attributes

## Notes

- This is a purely presentational component with no internal state beyond hover/focus.
- Keep the component slim — it will be rendered many times (once per target field) so performance matters.
- Use `React.memo` to prevent unnecessary re-renders when sibling rows change.
- Expression summary formatting logic should be extracted to a utility function (`truncateExpression(expr: string, maxLen?: number): string`) for unit testing and reuse. Default max length is 60.
