## Summary

Consolidate and expand automated UI test coverage for the new Project Overview hierarchy, mapping-row behaviors, right-rail cards, and standardized breadcrumbs so acceptance examples remain protected against regressions.

---

## Scope

### In Scope

- Add/update tests for:
  - simplified header and removed legacy sections
  - mappings table columns and row action navigation behavior
  - status-based row actions by mapping status (Draft/Ready/Has Errors)
  - deployment label wording normalization
  - search behavior (name + source/target schema text)
  - deployment activity empty state + View deployments CTA
  - compact schemas card content and Manage schemas action visibility
  - breadcrumb hierarchy across project/mapping/deployment routes
  - non-clickable `Projects` breadcrumb segment behavior when `/projects` route is absent
  - responsive structure assertions where deterministic
- Ensure prior tests tied to removed sections are updated or replaced.

### Out of Scope

- New backend or e2e infrastructure work.
- Visual snapshot framework introduction.
