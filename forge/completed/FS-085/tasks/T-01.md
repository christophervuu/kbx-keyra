## Summary

Replace path-derived breadcrumb rendering with hierarchy-aware breadcrumb patterns for project/mapping/deployment surfaces so users see structural app location and not raw route segment formatting. Ensure breadcrumb clickability does not imply non-existent routes.

---

## Scope

### In Scope

- Update breadcrumb generation logic for project-related routes to canonical hierarchy:
  - `Home / Projects / {projectName}`
  - `Home / Projects / {projectName} / Mappings / {mappingName}`
  - `Home / Projects / {projectName} / Mappings / {mappingName} / Deployment`
  - `Home / Projects / {projectName} / Deployments`
- Use breadcrumb label context for project/mapping human-readable names.
- Prevent misleading links for non-real route segments (notably `Projects` if route absent).
- Update/add layout tests for breadcrumb structure and segment clickability behavior.

### Out of Scope

- Full Project Overview visual redesign content (handled by later tasks).
- Backend route additions (no creation of `/projects` route required).

## Change Requirements

- Breadcrumb strategy for project-family routes must be hierarchy-driven rather than generic segment titleization.
- `Projects` breadcrumb segment must remain structurally present even if not currently navigable as a real route.
- `Projects` breadcrumb segment must be explicitly non-clickable/disabled until a real `/projects` route exists (do not temporarily link it to Home).
- Dynamic object labels should resolve to human names when context is available and gracefully fall back when not.
- Breadcrumb output must remain deterministic for test assertions.

  - Mapping Deployment
  - Project Deployments
- Verify non-clickable behavior for `Projects` segment when `/projects` route is absent.
- Run `pnpm --filter ui test` for layout/breadcrumb suite.

## Acceptance Checks

- Breadcrumbs on all targeted routes match AE-09 hierarchy patterns.
- `Projects` segment behavior does not mislead users toward nonexistent route.
- Dynamic project/mapping labels use registered breadcrumb labels where available.
- Breadcrumb tests pass for all touched route contexts.
