## Summary

Add a "Schema Name" text input field to the `SchemaUploadDialog` that allows users to customize the schema name before creation. The field pre-populates with a sensible default (filename for file uploads, format-based label for paste mode) and is always editable. The "Add Schema" button is disabled when the name is empty or whitespace-only.

---

## Scope

### In Scope

- Add a labeled text input field ("Schema Name") to the dialog.
- Position it after the info panel and before the scope selection fieldset.
- Pre-populate with defaults:
  - File mode: `stripExtension(filename)` (existing behavior, now surfaced in the input).
  - Paste mode: `"Pasted JSON Schema"` for json-schema format, `"Pasted Sample JSON"` for sample-json.
- Make the name editable — user can type any non-empty string.
- Disable "Add Schema" button when name is empty or whitespace-only.
- Wire the name field value into the `handleUpload` call to `adapter.createSchema({ name: ... })`.
- Handle name reset on file re-selection: if user selects a new file, reset name to the new filename default.
- Track whether the user has manually edited the name (for the file re-selection reset logic).

### Out of Scope

- Schema name uniqueness validation.
- Name character restrictions (allow any non-empty string).
- Test updates (T-03).
- Changes to the paste input or mode toggle (T-01).

## Change Requirements

The `SchemaUploadDialog` component must be updated to:

1. **Add name state:**
   - `schemaName: string` (default: `''`)
   - `nameManuallyEdited: boolean` (default: `false`) — tracks whether the user has typed in the name field.

2. **Name field UI:**
   - Render a text input with label "Schema Name" between the info panel and scope fieldset.
   - Only visible when content is loaded (i.e., `fileInfo` or `pasteInfo` is non-null for the active mode).
   - Input: `type="text"`, `data-testid="schema-name-input"`, styled consistently with existing dialog inputs.
   - `value={schemaName}`, `onChange` updates `schemaName` and sets `nameManuallyEdited = true`.

3. **Default name population:**
   - When `fileInfo` is set (file selected): `setSchemaName(stripExtension(fileInfo.filename))`.
   - When `pasteInfo` is set (paste analyzed): `setSchemaName(defaultPasteName(pasteInfo.format))`.
   - Helper: `defaultPasteName(format)` → `"Pasted JSON Schema"` for `json-schema`, `"Pasted Sample JSON"` for `sample-json`.
   - Only set default when `!nameManuallyEdited` or when file re-selection occurs.

4. **File re-selection behavior:**
   - When a new file is selected (i.e., `handleFileChange` fires), always reset `schemaName` to the new filename default and reset `nameManuallyEdited` to `false`.

5. **Button enablement:**
   - "Add Schema" button disabled when:
     - Active mode has no loaded content (existing behavior), OR
     - `schemaName.trim().length === 0`

6. **Upload handler:**
   - Replace `name: stripExtension(fileInfo.filename)` with `name: schemaName.trim()` in the `adapter.createSchema()` call.

7. **Dialog reset:**
   - On close, reset `schemaName` to `''` and `nameManuallyEdited` to `false`.
