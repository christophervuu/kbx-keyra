## Summary

Add type information and test data to the `ChainSourceCard` dropdown options and `BuilderEntryActions` source picker by integrating the shared `SourceFieldOptionRow` component. Currently, `ChainSourceCard` only shows path text — this task adds the full 4-zone row layout.

---

## Scope

### In Scope

- Modify `ChainSourceCard.tsx` to:
  - Accept typed source options (currently `readonly string[]` — needs to become `SchemaPathEntry[]` or receive type info separately)
  - Wire PreviewContext to resolve test data for each option
  - Render each dropdown option using `<SourceFieldOptionRow>`
- Modify `BuilderEntryActions.tsx` source picker (if it has its own dropdown) to use `SourceFieldOptionRow`
- Update the `ChainSourceCardProps` interface if needed to accept type information per option
- Update callers of `ChainSourceCard` to pass typed options
- Update component tests

### Out of Scope

- ChainSourceCard's drop-zone drag-and-drop behavior
- ChainSourceCard's selected-source chip display (separate from dropdown options)
- Other picker components (handled in T-02, T-04, T-05)

## Change Requirements

### ChainSourceCard.tsx

- Change `sourceOptions` prop from `readonly string[]` to `readonly SchemaPathEntry[]` (or add a parallel `sourceOptionEntries` prop for backward compat — prefer breaking change since this is internal)
- Import and wire `PreviewContext` to get `sourceData`
- Replace the current option list `<li>` rendering (which just shows path text) with `<SourceFieldOptionRow path={option.path} type={option.type} testValue={resolveFieldTestValue(sourceData, option.path)} />`
- Update the search filter to still search by `option.path`
- Preserve: portalled dropdown, role="listbox", keyboard navigation, outside-click dismissal, aria-attributes

### ChainSourceCard callers

- Update all places that pass `sourceOptions` to ChainSourceCard to pass `SchemaPathEntry[]` instead of `string[]`
- If the caller already has access to `flattenSchemaPaths` result, simply pass it directly
- If the caller only has path strings, wrap them with a type lookup from the schema

### BuilderEntryActions.tsx

- If this component has its own source dropdown (verify during implementation), integrate `SourceFieldOptionRow`
- If it delegates to ChainSourceCard, no additional changes needed
