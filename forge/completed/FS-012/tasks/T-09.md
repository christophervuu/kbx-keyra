## Summary

Build the Diagnostics tab content component that displays engine diagnostics (errors and warnings) from execution results, categorized by severity with appropriate icons and styling.

---

## Scope

### In Scope

- New file `ui/src/features/mappings/components/preview/DiagnosticsDisplay.tsx`
- Render list of `Diagnostic` entries from `ExecutionResult.diagnostics`
- Severity icons/colors: error (red), warning (amber), info (blue)
- Each diagnostic shows: severity icon, message, target path (if available), expression (if available)
- Empty state: "No diagnostics" with success indicator
- Scrollable list for many diagnostics
- Count passed back to panel for badge display

### Out of Scope

- Filtering or searching diagnostics
- Clicking a diagnostic to navigate to the rule
- Grouping by category

---

## Relevant Areas

- `ui/src/features/mappings/components/preview/DiagnosticsDisplay.tsx` (new)
- `ui/src/features/mappings/components/preview/PreviewPanel.tsx` (renders in Diagnostics tab)
- `src/engine/types/results.ts` (Diagnostic type reference)

---

## Change Requirements

- Component receives diagnostics array from execution result
- Render each diagnostic as a list item with:
  - Severity icon: `⚠` for warning (amber), `✕` for error (red), `ℹ` for info (blue) — or SVG equivalents
  - Message text
  - Rule target path (if present in diagnostic metadata) in `font-mono text-xs`
  - Expression snippet (if present) in `font-mono text-xs text-gray-500`
- Empty state when diagnostics array is empty: green checkmark + "No issues found"
- If no execution has run yet: "Run a mapping to see diagnostics"
- Expose diagnostic count for parent badge: either via callback prop or by parent reading result directly

---

## Verification Requirements

- Renders diagnostics with correct severity styling
- Empty diagnostics shows success state
- Multiple diagnostics are scrollable
- Each diagnostic shows available metadata
- `tsc --noEmit` passes
- Component test verifies rendering with mock diagnostics

---

## Acceptance Checks

- Given execution with 2 warnings and 1 error, renders 3 items with correct colors/icons
- Given execution with 0 diagnostics, shows "No issues found"
- Given no execution yet, shows prompt message
- Diagnostics list is scrollable
- `tsc --noEmit` passes

## Notes
