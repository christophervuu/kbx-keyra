## Summary

Build the Test Case Manager UI component that provides save, load, and delete operations for test cases. Includes a dropdown selector for existing test cases, a save dialog for naming new test cases, and delete confirmation. Wires to the `useTestCases` hook for persistence.

---

## Scope

### In Scope

- New file `ui/src/features/mappings/components/preview/TestCaseManager.tsx`
- Dropdown/select showing saved test cases for current mapping
- "Save" button that opens a name input (inline or popover)
- Loading a test case populates source data input and expected output
- Delete button per test case (with confirmation or direct delete)
- Error display for quota exceeded on save
- Integration into PreviewPanel toolbar area

### Out of Scope

- Test case editing (rename) — save a new one instead
- Test case export/import
- Batch test execution
- Reordering test cases

---

## Relevant Areas

- `ui/src/features/mappings/components/preview/TestCaseManager.tsx` (new)
- `ui/src/features/mappings/components/preview/PreviewPanel.tsx` (integration)
- `ui/src/features/mappings/hooks/use-test-cases.ts` (consumes hook)

---

## Change Requirements

- Test case selector:
  - Dropdown showing test case names
  - Selecting a test case triggers `onLoad(testCase)` callback
  - Parent component uses this to populate source data and expected output
  - Empty state: "No saved test cases"
- Save flow:
  - "Save" button in toolbar
  - On click: shows inline text input for name + confirm button
  - On confirm: calls `saveTestCase` with current source data and expected output
  - On success: input closes, dropdown updates
  - On error (quota): shows error message inline
- Delete flow:
  - Small delete icon/button next to each test case in dropdown
  - Calls `deleteTestCase(id)` directly (no confirmation modal for Phase 0)
- Styling: compact, fits in toolbar row or below it
