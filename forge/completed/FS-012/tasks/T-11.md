## Summary

Build the Diff tab content component that renders a structural comparison between actual execution output and user-defined expected output. Uses the `computeDiff` utility to compute differences and displays them with color-coded entries for added, removed, and changed fields.

---

## Scope

### In Scope

- New file `ui/src/features/mappings/components/preview/DiffDisplay.tsx`
- Expected output textarea input (JSON)
- Validation of expected output JSON
- Call `computeDiff(actual, expected)` when both are valid
- Render diff entries color-coded:
  - Added (in actual, not in expected): green background
  - Removed (in expected, not in actual): red background
  - Changed: yellow/amber background with old → new values
- "All match" success state when `isEqual: true`
- Empty states for missing actual or expected

### Out of Scope

- Inline side-by-side text diff (not a text differ — structural only)
- Saving expected output separately from test cases
- Auto-scrolling to first difference

---

## Relevant Areas

- `ui/src/features/mappings/components/preview/DiffDisplay.tsx` (new)
- `ui/src/lib/utils/json-diff.ts` (imports `computeDiff`)
- `ui/src/features/mappings/components/preview/PreviewPanel.tsx` (renders in Diff tab)

---

## Change Requirements

- Expected output input:
  - Textarea with monospace font, JSON validation, inline error (same pattern as SourceDataInput)
  - Smaller height than source data input
  - Placeholder: "Paste expected output JSON..."
- Diff display:
  - When both actual and expected are valid: compute and render diff
  - Each `DiffEntry` rendered as a row: `{path}: {description}`
    - Added: `"{path}" is present in output but not expected` with green-100 bg
    - Removed: `"{path}" is expected but missing from output` with red-100 bg
    - Changed: `"{path}": expected {expected} → got {actual}` with amber-100 bg
  - Values truncated to reasonable length with ellipsis for display
- States:
  - No execution yet: "Run a mapping first to compare output"
  - No expected defined: "Enter expected output to compare"
  - `isEqual: true`: green checkmark + "Output matches expected"
  - Diff entries: scrollable list of differences
