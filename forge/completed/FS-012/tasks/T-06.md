## Summary

Build the Preview Panel shell component that replaces the Panel 5 placeholder in the Mapping Editor. Includes a tab bar (Output, Diagnostics, Trace, Diff), a toolbar with Run button, auto-run toggle, and trace toggle, and a stats bar showing execution duration and rule count.

---

## Scope

### In Scope

- New file `ui/src/features/mappings/components/preview/PreviewPanel.tsx`
- Tab bar with 4 tabs: Output, Diagnostics, Trace, Diff
- Toolbar: Run button (disabled when cannot execute), auto-run toggle, trace toggle
- Stats bar: execution duration, rules evaluated count
- Badge on Diagnostics tab showing count when > 0
- Integration into `MappingEditorPage.tsx` replacing `<PanelPlaceholder name="Preview (Panel 5)" />`
- Wiring to `usePreviewExecution` hook for state and actions
- Loading state indicator during execution
- Empty state when no execution has been run

### Out of Scope

- Tab content implementations (T-07 through T-11 handle individual tabs)
- Source data input (T-07)
- Test case manager UI (T-12)

## Change Requirements

- Create `PreviewPanel` component with:
  - Toolbar row: "Run" button (calls `run()`), auto-run checkbox/toggle, trace checkbox/toggle
  - Tab bar: Output | Diagnostics (with badge) | Trace | Diff
  - Content area: renders active tab's content (initially empty placeholders for each tab, to be filled by T-08–T-11)
  - Stats bar (bottom): shows `{duration}ms • {ruleCount} rules evaluated` when last result exists
- Run button disabled states:
  - When `sourceDataRaw` is null (invalid JSON)
  - When config or schemas are null
  - When execution is in progress
- Loading indicator shown when `state.status === 'executing'`
- Empty state: "Enter source data and click Run to preview execution results"
- Replace `<PanelPlaceholder name="Preview (Panel 5)" />` in `MappingEditorPage.tsx` with `<PreviewPanel />`
- Use Tailwind CSS 4 for all styling
- Maintain `data-testid="panel-slot-5"` on the panel root for test continuity
