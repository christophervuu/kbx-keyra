## Summary

Implement the `usePreviewExecution` hook that orchestrates executing the current mapping against source data, managing execution state (idle/executing/success/error/timeout), supporting manual and auto-run modes with debouncing, and updating the PreviewContext with results.

---

## Scope

### In Scope

- New file `ui/src/features/mappings/hooks/use-preview-execution.ts`
- Manual execution trigger (`run()` function)
- Auto-run mode with 500ms debounce on rule/data changes
- 2-second timeout with abort
- Execution state management (`PreviewExecutionState`)
- Trace toggle support (passes `{ trace: true }` to engine when enabled)
- Updates PreviewContext with sourceData and lastResult
- Unit tests with mocked `executeMapping`

## Change Requirements

Hook signature:
```typescript
function usePreviewExecution(params: {
  config: MappingConfig | null;
  sourceSchemaDetail: SchemaDetail | null;
  targetSchemaDetail: SchemaDetail | null;
  sourceDataRaw: string | null; // raw JSON string, null if invalid
}): {
  state: PreviewExecutionState;
  run: () => void;
  autoRun: boolean;
  setAutoRun: (enabled: boolean) => void;
  traceEnabled: boolean;
  setTraceEnabled: (enabled: boolean) => void;
}
```

Behavior:
- `run()`: Parse `sourceDataRaw` as JSON, call `executeMapping(config, parsedData, rawSourceSchema, rawTargetSchema, { trace: traceEnabled })`. Transition state through executing → success/error/timeout.
- Timeout: Use `setTimeout` with 2000ms. If execution hasn't completed (though it's synchronous, this guards against unexpectedly slow configs), set state to `timeout`.
- Since `execute` is synchronous, the timeout is primarily a UX safeguard. Wrap in a microtask or use `requestIdleCallback` pattern if needed to avoid blocking paint.
- Auto-run: When `autoRun` is true, debounce execution by 500ms whenever `config.rules` or `sourceDataRaw` changes.
- Guard: Do not execute if `config`, `sourceSchemaDetail`, `targetSchemaDetail`, or `sourceDataRaw` is null.
- Update `PreviewContext` sourceData whenever `sourceDataRaw` changes and is valid JSON.
- Update `PreviewContext` lastResult whenever execution completes successfully.
- Abort: If a new run starts while state is executing, the previous result is discarded (latest-wins).
