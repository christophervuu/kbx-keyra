## Summary

Update the existing `SuggestExpressionInput` type in `ui/src/lib/types/domain.ts` to include the approved showcase-mode context fields (`targetType`, `targetDescription`, `sourceContext`). The `sourceContext` field is a pre-formatted text block of available source fields (not a structured array). Deprecate the existing generic `context` field. All new fields are optional to maintain backward compatibility with existing code that references the type.

## Change Requirements

### `ui/src/lib/types/domain.ts`

Update `SuggestExpressionInput`:

```typescript
export interface SuggestExpressionInput {
  readonly instruction: string;
  readonly targetPath: string;
  readonly targetType?: string;
  readonly targetDescription?: string;
  /**
   * Pre-formatted text block of available source fields for the showcase/local slice.
   * Format: one line per field, e.g., "- Invoice.Amount (number)\n- Invoice.CurrencyCode (string)"
   * This is a temporary substitute for RAG retrieval and will become optional/ignored
   * once the backend implements its own context retrieval.
   */
  readonly sourceContext?: string;
  /**
   * @deprecated Use `sourceContext` instead. Retained for backward compatibility.
   */
  readonly context?: Readonly<Record<string, unknown>>;
}
```

Confirm `SuggestExpressionResult` is unchanged:

```typescript
export interface SuggestExpressionResult {
  readonly expression: string;
  readonly explanation?: string;
}
```

## Notes

The approved backend contract (Rev 2, Q1 resolution) uses `sourceContext` as a pre-formatted text string, not a structured array. This simplifies the type model — no need for a `SourceFieldDescriptor` interface. The UI formats source fields into a text block like:
```
- Invoice.Amount (number)
- Invoice.CurrencyCode (string)
- Invoice.Date (string)
```

This formatting responsibility lives in the component layer (T-06), not the type layer.
