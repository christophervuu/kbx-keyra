## Summary

Extend deployment persistence contracts so successful deploy/promote outcomes include referenced CDM schema commit SHA metadata for immutable traceability and downstream inspection.

## Scope

### In Scope

- Define/update deployment metadata shape to include referenced CDM schema commit SHA entries.
- Persist traceability metadata on successful deploy and promote operations.
- Ensure snapshot and/or deployment record includes durable commit SHA data as chosen implementation.
- Add tests validating traceability data persistence and retrieval.

- Approval workflow fields.

- Populate metadata from validated deploy-context schema set including reference role association.
- Persist commit SHA traceability in **both** the deployment item metadata field and the deployment snapshot S3 body metadata.
- Ensure traceability is attached for successful deploy/promote writes only.
