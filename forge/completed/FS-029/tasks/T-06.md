## Summary

Implement the empty-state entry point for the Value mode builder showing two distinct top-level buttons: `[+ Add Source]` and `[+ Add Transformation]`. These are the initial actions available when no source or function is configured, enabling both the source-first and transform-first paths.

---

## Scope

### In Scope

- New `BuilderEntryActions.tsx` component (or similar name) in `ui/src/features/mappings/components/`.
- Renders when the builder state is empty (no sources, no function).
- Two buttons at the top-left:
  - **[+ Add Source]** — opens the source field picker (existing SourceChipPicker or equivalent).
  - **[+ Add Transformation]** — opens the function picker (existing TransformFunctionPicker).
- On source selection: transitions state to `DirectCopy` (single source card).
- On function selection: transitions state to `FunctionCall` with empty argument slots ready to fill.
- Styling: buttons should be visually co-located (top-left area), compact, and clearly labeled.

### Out of Scope

- The source picker internals (reuse existing).
- The function picker internals (reuse existing).
- The SourceCard or ArgumentForm rendering after selection (those are T-02, T-03).

## Change Requirements

- Component accepts: `onSourceSelected: (path: string) => void`, `onFunctionSelected: (name: string) => void`.
- Renders two buttons side-by-side at the top-left of the builder area.
- Each button triggers its respective picker (popover/dropdown).
- The buttons are only shown when the builder is in empty state — the parent manages visibility.
- Accessible: both buttons have clear aria-labels, are keyboard focusable.
