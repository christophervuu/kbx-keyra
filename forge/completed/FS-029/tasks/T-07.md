## Summary

Create or update the expression generator to produce valid DSL expression strings from the new `ValueModeState` shape. This replaces the sequential pipeline chaining with direct function-and-arguments assembly, including support for nested argument expressions.

---

## Scope

### In Scope

- New or updated generator in `ui/src/features/mappings/lib/` (e.g. `source-card-expression-generator.ts`).
- Generates expressions for all state variants:
  - `DirectCopy` → `source("path")`
  - `SourceWithTransform` → `functionName(source("path"), arg2, arg3, ...)`
  - `FunctionCall` → `functionName(slot1, slot2, ...)` where each slot resolves recursively.
  - `PendingConnector` → no expression (incomplete state).
- Slot resolution:
  - `source` mode → `source("path")`
  - `source` mode + nested transform → `transformFn(source("path"), ...nestedArgs)`
  - `literal` mode → quoted string or number literal
  - `expression` mode → recursive generation
- Literal values: strings get quoted, numbers are bare, booleans are bare.
- Handle variadic functions (variable number of args).

### Out of Scope

- Round-trip decomposition (T-08).
- UI components.
- Engine-side validation of generated expressions.

## Change Requirements

- Export a `generateExpressionFromSourceCardState(state: ValueModeState): string | null` function.
- Returns `null` for incomplete/invalid states (e.g. PendingConnector, required slots missing).
- Recursively generates nested expressions for argument slots that contain transforms or sub-expressions.
- String literals are properly escaped/quoted.
- The function must be pure (no side effects, deterministic output for given input).

---

## Verification Requirements

- Unit tests covering each state variant:
  - DirectCopy → `source("order.customerName")` (AE-01).
  - SourceWithTransform → `formatDate(source("order.createdAt"), "ISO8601", "YYYY-MM-DD")` (AE-02).
  - FunctionCall with mixed slots → `concat(source("firstName"), " ", source("lastName"))` (AE-03).
  - FunctionCall from connector → `concat(source("order.firstName"), source("order.lastName"))` (AE-04).
  - Nested transform → `concat(upper(source("firstName")), source("lastName"))` (AE-07).
  - PendingConnector → `null`.
- Unit tests for edge cases: empty literal, numeric literal, boolean literal.
- Typecheck passes.

## Notes

The existing `pipeline-expression-generator.ts` uses sequential chaining. The new generator should be a fresh implementation since the state shape is fundamentally different (tree vs. linear chain). The old generator can remain until T-10 removes it.
