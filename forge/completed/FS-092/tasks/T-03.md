## Summary

Implement the right-side Mapping Details Area with Source and Builder panels for scalar targets using business-friendly controls. This includes source browsing/search, value source selection, mapping method configuration, output preview, notes, BA-friendly validation messaging, and Advanced Mode DSL reveal.

---

## Scope

### In Scope

- Source Panel:
  - source search + schema tree browse,
  - selected source details and metadata,
  - sample value display from selected sample context,
  - value source types (source field/static/constant/external/leave unmapped).
- Builder Panel:
  - target header + output,
  - scalar mapping method controls,
  - contextual method config,
  - notes editing,
  - row validation messaging,
  - advanced mode DSL diagnostics section (hidden by default).
- Wire panel edits to row summary/status updates in grid.

### Out of Scope

- Array builder advanced workflows.
- AI suggestion bulk review UX details.
- Architecture documentation updates.

---

## Relevant Areas

- `ui/src/features/mappings/components/*` (new SourcePanel/BuilderPanel and supporting controls)
- `ui/src/features/mappings/hooks/use-mapping-editor.ts`
- `ui/src/features/mappings/hooks/*` (panel state, output preview, validation projection)
- `ui/src/features/mappings/lib/*` (mapping-method labels/formatters)

---

## Change Requirements

- Source panel must not include top “Suggested source fields” section in this iteration.
- Advanced mode must be opt-in; DSL hidden in default mode.
- Mapping methods should map cleanly to underlying DSL generation while preserving business terminology.
- Validation copy in panel must be BA-friendly by default.

---

## Verification Requirements

- Component/integration tests for source selection -> builder hydration -> grid row summary updates.
- Tests for each value source type and core scalar method controls.
- Tests for Advanced Mode visibility toggle and default hidden DSL state.
- Manual QA pass for sample-switch output consistency in panels.

---

## Acceptance Checks

- Selecting a row opens Source + Builder details with consistent context (AE-02).
- Switching sample updates panel source/output values and validation context (AE-04).
- Transform flow (e.g., Format date) updates output + row method/source summaries (AE-06).
- Value source alternatives render contextual controls and row status impact (AE-07).
- Builder shows BA-friendly row validation and hides raw DSL unless Advanced Mode enabled (AE-13, AE-14).

---

## Blockers / Risks

- Method-to-DSL decomposition/regeneration complexity may expose edge cases in existing builder state model.
- Advanced mode preference must align with finalized per-user global persisted setting.

---

## Notes

- Keep builder language business-facing; avoid exposing raw DSL concepts outside Advanced Mode.
