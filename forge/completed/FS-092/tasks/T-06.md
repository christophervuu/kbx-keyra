## Summary

Implement AI suggestion lifecycle UX directly in the redesigned Mapping Grid and Builder panel: scope-aware auto-map triggers, visually distinct suggestion rows, and explicit accept/edit/dismiss flows that do not overwrite accepted mappings silently.

---

## Scope

### In Scope

- Auto-map initiation from toolbar/header with visible-scope messaging.
- Suggestion row rendering state and badges in grid.
- Builder panel suggestion detail presentation (reason/confidence/output).
- Accept, edit-before-accept, dismiss, and post-accept normalization behavior.
- Non-destructive merge behavior with existing accepted mappings.

### Out of Scope

- Replacing underlying AI runtime architecture.
- Non-mapping AI features (explain/smart-fix) redesign.
- Architecture documentation updates.

---

## Relevant Areas

- `ui/src/features/mappings/components/*` (grid statuses, builder suggestion actions)
- `ui/src/features/mappings/hooks/use-auto-map-workspace.ts` ?
- `ui/src/features/mappings/hooks/*` (new suggestion lifecycle integration hooks)

---

## Change Requirements

- Auto-map invocation must pass explicit visible scope derived from active filters/search.
- Suggestion states must remain persistent through unsaved-change model until user action.
- Acceptance path should convert suggestion row into normal mapped row semantics.

---

## Verification Requirements

- Integration tests for scoped auto-map request behavior.
- UI tests for suggestion state transitions and action outcomes.
- Regression checks ensuring existing accepted mappings are not overwritten.

---

## Acceptance Checks

- Auto-map runs only against current visible/filter scope and communicates that scope (AE-09).
- Suggestions are visually distinct and require explicit accept/edit/dismiss user action (AE-10).
- Accepted mappings remain stable and are not silently overwritten by future auto-map runs (AE-10).

---

## Blockers / Risks

- Existing FS-048 workspace suggestion model may require careful adaptation to row-embedded review UX.

---

## Notes
