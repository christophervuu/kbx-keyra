## Summary

Extend the `ApiAdapter` interface with deployment methods (deploy, promote, rollback, list, getCurrent) and implement them in both `HttpAdapter` and `LocalStorageAdapter`. Include staleness computation in the adapter response for UI consumption.

---

## Scope

### In Scope

- `ApiAdapter` interface additions: `deployMapping()`, `promoteDeployment()`, `rollbackDeployment()`, `listDeployments()`, `getCurrentDeployments()`
- `HttpAdapter` implementation calling new API routes
- `LocalStorageAdapter` implementation using localStorage-based deployment state
- Response types including staleness status per environment
- Staleness module integration (import from `src/lib/deployment/staleness.ts` or reimplement for client)

### Out of Scope

- UI components consuming these methods (T-05, T-06, T-07)
- Backend handler implementation (T-02)
