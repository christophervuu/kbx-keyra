## Summary

Create/extract a shared preview execution coordinator for Mapping Editor Output that only executes while Output view is active, tracks dirty state while Fields is active, and enforces monotonic runId ordering to prevent stale overwrite.

---

## Scope

### In Scope

- Shared coordinator/hook abstraction for Mapping Editor output execution lifecycle.
- Output-active execution trigger model and Fields-active dirty-only model.
- Pending debounce cancellation on Output close/unmount.
- Monotonic runId sequencing and stale completion rejection.

### Out of Scope

- Output viewer rendering.
- Node-to-Builder resolution.
