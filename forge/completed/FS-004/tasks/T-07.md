## Summary

Implement all 9 string operation functions. Most are straightforward wrappers around JavaScript string methods. `concat` is variadic, `substring` supports negative indices, and `contains` has special null handling (returns false instead of propagating null).

## Change Requirements

**concat(...values: string[]): string**
- Signature: 1 variadic string parameter (min 1), `handlesNull: false`
- Implementation: `args.join("")`
- Note: E005 for non-string args is handled by the evaluator's type check. The implementation can assume all args are strings.
- Note: Null propagation is handled by evaluator (if any arg is null, evaluator short-circuits before calling implementation)

**substring(value: string, start: number, end?: number): string**
- Signature: value (string, required), start (number, required), end (number, optional)
- Implementation:
  - If start is negative: `start = Math.max(0, value.length + start)`
  - If end is negative: `end = Math.max(0, value.length + end)`
  - If end is undefined: extract to end of string
  - Use `value.slice(resolvedStart, resolvedEnd)`
- Note: Use `slice` semantics for negative index handling

**upper(value: string): string**
- Implementation: `(args[0] as string).toUpperCase()`

**lower(value: string): string**
- Implementation: `(args[0] as string).toLowerCase()`

**trim(value: string): string**
- Implementation: `(args[0] as string).trim()`

**replace(value: string, search: string, replacement: string): string**
- Implementation: `value.replace(search, replacement)` (JS replace only replaces first occurrence by default with string arg)

**replaceAll(value: string, search: string, replacement: string): string**
- Implementation: `value.split(search).join(replacement)` or `value.replaceAll(search, replacement)`
- Note: `String.prototype.replaceAll` is available in ES2021+. Since the engine targets modern runtimes, either approach is acceptable.

**contains(haystack: string, needle: string): boolean**
- Signature: 2 required string params, `handlesNull: true`
- Implementation:
  - If haystack is null OR needle is null → return `false`
  - Otherwise: `(haystack as string).includes(needle as string)`
- This is a special null handler — returns false instead of null

**length(value: string): number**
- Signature: 1 required string param, `handlesNull: false`
- Implementation: `(args[0] as string).length`

## Verification Requirements

- **concat:**
  - 2 args: `concat("a", "b")` → `"ab"`
  - 3+ args: `concat("Hello", " ", "World")` → `"Hello World"`
  - Single arg: `concat("only")` → `"only"`
  - Empty strings: `concat("", "a", "")` → `"a"`

- **substring:**
  - Basic: `substring("Hello World", 0, 5)` → `"Hello"`
  - To end: `substring("Hello World", 6)` → `"World"`
  - Negative start: `substring("Hello", -3)` → `"llo"`
  - Negative end: `substring("Hello World", 0, -6)` → `"Hello"`
  - Out of bounds: `substring("Hi", 0, 100)` → `"Hi"`

- **upper:** `upper("hello")` → `"HELLO"`, `upper("ALREADY")` → `"ALREADY"`
- **lower:** `lower("HELLO")` → `"hello"`
- **trim:** `trim("  hello  ")` → `"hello"`, `trim("no-trim")` → `"no-trim"`

- **replace:**
  - First only: `replace("aaa", "a", "b")` → `"baa"`
  - No match: `replace("hello", "xyz", "abc")` → `"hello"`
  - Empty search: document behavior

- **replaceAll:**
  - All occurrences: `replaceAll("aaa", "a", "b")` → `"bbb"`
  - With dashes: `replaceAll("316-555-0182", "-", "")` → `"3165550182"`
  - No match: `replaceAll("hello", "xyz", "abc")` → `"hello"`

- **contains:**
  - Found: `contains("Hello World", "World")` → `true`
  - Not found: `contains("Hello", "xyz")` → `false`
  - Null haystack: `contains(null, "test")` → `false`
  - Null needle: `contains("hello", null)` → `false`
  - Both null: `contains(null, null)` → `false`
  - Case sensitive: `contains("Hello", "hello")` → `false`

- **length:**
  - `length("hello")` → `5`
  - `length("")` → `0`
  - Unicode: `length("café")` → `4` (basic test)

- TypeScript typecheck passes

## Blockers / Risks

- `substring` with negative indices: need to confirm behavior matches DSL spec's intent. The spec says "If negative, counts from end" which aligns with `String.prototype.slice` semantics.
- `replace` with empty search string has platform-specific behavior — document and test.

## Notes

- The evaluator's type checking ensures non-null string args reach the implementations (except `contains` which handles null itself).
- `concat` is variadic — its signature needs a variadic parameter to accept 1+ args.
- `substring` uses `slice`-like semantics for negative indices, not `substring()` (which clamps negatives to 0).
- `contains` is the only string function with `handlesNull: true`.
