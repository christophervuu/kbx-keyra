## Summary

Implement the 3 null handling functions: `default`, `coalesce`, and `isNull`. All three have `handlesNull: true` since their purpose is to explicitly deal with null values. These are among the simplest functions but foundational for DSL expressiveness.

---

## Scope

### In Scope

- Implement `default(value, fallback)` — return fallback when value is null
- Implement `coalesce(...values)` — return first non-null value (variadic, minimum 1 arg)
- Implement `isNull(value)` — return boolean indicating if value is null
- FunctionSignature for each (all with `handlesNull: true`)
- Registration exports
- Unit tests

### Out of Scope

- Null propagation logic in the evaluator (already implemented in FS-003)
- Other functions that handle null (eq, neq, if, contains, valueMap — those are in their respective category tasks)

## Change Requirements

**default(value: any, fallback: any): any**
- Signature: 2 required parameters, `handlesNull: true`
- Implementation: `return args[0] === null ? args[1] : args[0]`
- Both args are always evaluated (no short-circuit) — but that's the evaluator's concern, not the implementation's

**coalesce(...values: any[]): any**
- Signature: 1 variadic parameter, `handlesNull: true`
- Implementation: iterate args, return first non-null, or null if all null
- Note: E003 for zero args is handled by evaluator arity check (min 1 if the variadic param is required)

**isNull(value: any): boolean**
- Signature: 1 required parameter, `handlesNull: true`
- Implementation: `return args[0] === null`

All three are trivial implementations but critical for the null handling semantics of the DSL.

## Verification Requirements

- **default:**
  - `default(null, "fallback")` → `"fallback"`
  - `default("present", "fallback")` → `"present"`
  - `default(null, null)` → `null` (fallback is also null)
  - `default(0, "fallback")` → `0` (0 is not null)
  - `default("", "fallback")` → `""` (empty string is not null)
  - `default(false, "fallback")` → `false` (false is not null)

- **coalesce:**
  - `coalesce(null, null, "found")` → `"found"`
  - `coalesce("first", "second")` → `"first"`
  - `coalesce(null, null, null)` → `null`
  - `coalesce("only")` → `"only"` (single arg)
  - `coalesce(null)` → `null` (single null arg)
  - `coalesce(0, "other")` → `0` (0 is not null)

- **isNull:**
  - `isNull(null)` → `true`
  - `isNull("hello")` → `false`
  - `isNull(0)` → `false`
  - `isNull("")` → `false`
  - `isNull(false)` → `false`

- TypeScript typecheck passes
