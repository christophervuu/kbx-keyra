## Summary

Introduce the `TransformChainStep` type and evolve `InlineTransform` from a single transform (`{ functionName, args }`) to a chain model (`{ steps: readonly TransformChainStep[] }`). Update all factory functions, type guards, and existing tests to use the new shape. This is the foundational state model change that all subsequent tasks depend on.

## Change Requirements

The `InlineTransform` interface must change from:

```ts
interface InlineTransform {
  readonly functionName: string;
  readonly args: readonly ArgumentSlot[];
}
```

To:

```ts
interface TransformChainStep {
  readonly functionName: string;
  readonly args: readonly ArgumentSlot[];
}

interface InlineTransform {
  readonly steps: readonly TransformChainStep[];
}
```

`TransformChainStep` has the same shape as the old `InlineTransform`. This is intentional for mechanical migration.

Factory functions to add:
- `makeChainStep(functionName: string, args: readonly ArgumentSlot[] = []): TransformChainStep`
- `makeSingleStepTransform(functionName: string, args: readonly ArgumentSlot[] = []): InlineTransform` -- convenience for single-step transforms, returns `{ steps: [{ functionName, args }] }`

Existing test assertions that construct `InlineTransform` objects (e.g., `{ functionName: 'upper', args: [] }`) must be updated to `{ steps: [{ functionName: 'upper', args: [] }] }` or use the new factory helpers.
