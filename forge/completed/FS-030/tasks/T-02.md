## Change Requirements

The `generateInlineTransform()` function must change from generating a single function call wrapping the source to iterating through `transform.steps`:

```ts
function generateInlineTransform(sourcePath: string, transform: InlineTransform): string | null {
  let expression = `source(${quoteString(sourcePath)})`;
  for (const step of transform.steps) {
    const extraArgs: string[] = [];
    for (const arg of step.args) {
      const generated = generateSlot(arg);
      if (generated === null) return null;
      extraArgs.push(generated);
    }
    expression = `${step.functionName}(${[expression, ...extraArgs].join(', ')})`;
  }
  return expression;
}
```

If `transform.steps` is empty, return `null` (invalid state).

The `generateSlot()` function for `mode: 'source'` slots with a `transform` also needs to handle the new chain shape -- this should work automatically since it calls `generateInlineTransform()`.

All existing generator tests must be updated to construct `InlineTransform` using the new shape (e.g., `{ steps: [{ functionName: 'upper', args: [] }] }`). Use factory helpers from T-01 where appropriate.
