## Summary

Create a shared `ErrorBanner` component in `ui/src/components/` that renders an inline error message with optional retry button. The component consumes `AsyncState` in error status and conditionally renders the retry affordance based on the `retryable` flag. It should be drop-in composable for any feature surface that uses `useAsyncState`.

---

## Scope

### In Scope

- New `ui/src/components/ErrorBanner.tsx` component
- Props interface: error message, retryable flag, retry callback, optional className
- Convenience wrapper that accepts full `AsyncState` and `retry` action for zero-boilerplate usage
- Loading state during retry (shows spinner on retry button)
- Brief "Recovered" indication state after successful retry (when error was previously visible to user) — subtle green flash or brief text, auto-dismisses after ~2 seconds
- Accessible: appropriate ARIA role (`alert`), focus management
- Visual: Tailwind-styled inline banner (red for non-retryable, amber for retryable with retry button)
- Unit/component tests with React Testing Library

### Out of Scope

- Toast/notification system
- Global error boundary
- Feature-specific error surfaces (features compose ErrorBanner as needed)
- Animation/transitions

## Change Requirements

- Component API:
  ```typescript
  interface ErrorBannerProps {
    message: string;
    retryable?: boolean;
    onRetry?: () => void;
    retrying?: boolean;
    className?: string;
  }
  ```
- Additionally export a convenience component or helper that accepts `AsyncState` directly:
  ```typescript
  interface AsyncErrorBannerProps<T> {
    state: AsyncState<T>;
    retry: () => void;
    className?: string;
  }
  ```
- Visual design:
  - Full-width inline banner (not floating/toast)
  - Red background (light) + red text for non-retryable errors
  - Amber background (light) + amber text for retryable errors
  - Error icon (Lucide `AlertCircle` or `AlertTriangle`)
  - Message text
  - "Retry" button (only when `retryable: true` and `onRetry` provided)
  - Spinner on retry button when `retrying: true`
- Accessibility:
  - `role="alert"` on the banner container
  - Retry button has accessible label "Retry"
- Add to `ui/src/components/index.ts` barrel export
