## Summary

Implement runtime-environment endpoints/components that ingest artifacts, verify integrity, persist immutable artifacts locally, update local active pointers, and append deployment/rollback history without any runtime dependency on sandbox state.

---

## Scope

### In Scope

- Runtime deploy ingestion endpoint contract.
- Local immutable artifact persistence and hash verification.
- Active pointer update semantics (`mappingId -> artifactId`).
- Append-only runtime deployment history events for deploy/promote/rollback.
- Rollback pointer-change logic using existing local artifacts.

### Out of Scope

- Control-plane orchestration request flow (T-03).
- UI changes.

## Change Requirements

- Runtime deploy endpoint rejects artifact on hash mismatch.
- Runtime deploy endpoint rejects artifact payloads above configured maximum with deterministic remediation diagnostics.
- Successful ingestion stores artifact immutably and updates active pointer atomically or with safe failure semantics.
- Rollback records new event and repoints pointer without artifact mutation.
- If rollback target artifact is missing locally, endpoint returns `artifact_not_available_for_rollback` and does not auto-import in MVP.
- Runtime read path for execution/preview resolves only local pointer+artifact.

---

## Verification Requirements

- Integration tests for ingestion success/failure (hash mismatch, duplicate artifact, pointer update failure).
- Integration tests for payload-too-large rejection behavior.
- Rollback tests verifying pointer move + append-only history.
- Rollback tests verifying missing-artifact deterministic failure + remediation payload contract.
- Regression tests confirming runtime execution path does not read sandbox deployment state.

---

## Acceptance Checks

- Runtime ingestion endpoint enforces artifact integrity check prior to activation.
- Runtime ingestion endpoint enforces configured payload size limits with actionable error contract.
- Active pointer updates only on successful local artifact persistence.
- Rollback behavior is pointer-only and append-only.
- Missing rollback artifact returns `artifact_not_available_for_rollback` without implicit re-import.
- Runtime execution/lookup path uses local resources only.
- Targeted tests and typecheck pass.

---

## Blockers / Risks

- Ensuring idempotency for repeated relay calls with same artifact and environment.

---

## Notes

- Keep runtime-side contracts minimal and deterministic for internal deployment APIs.
