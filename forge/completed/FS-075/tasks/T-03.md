## Summary

Add static and behavioral checks that guarantee AI invocations remain backend-mediated through standard adapter/backend paths and that AI secrets cannot appear in browser code or bundles.

---

## Scope

### In Scope

- Static enforcement rules preventing direct browser model/AI-runtime usage.
- Checks that AI hooks/components route through `ApiAdapter`.
- Secret exposure scanning for UI source/build artifacts and env usage patterns.
- Test coverage and failure reporting for these policies.

### Out of Scope

- Rewriting AI feature logic beyond what is required for policy compliance.
- New secret-management platform adoption.

## Change Requirements

- Fail verification when browser code imports forbidden AI/model layers.
- Fail verification on direct AI endpoint/provider calls that bypass adapter contracts.
- Fail verification when forbidden secret variables/tokens appear in client surfaces.

---

## Verification Requirements

- Policy checks run in deterministic gate command path.
- Seeded violation fixtures trigger expected failures.
- Compliance path passes on current canonical architecture.

---

## Acceptance Checks

- Backend-only enforcement checks exist and block adapter-bypass/browser-model usage.
- No-browser-secret checks exist and block forbidden exposure.
- Results are integrated into acceptance gate output.

---

## Blockers / Risks
