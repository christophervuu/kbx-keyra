## Summary

Create the `SchemaLibraryCard` component that renders a single schema as a visually rich card with name, origin badge, scope badge, field count, format, project usage count, and sync status indicator. The card is clickable/keyboard-navigable and routes to the Schema Detail page (`/schemas/:schemaId`).

---

## Scope

### In Scope

- `SchemaLibraryCard` component accepting a `SchemaLibraryItem` prop.
- Visual layout with all required metadata fields.
- Origin badge with emoji + color: 📚 CDM (purple), 📄 Published (blue), 💾 Local (green).
- Scope badge: "Global" or "Project-Level" with distinct styling.
- Field count display: "{N} fields".
- Format display: "JSON Schema" / "XSD" / "Inferred".
- Project usage: "{N} projects" with tooltip showing project names (if ≤ 5).
- Sync status indicator: ✓ Synced (green) / ⚠ Not synced (amber) / ⚠ Local changes (amber) / ⚠ Inferred (amber) / neutral for upload-only.
- Click handler navigating to `/schemas/:schemaId` via `react-router` `useNavigate`.
- Keyboard accessibility: `tabIndex={0}`, Enter/Space triggers navigation, focus ring.
- Component tests covering all variants and accessibility.

### Out of Scope

- Grid layout container (T-04 handles grid placement).
- Loading skeleton variant (T-04 handles skeleton).
- Filter/sort interaction (T-03).
- Any write/edit actions on the card.

## Change Requirements

**Component props:**
```ts
interface SchemaLibraryCardProps {
  item: SchemaLibraryItem;
}
```

**Visual structure:**
- Outer container: `Card`-like styling with border, rounded corners, hover shadow, cursor-pointer.
- Primary row: Schema name (font-semibold, truncate if long).
- Badge row: Origin badge + Scope badge (inline, gap-2).
- Metadata row: Field count · Format · Sync status.
- Footer row: Project usage (e.g., "Used by 3 projects").

**Badge styling:**
- Origin badges use Tailwind background + text color:
  - CDM: `bg-purple-100 text-purple-800` (📚 prefix)
  - Published: `bg-blue-100 text-blue-800` (📄 prefix)
  - Local: `bg-green-100 text-green-800` (💾 prefix)
- Scope badges:
  - Global: `bg-gray-100 text-gray-700`
  - Project-Level: `bg-amber-100 text-amber-700`

**Sync status indicator:**
- Synced: `✓` with `text-green-600`
- Not synced: `⚠` with `text-amber-600`
- Local changes: `⚠` with `text-amber-600`
- Inferred: `⚠` with `text-amber-600`
- Local (upload, no sync concept): no indicator or neutral dash

**Interaction:**
- `onClick` → `navigate(PATHS.SCHEMA_DETAIL.replace(':schemaId', item.schemaId))`
- `onKeyDown` for Enter/Space → same navigation
- `tabIndex={0}` for keyboard focus
- `role="article"` or semantic card structure
- `aria-label` including schema name for screen readers
