## Summary

Create the `SchemaLibraryPage` component that assembles all Schema Library sub-components into the final page. It wires the `useSchemaLibrary` hook to the search/filter/sort controls and card grid, handles loading skeleton, error banner, empty state, and no-results state, and updates the route-level page in `routes/pages/SchemaLibrary.tsx` to render the feature page.

---

## Scope

### In Scope

- `SchemaLibraryPage` component in `ui/src/features/schemas/components/`.
- Page header with `PageHeader` showing "Schema Library ({N} schemas)".
- Skeleton loading state (6-8 shimmer cards) with `role="status"` and sr-only text.
- Error state: inline alert banner with "Failed to load schemas" + retry button, `role="alert"`.
- Empty state (no schemas): icon + "No schemas available" + subtext.
- No-results state: delegates to `SchemaLibraryNoResults` (T-03).
- Card grid layout: responsive grid (2-3 columns on desktop).
- Wiring: hook state → controls → card list.
- Route page update: `ui/src/routes/pages/SchemaLibrary.tsx` renders `SchemaLibraryPage`.
- Preserve `data-testid="page-schema-library"`.
- Integration/component tests for the assembled page.

### Out of Scope

- Card component internals (T-02).
- Control component internals (T-03).
- Hook data logic (T-01).
- Schema Detail navigation behavior (tested at card level in T-02).
- Mobile layout.

## Change Requirements

**SchemaLibraryPage component:**

```tsx
export function SchemaLibraryPage() {
  const {
    filteredItems, totalCount, status, error,
    filters, sort,
    setSearch, toggleOriginFilter, toggleFormatFilter, toggleScopeFilter,
    setSort, clearFilters, retry
  } = useSchemaLibrary();

  // Render states based on `status`:
  // - 'loading' → SchemaLibrarySkeleton
  // - 'error' → error banner with retry
  // - 'success' + totalCount === 0 → SchemaLibraryEmptyState
  // - 'success' + filteredItems.length === 0 → SchemaLibraryNoResults
  // - 'success' + filteredItems.length > 0 → controls + card grid
}
```

**Layout structure (loaded state):**
1. `PageHeader` with title "Schema Library ({totalCount} schemas)" and optional description.
2. Controls bar: search + filter toggles + sort control (horizontal row).
3. Active filter chips (below controls, above grid).
4. Card grid: responsive CSS grid (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`).

**SchemaLibrarySkeleton:**
- 6 placeholder cards with Tailwind `animate-pulse` styling.
- Each card mimics the card layout (title bar + badge row + metadata row).
- `role="status"` with `<span className="sr-only">Loading schemas</span>`.

**SchemaLibraryEmptyState:**
- Centered layout.
- Icon (e.g., Lucide `Database` or `FileText`).
- Heading: "No schemas available".
- Subtext: "Upload a schema from a Project Overview page, or link one from the CDM library."
- No action button (upload lives on Project Overview).

**Route page update:**
```tsx
// ui/src/routes/pages/SchemaLibrary.tsx
import { SchemaLibraryPage } from '@/features/schemas';

export default function SchemaLibrary() {
  return <SchemaLibraryPage />;
}
```
- Preserve `data-testid="page-schema-library"` (move to SchemaLibraryPage wrapper div).
