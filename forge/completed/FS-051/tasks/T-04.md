## Summary

Add a ValidationSummaryRow (or reuse ArrayBuilder's existing implementation) between the BuilderFeedbackArea and the scrollable content area in ScalarFieldBuilder. This pinned bar shows error, warning, and incomplete counts, matching the array builder's existing pattern for surfacing validation state without requiring the user to scroll.

---

## Scope

### In Scope

- Add a validation summary row to ScalarFieldBuilder, positioned between BuilderFeedbackArea and the scrollable content
- The row shows error count, warning count, and/or incomplete indicator (matching ArrayBuilder's ValidationSummaryRow)
- The row is pinned (`shrink-0`) and does not scroll with the content
- Derive counts from the current field's validation diagnostics and chain completeness
- Use the same visual styling as ArrayBuilder's ValidationSummaryRow (compact bar with severity-colored badges)
- If ArrayBuilder's ValidationSummaryRow is implemented as a standalone component, reuse it directly. If it's inline, extract it as a shared component for both builders.

### Out of Scope

- BuilderFeedbackArea changes
- Validation logic changes (existing validation sources are sufficient)
- Visual frame changes (T-02 scope)
- Completion status changes (T-03 scope)
