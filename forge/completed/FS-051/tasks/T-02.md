## Summary

Remove the outer border, rounded corners, and background from ScalarFieldBuilder's wrapper. Remove the header background. Align scrollable content spacing and divider treatment to match ArrayBuilder's visual patterns. This task addresses the most visible visual inconsistency — the scalar builder has a boxed appearance while the array builder renders without a frame.

---

## Scope

### In Scope

- Remove `rounded-lg border border-slate-700 bg-slate-900/30` from ScalarFieldBuilder's outer wrapper — replace with `flex flex-col gap-0 overflow-y-auto` (matching ArrayBuilder)
- Remove `bg-slate-900/40` from ScalarFieldBuilder header — keep `shrink-0 border-b border-slate-700 px-4 py-3`
- Remove `bg-slate-900/20` from the scrollable content area
- Align scrollable content padding to `space-y-4 px-4 py-4` (matching ArrayBuilder)
- Ensure divider treatment uses `h-px bg-slate-700/60` (matching ArrayBuilder's divider pattern)
- Remove `bg-slate-900/40` from the footer action row — keep `shrink-0 border-t border-slate-700 px-4 py-3`

### Out of Scope

- Header content changes (completion status, overflow menu) — T-03 scope
- Validation summary row — T-04 scope
- Action row content changes — T-05 scope
- ArrayBuilder changes
- ChainBuilder internal styling
- BuilderFeedbackArea changes
