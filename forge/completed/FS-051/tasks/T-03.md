## Summary

Add a completion status label (Not started / In progress / Complete / Has errors) to the ScalarFieldBuilder header row 2, matching the ArrayBuilder's existing pattern. This closes the gap where the scalar builder shows only a "Required" label while the array builder shows both "Required" and a completion status indicator.

---

## Scope

### In Scope

- Add a completion status label to ScalarFieldBuilder header row 2, adjacent to the existing "Required" label
- Derive completion status from the chain state and validation:
  - **Not started:** no source selected (chain source is `none`)
  - **Complete:** chain has a valid source, all steps structurally complete, expression is non-empty and valid
  - **In progress:** chain has a source but is structurally incomplete (e.g., step has missing args)
  - **Has errors:** chain has validation errors (parse errors, type mismatches)
- Use the same visual treatment as ArrayBuilder's completion status labels (muted for not-started, green for complete, blue for in-progress, red/amber for errors)
- Ensure the completion status updates reactively as the user edits the chain

### Out of Scope

- Changes to ArrayBuilder's completion status (already implemented)
- Visual frame changes (T-02 scope)
- Validation summary row (T-04 scope)
- Action row changes (T-05 scope)
