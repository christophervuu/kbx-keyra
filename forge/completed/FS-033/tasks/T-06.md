## Change Requirements

1. **Mock `matchMedia`:** Set up a `matchMedia` mock that can be configured per test to simulate wide/medium/narrow viewports. This is needed because `useTestLabLayout` uses `matchMedia` for breakpoint detection.

2. **New test cases:**

   - **Wide viewport rendering (AE-01):** Mock wide viewport → assert 4 ResultPanels visible by testId, assert no tab bar
   - **Medium viewport rendering (AE-02):** Mock medium viewport → assert vertical stack, Output panel present and not collapsible, other panels have collapse toggles
   - **Narrow viewport rendering (AE-03):** Mock narrow viewport → assert tab bar present, assert tab switching changes visible panel
   - **Panel collapse (AE-04):** Click Diagnostics collapse toggle → assert panel content hidden, click again → content visible
   - **Trace disabled (AE-05):** Set traceEnabled false → Trace panel collapsed with disabled message
   - **Empty state (AE-10):** No execution run → each panel shows its empty state
   - **Diagnostic badge (AE-11):** After execution with diagnostics → Diagnostics panel header shows count badge
   - **Summary bar stats (AE-09):** After execution → summary bar shows duration, rule counts, diagnostic counts
   - **Corrupt localStorage (AE-12):** Set `keyra:testlab-layout` to invalid JSON → page renders with default layout, no errors
   - **Main split ratio (AE-13):** Assert left panel width is driven by `layout.mainSplit` (default ~35%), not hardcoded; verify main split divider renders

3. **Preserve existing tests:** All existing tests for execution flow, run button state, test case loading, auto-run toggle, trace toggle should continue to pass. Update selectors if the DOM structure changed (e.g., tab-related testIds that may have moved to the narrow breakpoint rendering path).

## Notes

- For `matchMedia` mocking, use a pattern like:
  ```ts
  function mockMatchMedia(width: number) {
    Object.defineProperty(window, 'matchMedia', {
      writable: true,
      value: vi.fn().mockImplementation(query => ({
        matches: /* evaluate query against width */,
        media: query,
        addEventListener: vi.fn(),
        removeEventListener: vi.fn(),
        ...
      })),
    });
  }
  ```
- Consider grouping tests by breakpoint for readability
- The corrupt localStorage test should set the value before rendering and verify no errors in console
