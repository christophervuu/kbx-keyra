## Summary

Add a compact sticky execution summary bar between the top bar and the result panel area in `AdvancedTestingPage`. The bar displays the current execution status, duration, rule statistics, and diagnostic severity counts, providing at-a-glance context without looking at individual panels.

---

## Scope

### In Scope

- Create `ExecutionSummaryBar` component at `ui/src/features/mappings/components/preview/ExecutionSummaryBar.tsx`
- Render between the top bar and the result panel area in `AdvancedTestingPage`
- Display execution status: idle, executing (with spinner), success, error
- Display duration in ms when available
- Display rule stats: evaluated, succeeded, failed counts
- Display diagnostic counts by severity: errors (red badge), warnings (amber badge), info (blue badge)
- Sticky positioning so it remains visible when scrolling panel content
- Compact height (~32px)
- Unit tests for rendering states

### Out of Scope

- Changes to execution logic or `usePreviewExecution`
- Changes to the top bar controls
- Layout resize behavior (T-04)

## Change Requirements

1. **`ExecutionSummaryBar` component:**

   Props:
   ```ts
   interface ExecutionSummaryBarProps {
     state: PreviewExecutionState;
     className?: string;
   }
   ```

   The component extracts all display data from `PreviewExecutionState`:

   - **Idle:** "No results yet" with muted text
   - **Executing:** spinner + "Executing…"
   - **Success:** green dot + "Success" + duration badge + rule stats + diagnostic badges
   - **Error:** red dot + "Error" + error message (truncated)
   - **Timeout:** amber dot + "Timeout"

   Rule stats (from `state.result.stats` when available):
   - `{rulesEvaluated} rules: {rulesSucceeded} passed, {rulesFailed} failed`

   Diagnostic badges (from `state.result.diagnostics` when available):
   - Count by severity: `error`, `warning`, `info`
   - Only show badges for severities with count > 0
   - Color: error = red-500, warning = amber-500, info = blue-500

   Duration: `{stats.durationMs}ms` rendered as a subtle badge

2. **Integration in `AdvancedTestingPage`:**
   - Insert `ExecutionSummaryBar` between the top bar and the result area
   - Pass `state` from `usePreviewExecution`
   - Position: sticky within the right panel area, so it stays visible when individual panels scroll
   - Render at all breakpoints (wide, medium, narrow)

3. **Update barrel:** Export `ExecutionSummaryBar` from `preview/index.ts`
