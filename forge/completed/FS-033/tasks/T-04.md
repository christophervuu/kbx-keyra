## Summary

Add mouse-event-based resizable dividers to the Advanced Testing page. This includes: (1) a main split divider between the left panel (source + test cases) and the right result area, (2) a vertical divider between the left and right result columns in the wide 2x2 grid, and (3) a horizontal divider between the top and bottom result rows. Sizes are persisted to localStorage via `useTestLabLayout`.

---

## Scope

### In Scope

- Main split divider between left panel (source + test cases) and right result area — active at all breakpoints (wide and medium)
- Vertical divider between left column (Output + Diagnostics) and right column (Diff + Trace) — wide breakpoint only
- Horizontal divider between top row (Output + Diff) and bottom row (Diagnostics + Trace) — wide breakpoint only
- Mouse-event-based drag interaction (mousedown/mousemove/mouseup) — same pattern as `useResizableLayout` in Mapping Editor
- Cursor forcing during drag (`col-resize` / `row-resize`)
- Text selection disabled during drag
- Visual hover feedback on divider (subtle highlight)
- Size clamping to minimums: main split [0.2, 0.5], column/row splits [0.2, 0.8] — each corresponding to minimum panel sizes
- Persist updated split ratios via `useTestLabLayout.setMainSplit` / `setColumnSplit` / `setRowSplit`
- Column and row dividers only active in `wide` breakpoint — not rendered at `medium` or `narrow`

### Out of Scope

- Panel collapse logic (handled by T-02/T-03)
- Execution summary bar (T-05)

## Change Requirements

1. **Main split divider:** Between the left panel and right result area:
   - Rendered at all breakpoints (wide and medium) as a vertical divider
   - Drag updates `setMainSplit` ratio, clamped to [0.2, 0.5]
   - Same visual style and interaction as the grid dividers below
   - Left panel minimum width: 200px

2. **Grid divider elements:** In the wide layout grid, insert thin divider elements at the column and row gaps:
   - Vertical divider: positioned between the two result columns, full height of the grid
   - Horizontal divider: positioned between the two result rows, full width of the grid
   - Divider visual: 4px wide/tall, `bg-slate-700` default, `bg-slate-500` on hover, `bg-blue-500` during drag

3. **Drag interaction:**
   - `mousedown` on divider starts tracking: attach `mousemove` / `mouseup` listeners to `document`
   - `mousemove` calculates new split ratio based on mouse position relative to the grid container
   - Apply ratio clamping: main split [0.2, 0.5], column split [0.2, 0.8], row split [0.2, 0.8]
   - `mouseup` ends tracking, removes listeners, persists via `useTestLabLayout`
   - During drag: set `document.body.style.cursor` to `col-resize` or `row-resize`, set `document.body.style.userSelect = 'none'`
   - On mouseup: restore cursor and userSelect

3. **Grid update:** The wide layout grid template must use the split ratios from `useTestLabLayout` to set `grid-template-columns` and `grid-template-rows` dynamically.

4. **Interaction isolation:** Drag uses raw mouse events (not HTML5 DnD) to avoid conflicts with source-field drag-and-drop on the Mapping Editor page. This page doesn't have that concern but the pattern should be consistent.

5. **Main split update:** The left panel width set in T-03 via `layout.mainSplit` must respond to drag updates in real-time during the drag interaction (not just on mouseup).
