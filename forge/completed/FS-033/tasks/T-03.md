## Summary

Replace the tabbed right panel in `AdvancedTestingPage` with the multi-panel simultaneous layout. Replace the hardcoded 35/65 left/right split with the hook-driven `mainSplit` ratio. On wide viewports, render a 2x2 grid of `ResultPanel`-wrapped display components. On medium viewports, render a vertical stack. On narrow viewports, fall back to the existing tab layout. Wire `useTestLabLayout` for state management and `ResultPanel` for panel chrome.

## Change Requirements

The `AdvancedTestingInner` component must be updated to:

1. **Replace tab state** with `useTestLabLayout({ traceEnabled })` for panel/layout state management

2. **Replace hardcoded left panel width:** The current `w-[35%]` on the left panel div must be replaced with a dynamic width using `layout.mainSplit` (e.g., `style={{ width: \`${layout.mainSplit * 100}%\` }}`). The right panel fills the remaining space via `flex: 1`. T-04 will add the drag handle between them.

3. **Conditionally render** based on `layout.breakpoint`:
   - `'wide'`: 2x2 CSS Grid layout
   - `'medium'`: vertical flex stack
   - `'narrow'`: existing tabbed layout (preserve current `TABS` array, `activeTab` state, and tab rendering logic)

4. **Wide layout grid structure:**
   ```
   display: grid
   grid-template-columns: {columnSplit}fr {1-columnSplit}fr
   grid-template-rows: {rowSplit}fr {1-rowSplit}fr
   ```
   With divider gaps (T-04 will add drag handles into these gaps later).

5. **Wrap each display component in `ResultPanel`:**
   - Output: `title="Output"`, not collapsible at medium, empty state: "Run a test to see the mapping output"
   - Diff: `title="Diff"`, badge: none, empty state: "Run a test and set expected output to see the diff"
   - Diagnostics: `title="Diagnostics"`, badge: `{ count: diagnosticCount, variant: 'warning' }` when count > 0, empty state: "No diagnostics from the last execution"
   - Trace: `title="Trace"`, collapsed driven by layout state + traceEnabled, empty state: "Enable Trace in the top bar to see execution trace" (when disabled) or "Run a test with Trace enabled to see trace entries" (when enabled but no data)

6. **Medium layout:** Panels stack vertically. Output is always expanded (not collapsible). Diff, Diagnostics, Trace have collapse toggles. Collapsed headers remain in their natural document order. Each panel gets equal flex share of remaining space when expanded.

7. **Preserve existing behavior:** All execution logic, source data handling, test case loading, top bar controls remain unchanged. The `loadKey`, `loadedSourceData`, `loadedExpectedOutput`, `currentExpectedOutput` state and handlers are untouched.

8. **Idle/executing state rendering:** Before any execution or during execution, the ResultPanels should show their empty states (idle) or a lightweight loading indicator (executing). The global idle/loading overlays that currently cover the entire right panel should be replaced by per-panel empty state rendering within their ResultPanel wrappers.
