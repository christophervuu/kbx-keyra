## Summary

Create a `useTestLabLayout` hook that manages the Test Lab multi-panel layout state: panel collapsed/expanded states, responsive breakpoint detection (wide/medium/narrow), divider split ratios (including the main left/right split), trace-enabled auto-expand/collapse behavior, and localStorage persistence with graceful fallback. This hook is the state backbone for the redesigned Advanced Testing page.

---

## Scope

### In Scope

- Create `useTestLabLayout` hook at `ui/src/features/mappings/hooks/use-test-lab-layout.ts`
- Manage collapsed state for each panel: `output`, `diff`, `diagnostics`, `trace`
- Detect responsive breakpoint: `wide` (>= 1280px), `medium` (1024–1279px), `narrow` (< 1024px)
- Manage split ratios: `mainSplit` (0-1) for left/right main divider, `columnSplit` (0-1) for wide layout vertical divider, `rowSplit` (0-1) for wide layout horizontal divider
- Accept `traceEnabled` as input; auto-expand trace panel when enabled, auto-collapse when disabled
- Persist layout to localStorage (`keyra:testlab-layout`) on changes
- Read persisted layout on mount with graceful fallback for missing/invalid data
- Expose toggle functions per panel, split ratio setters (including main split)
- Unit tests for all state transitions

### Out of Scope

- Drag handle mechanics (handled by T-04 which uses this hook's split ratio setters)
- Rendering or DOM — this is a pure state hook
- Execution summary bar (T-05)

## Change Requirements

The hook must expose the following contract:

```ts
interface UseTestLabLayoutParams {
  traceEnabled: boolean;
}

type LayoutBreakpoint = 'wide' | 'medium' | 'narrow';

interface TestLabLayoutState {
  breakpoint: LayoutBreakpoint;
  collapsed: {
    output: boolean;
    diff: boolean;
    diagnostics: boolean;
    trace: boolean;
  };
  mainSplit: number;   // 0-1 ratio for left/right main divider (default 0.35)
  columnSplit: number; // 0-1 ratio for wide mode vertical divider
  rowSplit: number;    // 0-1 ratio for wide mode horizontal divider
}

interface UseTestLabLayoutResult {
  layout: TestLabLayoutState;
  togglePanel: (panel: 'output' | 'diff' | 'diagnostics' | 'trace') => void;
  setMainSplit: (ratio: number) => void;
  setColumnSplit: (ratio: number) => void;
  setRowSplit: (ratio: number) => void;
}
```

Behavior rules:
- **Breakpoint detection:** Use `window.matchMedia` with listeners. Update `breakpoint` on window resize.
- **Default state:** `mainSplit: 0.35`, `columnSplit: 0.5`, `rowSplit: 0.5`, all panels expanded except `trace` when `traceEnabled === false`
- **Output panel:** Not collapsible at `medium` breakpoint. `togglePanel('output')` is a no-op at medium.
- **Trace auto-behavior:** When `traceEnabled` changes from `false` to `true`, auto-expand trace. When `traceEnabled` changes from `true` to `false`, auto-collapse trace.
- **Narrow breakpoint:** At narrow, the hook returns the layout state but the rendering layer (T-03) will ignore multi-panel state and render tabs instead.
- **Persistence:** Write to `keyra:testlab-layout` on every state change. Read on mount. Invalid JSON falls back to defaults silently. Storage write failures are caught and ignored.
- **Split ratio clamping:** `mainSplit` is clamped to [0.2, 0.5] — left panel minimum 20%, maximum 50%. `columnSplit` and `rowSplit` are clamped to [0.2, 0.8] to prevent panels from becoming invisibly small.
