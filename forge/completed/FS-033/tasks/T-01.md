## Summary

Create a reusable `ResultPanel` component that wraps individual result displays (Output, Diff, Diagnostics, Trace) with consistent chrome: a header bar with title and optional badge, collapse/expand toggle, and empty state rendering. This component is the building block for the multi-panel layout and is independent of the layout itself.

---

## Scope

### In Scope

- Create `ResultPanel` component at `ui/src/features/mappings/components/preview/ResultPanel.tsx`
- Header bar: title text (left), optional badge with count and color variant, collapse/expand chevron button (right)
- Collapsed state: only header visible; children remain mounted but hidden (CSS `hidden` or `h-0 overflow-hidden`)
- Empty state: when `isEmpty` is true, render `emptyState` node instead of children
- Collapsible prop (default true): when false, hide the collapse toggle
- Focus ring on collapse button for accessibility
- `data-testid` prop support
- `className` prop for layout integration
- Unit tests for all rendering states

## Change Requirements

The `ResultPanel` component must implement the following props contract:

```ts
interface ResultPanelProps {
  title: string;
  badge?: { count: number; variant: 'info' | 'warning' | 'error' };
  collapsed: boolean;
  onToggleCollapse: () => void;
  collapsible?: boolean;
  emptyState?: React.ReactNode;
  isEmpty?: boolean;
  children: React.ReactNode;
  className?: string;
  testId?: string;
}
```

Rendering behavior:
- Header bar is always visible regardless of collapsed state
- Badge renders as a small pill next to the title with color coding: `info` = blue, `warning` = amber, `error` = red
- Collapse toggle uses a Lucide chevron icon (ChevronDown when expanded, ChevronRight when collapsed)
- When collapsed, content area is hidden but children stay in the DOM (use CSS visibility approach, not conditional rendering)
- When `isEmpty` is true and component is expanded, render `emptyState` instead of `children`
- Header has a subtle bottom border; background matches panel theme (slate-900/950)
- Collapse button has `aria-expanded` attribute and `aria-label`

Update `ui/src/features/mappings/components/preview/index.ts` to export `ResultPanel`.
