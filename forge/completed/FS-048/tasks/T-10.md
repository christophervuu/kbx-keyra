## Summary

Complete the end-to-end integration of the Auto-Map Review Workspace into the Mapping Editor page. This includes wiring the workspace hook to the workspace components, updating ObjectSummaryPanel to show persisted suggestion indicators, retiring the right-side drawer composition, and ensuring the complete user flow works from trigger to review to exit.

---

## Scope

### In Scope

- Wire `useAutoMapWorkspace` hook in the MappingEditor page composition
- Connect `AutoMapWorkspace` + `WorkspaceToolbar` + `WorkspaceSuggestionCard[]` + `WorkspaceSuggestionPreview` in the center panel slot
- Update `ObjectSummaryPanel`:
  - Show "N suggestions pending review" indicator below "Auto-Map This Section" button when persisted suggestions exist
  - "Auto-Map This Section" button enters workspace mode (calls `enterAutoMapWorkspace`)
  - If persisted suggestions exist: label changes to "Review Auto-Map Suggestions" (enters workspace, loads persisted state)
- Add **EditorTopBar re-entry affordance**:
  - When persisted suggestions exist for any section of the current mapping, show a subtle status pill or small link in `EditorTopBar`
  - Example: a small pill like "Auto-Map: 3 pending" or a text link "Return to Auto-Map review"
  - Clicking it enters workspace mode for the section with persisted suggestions
  - This is a persistent, discoverable affordance — not a temporary toast
  - Visually subtle (secondary/muted styling) — not a dominant global CTA
  - Hidden when no persisted suggestions exist
- Retire the right-side `AutoMapReviewDrawer`:
  - Remove `AutoMapReviewDrawer` composition from the route page level
  - Remove the mutual-exclusion logic with `VersionHistoryDrawer`
  - Keep the component file for now but remove the render call
- Update `MappingEditorPage` center panel:
  - When `view === 'automap'`: render the fully-wired `AutoMapWorkspace`
  - Pass all hook methods to workspace components
  - Wire preview context for source data availability
- Ensure "Auto-Map This Section" triggers in `ObjectSummaryPanel` correctly:
  - First time (no persisted suggestions): enter workspace mode + trigger generation
  - Re-entry (persisted suggestions exist): enter workspace mode + load from persistence
- Navigation guard: if the user has pending suggestions, show a brief indicator but do not block navigation (suggestions are persisted)
- Update barrel exports as needed

### Out of Scope

- Deleting the old `AutoMapReviewDrawer` component file (cleanup can happen in a follow-up)
- Deleting the old `useAutoMapReview` hook file (cleanup can happen in a follow-up)
- Backend changes
- New routes

## Change Requirements

- `MappingEditor.tsx` (route page):
  - Replace `useAutoMapReview` with `useAutoMapWorkspace`
  - Remove `AutoMapReviewDrawer` render call
  - Remove mutual-exclusion logic between Auto-Map drawer and Version History drawer
  - Wire `enterAutoMapWorkspace` / `exitAutoMapWorkspace` to hook and view state
  - Pass workspace props to `MappingEditorPage`

- `MappingEditorPage.tsx`:
  - When `view === 'automap'`: render `AutoMapWorkspace` with wired props in center panel slot
  - Wire `toolbarSlot` with `WorkspaceToolbar`
  - Wire card list with `WorkspaceSuggestionCard` mapped over `filteredItems`
  - Wire preview via `WorkspaceSuggestionPreview` in card `previewSlot`

- `ObjectSummaryPanel.tsx`:
  - Add `hasPersistedSuggestions: boolean` prop
  - Add `pendingSuggestionCount: number` prop
  - When `hasPersistedSuggestions`:
    - Show "N suggestions pending review" below the Auto-Map button
    - Change button label to "Review Auto-Map Suggestions"
  - `onAutoMap` callback triggers workspace entry (not drawer open)

- `EditorTopBar.tsx`:
  - Add `autoMapPendingCount: number` prop (0 = no affordance shown)
  - Add `autoMapSectionPath: string | null` prop
  - Add `onReturnToAutoMap: () => void` prop
  - When `autoMapPendingCount > 0`:
    - Render a subtle status pill or text link in the top bar (secondary styling, not primary button)
    - Content: e.g., "Auto-Map: N pending" or "Return to review (N)"
    - Clicking fires `onReturnToAutoMap()` which enters workspace mode
  - When `autoMapPendingCount === 0`: affordance is hidden
  - Placement: in the action area of Row 2, before or after the Save button — visually secondary

- Drawer retirement:
  - Remove `<AutoMapReviewDrawer>` JSX from `MappingEditor.tsx`
  - Remove associated state/props (`isAutoMapDrawerOpen`, etc.)
  - Remove drawer-related mutual exclusion with `VersionHistoryDrawer`
  - Version History drawer should work independently (no longer needs drawer exclusion)
