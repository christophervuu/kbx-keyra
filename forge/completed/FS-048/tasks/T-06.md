## Summary

Create the `WorkspaceSuggestionCard` component that renders each suggestion in the Auto-Map Review Workspace. This evolves the FS-046 `SuggestionReviewCard` to take advantage of the wider middle panel with expanded/collapsed states, richer expression comparison, status badges, and a preview slot.

---

## Scope

### In Scope

- Create `ui/src/features/mappings/components/WorkspaceSuggestionCard.tsx`:
  - **Collapsed state** (default for accepted/edited/dismissed):
    - Target field path
    - Status badge (Suggested / Accepted / Edited / Dismissed / Stale)
    - One-line expression summary (truncated to ~80 chars)
    - Expand toggle
  - **Expanded state** (default for suggested/stale):
    - Target field path
    - Status badge with color coding
    - New/Replace badge
    - Current expression section (if replacing): the expression at generation time
    - Suggested expression section: the AI-proposed expression
    - Explanation text
    - Confidence badge (High ≥ 0.8 / Medium ≥ 0.5 / Low < 0.5) with color
    - Validation badge (Valid/Warning/Invalid) with expandable diagnostics
    - Preview slot (rendered by parent via render prop or children — actual preview in T-09)
    - Stale indicator (when `status === 'stale'`): warning message + per-item Refresh button
    - Action buttons:
      - Accept (primary)
      - Edit (secondary)
      - Dismiss (tertiary) — or "Keep Current" for replacement suggestions
      - Undo (only when dismissed)
      - Refresh (only when stale)

- Status badge color mapping:
  - Suggested: blue
  - Accepted: green
  - Edited: purple
  - Dismissed: gray
  - Stale: yellow/amber

- Expression comparison:
  - Side-by-side layout when panel width allows (> 600px content area)
  - Stacked layout for narrower panels
  - Syntax-highlighted DSL expressions (use existing `dsl-tokenizer.ts` if practical, otherwise plain text with monospace font)
  - "No current rule" placeholder when `existingExpressionAtGeneration` is null

### Out of Scope

- Preview evaluation logic (T-09)
- Filter logic (T-07)
- Bulk actions (T-07)
- Per-suggestion refresh backend call (T-08)

## Change Requirements

- `WorkspaceSuggestionCard` props:
  - `item: SuggestionWorkspaceItem`
  - `isExpanded: boolean`
  - `onToggleExpand: () => void`
  - `onAccept: (targetPath: string) => void`
  - `onEdit: (targetPath: string) => void`
  - `onDismiss: (targetPath: string) => void`
  - `onUndoDismiss: (targetPath: string) => void`
  - `onRefreshItem?: (targetPath: string) => void`
  - `previewSlot?: React.ReactNode` (for T-09 preview integration)

- Cards must be keyboard accessible:
  - Expand/collapse toggle: button with `aria-expanded`
  - Action buttons: focusable with descriptive labels
  - Status badges: informational text (not interactive)

- Expression comparison must handle:
  - Long expressions with wrapping
  - Null existing expression ("No current rule" placeholder)
  - Expression truncation in collapsed state

- Diagnostics section:
  - Expandable/collapsible within the card
  - Shows diagnostic code, severity icon, and message
  - Empty when no diagnostics

- Dismissed state:
  - Card collapses to single row with "Dismissed" badge and Undo button
  - Undo restores full expanded view

- "Keep Current" replaces "Dismiss" label when `isNew === false` (replacing an existing rule)
