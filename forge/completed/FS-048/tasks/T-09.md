## Summary

Add optional preview support to the Auto-Map Review Workspace. When sample source data is available via PreviewContext, each expanded suggestion card shows the evaluated output of both the current expression and the suggested expression, enabling side-by-side comparison of what the suggestion would produce.

---

## Scope

### In Scope

- Create `ui/src/features/mappings/hooks/use-suggestion-preview.ts`:
  - Accepts `expression: string`, `sourceData: unknown | null`
  - Returns `{ result: unknown | null; error: string | null; isEvaluating: boolean }`
  - Uses `evaluateExpression()` from `ui/src/lib/engine/`
  - Only evaluates when `sourceData` is non-null and expression is non-empty
  - Debounced evaluation (150ms) to avoid excess computation

- Create `ui/src/features/mappings/components/WorkspaceSuggestionPreview.tsx`:
  - Renders inside the suggestion card's preview slot
  - Shows two columns/rows:
    - "Current output:" — result of existing expression (or "No current rule")
    - "Suggested output:" — result of suggested expression
  - Handles evaluation errors inline: "Preview unavailable — expression could not be evaluated"
  - Shows "Evaluating..." state briefly during debounce

- Workspace-level callout when no source data:
  - Rendered in `AutoMapWorkspace` (above card list)
  - "Load sample source data to preview what suggestions would produce"
  - Links to or references the inline preview strip's test case selector
  - Hidden when source data is available

- Performance considerations:
  - Only evaluate for expanded cards (lazy evaluation)
  - Debounce to 150ms
  - Do not block card rendering while evaluating
  - Cache results per expression+sourceData combination (optional optimization)

### Out of Scope

- Execution of full mapping (preview evaluates single expressions only)
- Backend preview calls
- Modifying `evaluateExpression()` or engine behavior
- Preview for array or complex multi-rule expressions (single expression evaluation only)

## Change Requirements

- `useSuggestionPreview` hook:
  - Must short-circuit when `sourceData` is null or expression is empty
  - Must debounce evaluation by 150ms
  - Must catch parse/evaluate errors and return user-friendly error string
  - Must not throw — errors are always returned as state

- `WorkspaceSuggestionPreview` component:
  - Props: `currentExpression: string | null`, `suggestedExpression: string`, `sourceData: unknown | null`
  - Uses `useSuggestionPreview` twice: once for current, once for suggested
  - Renders results side-by-side or stacked:
    - Current: formatted JSON output or "No current rule" or error
    - Suggested: formatted JSON output or error
  - Results displayed with monospace font and JSON formatting for objects/arrays
  - Primitive results displayed inline

- Source data callout:
  - Uses `useContext(PreviewContext)` or equivalent to check for source data availability
  - Callout is an informational banner, not a blocking element
  - Includes an info icon (Lucide `Info`) and descriptive text
