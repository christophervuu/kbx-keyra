## Change Requirements

**AsyncState<T> type:**
```typescript
type AsyncState<T> =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success'; data: T; updatedAt: Date }
  | { status: 'error'; error: AppError; retryable: boolean }
  | { status: 'stale'; data: T; refreshing: boolean };
```

**AppError type:**
```typescript
interface AppError {
  message: string;
  code?: string;
  statusCode?: number;
  retryable: boolean;
  cause?: unknown;
}
```

Include a factory function `toAppError(error: unknown): AppError` that normalizes any thrown value into an AppError (handles Error instances, strings, unknown values).

**useAsyncState<T>() hook:**
- Returns `[state: AsyncState<T>, actions: AsyncActions<T>]`
- Actions include:
  - `execute(promise: Promise<T>): void` — triggers loading → success/error transition
  - `reset(): void` — returns to idle
  - `markStale(): void` — transitions success → stale (data preserved)
  - `refresh(promise: Promise<T>): void` — transitions stale → stale(refreshing) → success/error
- Implementation uses `useReducer` internally (no external state library)
- Must handle race conditions: if `execute` is called while already loading, only the latest promise's result is applied (stale closure protection)
- On error, defaults `retryable: true` unless the AppError explicitly sets it to false
