## Summary

Register all frontend routes from Section 5.2 of the product spec using React Router v6. Each route renders a placeholder page component showing the page name and "Coming Soon" message. Add a catch-all route for the "Not Found" page.

---

## Scope

### In Scope

- `ui/src/App.tsx` — React Router setup with `BrowserRouter` and route definitions
- `ui/src/routes/index.ts` — route path constants
- Placeholder page components for each route (one file per page in `ui/src/routes/` or `ui/src/features/`)
- "Not Found" catch-all page
- Tests verifying routes render

### Out of Scope

- Navigation bar (T-08)
- Breadcrumbs (T-08)
- Layout wrapper (T-08)
- Any screen-specific content (FS-009+)
- Route guards or authentication

## Relevant Areas

- `ui/src/App.tsx`
- `ui/src/routes/`
- `tests/ui/routes/`
- `specs/PRODUCT-TECHNICAL.md` Section 5.2

## Change Requirements

**Routes to register (from Section 5.2):**

| Path | Page Name |
|------|-----------|
| `/` | Home Dashboard |
| `/projects/new` | Create Project |
| `/projects/:projectId` | Project Overview |
| `/projects/:projectId/settings` | Project Settings |
| `/projects/:projectId/deployments` | Project Deployments |
| `/projects/:projectId/mappings/new` | Create Mapping |
| `/projects/:projectId/mappings/:mappingId` | Mapping Editor |
| `/projects/:projectId/mappings/:mappingId/deploy` | Mapping Deployment |
| `/schemas` | Schema Library |
| `/schemas/:schemaId` | Schema Detail |
| `/templates` | Template Library |
| `/settings` | Settings |
| `*` (catch-all) | Not Found |

**Placeholder page component:**
- Each page renders: `<h1>{Page Name}</h1><p>Coming Soon</p>`
- Includes a `data-testid` attribute for test targeting (e.g., `data-testid="page-home-dashboard"`)

**Route constants:**
- Export path strings from a central file for use in navigation links (T-08)
