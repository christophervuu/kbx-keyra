## Change Requirements

**Create `forge/architecture/ui-application.md` documenting:**

1. **Overview** — React 18 + TypeScript + Vite + Tailwind CSS 4 application
2. **Module Structure** — layout of `ui/src/` directories and their responsibilities
3. **Adapter Pattern** — ApiAdapter interface, LocalStorageAdapter (Phase 0), HttpAdapter (Phase 1 placeholder), AdapterProvider context, useAdapter() hook, bootstrap logic
4. **State Management** — AsyncState<T> pattern, useAsyncState() hook, React Context + useReducer only (no external libraries in Phase 0), evaluation criteria for future adoption
5. **Routing** — React Router v6, all registered routes, layout route pattern, breadcrumb generation approach
6. **Component Organization** — shared primitives in `components/`, feature-specific in `features/{name}/`, no cross-feature imports
7. **Constraints** — no state management library, no data-fetching library, desktop-first (1024px min), TypeScript strict, components never call fetch() directly
8. **Technology Decisions** — Tailwind CSS 4, Lucide React, pnpm, Vitest + RTL, ESLint + Prettier
