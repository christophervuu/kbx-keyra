## Summary

Initialize the `ui/` directory as a Vite + React 18 + TypeScript (strict) application with Tailwind CSS 4, Lucide React icons, React Router v6, ESLint, Prettier, and Vitest + React Testing Library. Configure pnpm as the package manager. This establishes the build system and tooling foundation that all subsequent tasks build upon.

---

## Scope

### In Scope

- `pnpm create vite` (or equivalent manual setup) in `ui/`
- `package.json` with all required dependencies and devDependencies
- `tsconfig.json` with strict mode enabled, path aliases
- `vite.config.ts` with React plugin, path resolution
- `tailwind.config.ts` with Tailwind CSS 4 setup
- Global CSS file with Tailwind directives
- ESLint config (flat config format) with TypeScript, React, and import rules
- Prettier config (`.prettierrc`)
- Vitest config (in `vite.config.ts` or separate `vitest.config.ts`)
- React Testing Library setup (`vitest-setup.ts` with `@testing-library/jest-dom`)
- `package.json` scripts: `dev`, `build`, `preview`, `lint`, `format`, `format:check`, `test`, `typecheck`
- Minimal `main.tsx` and `App.tsx` that render "Hello KeyRa" (routing comes in T-07)
- `index.html` entry point
- `.gitignore` for `node_modules/`, `dist/`, etc.
- `pnpm-workspace.yaml` if needed for monorepo awareness

### Out of Scope

- Routing (T-07)
- Components (T-08, T-09)
- Type definitions (T-02, T-03, T-04)
- Adapter code (T-05, T-06)
- Any feature implementation

## Change Requirements

- Initialize a working Vite application in `ui/` with React and TypeScript
- TypeScript `strict: true` in `tsconfig.json`
- Configure path aliases: `@/` → `ui/src/`
- Install and configure Tailwind CSS 4 with the Vite plugin approach
- Install Lucide React (`lucide-react`)
- Install React Router v6 (`react-router-dom`)
- Install and configure ESLint with:
  - `@typescript-eslint/parser` and `@typescript-eslint/eslint-plugin`
  - `eslint-plugin-react` and `eslint-plugin-react-hooks`
  - `eslint-plugin-import` (optional but recommended)
- Install and configure Prettier
- Install and configure Vitest with React Testing Library:
  - `vitest`
  - `@testing-library/react`
  - `@testing-library/jest-dom`
  - `@testing-library/user-event`
  - `jsdom` environment
- Add a smoke test that renders App and confirms it mounts
- All scripts must work: `pnpm dev`, `pnpm build`, `pnpm test`, `pnpm lint`, `pnpm typecheck`, `pnpm format:check`
