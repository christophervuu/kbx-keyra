## Summary

Implement the global app shell layout component with a top navigation bar, breadcrumb bar, and page content container. The nav bar includes the app name/logo and primary nav links (Home, Schema Library, Templates, Settings). Breadcrumbs reflect the current route hierarchy. Layout is responsive down to 1024px.

---

## Scope

### In Scope

- `ui/src/components/layout/AppLayout.tsx` — main layout wrapper (renders as route layout element)
- `ui/src/components/layout/NavBar.tsx` — top navigation bar
- `ui/src/components/layout/Breadcrumbs.tsx` — breadcrumb bar
- `ui/src/components/layout/index.ts` — barrel export
- Integration with React Router (layout route, `<Outlet />`, `useLocation`, `useMatches` or `useParams`)
- Responsive styling: works at 1024px, optimized for 1280px+
- Tests for breadcrumb generation and nav link rendering

### Out of Scope

- Sidebar navigation
- Mobile layout (below 1024px)
- User menu / auth UI
- Feature-specific content within the layout
- Panel collapse behavior (mentioned in spec for 1024px but implementation details deferred to FS-009+)

## Change Requirements

**AppLayout:**
- Wraps all routes as a layout route element
- Renders: NavBar → Breadcrumbs → `<main>` with `<Outlet />`
- Full-height layout (min-h-screen)
- Content area has appropriate padding and max-width

**NavBar:**
- Fixed/sticky at top
- Left: App name "KeyRa" (text logo, no image required)
- Center/Right: nav links — "Home" (`/`), "Schemas" (`/schemas`), "Templates" (`/templates`), "Settings" (`/settings`)
- Active link is visually highlighted
- Uses React Router `<NavLink>` for active state
- Uses route constants from T-07

**Breadcrumbs:**
- Below the nav bar
- Generates breadcrumb segments from the current route path
- Home is always the first segment
- Dynamic segments (`:projectId`, `:mappingId`) show the param value
- Each segment (except the last) is a clickable link
- Last segment is plain text (current page)
- Separator: `/` or `>` between segments

**Responsiveness:**
- At 1280px+: full layout with comfortable spacing
- At 1024px–1279px: tighter spacing, nav links may condense
- Below 1024px: not required (can overflow or be unstyled)

## Notes

- Breadcrumb generation from route paths can use React Router's `useMatches()` with route handle metadata, or can parse `useLocation().pathname` directly. Either approach is acceptable.
- The nav bar links correspond to the top-level navigation. Project-level navigation (within a project) is not part of this task — it will be added in FS-013.
- Use Tailwind utility classes for all styling — no CSS modules or styled-components.
- Consider using Lucide React icons for nav items (e.g., Home, Library, Layout, Settings icons alongside text).
