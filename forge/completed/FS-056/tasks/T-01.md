## Summary

Create the foundational TypeScript types and interfaces used across all schema ingestion modules: `SchemaNode`, `SchemaMetadata`, `IngestionRequest`, `IngestionResult`, `SchemaSearchResult`, query filter types, and pipeline configuration constants (thresholds, batch sizes). These types form the contract between parser, DynamoDB writer, OpenSearch indexer, and Lambda handlers.

---

## Scope

### In Scope

- `SchemaNode` interface matching DynamoDB table schema (schemaId, path, fieldName, type, description, depth, isArray, isRequired, parentPath, childCount, subtreeFieldCount, embeddingText)
- `SchemaMetadata` interface matching DynamoDB table schema
- `IngestionRequest` type (input to ingestSchema Lambda)
- `IngestionResult` type (inline response and Step Functions response variants)
- `SchemaSearchResult` type (query endpoint response)
- `QuerySchemaNodesRequest` type (query endpoint input)
- `SchemaFormat` enum/union (`json-schema` | `xsd`)
- `SchemaStatus` enum/union (`ingesting` | `ready` | `error`)
- `SchemaOrigin` enum/union (`cdm` | `published` | `local`)
- Pipeline constants: `INLINE_FIELD_THRESHOLD = 500`, `DYNAMO_BATCH_SIZE = 25`, `OPENSEARCH_BULK_SIZE = 500`
- `getInlineFieldThreshold(): number` utility — reads `SCHEMA_INLINE_FIELD_THRESHOLD` env var (default `500`)
- Embedding text generation utility function (`generateEmbeddingText(node: SchemaNode): string`)

### Out of Scope

- DynamoDB client code
- OpenSearch client code
- Lambda handler implementation
- AWS SDK imports

## Change Requirements

- Create `src/lib/schema/` directory structure with barrel export
- Define all interfaces and types with JSDoc comments explaining each field
- `SchemaNode` must include all fields from the product spec's SchemaNodes table definition
- `SchemaMetadata` must include all fields from the product spec's SchemaMetadata table definition
- `QuerySchemaNodesRequest` must include `includeParentChain?: boolean` field (opt-in, default false per Q2 resolution)
- `generateEmbeddingText` must produce format: `"{path} | {fieldName} ({type}) | {description}"` when description exists, `"{path} | {fieldName} ({type})"` when it does not
- `getInlineFieldThreshold()` reads `process.env.SCHEMA_INLINE_FIELD_THRESHOLD`, parses as integer, returns `INLINE_FIELD_THRESHOLD` constant (500) if env var is unset or invalid
- Constants must be exported and documented with rationale
- All types must be importable from `src/lib/schema` barrel
