## Summary

Build the Create Mapping flow page (`/projects/:projectId/mappings/new`) as a multi-step wizard: Step 1 (name), Step 2 (select source schema or skip), Step 3 (select target schema or skip). On submit, creates the mapping and navigates to the Mapping Editor. Replace the existing route placeholder.

---

## Scope

### In Scope

- New file `ui/src/features/projects/components/CreateMappingPage.tsx`
- Step 1: Name input (required)
- Step 2: Source schema selector (dropdown of project schemas) + "Skip — add schema later" option
- Step 3: Target schema selector (dropdown of project schemas) + "Skip — add schema later" option
- Step navigation: Back/Next buttons, step indicator
- Submit: calls `adapter.createMapping()` with form data
- On success: navigate to Mapping Editor
- Handle skipped schemas (omit `sourceSchemaRef`/`targetSchemaRef` from input — they are optional per Q1 resolution)
- Load project's schemas to populate dropdowns
- Replace `ui/src/routes/pages/CreateMapping.tsx` content
- Cancel: navigate back to project overview

### Out of Scope

- Schema upload during mapping creation (user must attach schemas to project first)
- Mapping template selection
- Rule pre-population

## Change Requirements

- Step wizard layout:
  - Step indicator at top (1/3, 2/3, 3/3) with step labels
  - Content area for current step
  - Footer with Back/Next/Create buttons
- Step 1 — Name:
  - Input field with label "Mapping Name *"
  - Validation: required, non-empty
  - "Next" enabled only when name is non-empty
- Step 2 — Source Schema:
  - Dropdown/list of schemas attached to this project
  - Each option shows: schema name + format badge
  - "Skip — add schema later" as a special option
  - "Next" always enabled (skip is valid)
- Step 3 — Target Schema:
  - Same as Step 2 but for target
  - "Create Mapping" button instead of "Next"
- On submit:
  - Build `CreateMappingInput`:
    - `projectId` from route params
    - `name` from Step 1
    - `sourceSchemaRef`: from selected schema, or omit entirely when skipped (`undefined`)
    - `targetSchemaRef`: from selected schema, or omit entirely when skipped (`undefined`)
  - Call `adapter.createMapping(input)`
  - Navigate to `PATHS.MAPPING_EDITOR.replace(':projectId', projectId).replace(':mappingId', result.mappingId)`
- Skipped schema handling:
  - Simply omit `sourceSchemaRef`/`targetSchemaRef` from `CreateMappingInput` — they are optional per Q1 resolution
  - No sentinel values, no empty strings — `undefined` means "not yet assigned"
  - Editor will detect missing schema refs and show banner
- Load project schemas:
  - Read `projectId` from params
  - Load project via `adapter.getProject(projectId)` to get `schemaRefs`
  - Load each schema's metadata for display in dropdowns
- Replace `ui/src/routes/pages/CreateMapping.tsx` to render `CreateMappingPage`
- Maintain `data-testid="page-create-mapping"`
