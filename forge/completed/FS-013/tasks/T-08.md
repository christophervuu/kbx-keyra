## Change Requirements

- `ProjectOverviewPage` component:
  - Reads `projectId` from `useParams()`
  - Calls `useProjectOverview(projectId)`
  - Conditional rendering based on `loadState`:
    - `'loading'`: Render skeleton layout (placeholder cards/rows)
    - `'error'`: "Failed to load project" message + retry button calling `retry()`
    - `'not-found'`: "Project not found" message + Link to Home Dashboard
    - `'loaded'`: Render all four sections
  - Layout: vertical stack with gap between sections
  - Sections A-D rendered in order, all receiving appropriate props from hook
  - Section B receives `schemas` + action callbacks
  - Section C receives `mappings` + `projectId` + action callbacks
  - Section D receives counts + action callbacks
  - Navigation callbacks:
    - "Create Mapping" → `navigate(PATHS.CREATE_MAPPING.replace(':projectId', projectId))`
    - "Delete Project" → after delete, `navigate(PATHS.HOME)`
    - "Duplicate Project" → after duplicate, `navigate` to new project
- Replace `ui/src/routes/pages/ProjectOverview.tsx`:
  - Import and render `ProjectOverviewPage` from feature module
  - Maintain `data-testid="page-project-overview"`
- Use `PageHeader` for page title area
