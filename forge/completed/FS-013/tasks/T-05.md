## Summary

Build the Schema Management section (Section B) of the Project Overview page. Displays attached schemas as cards with metadata badges, provides "Upload Schema" and "Link Schema" action buttons, and supports schema removal with confirmation when mappings reference the schema.

---

## Scope

### In Scope

- New file `ui/src/features/projects/components/SchemaManagementSection.tsx`
- New file `ui/src/features/projects/components/SchemaCard.tsx`
- Schema card layout: name, origin badge (CDM/Published/Local), scope badge (Global/Project-Level), field count, format, sync status
- "Upload Schema" button (triggers upload flow from T-11)
- "Link Schema" button (opens schema picker for existing schemas)
- "View" action on card → navigate to `/schemas/:schemaId`
- "Remove" action on card → confirmation dialog (with warning if mappings reference it)
- Empty state: "No schemas attached" with action buttons
- Sync status indicator: "⚠ Not synced" for all schemas in Phase 0
- "⚠ Inferred from sample data" badge for inferred schemas

### Out of Scope

- Schema upload logic itself (T-11)
- Schema Library page
- GitHub sync functionality
- Schema Detail page content

## Change Requirements

- `SchemaManagementSection` receives: `schemas: SchemaCardData[]`, `onUpload`, `onLink`, `onRemove`, `onView`, `mappingsReferencingSchema` function
- Section header: "Schemas" with "Upload Schema" and "Link Schema" buttons
- Schema cards in a responsive grid (2-3 columns on desktop)
- Each `SchemaCard`:
  - Schema name (bold)
  - Format badge: "JSON Schema" (blue) or "XSD" (purple)
  - Origin badge: "CDM" (green), "Published" (blue), "Local" (gray)
  - Scope badge: "Global" or "Project-Level"
  - Field count: "{n} fields"
  - Sync status: "⚠ Not synced" (amber) — static in Phase 0
  - If inferred: "⚠ Inferred from sample data" warning badge
  - Actions: "View" button, "Remove" button (with trash icon)
- Link Schema picker (`SchemaLinkPicker`):
  - Lists all schemas from `listSchemas()` that are not already attached
  - Selectable list with confirm button
  - Closes on select + confirm
- Remove confirmation:
  - If schema is referenced by mappings: warning text listing affected mapping names
  - If not referenced: simple "Remove this schema from the project?" confirm
- Empty state: illustration/icon + "No schemas attached to this project" + "Upload Schema" and "Link Schema" buttons
