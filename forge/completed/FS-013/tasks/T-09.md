## Summary

Build the Create Project wizard page (`/projects/new`) with a simple form for project name, description, and tags. On submit, creates the project via the adapter and navigates to the new project's overview page. Replace the existing route placeholder.

---

## Scope

### In Scope

- New file `ui/src/features/projects/components/CreateProjectPage.tsx`
- Form fields: Name (required), Description (optional textarea), Tags (comma-separated input or tag chips)
- Client-side validation: name required (non-empty after trim)
- Submit: calls `adapter.createProject()` with form data
- On success: navigate to `/projects/{newProjectId}`
- Cancel button: navigate to `/` (Home Dashboard)
- Submitting state (button loading indicator)
- Error state if creation fails
- Replace `ui/src/routes/pages/CreateProject.tsx` content

### Out of Scope

- Tag autocomplete or suggestion
- Project templates
- Bulk project creation

---

## Relevant Areas

- `ui/src/features/projects/components/CreateProjectPage.tsx` (new)
- `ui/src/routes/pages/CreateProject.tsx` (replace content)
- `ui/src/features/projects/components/index.ts` (barrel update)
- `ui/src/lib/api/types.ts` (CreateProjectInput)

---

## Change Requirements

- Form layout:
  - "Create New Project" heading
  - Name field: `<input>` with label "Project Name *", placeholder "Enter project name"
  - Description field: `<textarea>` with label "Description", placeholder "Describe your project (optional)"
  - Tags field: `<input>` with label "Tags", placeholder "Enter tags separated by commas". Parse on submit: split by comma, trim each, filter empty.
  - Buttons: "Create Project" (primary, submit), "Cancel" (secondary/ghost)
- Validation:
  - Name: required. Show red border + "Project name is required" if submitted empty.
  - No server-side validation in Phase 0.
- Slug generation: derive from name (lowercase, replace spaces with hyphens, remove special chars)
- On submit:
  - Set submitting state
  - Call `adapter.createProject({ name, description, slug, tags })`
  - On success: `navigate(PATHS.PROJECT_OVERVIEW.replace(':projectId', result.projectId))`
  - On error: show inline error message
- Cancel: `navigate(PATHS.HOME)`
- Replace `ui/src/routes/pages/CreateProject.tsx` to render `CreateProjectPage`
- Maintain `data-testid="page-create-project"`
- Use `Card` for form container, `Button` for actions, `PageHeader` for heading

## Notes

Keep the form simple for Phase 0. No multi-step wizard for project creation — a single form with all three fields is sufficient. The tag input can be a plain text input with comma parsing on submit; a more interactive tag chip component is a nice-to-have but not required.
