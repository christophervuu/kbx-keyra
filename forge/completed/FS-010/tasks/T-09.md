## Change Requirements

- Add new H2 section `## Engine Integration` to `ui-application.md` after the existing `## State Management` section
- Document:
  - The engine is consumed via `ui/src/lib/engine/index.ts` which re-exports from `src/engine/`
  - Vite resolves the engine as a source dependency (not a pre-built package)
  - The engine is pure and synchronous — safe to call from React hooks
  - `useEngineValidation()` is the canonical pattern: accepts config + schemas, debounces, returns typed result
  - The hook returns `ValidationResult | null`, per-rule diagnostic accessor, summary, and isValidating flag
  - Future hooks (e.g., `useEngineExecution()`) follow the same pattern: debounce → call → typed result
  - Engine self-initializes function registry on first import — no setup code needed in UI
  - Bundle note: the engine adds ~X KB to the bundle (determine actual size from T-01 and document)
- Add new H2 section `## Mapping Editor Architecture` documenting:
  - Multi-panel layout: named panel slots rendered in a CSS Grid
  - Panel pattern: each panel is a child component rendered into a slot; adding panels = adding children
  - Editor state is managed via `useReducer` in the feature module
  - Data flow: `useMappingEditor()` hook → loads data → provides state + dispatch → child components render
- Update `## Module Structure` to add `lib/engine/` entry and `features/mappings/` entries
- Update the `Last Updated` date for `ui-application.md` in `INDEX.md`
