## Summary

Implement multi-select via row checkboxes with a "Select All" header checkbox. When 1+ rules are selected, render a bulk action bar with "Delete selected", "Duplicate selected", and "Copy to clipboard". Implement single-rule copy and global paste-from-clipboard for rule cross-mapping reuse.

---

## Scope

### In Scope

- Checkbox selection state management (Set of selected indexes)
- "Select All" checkbox in list header (toggles all/none)
- Bulk action bar that appears when selection is non-empty
- Bulk actions: "Delete selected" (with confirmation), "Duplicate selected" (append copies), "Copy to clipboard" (as JSON)
- Per-row "Copy rule" action (copies single rule as JSON to clipboard)
- "Paste rules" action (reads clipboard, parses JSON, appends rules)
- Clipboard format: JSON array of `MappingRule` objects
- Error handling for invalid paste data (toast notification)
- Bulk action bar announced to screen readers when it appears
- Deselect after bulk action completes
- All bulk operations trigger validation

### Out of Scope

- Drag selection (click-and-sweep to select multiple)
- Shift+click range selection (nice-to-have, not required)
- Cross-mapping paste via UI (clipboard-based paste handles this implicitly)
- Undo bulk operations

## Change Requirements

- Selection state: `Set<number>` of selected rule indexes managed by RuleList (or parent via reducer)
- Each RuleRow checkbox is controlled by selection state
- Header row includes "Select All" checkbox:
  - If none selected → unchecked
  - If some selected → indeterminate
  - If all selected → checked
  - Click toggles between all/none
- When `selection.size > 0`, render `BulkActionBar` above or below the list:
  - Shows: "{N} rule(s) selected"
  - Actions: "Delete selected", "Duplicate selected", "Copy to clipboard"
- "Delete selected":
  - Opens ConfirmDialog: "Delete {N} selected rules?"
  - On confirm: remove all selected indexes from rules array, clear selection
- "Duplicate selected":
  - Creates copies of selected rules
  - Appends copies at the end of the rules array
  - Clears selection
- "Copy to clipboard":
  - Serializes selected rules as JSON array string
  - Writes to clipboard via `navigator.clipboard.writeText()`
  - Shows success toast/notification
- Per-row "Copy rule" action:
  - Serializes single rule as JSON array `[rule]` (consistent format with multi-copy)
  - Writes to clipboard
- "Paste rules" action (button in list header or toolbar):
  - Reads clipboard via `navigator.clipboard.readText()`
  - Parses JSON
  - Validates parsed data is an array of objects with `target` and `expression` fields
  - If valid: appends rules to end of array
  - If invalid: show error toast "Invalid rule data in clipboard"
- BulkActionBar uses ARIA live region to announce appearance to screen readers
- After any bulk operation: clear selection, trigger validation
