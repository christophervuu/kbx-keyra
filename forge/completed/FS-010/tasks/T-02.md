## Summary

Replace the placeholder `MappingEditor.tsx` route page with a full multi-panel layout container and top bar. The layout accommodates 8 named panels (only Panel 3 is functional in FS-010; others are labeled placeholders). The top bar displays mapping metadata: name, version, save status, deploy badges, source/target schema names, and a "Go to Deploy Page" link.

---

## Scope

### In Scope

- Replace `ui/src/routes/pages/MappingEditor.tsx` with a component that mounts the feature-level `<MappingEditorPage />`
- Create `ui/src/features/mappings/` directory with feature module structure
- Create `ui/src/features/mappings/components/MappingEditorPage.tsx` — the full editor container
- Create `ui/src/features/mappings/components/EditorTopBar.tsx` — top bar component
- Create `ui/src/features/mappings/components/PanelPlaceholder.tsx` — generic placeholder for inactive panels
- Multi-panel layout using CSS Grid or Flexbox with named regions
- Top bar contents: mapping name (text), version badge ("v{N}"), save status indicator ("Saved" / "Unsaved changes"), deploy status badges (DEV/QA/PROD using shared `StatusBadge`), source → target schema names, "Go to Deploy Page" link
- Layout must accommodate future panel additions without structural refactoring
- Panel names/labels for placeholders: "Source Schema (Panel 1)", "Target Schema (Panel 2)", "Rule List (Panel 3)", "Expression Builder (Panel 4)", "Preview (Panel 5)", "Diagnostics (Panel 6)", "AI Assist (Panel 7)", "History (Panel 8)"
- Feature barrel export (`ui/src/features/mappings/index.ts`)
- Responsive: functional at 1024px, optimal at 1280px+

### Out of Scope

- Data loading logic (T-07 owns that)
- Rule list content (T-03)
- Engine integration (T-01)
- Save button functionality (T-07)
- Deploy page navigation functionality (renders as link only, target route exists from FS-008)

## Change Requirements

- `MappingEditor.tsx` route page becomes a thin wrapper that renders `<MappingEditorPage />` from the feature module
- The page extracts `projectId` and `mappingId` from route params and passes them down
- `MappingEditorPage` renders:
  - `EditorTopBar` at the top (full width)
  - A panel grid below with named slots for all 8 panels
  - Panel 3 slot renders children (where Rule List will mount in T-03)
  - All other slots render `<PanelPlaceholder name="Panel Name" />`
- `EditorTopBar` accepts props for: `mappingName`, `version`, `saveStatus`, `deployStatuses`, `sourceSchemaName`, `targetSchemaName`, `projectId`, `mappingId`
- `EditorTopBar` renders "Go to Deploy Page" as a `<Link>` to `PATHS.MAPPING_DEPLOYMENT` with params filled
- Save status prop: `'saved' | 'unsaved' | 'saving' | 'error'` — displayed as text indicator with color
- Deploy badges use `StatusBadge` component from shared primitives
- Layout uses Tailwind CSS Grid for panel arrangement: side-by-side columns with adjustable proportions
- Panel slots accept children so T-03+ can render real content without modifying the layout component
