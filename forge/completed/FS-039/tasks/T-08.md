## Summary
Implement the full condition step editor UI within the chain-based Builder. Conditions are total (else is required and cannot be removed). The left operand defaults to the current accumulated chain value, shown as an explicit labeled token with an escape hatch to switch to a different reference. Both Then and Else branches support full chains (source + steps). Completed conditions collapse into readable summaries. Supports else-if by adding additional condition clauses.

## Change Requirements
Create `ConditionStepEditor.tsx` that renders the full condition editing UI within the chain-based builder.

**Left operand current-value default:**
- On condition step creation, each predicate's left operand initializes as `{ kind: 'currentValue' }`
- The UI shows this as a labeled token/chip (e.g., pill reading "current value" or showing truncated chain summary)
- The token is **visible and explicit** — not hidden or implicit
- A "Change input" action (dropdown, button, or selector) allows switching to:
  - `{ kind: 'field' }` — source path selector
  - `{ kind: 'static' }` — literal value input
  - `{ kind: 'expression' }` — raw DSL expression
- When switched from current value, the summary text reflects the explicit reference:
  - Default: `If current value is empty then ...`
  - Switched: `If source("customerType") = "VIP" then ...`

**Structure:**
- (1) IF clause with predicate rows (AND-combined), left operand defaults to current value
- (2) THEN branch as an embedded chain builder
- (3) ELSE branch as an embedded chain builder (always present, structural requirement)
- "Add else-if" to insert additional clauses
- Branch chain editors are mini-chain builders that recursively use the same chain rendering components

**Expression generation:**
- When `left.kind === 'currentValue'`, the generator substitutes the accumulated chain expression up to this step
- When `left.kind === 'field'`, generates `source("path")`
- Predicate expression uses comparison operator: `eq(left, right)`, `gt(left, right)`, etc.

**Collapse:**
- When complete (all predicates filled, both branches valid), condition can collapse to summary
- Summary includes operand context: "If current value ..." vs "If source(\"field\") ..."
