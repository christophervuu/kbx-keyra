## Change Requirements
The architecture document must accurately reflect the implemented state after all FS-039 tasks complete. Key sections to update:

- **Two-Tier Save Model → Auto-Draft Save Model:** Three persistence layers (in-memory draft → draftRules map → saved config → version increment). Remove Apply step.
- **Expression Builder Architecture → Chain-based Builder:** ChainState model with source + ordered steps. No mode tabs. Unified step picker with type-filtered transforms + condition + value map.
- **New: Chain Model types:** ChainState, ChainSource (field/static/none), ChainStep (TransformStep/ConditionStep/ValueMapStep), OperandValue (currentValue/field/static/expression). Conditions are total (else required). Value maps have required default.
- **New: OperandValue and currentValue:** Document that condition left operands default to `{ kind: 'currentValue' }`, shown as explicit labeled token in UI. "Change input" escape hatch to switch to field/static/expression. Expression generator substitutes accumulated chain expression. Decomposer detects and reconstructs currentValue kind.
- **Component Hierarchy:** Add ChainBuilder.tsx (new, replaces UnifiedExpressionBuilder), ChainStepCard.tsx, ConditionStepEditor.tsx, ValueMapStepEditor.tsx, UnsavedChangesOverlay.tsx. Annotate old components as legacy.
- **Module Structure:** Add chain-builder-state.ts, chain-expression-generator.ts, chain-decomposer.ts, chain-summary.ts.
- **Remove all references to:** Apply button, applyRule(), unsavedRuleCount, lastAppliedExpression, onRuleApplied, Next Unmapped button in Builder.
