## Summary
Update `LiveExpressionDisplay` and `LiveResultDisplay` to work with the auto-draft model. Expression display updates on every chain change. Result display triggers evaluation with a 300ms debounce after expression changes. Update `ConnectedInlinePreviewStrip` to trigger preview on draft expression changes instead of on Apply.

---

## Scope

### In Scope
- `LiveExpressionDisplay`: ensure it receives the generated expression on every change (verify existing behavior works with new flow)
- `LiveResultDisplay`: ensure `useExpressionPreview()` triggers on draft expression changes with debounce
- `ConnectedInlinePreviewStrip`: replace `onRuleApplied` trigger with draft-expression-change trigger for auto-preview
- Show parse errors inline in LiveExpressionDisplay (red highlighting)
- Show evaluation errors in LiveResultDisplay (error message)
- Show placeholder in LiveResultDisplay when no source data

### Out of Scope
- Chain builder UI (T-06)
- EditorTopBar changes (T-11)

## Change Requirements
`LiveExpressionDisplay` already receives expression via props — verify this works with the new auto-draft flow (expression updates on every chain change). `LiveResultDisplay` already uses `useExpressionPreview()` with debounce — verify the debounce triggers correctly when expression changes come more frequently (every keystroke/step change vs on Apply). `ConnectedInlinePreviewStrip`: replace the `lastApplyTimestamp`/`onRuleApplied` mechanism with a debounced effect watching the current draft expression for the selected field. When the draft expression stabilizes (300ms debounce), trigger a full mapping preview if source data is loaded.

## Notes
