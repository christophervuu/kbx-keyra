## Change Requirements
The `draftRules` map is a `Map<string, string>` where keys are target paths and values are draft DSL expressions. When `save()` is called: iterate draftRules entries, for each entry upsert/delete rules in the saved rules array (empty expression = delete rule), then persist via adapter, increment version, snapshot history, and clear draftRules. `hasUnsavedChanges` is true when any draftRules entry differs from its corresponding saved rule. `unsavedChangeCount` counts such entries. Navigation guard triggers on `hasUnsavedChanges`. Per-field revert removes the entry from draftRules. Empty expressions in draftRules are meaningful (they mean "delete this rule on save").
