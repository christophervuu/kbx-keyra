## Summary

Create an `ActivityPlaceholder` component for the Home Dashboard right rail. This component shows a card with "Recent Activity" heading and placeholder content indicating that the activity feed will be available when event tracking is implemented.

---

## Scope

### In Scope

- Create `ActivityPlaceholder.tsx` in `ui/src/features/home/components/`
- Render a `Card` (or card-styled div) with:
  - "Recent Activity" heading
  - An Activity icon (from Lucide)
  - Placeholder text: "Activity feed will appear here when event tracking is available."
  - Muted visual treatment consistent with the dark theme
- Export from feature barrel
- Add component tests

### Out of Scope

- Implementing an actual activity feed
- Fetching activity data from the adapter
- Wiring into the page layout (T-05 handles composition)
