## Summary

Retire the `DashboardTabs` three-tab shell component and remove the `SchemaLibraryCard` from `HomeDashboardPage`. After this task, the Home page renders project content directly without a tab navigation layer, and Schema Library is accessible only through top-level navigation. Schema count remains visible in the MetricsBar.
