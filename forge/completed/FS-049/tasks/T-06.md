## Summary

Improve the visual differentiation of project status and deploy information on `ProjectCard`. Add a condensed deploy summary for Phase 0 (where all environments are `'not-deployed'`), add a left-border error accent for projects with errors, and strengthen the status badge styling for better visual scanning.

---

## Scope

### In Scope

- Modify `ProjectCard.tsx` to show a condensed "Not deployed" label when all three environment deploy statuses are `'not-deployed'`
- When any environment has a non-default status, continue showing individual DEV/QA/PROD badges as before
- Add a left-border accent (`border-l-2 border-l-red-500`) to the card when `worstStatus === 'has-errors'`
- Strengthen `WorstStatusBadge` styling:
  - `ready`: green badge with subtle filled background (`bg-green-500/15`)
  - `has-errors`: red badge with subtle filled background (`bg-red-500/15`)
  - `draft`: current slate styling (acceptable as-is)
- Update `ProjectTable` to apply similar condensed deploy logic (show "—" in DEV/QA/PROD columns when all are `'not-deployed'`, or a single "Not deployed" cell spanning the 3 columns)
- Add/update component tests

### Out of Scope

- Changing the `ProjectListItem` type or data source
- Adding new deploy statuses or types
- Modifying `useDashboardData` logic
