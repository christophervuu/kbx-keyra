## Summary

Ensure comprehensive test coverage for the refactored Home Dashboard. Update existing `HomeDashboardPage` tests to validate the new layout (two-column, no tabs, no Schema Library card), and ensure all new components (`NeedsAttention`, `ContinueWhereYouLeftOff`, `ActivityPlaceholder`) and enhancements (`ProjectCard` deploy/status changes) have passing tests. This task serves as the integration verification gate for the FS-049 implementation.
