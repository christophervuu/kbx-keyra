## Summary

Restructure `HomeDashboardPage` from its current single-column layout to a two-column layout with a main content area (~70-75%) and a right rail (~25-30%). Wire all new and existing sections into the correct positions: MetricsBar → Needs Attention → Continue Where You Left Off → Projects in the main column; Activity placeholder in the right rail. Update loading, error, and empty states to reflect the new layout structure.

- Main column receives: MetricsBar, NeedsAttention, ContinueWhereYouLeftOff, ProjectList
- Right rail receives: ActivityPlaceholder (from T-07)
- Wire `useRecentActivity` (from T-03) to get recent items and pass to `ContinueWhereYouLeftOff`
