## Summary

Create a `NeedsAttention` component that surfaces a compact summary of items requiring user follow-up. In Phase 0, only "mappings with errors" is derived from real data; other attention items (stale deployments, unsynced schemas) are scaffold placeholders. The component shows a positive-state message when nothing needs attention.

---

## Scope

### In Scope

- Create `NeedsAttention.tsx` in `ui/src/features/home/components/`
- Accept metrics data (at minimum `statusBreakdown.hasErrors`) as props
- Render attention items as compact rows with icon + label + count
- "Mappings with errors" derives its count from `statusBreakdown.hasErrors`
- "Stale deployments" and "Unsynced schemas" show scaffold/placeholder values (muted "—" or "0")
- When all items are zero/placeholder, show "Nothing needs attention" with positive visual treatment (e.g., green check icon + muted text)
- Use `<button>` elements for attention item rows to support future click-through, but `onClick` is a no-op for now
- Export from feature barrel
- Add component tests

### Out of Scope

- Deep-linking from attention items to filtered views
- Real stale deployment or unsynced schema detection
- Wiring into the page layout (T-05 handles composition)
- Modifying `useDashboardData` (the hook already provides `statusBreakdown.hasErrors`)
