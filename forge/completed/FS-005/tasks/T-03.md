## Summary

Implement `filter()` and `find()` — the two other scope-creating functions. Both iterate an array, push each element onto the scope stack, evaluate a boolean condition per element, and pop the scope. `filter()` returns all matching elements unchanged; `find()` returns the first match or null. Both emit appropriate diagnostics for non-boolean conditions, empty results, and no-match scenarios.

## Change Requirements

After this task is complete:

1. `filter()` implementation:
   - Signature: `[{ name: 'array', type: 'array' }, { name: 'condition', type: 'any' }]`, `handlesNull: true`, `lazyArgs: [1]`
   - If array is null → return null
   - If array is `[]` → return `[]`
   - For each element:
     - `context.pushScope(element)`
     - `try { condResult = context.evaluate(conditionNode, context) }`
     - If `condResult.value` is `true` → include original element in output
     - If `condResult.value` is `null` → exclude element
     - If `condResult.value` is not boolean and not null → emit E017, exclude element
     - `finally { context.popScope() }`
   - After iteration: if output is empty, emit E016 (warning)
   - Return output array

2. `find()` implementation:
   - Signature: `[{ name: 'array', type: 'array' }, { name: 'condition', type: 'any' }]`, `handlesNull: true`, `lazyArgs: [1]`
   - If array is null → return null
   - If array is `[]` → return null (no E019 for empty arrays — only for non-empty arrays with no match)
   - For each element:
     - `context.pushScope(element)`
     - `try { condResult = context.evaluate(conditionNode, context) }`
     - If `condResult.value` is `true` → pop scope, return this element immediately
     - If `condResult.value` is `null` → skip
     - If `condResult.value` is not boolean and not null → emit E017, skip
     - `finally { context.popScope() }`
   - If no match found → return null + emit E019 (warning)

3. Both registered in registry via `registerArrayFunctions()`.

## Notes

- `filter()` does NOT transform elements. This is a critical distinction from `map()`. The output elements are the exact original objects from the input array.
- `find()` short-circuits on first match (pops scope and returns immediately). The try/finally pattern must handle this correctly — ensure scope is popped even on the early return path.
- For E016: only emit on non-empty input arrays. If the input is `[]`, returning `[]` is not a warning — the input was already empty.
- Can be developed in parallel with T-02 (both depend only on T-01).
