## Summary

Implement the `map()` function — the most complex array function in the DSL. It iterates an array, pushes each element onto the scope stack, evaluates a template (object template or expression) per element using re-entrant `context.evaluate()`, collects results, and pops the scope. Scope cleanup is guaranteed by try/finally. Supports nested `map()` calls via the scope stack.

## Change Requirements

After this task is complete:

1. `src/engine/functions/arrays.ts` exists with:
   - `mapSignature`: params `[{ name: 'array', type: 'array' }, { name: 'template', type: 'any' }]`, `handlesNull: true`, `lazyArgs: [1]`
   - `mapImplementation`: receives `[arrayValue, templateAstNode]`

2. `map()` implementation logic:
   - If `arrayValue` is `null` → return `null`
   - If `arrayValue` is `[]` → return `[]`
   - For each element in array:
     - `context.pushScope(element)`
     - `try { result = context.evaluate(templateAstNode, context) }`
     - Collect `result.value` into output array
     - Collect `result.diagnostics` into accumulated diagnostics
     - `finally { context.popScope() }`
   - Return output array

3. Object template evaluation:
   - When the evaluator encounters an `ObjectTemplate` AST node via `context.evaluate()`, it produces an object with each property's value expression evaluated in the current scope
   - Nested object templates are evaluated recursively (handled by evaluator, not by map() directly)

4. Registration:
   - `registerArrayFunctions(registry)` function exports and registers `map`
   - `registerAllFunctions()` barrel calls `registerArrayFunctions()`
