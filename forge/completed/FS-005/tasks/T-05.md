## Summary

Implement `join()` (array-to-string), `count()` (array-to-number), and `get()` (object field accessor). `join()` and `count()` are `handlesNull: true` functions with special null behavior (count returns 0, join returns null for null array but skips null elements within). `get()` reads fields from arbitrary in-memory objects using the same path resolution as `source()`/`item()`.

---

## Scope

### In Scope

- Implement `join()`, `count()`, `get()` in `src/engine/functions/arrays.ts`
- `join()`: concatenate string array with separator, null elements skipped, empty → `""`, E005 for non-string elements
- `count()`: return array length, null → 0, empty → 0
- `get()`: read field via resolvePath, E018 if first arg is not object/null
- All registered in function registry
- Comprehensive unit tests

### Out of Scope

- Array iteration functions (map, filter, find)
- Array construction functions (array, merge, flatten, first, nth)

## Change Requirements

After this task is complete:

1. `join()` implementation:
   - Signature: `[{ name: 'array', type: 'array' }, { name: 'separator', type: 'string' }]`, `handlesNull: true`
   - If array is null → return null
   - If array is `[]` → return `""`
   - Filter out null elements from array
   - For remaining elements: if any is not a string → emit E005, skip that element (or halt — check DSL spec behavior)
   - Join remaining string elements with separator
   - Return resulting string

2. `count()` implementation:
   - Signature: `[{ name: 'array', type: 'array' }]`, `handlesNull: true`
   - If array is null → return `0` (exception to null propagation)
   - If array is `[]` → return `0`
   - Otherwise → return `array.length`

3. `get()` implementation:
   - Signature: `[{ name: 'object', type: 'object' }, { name: 'path', type: 'string' }]`, `handlesNull: false` (null object → null via propagation)
   - Actually: need `handlesNull: false` so null object short-circuits to null naturally
   - If first arg is not null and not an object → emit E018, return null
   - Use `resolvePath(object, path)` to read the field
   - Return the resolved value (null if path not found)

## Notes

- This task can be developed in parallel with T-01, T-02, T-03, and T-04.
- `join()` has nuanced null behavior: the function itself is `handlesNull: true` (so null array is received, not short-circuited), but the implementation explicitly returns null for null array and `""` for empty array. Null elements within the array are skipped.
- `get()` is frequently composed with `find()` and `first()`: `get(find(...), "field")`, `get(first(...), "field")`. These compositions are tested in T-06.
- For `join()` E005 on non-string elements: the spec says emit E005 if non-null element is not string. The implementation should skip that element (not halt the entire join) and continue with remaining elements.
