## Change Requirements

After this task is complete, `mapping-engine.md` includes:

1. **Updated Module Structure** — `functions/` section shows `arrays.ts` alongside existing category files:
   ```
   functions/
     ...existing categories...
     arrays.ts           map, filter, find, array, merge, flatten, first, nth, join, count, get
   ```

2. **New Section: "Array Functions and Scope Stack"** covering:
   - The `lazyArgs` field on FunctionSignature and how it changes evaluator dispatch
   - Why lazy args are needed (template/condition must be re-evaluated per element)
   - The scope-creating function pattern:
     - Receive array (evaluated) + AST node (lazy)
     - For each element: pushScope → evaluate AST node → collect result → popScope
     - try/finally guarantees scope cleanup
   - Scope stack state diagram (what stack looks like at each nesting level)
   - How evaluator derives currentItem/parentItem from stack before dispatch
   - `context.evaluate()` re-entrant call contract

3. **Null/Empty Behavior Table** — the complete table from DSL Arrays spec §5, documenting per-function behavior for null and empty array inputs.

4. **Updated Function Implementation Pattern** — adds a "Scope-Creating Functions" subsection describing the additional responsibilities these functions have beyond normal functions:
   - They receive mixed args (values + AST nodes)
   - They manage scope stack lifecycle
   - They call back into the evaluator
   - They must use try/finally
   - They collect diagnostics from sub-evaluations

5. `forge/architecture/INDEX.md` — `mapping-engine.md` row's `Last Updated` date is set to today's date.
