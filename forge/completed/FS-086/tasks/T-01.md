## Summary

Restructure Project Overview page composition so mappings become the dominant full-width content area and remove default right-rail and bottom schema-grid surfaces. This task establishes the core layout shell required by all subsequent behavior tasks.

---

## Scope

### In Scope

- Update `ProjectOverviewPage` layout from two-column + right rail to single-column flow.
- Remove rendering of right-rail cards (`Deployment Activity`, right-rail `Schemas`) from default overview.
- Remove always-visible default rendering of `SchemaManagementSection` from Project Overview page flow.
- Keep breadcrumb + header + mappings sequence intact.
- Preserve existing data loading/error/skeleton handling while altering composition.

### Out of Scope

- New linked-schemas modal/drawer/inline interaction implementation.
- Mapping row action logic changes.
- Architecture document updates.
