## Summary

Create the foundational SAM template file (`template.yaml`) with Parameters, Globals, and Outputs sections, plus `samconfig.toml` for environment-specific deployment configuration. This scaffold establishes the structure that all subsequent infrastructure tasks add resources to.

---

## Scope

### In Scope

- `template.yaml` at repository root with SAM transform, parameters (Stage, etc.), Globals (Function defaults), and Outputs
- `samconfig.toml` with `[default]`, `[dev]`, and `[prod]` config environments
- Parameters: `Stage`, `StorageBucketName`, `OpenSearchEndpoint`
- Globals: Runtime `nodejs20.x`, MemorySize 256, Timeout 29, common environment variables
- Outputs: `ApiUrl`, `StorageBucketName`, table ARNs
- Validate with `sam validate`

### Out of Scope

- Individual resource definitions (tables, functions, etc.) — those are separate tasks
- Lambda handler stubs — only the template structure
- Deployment execution

---

## Relevant Areas

- `template.yaml` (new)
- `samconfig.toml` (new)

---

## Change Requirements

- Create `template.yaml` with:
  - `AWSTemplateFormatVersion: '2010-09-09'`
  - `Transform: AWS::Serverless-2016-10-31`
  - Parameters: `Stage` (String, default `dev`, AllowedValues `dev/staging/prod`), `OpenSearchEndpoint` (String)
  - Globals.Function: Runtime, MemorySize, Timeout, Environment variables referencing parameters and resource refs (use placeholder `!Ref` for resources not yet defined — they will be added by subsequent tasks)
  - Outputs section with placeholder outputs
- Create `samconfig.toml` with:
  - `[default.deploy.parameters]` — stack name pattern `keyra-{stage}`, region `us-east-1`, capabilities `CAPABILITY_IAM`
  - `[dev.deploy.parameters]` — parameter overrides for dev stage
  - `[prod.deploy.parameters]` — parameter overrides for prod stage
- Template must pass `sam validate` (with allowance for forward-references that will be satisfied by subsequent tasks)

---

## Verification Requirements

- `sam validate` passes on the template (or would pass once forward-referenced resources are stubbed)
- Template YAML is syntactically valid
- Parameters section includes Stage, OpenSearchEndpoint
- Globals section sets nodejs20.x runtime, 256MB memory, 29s timeout
- samconfig.toml has at least default and dev environments
