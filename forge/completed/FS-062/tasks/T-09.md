## Change Requirements

Create `forge/architecture/infrastructure.md` covering:

1. **Purpose and Scope** — What this document covers (IaC, deployment substrate, environment config)
2. **IaC Framework** — AWS SAM choice rationale, `template.yaml` as single source of truth
3. **Resource Inventory** — Summary table of all resources (DynamoDB tables, S3 bucket, API Gateway, Lambda functions, OpenSearch collection, Step Functions)
4. **Naming Conventions** — Stage-prefix pattern `{Stage}-keyra-{resource}`, account-id for globally unique resources
5. **Environment Configuration** — Variable mapping table (local → dev → prod), endpoint overrides
6. **Local Development** — Docker Compose services, setup script, sam local usage
7. **Lambda Packaging** — esbuild bundling, externals, bundle size limits
8. **Cold Start Strategy** — Memory sizing, provisioned concurrency, SDK client reuse
9. **Deployment Flow** — `sam build` → `sam deploy` → outputs
10. **Cross-References** — Links to backend-api.md, persistence-model.md, schema-ingestion.md
