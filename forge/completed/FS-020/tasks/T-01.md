## Summary

Replace the existing 8-panel grid layout in `MappingEditorPage` with a new three-column (source | target worklist | builder) + full-width bottom area layout structure. This is the foundational layout change that all subsequent FS-020 tasks build upon. The component contract (props/slots) must accommodate all new panel roles while preserving the route-level composition pattern.

---

## Scope

### In Scope

- Replace the CSS grid definition in `MappingEditorPage` from `grid-cols-[200px_1fr_240px] grid-rows-[1fr_1fr_180px]` to a new three-column + bottom layout
- New layout structure:
  - Top: `EditorTopBar` (unchanged)
  - Below top bar: `GlobalToolbar` slot (new)
  - Main area: three columns — Source (left, collapsible), Target Worklist (center, primary), Builder/Editor (right)
  - Bottom: full-width area for Preview/Testing/Diagnostics
- Update `MappingEditorPageProps` to reflect new slot model:
  - `sourceContent` (left column)
  - `targetWorklistContent` (center column)
  - `builderContent` (right column)
  - `bottomContent` (full-width bottom area)
  - `toolbarContent` (global toolbar)
  - Preserve: `configPanelContent`, `historyPanelContent`, `onHistoryToggle` (these integrate into the new layout as overlays/drawers)
- Responsive: at ≤1024px, source column collapses to icon-bar or hidden with expand toggle
- Target column must never collapse
- Maintain `data-testid` attributes for testability (update to new slot names)
- Preserve `PreviewProvider` context wrapping

### Out of Scope

- Implementing the actual Target Worklist component (T-02)
- Implementing the Global Toolbar component (T-04)
- Implementing the Builder/Editor content (T-05, T-06, T-07)
- Implementing Preview relocation logic (T-08)
- Modifying `EditorTopBar` internals
- Changing `useMappingEditor` hook

## Change Requirements

After this task is complete:

- `MappingEditorPage` renders a three-column layout with a full-width bottom area
- Layout proportions at 1280px+: source column ~220px, target worklist fills remaining center, builder column ~360px, bottom area ~200px height
- At 1024px: source column collapses (CSS `@media` or Tailwind responsive class)
- Each slot accepts `ReactNode` via props and renders `PanelPlaceholder` when content is not provided
- The old 8-panel slot names (`panel-slot-1` through `panel-slot-8`) are replaced with semantic test IDs: `source-panel`, `target-worklist`, `builder-panel`, `bottom-area`, `global-toolbar`
- `PreviewProvider` wraps the layout content
- Configuration and History remain accessible via their existing patterns (drawer overlays, not grid slots)
- ASCII layout diagram in component JSDoc is updated to reflect new structure
