## Summary

Move the existing Preview Panel and Diagnostics components from their current grid positions (Panel 5, Panel 6) to the new full-width bottom area of the redesigned layout. This consolidates all output/testing/diagnostics into a single expandable bottom section with tabs for Preview, Diagnostics, and Test Cases.

---

## Scope

### In Scope

- Compose existing preview components (`PreviewPanel`, `SourceDataInput`, `OutputDisplay`, `DiffDisplay`, `DiagnosticsDisplay`, `TraceDisplay`, `TestCaseManager`) into the bottom area slot
- Bottom area uses a tabbed interface: "Preview" | "Diagnostics" | "Trace" | "Test Cases"
- Bottom area is collapsible/expandable (drag handle or toggle button)
- Default height: ~200px, expandable to ~400px, collapsible to header-only (~32px)
- Full-width (spans all three columns)
- Preserve all existing preview/diagnostics functionality — only the position changes
- Maintain `PreviewProvider` context integration

### Out of Scope

- Modifying preview component internals
- Adding new preview features
- Changing engine execution behavior
- Right panel preview (explicitly excluded per spec decision)
