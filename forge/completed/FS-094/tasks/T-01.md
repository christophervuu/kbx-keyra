## Summary

Create the new replacement builder state model (`SmartBuilderDraft`, tray inputs, composition forms, history) and pure expression generator utilities. This task establishes the new non-chain architecture and deterministic DSL output surface used by all UI behavior.

---

## Scope

### In Scope

- Add smart-builder state types/factories.
- Add deterministic state->DSL expression generator.
- Add expression history/undo primitives for direct->compose transitions.
- Add enrichment/static/constant/item/parent input rendering metadata in state.
- Add supported-expression decomposition -> `SmartBuilderDraft` hydration primitives.

### Out of Scope

- React component rendering.
- Source panel click wiring.
- Architecture documentation updates.

## Change Requirements

- Model must be independent from legacy `ChainBuilderState`.
- Expression generation must be deterministic and side-effect free.
- Composition variants must include direct/concat/coalesce/math/condition/valueMap/array bridges/advanced expression.
- Undo baseline must preserve pre-compose direct expression snapshot.
- `SmartBuilderDraft.inputs` insertion order must be canonical in Rev 1 and used by expression generation unless composition-specific ordering is explicit.
- Decomposer contracts must return either hydratable smart state or explicit non-decomposable outcome for Advanced-mode handoff.

---

## Verification Requirements

- Unit tests for deterministic generation and state transitions.
- Tests for per-input transform output composition.
- Typecheck/lint for new modules.

---

## Acceptance Checks

- New state model exists and is not built on chain-builder internals.
- Generator emits expected DSL for direct, transforms, condition, null, convert, enrichment flows.
- Generator preserves deterministic insertion-order semantics for concat/coalesce/math default operand ordering.
- Undo primitives restore prior direct expression after compose transition.
- Decomposition/hydration primitives support AE-16 guided-mode hydration outcomes.
- Tests pass for touched files.
