## Summary

Build the new Smart Builder UI shell (target header, empty-state messaging, input tray badges, action groups, unavailable section) and integrate it as the default scalar builder surface in Mapping Editor.

---

## Scope

### In Scope

- `SmartBuilderPanel` component and layout.
- `InputTray` component with source-kind badges and tray controls.
- `BuilderActionList` component with grouped categories and disabled-reason rendering.
- Replace/bypass legacy scalar builder surface entry points.
- Complex-expression banner rendering and Advanced-mode fallback presentation for non-decomposable saved expressions.

### Out of Scope

- Detailed condition/array editors.
- Architecture docs.

- Empty state copy and "Other ways to fill this field" CTA row must match spec intent.

- Enabled actions appear first; disabled actions are visible with reasons.
- Advanced raw editor remains available but not presented as action-catalog source.
