## Summary

Implement the array integration bridge so smart-tray action catalog can represent array operations and hand off appropriately to existing array authoring capabilities while preserving valid `item()/parent()` scope semantics.

---

## Scope

### In Scope

- Array action availability/resolution integration.
- Bridge behavior between scalar smart tray and existing `ArrayBuilder` flows.
- Route array target fields and tray-selected array actions into `ArrayBuilder`-compatible state.
- Scope-safe expression generation for array-related operations where handled in smart tray.
- Explicit UX messaging for actions requiring deeper array editor handoff.

### Out of Scope

- Full replacement of existing deep nested ArrayBuilder UI.
- Engine-level array function changes.

---

- `ui/src/features/mappings/lib/smart-builder-action-resolver.ts`

- `ui/src/features/mappings/components/SmartBuilderPanel.tsx`
- `ui/src/features/mappings/**/*.test.ts(x)`

---

## Change Requirements

- Represent required array functions in action model (`map/filter/find/array/merge/flatten/first/nth/join/count/get`).
- Ensure `item`/`parent` options are context-gated.
- For unsupported deep flows in smart tray, provide deterministic handoff to existing `ArrayBuilder` rather than invalid generation.
- Do not implement full tray-native replacement of deep array authoring in Rev 1.
- Engine validation remains the canonical guard.

---

## Verification Requirements

- Resolver tests for array/scalar mixed contexts.
- Integration tests for bridge behavior and scope gating.
- Typecheck/lint for touched modules.

---

## Acceptance Checks

- Array actions appear when valid and are disabled with reasons when invalid.
- Smart tray + existing ArrayBuilder integration preserves valid scope semantics and compatible state transfer.
- No invalid array DSL is emitted from guided actions without diagnostics.

---

## Blockers / Risks

- Scope/context mismatches may be subtle in nested array cases.

---

## Notes

- If deep-array replacement is later approved, this bridge becomes migration seam.
