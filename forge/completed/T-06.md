## Summary

Adjust UI-facing deployment and server-preview environment contracts so runtime targets are DEV/PREPROD/PROD, QA terminology is removed, and SANDBOX is represented as control-plane context rather than a deploy target.

---

## Scope

### In Scope

- Replace QA labels/enums/options with PREPROD on deployment and preview surfaces.
- Update any environment selectors, status badges, and adapter-facing type usage for runtime environments.
- Ensure UI shows SANDBOX context only where control-plane context is required (not as deploy target).
- Update UI tests for environment labels/options and preview metadata rendering.

### Out of Scope

- Backend deployment mechanics.
- Auth/security UI additions.

- Runtime environment options shown to users are DEV, PREPROD, PROD.

- Preview response metadata surface includes environment + artifact identity from backend contract.
