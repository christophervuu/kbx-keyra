## Summary

Create a `useServerPreview` hook that wraps `adapter.previewOnServer()` with Phase 0 gating, error handling, timeout protection, and typed result conversion. This hook provides the server-side execution capability for the comparison workflow's environment sides.

---

## Scope

### In Scope

- Create `ui/src/features/mappings/hooks/use-server-preview.ts`
- Implement `useServerPreview` hook with the following contract:
  - Inputs: `mappingId`, `environment`, `sourceData` (parsed JSON)
  - Outputs: `{ execute, result, isExecuting, error, isAvailable }`
  - `isAvailable` reflects whether server preview is supported (Phase 0: always `false`)
- Phase 0 detection: attempt a capability check or catch the "Not available in offline mode" error and set `isAvailable = false`
- Timeout protection: 10-second timeout for server calls
- Error handling: catch adapter errors, map to user-friendly messages
- Return `ServerPreviewResult` on success (re-exported from domain types)
- Add unit tests

### Out of Scope

- Comparison orchestration (that's T-04)
- UI components
- Modifying `ApiAdapter` or `LocalStorageAdapter`

## Change Requirements

Create the hook with:

- `execute(sourceData: Record<string, unknown>): Promise<void>` — triggers server preview for the configured environment
- Internally calls `adapter.previewOnServer(mappingId, { environment, sourceData })`
- Wraps call in a timeout (10 seconds) using `Promise.race` with a timeout promise
- On success: stores `ServerPreviewResult` in state
- On timeout: sets error state with "Server preview timed out after 10 seconds"
- On adapter error: catches error, checks for "Not available in offline mode" message to set `isAvailable = false`, otherwise stores error message
- `isAvailable` starts as `true` and is set to `false` on the first "Not available" error (sticky for the hook lifetime)
- The hook should be stable across re-renders (memoized execute callback)
