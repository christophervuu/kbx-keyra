## Summary

Create the `ComparisonDiffDisplay` component that displays the diff between two comparison side outputs. This is a dedicated, read-only comparison diff component — separate from the existing `DiffDisplay` (which includes an editable expected-output textarea for the Diff tab). `ComparisonDiffDisplay` reuses the shared `computeDiff` utility and diff rendering primitives (color conventions, entry formatting helpers) but owns its own comparison-oriented layout and labeling.

---

## Scope

### In Scope

- Create `ui/src/features/mappings/components/comparison/ComparisonDiffDisplay.tsx`
- Render diff between left and right comparison outputs:
  - **Match state:** green "Outputs match" indicator with check icon
  - **Diff state:** summary count ("N differences found") + diff entry list with path, type (added/removed/changed), and values
  - **Cannot compute:** gray "Cannot compute diff — one side has no output" message
  - **Idle:** no diff section shown (both sides must complete)
- Use `computeDiff` from `ui/src/lib/utils/json-diff.ts` for diff computation
- Style diff entries with color coding: green for added, red for removed, amber for changed
- Add component tests

### Out of Scope

- Diff computation logic changes (reuse existing `computeDiff`)
- Editable expected output (unlike existing `DiffDisplay`, this is read-only — Q3 resolution confirms separate component)
- Side panel rendering (that's T-06)

## Change Requirements

Component props:

```ts
interface ComparisonDiffDisplayProps {
  leftOutput: Record<string, unknown> | null;
  rightOutput: Record<string, unknown> | null;
  leftLabel: string;
  rightLabel: string;
  overallStatus: ComparisonState['overallStatus'];
}
```

Rendering rules:

- `overallStatus === 'idle' | 'executing'`: render nothing (or a subtle placeholder)
- `leftOutput === null || rightOutput === null`: render "Cannot compute diff — one side has no output" in a gray info box
- `diffEntries.length === 0`: render green "Outputs match ✓" indicator
- `diffEntries.length > 0`: render summary header ("N differences found") + scrollable list of diff entries

Diff entry rendering:
- Each entry shows: path, diff type icon (added/removed/changed), values
- Entry descriptions reference `leftLabel` / `rightLabel` instead of generic "expected"/"actual"
  - Added: `"${path}" is present in ${rightLabel} but not in ${leftLabel}`
  - Removed: `"${path}" is present in ${leftLabel} but not in ${rightLabel}`
  - Changed: `"${path}": ${leftLabel} has ${leftValue} → ${rightLabel} has ${rightValue}`
- Long values are truncated (60 chars) with ellipsis

Test IDs: `comparison-diff-display`, `comparison-diff-match`, `comparison-diff-count`, `comparison-diff-entry`

Shared rendering primitives:
- Extract or reference the `formatValue` / value truncation helpers from `DiffDisplay.tsx` — these can be shared utilities or duplicated inline if they are small
- Use the same color classes as `DiffDisplay`: green-500/green-900 for added, red-500/red-900 for removed, amber-500/amber-900 for changed
- The key difference from `DiffDisplay` is: no editable textarea, no expected-output input, no side-by-side JSON rendering of expected vs actual — only a list of `DiffEntry` rows with comparison labels
