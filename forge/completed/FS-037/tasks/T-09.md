## Summary

Implement separate `ComparisonSnapshot` storage that links comparison results to test cases by ID. Per Q2 resolution, comparison snapshots are stored as independent records in their own localStorage key (`keyra:comparison-snapshots:{mappingId}`), not as fields on the `TestCase` type. Add a `useComparisonSnapshots` hook for snapshot CRUD, a "Save Comparison" action in the CompareTab, and a read-only historical view for stored snapshots accessible from the TestCaseManager.

## Change Requirements

**Separate `ComparisonSnapshot` storage (Q2 resolution):**

The `TestCase` type is NOT extended. Instead, comparison snapshots are stored as independent records:

Storage model:
- localStorage key: `keyra:comparison-snapshots:{mappingId}`
- Value: `ComparisonSnapshot[]` (JSON-serialized array)
- Each `ComparisonSnapshot` has an `id` (unique), `testCaseId` (link), `mappingId`, `mode`, `leftResult`, `rightResult`, `diffEntries`, `capturedAt`

`useComparisonSnapshots(mappingId)` hook:

- `snapshots: ComparisonSnapshot[]` — all snapshots for this mapping
- `snapshotsForTestCase(testCaseId: string): ComparisonSnapshot[]` — filter by test case
- `saveSnapshot(snapshot: Omit<ComparisonSnapshot, 'id'>): ComparisonSnapshot` — generate ID, persist, return
- `deleteSnapshot(snapshotId: string): void` — remove a single snapshot
- `deleteSnapshotsForTestCase(testCaseId: string): void` — remove all snapshots linked to a test case

CompareTab "Save Comparison" button:

- Visible after a comparison completes (status `'complete'` or `'partial-error'`)
- If a test case is loaded: saves the comparison snapshot linked to that test case
- If no test case is loaded: shows a mini-form to name and save a new test case with the current source data, then links the snapshot to the newly created test case
- Success feedback: brief toast or inline success message

TestCaseManager indicator:

- Query `snapshotsForTestCase(testCaseId)` to determine if a test case has linked snapshots
- Test cases with linked snapshots show a small comparison icon (e.g., `GitCompare` from Lucide) and count badge
- Clicking the indicator expands or opens a read-only view of the linked snapshots:
  - Mode, captured timestamp
  - Summary: "Outputs match" or "N differences"
  - Left/right labels and output excerpts (truncated)
