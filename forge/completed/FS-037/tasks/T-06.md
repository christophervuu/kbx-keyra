## Summary

Create the `ComparisonSidePanel` and `EnvironmentMetadataBar` components that display a single side of a comparison result. The side panel shows the execution output (or error) below a metadata bar that identifies the execution context: environment name, snapshot version, deployment timestamp, engine version, and saved/unsaved state for client-side executions.

---

## Scope

### In Scope

- Create `ui/src/features/mappings/components/comparison/ComparisonSidePanel.tsx`
- Create `ui/src/features/mappings/components/comparison/EnvironmentMetadataBar.tsx`
- `EnvironmentMetadataBar` renders:
  - Execution context badge ("Client-side" or environment name like "DEV")
  - Config/snapshot version (e.g., "v5" or "Snapshot v5")
  - Deployment timestamp for server-side results (relative + absolute on hover)
  - Engine version
  - "unsaved changes" badge for working config when applicable
  - Saved-at timestamp for client-side "saved" variant
- `ComparisonSidePanel` renders:
  - `EnvironmentMetadataBar` at the top
  - JSON output display (formatted, syntax-highlighted) when status is `success`
  - Loading spinner when status is `executing`
  - Error message display when status is `error`
  - Empty/idle state when no execution has run
- Add component tests for both components

### Out of Scope

- Diff computation or display (that's T-07)
- Comparison orchestration
- Side-by-side layout composition (that's T-08)

## Change Requirements

`EnvironmentMetadataBar` props:

```ts
interface EnvironmentMetadataBarProps {
  metadata: ComparisonSideMetadata;
  label: string;
}
```

Rendering rules:
- `executionContext === 'client'`: show "Client-side" badge in blue
- `executionContext === 'server'`: show environment name badge (DEV=green, QA=amber, PROD=red)
- Show version as "v{configVersion}" for client, "Snapshot v{snapshotVersion}" for server
- Show `deployedAt` as relative time (e.g., "2 days ago") with ISO timestamp on hover tooltip
- Show `engineVersion` as small text
- Show "unsaved" warning badge when `hasUnsavedChanges === true`
- Test IDs: `metadata-bar`, `metadata-context`, `metadata-version`, `metadata-timestamp`, `metadata-unsaved`

`ComparisonSidePanel` props:

```ts
interface ComparisonSidePanelProps {
  side: 'left' | 'right';
  result: ComparisonSideResult;
}
```

Rendering rules:
- Status `idle`: show "Run comparison to see results" placeholder
- Status `executing`: show centered spinner with "Executing..."
- Status `success`: show `EnvironmentMetadataBar` + formatted JSON output
- Status `error`: show `EnvironmentMetadataBar` + error message in red
- Test IDs: `comparison-side-{left|right}`, `comparison-side-output`, `comparison-side-error`
