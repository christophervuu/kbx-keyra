## Summary

Implement array-specific result preview within the Array Builder's feedback area. The preview shows the generated array's shape, first 10 items by default with a "Showing 10 of N items" summary, empty/null result states, and for merge branches, a branch contribution summary. The preview reuses the existing `useExpressionPreview` hook and engine integration but formats the output specifically for array results.

---

## Scope

### In Scope

- Array result preview rendering in the BuilderFeedbackArea result row
- Preview result shape: formatted JSON showing array structure
- First N items display: show up to 10 items by default with "Showing 10 of N items" summary and expandable access to full result
- Empty array display: `[]` with info message "Array is empty" or "All items were filtered out"
- Null result display: "No result — source array not found" or similar
- Merge branch contribution summary: "Branch 1: 3 items, Branch 2: 1 item" (when practical to derive)
- Item count badge: "N items" shown in result row
- Integration with `useExpressionPreview` or `usePreviewExecution` for live preview on expression change

### Out of Scope

- Changes to the preview execution engine
- Changes to `ConnectedInlinePreviewStrip` or `InlinePreviewStrip`
- Full-page preview (test lab handles that)

## Change Requirements

- `ArrayResultPreview.tsx`:
  - Receives preview result from `useExpressionPreview`
  - If result is `null`: show "No result" with contextual hint (e.g., "Source array path may not exist in the data")
  - If result is `[]`: show "Empty array" with contextual hint (e.g., "Filter condition excluded all elements" when in Filter+Map mode)
  - If result is an array:
     - Show item count badge: "N items"
    - Render first 10 items as formatted JSON (compact, one level of nesting visible)
    - Show summary: "Showing 10 of N items" when array has more than 10 items
    - Expandable access to full result when truncated
    - Each item shows a brief structural summary (field count, key field values if identifiable)
  - For Merge Branches mode:
    - If branch count and item positions are derivable, show branch contribution: "Branch 1: 3 items • Branch 2: 1 item"
    - This is best-effort — if not derivable, skip contribution summary
- Integration with `ArrayBuilder.tsx`:
  - The BuilderFeedbackArea result row renders `ArrayResultPreview` when the builder has a non-empty expression
  - Preview updates live as the expression changes (debounced via `useExpressionPreview`)
  - Preview is gated on source data availability (same as scalar preview)
  - When no source data: result row shows "Load test data to see preview" (matching scalar builder pattern)
- Merge branch contribution derivation:
  - For a `merge(a, b, ...)` expression, execute each branch sub-expression separately to get individual counts
  - If sub-execution is impractical, use heuristic: assume items appear in branch order (first N are branch 1, next M are branch 2, etc.)
  - Mark contribution summary as "(estimated)" when using heuristic

## Notes

- The preview infrastructure already exists and works for scalar expressions. This task adapts the display formatting for array results — not the execution machinery.
- Default truncation at 10 items (resolved Q4). Shows "Showing 10 of N items" summary with expand access to full result.
- Consider using a collapsible tree view for complex object items rather than raw JSON, for readability. However, keep the v1 implementation simple (formatted JSON) and iterate on the display in a follow-up.
