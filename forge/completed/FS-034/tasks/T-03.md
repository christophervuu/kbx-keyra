## Summary
Build the `TestCaseListPanel` component that replaces the dropdown-based `TestCaseManager` as the primary test case list surface. It renders a vertical list of test cases with selection, pass/fail status badges, and context actions (rename, duplicate, delete). Includes the Scratchpad pseudo-entry.

---

## Scope

### In Scope
- Create `TestCaseListPanel` component at `ui/src/features/mappings/components/preview/TestCaseListPanel.tsx`
- Vertical list rendering with each row showing: name, pass/fail badge (green/red/gray), last-run relative timestamp
- Selection model: clicking a row selects it and fires `onSelect(testCase)` callback; Scratchpad entry fires `onSelectScratchpad()`
- Scratchpad pseudo-entry at top of list (permanent, non-deletable, non-renamable)
- Visual highlight on selected row
- Inline rename: double-click name → input field → Enter confirms, Escape cancels
- Context actions per row: Duplicate button, Delete button
- Delete confirmation when case has run results
- Empty state when no test cases exist
- Status badge rendering using `TestRunResult` data
- Export from preview barrel

### Out of Scope
- Add New / Save Current buttons (T-04)
- Run All / Rerun Failed buttons (T-06)
- Batch execution logic
- Wiring into AdvancedTestingPage (T-07)

## Change Requirements
- Props interface: `testCases`, `selectedId: string | null`, `runResults: Record<string, TestRunResult>`, `onSelect(tc: TestCase)`, `onSelectScratchpad()`, `onRename(id, newName)`, `onDuplicate(id)`, `onDelete(id)`, and toolbar slot props for Add New / Run All buttons (rendered by parent)
- Scratchpad row: always first, visually distinct (italic or different styling), shows "Scratchpad" label, no status badge
- Status badges: green CheckCircle for pass, red XCircle for fail, gray Circle for not-run
- Inline rename uses a controlled input with blur-to-cancel behavior
- Delete shows a confirmation prompt when `runResults[id]` exists (user might lose results)
- Empty state: "No test cases yet. Click Add New to create one."
- Accessible: proper `role=listbox` / `role=option` or `role=list` / `role=listitem` with `aria-selected`
