## Summary

Update `forge/architecture/ui-application.md` to document the new chain-based Builder information architecture, replacing the Expression Builder Architecture section's current 3-mode model with the new entry-point + chain + progressive disclosure model. Update `INDEX.md` last-updated date.

## Scope

### In Scope

- Update the "Expression Builder Architecture" section in `ui-application.md`:
  - Replace the 3-mode model description with the new entry-point model (Source/Static/External)
  - Document the `ChainBuilderState` type system and its relationship to the old `ExpressionBuilderState`
  - Document the chain model semantics (base value → transform → condition → value map)
  - Document the new component hierarchy (`ChainBuilderShell`, entry-point components, step forms, collapsible containers)
  - Document the new generator (`chain-expression-generator.ts`) and decomposer (`chain-decomposer.ts`)
  - Document backward compatibility approach (legacy decomposers retained)
- Update the Module Structure section:
  - Add new files: `chain-builder-state.ts`, `chain-expression-generator.ts`, `chain-decomposer.ts`, `ChainBuilderShell.tsx`, and new component files
  - Note that `UnifiedExpressionBuilder.tsx` and related legacy files are retained for fallback
- Update `forge/architecture/INDEX.md` — bump `Last Updated` date for `ui-application.md`

### Out of Scope

- Creating a new architecture document (the Builder is part of the existing UI application subsystem)
- Removing documentation of legacy components (they still exist in codebase)
