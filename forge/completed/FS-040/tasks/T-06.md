## Change Requirements

1. In `ui-application.md`, within the Mapping Editor Architecture section, add or update the following:

   **ScalarFieldBuilder description** — update to reflect:
   - Suggested Sources row removed
   - `BuilderFeedbackArea` added between Header and Expression Area
   - Action row redesigned: `Reset draft`, AI placeholders with descriptive tooltips
   - Header overflow menu (⋮) added for destructive action `Remove mapping`

   **New subsection: Builder Validation Model (FS-040)** — documenting:
   - Two-level validation: structural (Builder state inspection) + output type (engine AST inference)
   - `useBuilderValidation` hook contract:
     - Inputs: `builderState`, `expression`, `targetType`, `mode`, `parseResult`, `isParseValid`
     - Outputs: `BuilderValidationState` with `structureValid`, `structureIssues`, `outputTypeValid`, `outputTypeMismatch`, `canApply`, `canSave`
   - Structural validation: mode-specific checks (Value/Conditional/ValueMap), error keys, BA-friendly messages
   - Output type validation: AST-based inference via engine, compatibility matrix, `unknown` → no mismatch
   - Apply gated by structural + parse validity; Save gated by Apply + output type validity

   **New subsection: Builder Feedback Area (FS-040)** — documenting:
   - `BuilderFeedbackArea` component in the hierarchy
   - Expression, Result, Validation rows
   - Relocated from inside `UnifiedExpressionBuilder` to `ScalarFieldBuilder` top-level

   **New subsection: Unsaved Diff (FS-040)** — documenting:
   - `useUnsavedDiff` hook contract
   - `UnsavedDiffPanel` component
   - Per-target-field diff scope
   - Baseline from `useMappingEditor.savedRules`

   **Updated component hierarchy:**
   ```
   ScalarFieldBuilder
   ├── Header (target path, type badge, status, mode toggle, ⋮ overflow menu)
   ├── BuilderFeedbackArea (Expression, Result, Validation)
   ├── UnsavedDiffPanel (expandable, conditional)
   ├── Expression Area (UnifiedExpressionBuilder or RawDslEditor)
   └── Action Row (Suggest, Explain, Fix, Reset draft, Next unmapped, Apply)
   ```
   Note: "Remove mapping" is in the header overflow menu (⋮), not in the action row or a secondary row.

   **Updated `useMappingEditor` additions** — add `savedRules` to the documented additions.

2. In `INDEX.md`, update the `Last Updated` date for `ui-application.md` to the current date.
