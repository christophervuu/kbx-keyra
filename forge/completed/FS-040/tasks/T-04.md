## Summary

Redesign the Builder action row at the bottom of `ScalarFieldBuilder`. Rename "Clear" to "Reset draft" with confirmation behavior for non-trivial expressions. Move the destructive "Remove mapping" action out of the action row entirely into a new header overflow menu (⋮). Update AI placeholder button tooltips with descriptive future-state text. Update all ARIA attributes and test IDs.

---

## Scope

### In Scope

- Rename "Clear" button label to "Reset draft" with `RotateCcw` icon (from Lucide).
- "Reset draft" behavior:
  - When expression is trivial (empty or a bare `source("...")` with no transforms): reset immediately, no confirmation.
  - When expression is non-trivial: show a confirmation prompt ("Reset draft? Your current expression will be cleared.") before resetting.
  - Reset action: set expression to empty string, reset builder state to default empty Value mode.
  - Enabled when expression is non-empty OR builder state is dirty.
- Rename "Clear mapping" (red destructive button) to "Remove mapping".
- Move "Remove mapping" out of the action row into a **header overflow menu (⋮)**:
  - Add a kebab menu button (⋮ / `MoreVertical` icon from Lucide) to the existing header row, right-aligned near the mode toggle.
  - The menu is a simple dropdown with "Remove mapping" as a destructive option (red text).
  - `aria-haspopup="menu"` and `aria-expanded` on the trigger button.
  - Menu items have `role="menuitem"`.
  - The overflow menu is only present when `currentStatus === 'mapped'` and `onClearMapping` is provided (if no overflow actions are applicable, the ⋮ button is hidden).
- Add a confirmation dialog for "Remove mapping": "Remove mapping for {targetPath}? This will delete the saved rule." with confirm/cancel.
- Update AI action tooltips from `AI_COMING_SOON` to descriptive per-action text:
  - Suggest: "AI-powered expression suggestions — available in a future release"
  - Explain: "AI-powered explanation — available in a future release"
  - Fix: "AI-powered fix suggestions — available in a future release"
- Update `aria-disabled="true"` and add descriptive `aria-label` to each AI action button.
- Update `data-testid` values:
  - `clear-mapping-btn` → `remove-mapping-btn`
  - Add `reset-draft-btn`
  - Keep `ai-suggest-btn`, `ai-explain-btn`, `ai-fix-btn`
- Ensure keyboard accessibility for all buttons.
- Ensure "Remove mapping" confirmation uses `role="alertdialog"`.

### Out of Scope

- Actual AI endpoint integration.
- Changes to Apply/Save button gating (T-03).
- Pinned feedback area (T-02).
- Unsaved diff (T-05).

## Change Requirements

1. **Reset draft button:**
   - Icon: `RotateCcw` (Lucide).
   - Label: "Reset draft"
   - `data-testid="reset-draft-btn"`
   - `aria-label="Reset current draft expression"`
   - Enabled when `expression.trim().length > 0` or builder state is dirty.
   - Confirmation logic:
     - Trivial check: expression matches `/^source\("[^"]*"\)$/` (bare source reference) or is empty → no confirmation.
     - Non-trivial: show inline confirmation (a prompt bar or small dialog). Use a simple state toggle (`confirmingReset`) that shows "Reset draft?" + Confirm/Cancel inline.
   - On confirm or immediate reset: call `handleExpressionChange('')`, reset builder state (this may need a new `onReset` callback from `UnifiedExpressionBuilder` or simply trigger via `key` prop change on the builder).

2. **Remove mapping — header overflow menu:**
   - Add a kebab menu trigger button (`MoreVertical` icon from Lucide) to the header row in `ScalarFieldBuilder`, right-aligned after the mode toggle.
   - `data-testid="header-overflow-trigger"`
   - `aria-haspopup="menu"`, `aria-expanded`, `aria-label="More actions"`
   - Only rendered when overflow actions are applicable (currently: `currentStatus === 'mapped'` and `onClearMapping` is provided).
   - Menu dropdown:
     - `role="menu"`, positioned below the trigger.
     - Contains a single item: "Remove mapping" with `role="menuitem"`, red text styling, `data-testid="remove-mapping-btn"`.
     - `aria-label="Remove saved mapping for {targetPath}"`
   - On click "Remove mapping": close menu, open confirmation dialog (`role="alertdialog"`):
     - Title: "Remove mapping"
     - Message: "Remove mapping for {targetPath}? This will delete the saved rule."
     - Actions: "Remove" (destructive, red) + "Cancel"
   - On confirm: call `onClearMapping(selectedTargetPath)`.
   - Menu closes on outside click, Escape key, or item selection.
   - Implementation: use a simple `useState`-based dropdown (no external dropdown library in Phase 0). Position with absolute/relative CSS.

3. **AI action buttons:**
   - Tooltips updated to per-action descriptive text.
   - Each button gets `aria-label="{action} — {tooltip text}"`.
   - Visual appearance remains the same (disabled, muted).

4. **Action row layout change:**
   ```
   Header row: [type badge] [target path] [Builder|Editor toggle] [⋮ overflow menu]
   Action row: [Suggest] [Explain] [Fix] [Reset draft] | <spacer> | [Next unmapped →] [Apply]
   ```
   "Remove mapping" is no longer in the action row — it is in the header overflow menu.
