## Summary

Implement side-by-side Source/Target schema cards and a simple Schema Summary section that show only approved baseline metadata with no readiness/match/array analytics surfaces.

---

## Scope

### In Scope

- Render Source Schema and Target Schema cards side-by-side (responsive stack fallback allowed).
- Add selector controls for source and target schema IDs.
- Show selected schema metadata on each card: name, field count, required field count, format, origin.
- Add Schema Summary section with exactly four values:
  - source fields
  - source required fields
  - target fields
  - target required fields
- Support deterministic fallback display when required count is unavailable.
- Use required count source precedence:
  1) metadata `requiredFieldCount`
  2) normalized parsed schema node required-leaf count
  3) `—` fallback

### Out of Scope

- In-card add-schema action wiring.
- Start mode logic.
- Submission branching.
- Raw JSON Schema/XSD required-count parsing inside `CreateMappingPage`.
