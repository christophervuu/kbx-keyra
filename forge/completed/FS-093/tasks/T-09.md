## Summary

Update preview/test case UI and client-side input-set model to support one primary sample payload plus named enrichment sample payloads, including missing-required enrichment indicators and compatibility with legacy single-source samples.

---

## Scope

### In Scope

- Rename/align sample model terminology to Input Set where appropriate.
- Input set data model and editor support for `sourceData` + `externalSources` + optional expected output.
- UI indicators for missing required enrichment sample payloads.
- Preview execution request composition with both payload classes.
- Legacy sample format compatibility/defaulting and migration.

### Out of Scope

- Full Test Lab redesign beyond enrichment sample support.
- New execution engines.

---

## Relevant Areas

- `ui/src/features/mappings/hooks/use-preview-execution.ts`
- `ui/src/features/mappings/hooks/use-test-cases.ts`

- related tests/fixtures

## Change Requirements

- Existing stored samples without `externalSources` must continue to load.
- Required enrichment sample omissions must surface clear warning/block behavior per finalized policy.
- Preview request must pass both source and enrichment samples.
- Input sets persist as versioned structures and migrate old single-source samples to `externalSources: {}`.
