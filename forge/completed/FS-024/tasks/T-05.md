## Summary

Add [Format] ghost button to the Source JSON pane header and [Copy] ghost button to the Output pane header. Format parses and pretty-prints the textarea JSON. Copy writes output to clipboard with "Copied ✓" feedback for 1.5 seconds. Both are styled as ghost buttons (low-contrast, hover-reveal) consistent with the editor visual language.

---

## Scope

### In Scope

- Add [Format] ghost button in Source pane header:
  - `data-testid="strip-format-button"`
  - On click: attempt `JSON.parse(sourceData)` → if valid, re-serialize with 2-space indent and call `onSourceDataChange(formatted)`.
  - On parse failure: brief shake animation (CSS `animate-shake` or equivalent), no change to textarea.
- Add [Copy] ghost button in Output pane header:
  - `data-testid="strip-copy-button"`
  - On click: `navigator.clipboard.writeText(outputText)`.
  - On success: button text changes to "Copied ✓" for 1.5 seconds, then reverts to "Copy".
  - On failure: button text changes to "Copy failed" for 1.5 seconds, then reverts.
  - Disabled when output is empty/null.
- Ghost button styling: transparent background, muted text, visible on hover (`opacity-0 group-hover:opacity-100` or similar).
- Update tests.

### Out of Scope

- Any other pane header buttons.
- Syntax highlighting in the source textarea.
- Changing the output display format.

## Notes

- Mock `navigator.clipboard.writeText` in tests using `vi.fn()` assigned to `Object.assign(navigator, { clipboard: { writeText: vi.fn() } })` or similar pattern.
- The shake animation can be a simple CSS keyframe: `@keyframes shake { 0%, 100% { transform: translateX(0); } 25% { transform: translateX(-2px); } 75% { transform: translateX(2px); } }` applied via a Tailwind arbitrary utility or inline style class.
- Ghost button pattern: `text-slate-600 hover:text-slate-300 text-[10px] uppercase tracking-wide`.
