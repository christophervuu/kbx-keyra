## Summary

- Update tests affected by enum changes.

## Change Requirements

- Canonical environment sequence is SANDBOX, DEV, PREPROD, PROD.
- New writes and request validation must reject QA for create/update operations.
- Legacy QA persistence values may be normalized to PREPROD at read/model boundaries.
- Add explicit migration notes/comments and deterministic tests around QA normalization.

---

## Verification Requirements

- Unit tests for environment parsing/normalization and write-time validation.
- Route-level tests showing QA rejected on mutation APIs but normalized on historical reads where applicable.
- Typecheck/build for touched areas.

- QA is not accepted as canonical mutation input.

- Updated tests pass for normalization and validation behavior.
