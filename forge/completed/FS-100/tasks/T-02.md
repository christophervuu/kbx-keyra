## Summary

Create an explicit one-time import/migration utility that moves browser-local mapping records into backend persistence for deployability, while preserving IDs/rules/expressions and normalizing required deployment fields.

---

## Scope

### In Scope

- Discovery and classification of browser-local mapping records in backend mode.
- Explicit user-visible import/migration path (not silent startup migration).
- Preserve mapping IDs when safe, preserve rules/expressions unchanged.
- Normalize engineVersion/schema references/enrichment declarations/saved version requirements.
- Persist migrated mappings and required artifacts through backend adapter.
- Produce migration summary: imported, skipped, failed (with reasons).
- Idempotent rerun behavior.

### Out of Scope

- Runtime execution implementation.
- Deployment UI pipeline redesign.

---

## Relevant Areas

- `ui/src/lib/api/local-storage-adapter.ts`
- `ui/src/lib/api/http-adapter.ts`
- `ui/src/lib/api/bootstrap.ts`
- mapping persistence endpoints under `src/lambda/mapping/*`
- `src/lib/persistence/{mappings.ts,mapping-revisions.ts,mapping-versions.ts,types.ts}`
- migration/import utilities/scripts (new or existing)

---

## Change Requirements

- Backend mode deployment must not depend on browser-local mapping state.
- No silent migration on app startup.
- Browser-only mappings must be importable via explicit workflow/utility.
- Migration must not alter mapping behavior.
- Non-migratable records must be reported, not silently dropped.

---

## Verification Requirements

- Migration tests for successful normalization and idempotent reruns.
- Negative tests for invalid legacy mappings with actionable reports.
- Fixture test proving imported mapping can enter deploy pipeline.

---

## Acceptance Checks

- Explicit import path exists and is user-visible/controlled.
- Imported records preserve expressions and mapping behavior.
- Migrated records are retrievable from backend-only persistence for deployment.
- Summary report contains imported/skipped/failed counts and reasons.

---

## Blockers / Risks

- Legacy shape variance may exceed current adapter assumptions.
