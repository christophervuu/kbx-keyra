## Summary

Implement the shared test infrastructure: page objects for navigation/interaction, test data factories for deterministic domain objects, storage seed/clear helpers for localStorage mode, HTTP seed/reset helpers for httpBackend mode, and a unified `seedData()`/`resetData()` abstraction that selects the correct mechanism based on active Playwright project.

---

## Scope

### In Scope

- Page objects (`tests/e2e/pages/`):
  - `app.page.ts` — shell navigation (nav links, breadcrumbs)
  - `project-list.page.ts` — home/project list interactions
  - `project-form.page.ts` — project create/edit form
  - `project-overview.page.ts` — project overview page interactions
  - `schema-upload.page.ts` — schema creation/upload interactions
  - `schema-detail.page.ts` — schema detail page tree rendering
  - `mapping-editor.page.ts` — mapping editor basic interactions (open, add rule, save)
- Test data factories (`tests/e2e/fixtures/test-data.ts`):
  - `createTestProject(overrides?)` → `ProjectMetadata`
  - `createTestMapping(overrides?)` → `MappingMetadata` / `MappingConfig`
  - `createTestSchema(overrides?)` → `SchemaMetadata` / `SchemaDetail`
  - Stable IDs (`test-project-1`, `test-mapping-1`, etc.) for reproducible assertions
- Storage helpers (`tests/e2e/fixtures/storage.ts`):
  - `seedLocalStorage(page, data)` — sets `keyra:*` keys via `page.evaluate()`
  - `clearLocalStorage(page)` — clears all `keyra:*` keys
- HTTP seed helpers (`tests/e2e/fixtures/http-seed.ts`):
  - `seedBackend(data)` — POST to mock server `/test/seed`
  - `resetBackend()` — POST to mock server `/test/reset`
- Unified adapter-agnostic helper (`tests/e2e/fixtures/seed.ts`):
  - `seedData(page, data)` — detects mode from test info and routes to correct mechanism
  - `resetData(page)` — detects mode and routes to correct reset mechanism
- Extended test fixture (`tests/e2e/fixtures/base.ts`):
  - Integrates seed/reset into test lifecycle (auto-reset in afterEach)
  - Exposes factory access and seed utilities as fixture parameters
- Schema fixture files (`tests/e2e/fixtures/schemas/`):
  - `simple-order.json` — 8-10 field flat JSON Schema for basic tests
  - `nested-customer.json` — 3-level nested schema for tree tests

### Out of Scope

- Actual test specs (T-04)
- Mock server implementation (T-02, assumed complete)
- CI configuration (T-05)

## Change Requirements

- Page objects must follow conventions from `e2e-testing.md`:
  - TypeScript classes accepting `Page` in constructor
  - Return `Locator` objects (not resolved values)
  - No assertions in page objects
  - `goto()` method for direct navigation
- Factories must produce valid domain objects compatible with both `LocalStorageAdapter` internal format and mock server expected shapes
- Unified seed abstraction must detect adapter mode from Playwright `testInfo.project.name` or a custom fixture parameter
- All helpers must be TypeScript with proper typing
- localStorage seed format must match actual `keyra:*` key structure used by `LocalStorageAdapter`
