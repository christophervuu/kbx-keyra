## Summary

Build the view toggle component that switches between grid and table views, with preference persisted to `localStorage`. Also implement a lightweight `useViewMode` hook that encapsulates the persistence logic.

---

## Scope

### In Scope

- New file `ui/src/features/home/hooks/use-view-mode.ts`
- New file `ui/src/features/home/components/ViewToggle.tsx`
- Two icon buttons: grid icon and list/table icon
- Active mode highlighted visually
- On click: switch mode and persist to `localStorage` key `keyra:dashboard:viewMode`
- On mount: read from localStorage, default to `'grid'` if not set
- Hook: `useViewMode()` returns `{ viewMode, setViewMode }`

### Out of Scope

- Card/table rendering (T-05, T-06)
- Other localStorage interactions

## Change Requirements

- `useViewMode` hook:
  ```typescript
  function useViewMode(): {
    viewMode: ViewMode;
    setViewMode: (mode: ViewMode) => void;
  }
  ```
  - Initialize from `localStorage.getItem('keyra:dashboard:viewMode')` ?? `'grid'`
  - `setViewMode` updates state AND persists to localStorage
  - If localStorage value is corrupted (not 'grid' or 'table'), default to 'grid'

- `ViewToggle` component:
  - Props: `viewMode: ViewMode`, `onChange: (mode: ViewMode) => void`
  - Two buttons side by side:
    - Grid icon (LayoutGrid from Lucide) — active when `viewMode === 'grid'`
    - Table/List icon (List from Lucide) — active when `viewMode === 'table'`
  - Active button: `bg-blue-100 text-blue-700` (or similar highlight)
  - Inactive button: `text-gray-400 hover:text-gray-600`
  - Wrapped in a `rounded-md border` container for grouping
  - `aria-label` on each button: "Grid view", "Table view"
  - `aria-pressed` on active button
