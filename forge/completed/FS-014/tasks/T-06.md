## Summary

Build the project table component for the table view of the project list. Renders a `<table>` with columns: Name, Description, Mappings, Status, DEV/QA/PROD deploy badges, and Last Modified. Each row is clickable and navigates to the project overview.

---

## Scope

### In Scope

- New file `ui/src/features/home/components/ProjectTable.tsx` (table container + rows)
- Table header with column labels
- Row per project with all required fields
- Description truncated in cell
- Worst-status as colored badge
- Deploy badge cells (DEV/QA/PROD)
- Clickable rows (navigate on click)
- Hover highlight on rows

### Out of Scope

- Sortable column headers (sorting handled by parent controls in T-04)
- Quick-action buttons per row (keep simple for Phase 0)
- Pagination

## Relevant Areas

- `ui/src/features/home/components/ProjectTable.tsx` (new)
- `ui/src/features/home/components/index.ts` (barrel update)
- `ui/src/components/StatusBadge.tsx` (deploy badges)

---

## Change Requirements

- `ProjectTable` receives: `projects: ProjectListItem[]`, `onProjectClick: (id: string) => void`
- Semantic HTML `<table>`:
  - `<thead>`: Name | Description | Mappings | Status | DEV | QA | PROD | Last Modified
  - `<tbody>`: one `<tr>` per project
- Row content:
  - Name: bold text, truncate if long
  - Description: `max-w-xs truncate` (single line truncation)
  - Mappings: numeric count
  - Status: worst-status badge (same styling as card)
  - DEV/QA/PROD: `StatusBadge status="not-deployed"` in each cell
  - Last Modified: formatted date
- Row behavior:
  - `onClick` → calls `onProjectClick(project.projectId)`
  - `cursor-pointer`
  - Hover: `hover:bg-gray-50` or `hover:bg-slate-800` (dark mode aware)
- Table styling:
  - `w-full text-sm`
  - Header: `bg-gray-50 text-left font-medium text-gray-500`
  - Cells: appropriate padding, border-bottom
