## Summary

Build the welcoming empty state component displayed when no projects exist. Shows an illustration/icon, heading, subtext, and a prominent "Create Your First Project" button that navigates to `/projects/new`.

---

## Scope

### In Scope

- New file `ui/src/features/home/components/DashboardEmptyState.tsx`
- Illustration or large icon (Lucide icon at large size is acceptable)
- "No projects yet" heading
- "Create your first project to start mapping data." subtext
- "Create Your First Project" button (primary variant, prominent)
- Button navigates to `/projects/new`
- Centered layout within page content area

### Out of Scope

- Custom SVG illustrations (use Lucide icons)
- Animation

---

## Relevant Areas

- `ui/src/features/home/components/DashboardEmptyState.tsx` (new)
- `ui/src/features/home/components/index.ts` (barrel update)
- `ui/src/components/Button.tsx` (reuse)
- `ui/src/routes/paths.ts` (PATHS.CREATE_PROJECT)

## Change Requirements

- Component layout (centered vertically and horizontally):
  - Large icon: `FolderOpen` or `Layers` from Lucide, `w-16 h-16`, gray color
  - Heading: "No projects yet" in `text-xl font-semibold`
  - Subtext: "Create your first project to start mapping data." in `text-gray-500`
  - Button: "Create Your First Project" using `Button` with primary variant, large size
  - Spacing: comfortable vertical gap between elements (`space-y-4` or similar)
- Button `onClick` or wrapping in `<Link>` to `PATHS.CREATE_PROJECT`
- Minimum height to center nicely in the available content area (`min-h-[400px] flex items-center justify-center flex-col`)
