## Summary

Build the project card component used in the grid view of the project list. Each card shows project name, truncated description, mapping count, worst-status badge, deploy badges (DEV/QA/PROD), and last modified date. The entire card is clickable and navigates to the project overview.

---

## Scope

### In Scope

- New file `ui/src/features/home/components/ProjectCard.tsx`
- Card layout with project info
- Worst-status badge (color-coded)
- Deploy badges row (DEV/QA/PROD using `StatusBadge`)
- Truncated description (max 2 lines with ellipsis)
- Clickable card (entire card is a link)
- Last modified date in relative or formatted form
- Hover state visual feedback

### Out of Scope

- Quick-action buttons on card (delete, edit — optional per spec, defer to keep simple)
- Grid container (parent `ProjectCardGrid` handles layout)
- Card animations

- `ui/src/components/Card.tsx` (reuse or extend)

## Change Requirements

- `ProjectCard` receives: `project: ProjectListItem`, `onClick: (id: string) => void`
- Card layout:
  - **Header**: Project name (bold, truncate if long) + worst-status badge
  - **Body**: Description (2-line truncate with `line-clamp-2`), mapping count ("N mappings")
  - **Footer**: Deploy badges row (DEV/QA/PROD `StatusBadge`) + last modified date
- Worst-status badge:
  - "Ready" → green background/text
  - "Draft" → gray background/text
  - "Has Errors" → red background/text
  - "No Mappings" → neutral/hidden
- All deploy badges: `StatusBadge status="not-deployed"` (Phase 0)
- Click handler: calls `onClick(project.projectId)` — parent uses `navigate()`
- Hover: subtle border or shadow change (`hover:shadow-md` or `hover:border-blue-300`)
- Cursor: `cursor-pointer`
- Last modified: format as relative ("2 days ago") or short date ("May 1, 2026")
- `ProjectCardGrid`: simple CSS grid container (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`) that renders a list of `ProjectCard`
