## Summary

Build loading skeleton and error state components for the Home Dashboard. The skeleton mimics the metrics bar + project card grid during initial load. The error state shows a banner with retry action, preserving any previously loaded data below it (stale-while-revalidate pattern).

---

## Scope

### In Scope

- New file `ui/src/features/home/components/DashboardSkeleton.tsx`
- New file `ui/src/features/home/components/DashboardErrorBanner.tsx`
- Skeleton: animated pulse placeholders for metrics bar (4-5 card shapes) + project card grid (6 card shapes)
- Error banner: alert-style banner at top of page with message and retry button
- Stale data: error banner renders above existing content (not replacing it)

### Out of Scope

- React error boundaries
- Toast notifications

---

## Relevant Areas

- `ui/src/features/home/components/DashboardSkeleton.tsx` (new)
- `ui/src/features/home/components/DashboardErrorBanner.tsx` (new)
- `ui/src/features/home/components/index.ts` (barrel update)
- `ui/src/components/Button.tsx` (reuse for retry)

## Change Requirements

- `DashboardSkeleton`:
  - Row of 4-5 small card placeholders (metrics bar height)
  - Grid of 6 larger card placeholders (project card height)
  - All use `bg-gray-200 rounded animate-pulse`
  - Cards have realistic proportions matching actual card dimensions
  - No interactivity

- `DashboardErrorBanner`:
  - Props: `message: string`, `onRetry: () => void`
  - Alert banner style: `bg-red-50 border border-red-200 rounded-md p-4`
  - Warning/error icon (AlertTriangle from Lucide)
  - Message text: defaults to "Failed to load dashboard data"
  - "Retry" button (secondary variant) calling `onRetry`
  - Dismissible: optional (can include X button, or keep permanently until retry succeeds)
  - Renders at top of page, above any content
