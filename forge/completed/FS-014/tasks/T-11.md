## Summary

Assemble the Home Dashboard page by composing all sub-components (metrics bar, project list, tabs, empty/loading/error states, Schema Library link), wiring them to the `useDashboardData` hook, and replacing the route placeholder. This is the final integration task that produces the complete dashboard.

---

## Scope

### In Scope

- New file `ui/src/features/home/components/HomeDashboardPage.tsx`
- Compose: `PageHeader` + "Create Project" CTA + `MetricsBar` + `DashboardTabs` (containing `ProjectList`) + Schema Library link
- Wire `useDashboardData` hook for state
- Wire `useViewMode` hook for view toggle
- Conditional rendering:
  - Loading: show `DashboardSkeleton`
  - Error: show `DashboardErrorBanner` + stale content if available
  - Empty (no projects): show `DashboardEmptyState`
  - Loaded: show full dashboard
- Schema Library link: card or button showing "Schema Library ({count} schemas)" → navigates to `/schemas`
- "Create Project" button in `PageHeader` actions slot → navigates to `/projects/new`
- Project card/row click → navigates to `/projects/:projectId`
- Replace `ui/src/routes/pages/HomeDashboard.tsx` to render `HomeDashboardPage`
- Maintain `data-testid="page-home-dashboard"`

### Out of Scope

- Individual component implementations (T-03–T-10)
- Hook implementations (T-02, T-07)
- Adapter changes

## Change Requirements

- `HomeDashboardPage` component:
  - Calls `useDashboardData()` for data
  - Calls `useViewMode()` for view preference
  - Uses `useNavigate()` for navigation actions
  - Layout:
    ```
    PageHeader (title="Dashboard", actions=[Create Project button])
    DashboardTabs
      Projects tab:
        MetricsBar (metrics, loading)
        ProjectList (projects, viewMode, handlers)
      Deployments tab: placeholder
      Activity tab: placeholder
    Schema Library link/card (at bottom or in sidebar position)
    ```
  - Conditional rendering based on `loadState`:
    - `'loading'`: `DashboardSkeleton`
    - `'error'`: `DashboardErrorBanner` + retry
    - `'loaded'` with 0 projects: `DashboardEmptyState`
    - `'loaded'` with projects: full dashboard content
  - Navigation handlers:
    - `handleCreateProject` → `navigate(PATHS.CREATE_PROJECT)`
    - `handleProjectClick(id)` → `navigate(PATHS.PROJECT_OVERVIEW.replace(':projectId', id))`
    - Schema Library link → `navigate(PATHS.SCHEMA_LIBRARY)` or `<Link>`
  - Schema Library link: Shows schema count from hook data, links to `/schemas`
- Replace `ui/src/routes/pages/HomeDashboard.tsx`:
  - Import and render `HomeDashboardPage` from feature module
  - Maintain `data-testid="page-home-dashboard"`
- Page title area: "Dashboard" with description "Overview of all projects and mappings"
