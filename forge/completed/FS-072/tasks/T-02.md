## Change Requirements

- `ValidateMappingsInput` includes mapping-scoped request data and optional sample-data fields.
- Request contract is single-mapping only for V1 (no batch shape in typed API).
- `ValidationReport` models structured issues (`category`, `severity`, `affectedRules`, `description`, `recommendation`) and summary metadata.
- `ValidationReport` constrains `category` to `correctness | completeness | maintainability | risk`.
- `ValidationReport` constrains `severity` to `info | warning | error`.
- Adapter call uses canonical `/ai/validate-mappings` contract and returns typed structured output.
- Existing error normalization semantics remain unchanged.
