## Summary

Enhance the existing `ObjectSummaryPanel` (fully implemented) to show an actionable summary when an object target is selected: ensure it displays object name, type, mapped ratio (using corrected leaf fields from T-12), required child counts, and a clickable list of child fields that navigates to the selected child's builder state.

---

## Scope

### In Scope

- Display object name and type in panel header
- Display mapped ratio (x / y) using child leaf fields from `coverageMap`
- Display required child count where available from schema metadata
- Render a list of child field rows with mapped/unmapped indicators
- Clicking a child row fires navigation to that child's `selectedTargetPath`
- Correct handling of nested objects (show immediate children only; nested leaf count in ratio)

### Out of Scope

- Object-level mapping authoring (explicitly out of scope per spec)
- Array child rendering (handled by ArrayMappingBuilder)
- Editing rules from the object summary panel
- Deep-nested expand/collapse in the summary (just one level of children)

- `ui/src/features/mappings/components/ObjectSummaryPanel.tsx`
- `ui/src/features/mappings/hooks/use-target-status.ts`
- `ui/src/features/mappings/components/MappingEditorPage.tsx` (navigation callback wiring)

## Change Requirements

- `ObjectSummaryPanel` receives props: `targetPath`, `targetNode`, `coverageMap`, `statusMap`, `onNavigateToChild(childPath)`.
- Header shows: `{fieldName} (object)` with the mapped ratio badge `x / y mapped`.
- If schema metadata includes `required` array, display count: `N required fields`.
- Child field list: render each immediate child of the object with:
  - field name
  - type badge (string/number/object/array/etc.)
  - mapped/unmapped status icon (derived from `statusMap`)
  - clickable row that calls `onNavigateToChild(childPath)`
- Clicking a child row sets `selectedTargetPath` to the child's full path, triggering the right panel to render the appropriate builder for that child's type.
- If object has zero children, show "No child fields" empty state.
