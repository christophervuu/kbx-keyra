## Summary

Update the preview panel's Source JSON and Output panes to fill the available vertical space of their container, resize dynamically when the panel is resized, and scroll internally when content exceeds available space.

---

## Scope

### In Scope

- Source JSON pane fills available height in preview panel
- Output pane fills available height in preview panel
- Both panes resize dynamically when the bottom panel / preview panel is resized
- Internal scrolling when content exceeds pane height
- Preserve headers/toolbars above panes (they should not scroll away)

### Out of Scope

- Changes to the preview panel's resize handle behavior
- Changes to InlinePreviewStrip collapsed state
- Changes to the Advanced Testing page layout
- Content formatting within the panes

---

## Relevant Areas

- `ui/src/features/mappings/components/InlinePreviewStrip.tsx`
- `ui/src/features/mappings/components/BottomArea.tsx`
- `ui/src/features/mappings/components/ConnectedInlinePreviewStrip.tsx`
- `ui/src/features/mappings/components/AdvancedTestingPage.tsx` ?

---

## Change Requirements

- Preview panel container should use `flex-col` with `h-full` or equivalent to establish a fill-height context.
- Source JSON and Output textareas/panes should use `flex-1 min-h-0 overflow-y-auto` (or equivalent) to fill remaining space after headers.
- When the bottom panel is resized (via drag handle), inner panes must respond dynamically — no fixed pixel heights on the panes themselves.
- Headers, toolbars, and run buttons above/below panes remain fixed (not scrolled).
- Both expanded inline preview strip (Target View) and BottomArea tabs (Rules View) should implement this pattern for their respective Source/Output surfaces.

---

## Verification Requirements

- Component test: panes expand to fill container when rendered at various heights.
- Manual visual verification: resizing the bottom panel causes panes to grow/shrink.
- Manual visual verification: long JSON content scrolls internally within pane.
- Typecheck passes.

---

## Acceptance Checks

- Source JSON and Output panes fill available height of preview panel
- Resizing the panel dynamically resizes inner panes
- Content exceeding pane height scrolls internally
- Headers/toolbars remain visible (not scrolled away)
- `tsc --noEmit` passes
- Lint passes

## Notes

- The key Tailwind pattern is: parent with `flex flex-col h-full`, header with `flex-none`, content area with `flex-1 min-h-0 overflow-y-auto`.
- Apply to both the inline preview expanded state and the Rules View BottomArea tabs that show Source/Output.
