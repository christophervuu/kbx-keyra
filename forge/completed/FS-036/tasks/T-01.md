## Summary

Create the foundational `DebugSelection` type and `useLinkedDebugSelection` hook that provides shared linked selection state for cross-panel debugging interactions. This hook manages which diagnostic, trace, output path, or diff entry is currently selected and exposes helpers for checking selection status. All other interactive tasks in this spec depend on this state model.

## Scope

### In Scope

- Define `DebugSelection` interface in `ui/src/features/mappings/types.ts`

- Hook API: `selection`, `select(selection)`, `clear()`, `isPathSelected(path)`, `isRuleSelected(ruleIndex)`
- Selection auto-clears when execution state transitions to `'executing'` (new run starts)

## Change Requirements

Define the `DebugSelection` interface:

```typescript
interface DebugSelection {
  targetPath: string;
  ruleIndex: number | undefined;
  source: 'diagnostics' | 'trace' | 'output' | 'diff';
}
```

Implement `useLinkedDebugSelection` hook:

- State: `selection: DebugSelection | null` via `useState`
- `select(sel: DebugSelection)`: sets `selection` to the provided value
- `clear()`: sets `selection` to `null`
- `isPathSelected(path: string)`: returns `true` if `selection?.targetPath === path`
- `isRuleSelected(ruleIndex: number)`: returns `true` if `selection?.ruleIndex === ruleIndex`
- Accept an optional `executionStatus` parameter; when it transitions to `'executing'`, auto-clear the selection via `useEffect`

Export the hook and types from the mappings feature barrel.
