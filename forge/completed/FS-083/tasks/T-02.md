## Summary

Introduce backend-owned environment configuration and typed runtime API client contracts so deploy/promote/rollback/preview routing, timeout policy, and retry policy are resolved from configuration rather than hardcoded values.

---

## Scope

### In Scope

- Add/configure deployment environment settings model (`DEV|PREPROD|PROD` endpoint/path/timeout/retry policy).
- Create typed control-plane runtime API client interfaces for deploy, rollback, preview, and status checks.
- Add canonical request/response typing aligned with backend error envelope.
- Add config validation for missing/invalid environment endpoint configuration.

### Out of Scope

- Full orchestration workflow logic for deploy/promote/rollback state transitions.
- UI rendering updates.

## Change Requirements

- Define environment config schema and loader with strict validation.
- Implement runtime API client wrappers that:
  - attach request IDs,
  - apply per-environment timeout settings,
  - normalize error envelopes.
- Ensure retryable classification is surfaced to orchestration layer (no hidden retries beyond contract).

---

## Verification Requirements

- Unit tests for config parsing/validation.
- Contract tests for API client request/response mapping and error normalization.
- Typecheck/lint clean for added typed contracts.

---

## Acceptance Checks

- Runtime API routing for each environment resolves entirely from config.
- Missing/invalid environment config fails deterministically with actionable error.
- API client contracts preserve canonical error envelope + requestId correlation.
- Tests cover timeout/retryable classification pass.

---

## Blockers / Risks

- Existing adapter and deployment code paths may have embedded environment assumptions that require refactor.

---

## Notes

- Keep API client deterministic and side-effect-light to support orchestration testing.
- Spec Rev 2 **D5**: Environment config canonical source = persisted admin settings; env-var fallback for bootstrap only. Implement config model accordingly.
