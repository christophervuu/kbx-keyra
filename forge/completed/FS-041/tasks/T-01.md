## Summary

Extend the `ExplainRuleInput` type to include the `targetPath` field required by the backend Lambda, add a new `ExplainRuleResult` structured return type, and update the `ApiAdapter.explainRule` method signature to return `Promise<ExplainRuleResult>` instead of `Promise<string>`. Update `LocalStorageAdapter` to match the new return type (it still throws, so the change is trivial).

---

## Scope

- Add `ExplainRuleResult` interface to `ui/src/lib/types/domain.ts`
- Update `ApiAdapter.explainRule` return type in `ui/src/lib/api/types.ts`
- Update `LocalStorageAdapter.explainRule` return type annotation in `ui/src/lib/api/local-storage-adapter.ts`
- Update the barrel export in `ui/src/lib/types/index.ts` if `ExplainRuleResult` is not auto-exported

### Out of Scope

## Change Requirements

### `ExplainRuleInput` (domain.ts)

Current:
```typescript
export interface ExplainRuleInput {
  readonly expression: string;
}
```

Updated:
```typescript
export interface ExplainRuleInput {
  readonly targetPath: string;
  readonly expression: string;
}
```

### `ExplainRuleResult` (domain.ts, new)

```typescript
export interface ExplainRuleResult {
  readonly explanation: string;
}
```

### `ApiAdapter.explainRule` (types.ts)

Current:
```typescript
explainRule(input: ExplainRuleInput): Promise<string>;
```

Updated:
```typescript
explainRule(input: ExplainRuleInput): Promise<ExplainRuleResult>;
```

Import `ExplainRuleResult` alongside `ExplainRuleInput` from `@/lib/types`.

### `LocalStorageAdapter.explainRule` (local-storage-adapter.ts)

Update the return type annotation to `Promise<ExplainRuleResult>`. The method body (throws `OFFLINE_MODE_MESSAGE`) remains unchanged.

Import `ExplainRuleResult` alongside `ExplainRuleInput`.
