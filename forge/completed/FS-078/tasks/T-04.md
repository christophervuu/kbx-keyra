## Summary

Bring Schema Library origin/status display and loading/empty/error treatment into the same CDM semantics used in Project Overview and Schema Detail.

---

## Scope

### In Scope

- Update Schema Library card origin/status presentation to canonical CDM copy.
- Remove conflicting legacy CDM status text for canonical states.
- Standardize CDM-specific loading/empty/error state copy and retry affordances where applicable.
- Keep Schema Library navigation-first for CDM actions (no inline Re-sync action on cards).

### Out of Scope

- Adding major new library interaction patterns (including inline Re-sync controls on library cards).
- Replacing entire filter/sort/search UI.
