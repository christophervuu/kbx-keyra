## Summary

Add unit tests to `tests/lambda/ai/auto-map.test.ts` covering the new target listing filter: suggestions for unlisted targets are removed, listed targets (including arrays) pass through, and backward compatibility is preserved when `targetSection` is a plain path string.

## Scope

### In Scope

- New test cases in `tests/lambda/ai/auto-map.test.ts` for the filtering behavior
- Test: AI returns suggestion for an object target not in listing → filtered out
- Test: AI returns suggestion for a listed scalar target → passes through
- Test: AI returns suggestion for a listed array target → passes through
- Test: `targetSection` is a plain path (no listing format) → no filtering occurs
- Test: `targetSection` listing has 5 entries, AI returns 6 suggestions (one unlisted) → only 5 pass
