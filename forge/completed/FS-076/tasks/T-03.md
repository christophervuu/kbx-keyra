## Summary

Implement backend link behavior that fetches selected CDM schema content from GitHub read APIs, persists schema records with required CDM provenance metadata, and returns project-linkable schema metadata.

---

## Scope

### In Scope

- Add/enable backend link endpoint/service for CDM schema files.
- Validate selected path is under CommonDataModels root and points to a file.
- Fetch schema content + commit SHA using read-only GitHub APIs.
- Persist metadata including `origin=cdm`, `repo`, `repoId`, `branch`, `path`, `commitSha`.
- Return linked schema metadata compatible with existing project schema attach flow.
- Ensure duplicate link requests in the same project for identical `repo+branch+path` return idempotent success.

### Out of Scope

- Manual re-sync behavior.
- UI picker interaction details.
- Non-CDM publish/link flows.

## Change Requirements

- Link operation must persist full CDM source metadata contract including numeric `repoId`.
- Link operation must project `repoId` into query/index fields for filtering/reporting surfaces.
- Linked schema must be created in read-only CDM mode (`origin=cdm`) with initial sync status.
- Link path validation must reuse root guard behavior from listing logic.
- No GitHub write endpoints may be called.

---

## Verification Requirements

- Integration tests for successful link metadata persistence and project attachment.
- Tests for invalid path / missing file / unsupported content failures.
- Tests asserting no GitHub write client usage in link flow.

---

## Acceptance Checks

- Linked schema records store required CDM metadata fields including `repoId` and `commitSha`.
- Project reference to linked schema is created or updated correctly.
- Invalid or out-of-root paths are rejected deterministically.
- No write-path GitHub calls are observed in link execution tests.

---

## Blockers / Risks

- Schema content normalization (JSON text/object handling) must remain compatible with ingestion/storage assumptions.

---

## Notes

- Ensure idempotency/duplicate-link behavior is deterministic and documented in handler response semantics.
