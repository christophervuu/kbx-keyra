## Summary

Wire the `ConfigurationPanel` component into the `MappingEditorPage` grid by adding a `configPanelContent` slot prop, connecting it at the page composition level (route page) with the config state and actions from `useMappingEditor`, and updating the panel name constant from "AI Assist" to "Configuration". Also update `forge/architecture/ui-application.md` to document the config mutation pattern.

---

## Scope

### In Scope

- Add `configPanelContent?: ReactNode` slot prop to `MappingEditorPageProps`
- Wire slot into Panel 7 grid cell (replace direct `PanelPlaceholder` rendering)
- Update `PANEL_NAMES[7]` from "AI Assist (Panel 7)" to "Configuration (Panel 7)"
- In the route-level page composition (`routes/pages/MappingEditor.tsx`), instantiate `ConfigurationPanel` with:
  - `configOptions` from `useMappingEditor` result
  - `onUpdateConfig` bound to `actions.updateConfig`
  - `parsedTargetSchema` from `useMappingEditor` result
- Pass the instantiated `ConfigurationPanel` as `configPanelContent` to `MappingEditorPage`
- Update `forge/architecture/ui-application.md`:
  - Add `configPanelContent` to the list of panel slot props
  - Document config mutation pattern (updateConfig action on useMappingEditor)
  - Note Panel 7 rename from "AI Assist" to "Configuration"

### Out of Scope

- Implementing section content (T-03 through T-06 handle that)
- Changing Panel 7 grid dimensions or position
- Adding panel toggle/tab behavior (panel is always visible in its slot)
