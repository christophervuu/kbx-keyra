## Summary

Update the `ApiAdapter` interface and `HttpAdapter` implementation to reflect the new revision/version separation. Add methods for listing revisions, listing versions, creating versions, and handling no-op save responses.

---

## Scope

### In Scope

- Update `ApiAdapter` interface: `saveMapping` returns revision info + noChange flag; add `createVersion`, `listRevisions`, `getRevision`; update `listVersions`/`getVersion` response shapes
- Update `HttpAdapter` to call new/modified endpoints
- Update domain types in `ui/src/lib/types/domain.ts` (MappingRevision, MappingVersion types)

### Out of Scope

- LocalStorageAdapter (T-04)
- UI hooks and components

---

## Relevant Areas

- `ui/src/lib/api/types.ts`
- `ui/src/lib/api/http-adapter.ts`
- `ui/src/lib/types/domain.ts`

---

## Change Requirements

- Add `MappingRevision` type: `{ revision, savedAt, savedBy, ruleCount }`
- Add/update `MappingVersion` type: `{ version, revisionNumber, createdAt, createdBy }`
- `saveMapping()` response shape: `{ revision, noChange: boolean }`
- Add `createVersion(mappingId): Promise<MappingVersion>`
- Add `listRevisions(mappingId): Promise<MappingRevision[]>`
- Add `getRevision(mappingId, revision): Promise<MappingRevisionDetail>`
- Update `listVersions` / `getVersion` to include `revisionNumber`
- HttpAdapter maps to correct endpoints
