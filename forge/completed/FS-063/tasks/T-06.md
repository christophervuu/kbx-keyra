## Summary

Update the EditorTopBar to display both current revision and current version, show a distinct Save button (disabled when no changes) and a separate Version action button. Add feedback for no-op save and version creation success.

---

## Scope

### In Scope

- Display "Revision N" and "Version N" (or "No version") in EditorTopBar metadata area
- Save button: disabled when `canSave` is false; on click calls `save()`; shows brief feedback on no-op
- Version button/action: separate from Save; on click calls `createVersion()`; shows success feedback
- Draft indicator (e.g., "Unsaved draft" label or dot) when `hasDraft` is true

### Out of Scope

- History drawer/panel (T-07)
- Version notes/comments

---

## Relevant Areas

- `ui/src/features/mappings/components/EditorTopBar.tsx`

---

## Change Requirements

- Replace single version display with dual display: "Rev {N}" + "v{N}" (or "—" if no version)
- Save button: wire to `save()` from hook; disabled state from `canSave`
- Version button: new button (secondary style or menu item); wire to `createVersion()`
- Brief toast/inline feedback on successful version creation
- Draft indicator when autosaved changes exist but not yet saved as revision

---

## Verification Requirements

- Component tests: Save disabled when no changes
- Component tests: Version button triggers createVersion
- Component tests: revision and version numbers displayed correctly
- Visual verification of draft indicator
- Typecheck passes
