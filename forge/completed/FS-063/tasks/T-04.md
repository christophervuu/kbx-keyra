## Summary

Implement the revised revision/version semantics in `LocalStorageAdapter` so the full flow works in Phase 0 local-only mode. This includes no-op detection, revision numbering, version creation, and separate history storage.

---

## Scope

### In Scope

- `LocalStorageAdapter` implementation of `saveMapping` with revision semantics + no-op detection (hash comparison)
- `createVersion` implementation
- `listRevisions` / `getRevision` / `listVersions` / `getVersion` implementations
- localStorage key patterns for revisions and versions

### Out of Scope

- UI hooks/components
- Backend/HttpAdapter

---

## Relevant Areas

- `ui/src/lib/api/local-storage-adapter.ts`

---

## Change Requirements

- Store revisions in `keyra:revisions:{mappingId}` (array of revision metadata)
- Store versions in `keyra:versions:{mappingId}` (array of version metadata)
- `saveMapping`: compare config hash with latest revision; if same, return `{ revision: current, noChange: true }`; otherwise increment revision, store snapshot, return new revision
- `createVersion`: create version pointing to latest revision number
- List/get methods read from localStorage arrays
