## Summary

Redesign the version history drawer/panel to show two tabs: Revisions (all explicit saves) and Versions (user-created milestones). Each version entry links to its underlying revision. Autosaved drafts do not appear.

---

## Scope

### In Scope

- History panel/drawer with tab navigation: "Revisions" | "Versions"
- Revisions tab: list of revisions (revision number, timestamp, rule count) in descending order
- Versions tab: list of versions (version number, linked revision number, timestamp) in descending order
- Clicking a revision or version loads that snapshot for viewing
- Empty states for each tab

### Out of Scope

- Restore/rollback functionality (follow-on)
- Diff between revisions
- Draft entries in history

---

## Relevant Areas

- `ui/src/features/mappings/components/` (existing VersionHistoryDrawer or new component)
- `ui/src/features/mappings/hooks/use-mapping-editor.ts`

---

## Change Requirements

- Tab component with "Revisions" and "Versions" options
- Revisions tab calls `adapter.listRevisions(mappingId)` and renders list
- Versions tab calls `adapter.listVersions(mappingId)` and renders list with revision link
- Each version row shows "v{N} → Rev {revisionNumber}" with timestamp
- Clicking loads read-only snapshot view (existing pattern)
- No autosave/draft entries in either list

## Verification Requirements

- Component tests: clicking entry triggers load
