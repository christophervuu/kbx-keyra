## Summary

Add node selection behavior (click to select, visual highlight, `onSelectNode` callback, externally controlled `selectedPath`), mapping status indicators for the target tree variant (mapped/unmapped/warning icons per node), and a toolbar with "Expand All", "Collapse All", and "Expand to depth N" controls.

---

## Scope

### In Scope

- **Selection:**
  - Click on a node row → node becomes selected
  - Selected node receives visual highlight (background color)
  - `onSelectNode(node: SchemaTreeNode)` callback fires on selection
  - `selectedPath` prop for external control of selection (parent can set which node appears selected)
  - Only one node can be selected at a time
- **Mapping status indicators (target variant):**
  - When `variant === 'target'` and `mappingStatus` map is provided:
    - Nodes whose path is in the map with value `'mapped'` show green checkmark icon
    - Nodes with value `'unmapped'` show gray empty circle icon
    - Nodes with value `'warning'` show yellow warning triangle icon
  - Nodes not in the map show no status icon
  - When `variant === 'source'`, no mapping status icons are shown
- **Toolbar controls:**
  - Rendered above the tree (below search input if present)
  - "Expand All" button — expands all expandable nodes
  - "Collapse All" button — collapses all nodes
  - "Expand to depth" control — select a depth (1, 2, 3) and expand all nodes up to that depth (AE-10)
  - Buttons use the shared `Button` primitive from FS-008 (ghost variant, small size)

### Out of Scope

- Keyboard-triggered selection (T-09)
- Drag-and-drop from selected nodes (FS-011)
- Context menus on nodes
- Multi-select (only single selection supported)
- Computing mapping status from rules (parent provides the map)

## Change Requirements

**Selection behavior:**

- Add `selectedPath` local state (or use prop if externally controlled)
- On node row click: set `selectedPath` to the clicked node's path, call `onSelectNode(node)`
- If `selectedPath` prop is provided, use it as the source of truth (controlled mode)
- If `selectedPath` prop is undefined, manage selection internally (uncontrolled mode)
- Selected row gets a distinct background color (e.g., `bg-blue-50` or `bg-indigo-50`)
- `aria-selected="true"` on the selected treeitem

**Mapping status icons:**

- Create `<MappingStatusIcon status={'mapped' | 'unmapped' | 'warning'} />` component
- Mapped: Lucide `CheckCircle2` icon in green (`text-green-600`)
- Unmapped: Lucide `Circle` icon in gray (`text-gray-400`)
- Warning: Lucide `AlertTriangle` icon in yellow/amber (`text-amber-500`)
- Render to the right of the field name (or at the end of the row)
- Only shown when `variant === 'target'` and the node's path exists in `mappingStatus` map
- Accessible: include `aria-label` on the icon (e.g., "Mapped", "Unmapped", "Has warnings")

**Toolbar:**

- Rendered between search input and tree content
- Three controls in a row:
  - "Expand All" button — sets `expandedPaths` to include all nodes that have children
  - "Collapse All" button — clears `expandedPaths` to empty set
  - "Expand to depth" — dropdown or segmented control to pick depth (1, 2, 3); expands all nodes with `depth < N`
- Toolbar uses small ghost buttons from the shared `Button` component
- Toolbar is always visible (not affected by search state)

**Expand to depth logic (AE-10):**
- Walk all nodes recursively
- Add to `expandedPaths` any node whose `depth < targetDepth` and `childCount > 0`
- Remove from `expandedPaths` any node whose `depth >= targetDepth`

## Notes

- Selection state and expand state are independent. Selecting a node does not expand or collapse it.
- The toolbar's "Expand to depth" control can be a simple dropdown (`<select>`) or button group for Phase 0. No need for a fancy popover.
- Mapping status icons are intentionally placed after the field name (not before the type icon) to maintain consistent left-alignment of field names across rows.
- The `mappingStatus` prop type is `Map<string, MappingNodeStatus>`. If the map doesn't contain a path, no icon is shown for that node. This handles partial mapping coverage gracefully.
