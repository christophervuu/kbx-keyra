## Summary

Replace the full-width 4-tab `BottomArea` container (Preview, Diagnostics, Trace, Test Cases) with a compact, collapsible inline preview strip. The strip contains a compact source data input, Run button, inline output display, status summary line, auto-preview toggle, and "Open Advanced Testing" link. When auto-preview is enabled and source data is loaded, the strip auto-runs on every Apply. Advanced features (diagnostics, trace, diff, test cases) are relocated to the dedicated Advanced Testing page (T-06).

---

## Scope

### In Scope

- Create new `InlinePreviewStrip.tsx` component to replace `BottomArea.tsx` in the editor layout.
- Strip layout: single horizontal row (~120px default height), collapsible (toggle to ~32px collapsed bar).
- Strip contents:
  - Compact JSON source input (textarea, constrained height, expandable)
  - "Run" button (triggers preview execution)
  - Inline output display (read-only, truncated, expandable)
  - Status line: error/warning counts or "Valid" text
  - "☑ Auto-preview" toggle (default on)
  - "Open Advanced Testing →" link (navigates to testing page)
- Auto-preview behavior: when toggle is on and `sourceData` is non-empty, subscribe to `onRuleApplied` events (from T-02) and trigger `run()` automatically. Output updates with a brief flash/highlight animation (`animate-pulse` for 300ms or similar).
- Wire to existing `usePreviewExecution` hook for run/result state.
- Update `MappingEditorPage` to render `InlinePreviewStrip` in the bottom slot instead of `BottomArea`.
- The `BottomArea` component is not deleted (it will be reused by the Advanced Testing page in T-06) but is no longer rendered in the editor.

### Out of Scope

- Creating the Advanced Testing page (T-06).
- Modifications to `usePreviewExecution` hook internals.
- Changes to the PreviewContext or preview data flow.
- Per-panel search (T-03).
- Save model (T-02).

## Change Requirements

- **New component `InlinePreviewStrip.tsx`:**
  - Props:
    - `sourceData: string` — current source JSON text
    - `onSourceDataChange: (value: string) => void`
    - `onRun: () => void`
    - `output: unknown | null`
    - `isRunning: boolean`
    - `status: { errors: number; warnings: number } | null`
    - `testingPageUrl: string` — href for "Open Advanced Testing" link
    - `isCollapsed: boolean`
    - `onToggleCollapse: () => void`
    - `autoPreview: boolean` — auto-preview toggle state
    - `onAutoPreviewChange: (enabled: boolean) => void`
    - `lastApplyTimestamp: number | null` — incremented on each Apply; triggers auto-run when changed
  - Layout:
    - Collapsed: single bar with "Preview" label, status summary, expand chevron
    - Expanded (~120px): flexbox row with source input (30%), Run button, output (45%), status + auto-preview toggle + link (25%)
  - Source input: `<textarea>` with `rows={3}`, monospace font, border, placeholder "Paste source JSON..."
  - Output: read-only `<pre>` with truncated content (max 3 lines), monospace, border; brief flash animation (`ring-2 ring-blue-400 transition-all duration-300`) when output updates via auto-preview
  - Status line: "N errors, M warnings" in red/amber or "✓ Valid" in green
  - Auto-preview toggle: small checkbox + "Auto-preview" label, positioned near status line
  - "Open Advanced Testing →" link styled as text button, navigates via React Router `<Link>`
  - **Auto-run logic:** `useEffect` watches `lastApplyTimestamp`; if `autoPreview` is true and `sourceData` is non-empty, calls `onRun()`. If `sourceData` is empty, no-ops silently (per AE-14).

- **`MappingEditorPage` update:**
  - Replace `bottomContent` slot rendering from `BottomArea` to `InlinePreviewStrip`
  - Adjust bottom area height allocation (from flexible tab container to fixed ~120px strip)
  - Pass required props from `usePreviewExecution` and `PreviewContext`

- **Route path addition:**
  - Add `PATHS.MAPPING_TEST` to `paths.ts`: `/projects/:projectId/mappings/:mappingId/test`
  - Used by the "Open Advanced Testing" link (route page created in T-06)
