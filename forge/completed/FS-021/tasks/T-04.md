## Summary

Update the `MappingEditorPage` three-column grid to allocate ~15% to the source panel, ~35% to the target worklist, and ~50% to the builder/editor panel. This rebalances from the current ~15/55/33 split to prioritize the primary authoring surface. The collapsible source panel behavior at <=1024px is preserved.

---

## Scope

### In Scope

- Update CSS grid/flex column widths in `MappingEditorPage.tsx` to achieve the 15/35/50 ratio.
- Verify the source panel remains `hidden lg:block` at <=1024px.
- When source panel is hidden, redistribute space: target ~40%, builder ~60% (approximate).
- Ensure minimum content readability at 1024px viewport.

### Out of Scope

- Content changes within any panel (only width allocation changes).
- Search inputs or filter chips (T-03).
- Top bar changes (T-01).
- Bottom area changes (T-05).

---

## Relevant Areas

- `ui/src/features/mappings/components/MappingEditorPage.tsx`
- `ui/src/features/mappings/components/MappingEditorPage.test.tsx`

---

## Change Requirements

- Update the column width classes in `MappingEditorPage`:
  - Source column: from current width to `w-[15%]` (or equivalent grid fraction)
  - Target column: from current width to `w-[35%]` (or equivalent grid fraction)
  - Builder column: from current width to `w-[50%]` (or equivalent grid fraction)
- If using CSS Grid: `grid-template-columns: 15% 35% 50%` (or `grid-template-columns: 15fr 35fr 50fr`).
- If using flexbox: `flex: 0 0 15%` / `flex: 0 0 35%` / `flex: 1 1 50%`.
- Responsive behavior:
  - At <=1024px (source hidden): target and builder fill remaining space proportionally (~40/60 or adjust to taste).
  - At >=1280px: exact 15/35/50 split.
- Ensure no horizontal overflow at 1024px minimum viewport.

---

## Verification Requirements

- Component test: at default viewport, three columns render with correct relative width classes.
- Component test: source panel has `hidden lg:block` (or equivalent responsive class).
- Visual verification: content in all three panels is readable and not clipped at 1280px and 1024px.
- Typecheck passes.

## Acceptance Checks

- Source panel occupies ~15% width at >=1280px viewport (per AE-08)
- Target worklist occupies ~35% width at >=1280px viewport (per AE-08)
- Builder/editor occupies ~50% width at >=1280px viewport (per AE-08)
- Source panel collapses at <=1024px
- No horizontal overflow at 1024px minimum viewport
- Typecheck and lint pass
- Existing `MappingEditorPage` tests pass (updated if CSS classes changed)

---

## Blockers / Risks

- If existing panel content has hard minimum widths (min-w-* classes), they may conflict with the new 15% source width. Check for and remove or reduce any `min-w-*` on the source panel.

---

## Notes

- This task is intentionally minimal — only CSS width changes. It unblocks T-03 (which adds search into the panels at these new widths).
- The 15/35/50 split uses the full width minus any fixed-width elements (scrollbars, borders). Use percentage-based widths that fill the container.
