## Summary

Redesign the Mapping Editor top area from three horizontal rows (global nav, breadcrumbs with raw UUIDs, editor status bar) into two rows (global nav + a consolidated context bar). The context bar displays human-readable project/mapping names as links, version badge, single highest-environment deploy badge with stale indicator, save state placeholder, and action buttons (History, overflow menu).

---

## Scope

### In Scope

- Redesign `EditorTopBar.tsx` to render the new context bar layout: `ProjectName / MappingName` links, version badge, deploy badge (highest env + stale logic), save state indicator (placeholder text — wired in T-02), Save button slot, History button, overflow menu.
- Suppress breadcrumb rendering for the Mapping Editor route in `AppLayout.tsx` or `Breadcrumbs.tsx` (the editor's own context bar replaces breadcrumbs).
- Implement deploy badge simplification: derive highest environment from deploy metadata; show stale indicator if `savedVersion > deployedVersion`.

## Change Requirements

- `EditorTopBar` receives updated props:
  - `projectName: string` and `projectId: string` (for link)
  - `mappingName: string` and `mappingId: string`
  - `version: number`
  - `deployStatus: { environment: 'DEV' | 'QA' | 'PROD'; version: number } | null` — highest deployed env
  - `savedVersion: number` — current saved version for stale comparison
  - `saveState: 'saved' | 'unsaved'` — simple prop (T-02 will wire the actual state)
  - `unsavedCount: number` — passed for display (T-02 will compute)
  - `onSave: () => void` — save action callback
  - `onHistoryToggle?: () => void` — existing prop preserved
- Layout: single row, flexbox, items centered:
  - Left: `ProjectName` link (→ project overview) / `MappingName` text, version badge (`v{N}`)
  - Center-right: Deploy badge (single), Save state text, Save button (primary, disabled when saved)
  - Right: History button, overflow menu
- Deploy badge logic:
  - If no deployments: neutral gray "Not deployed"
  - If deployed: show highest env name with green dot
  - Stale threshold is strictly `savedVersion > deployedVersion` (version number comparison only — no content diffing). This is simple to implement, simple to explain to users, and handles the common case correctly.
  - If stale: show "(stale)" suffix with amber dot
- Breadcrumb suppression: `AppLayout` or `Breadcrumbs` conditionally hides the breadcrumb row when the current route matches `/projects/:projectId/mappings/:mappingId` (exact path, not sub-routes). Implementation preference: add a `hideBreadcrumbs` flag via route `handle` metadata or a layout-level check on `location.pathname`.
- Remove raw UUIDs from any visible UI text in the editor top area.
