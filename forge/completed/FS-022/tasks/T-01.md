## Summary

Delete the GlobalToolbar component and its slot in MappingEditorPage. Move the Sort dropdown and Target View / Rules View toggle into the TargetWorklist's toolbar area (above the existing search input). Move the Auto-map placeholder button into EditorTopBar. Remove Focus mode entirely: delete the breadcrumb mode toggle, BreadcrumbNav rendering inside TargetWorklist, and the `breadcrumbMode`/`currentSubtreePath` state at the composition layer.

---

## Scope

### In Scope

- Delete `ui/src/features/mappings/components/GlobalToolbar.tsx`.
- Remove the `toolbarContent` slot/prop from `MappingEditorPage.tsx` and the corresponding DOM element (`data-testid="global-toolbar"` wrapper).
- Add a `sort` prop, `onSortChange` callback, `view` prop, and `onViewToggle` callback to `TargetWorklistProps`.
- Render a sort `<select>` and Target View / Rules View toggle buttons in the TargetWorklist toolbar area, above the existing search input.
- When `view === 'rules'`, the sort dropdown and filter chips are hidden (only the view toggle remains visible), since RuleList replaces the tree.
- Add a disabled Auto-map placeholder button to `EditorTopBar.tsx`.
- Remove `BreadcrumbNav.tsx` rendering from inside `TargetWorklist.tsx`. Remove the `breadcrumbMode` and `currentSubtreePath` props from `TargetWorklistProps`. Remove `onSubtreeNavigate` prop.
- Remove `breadcrumbMode` and `currentSubtreePath` state and the `onBreadcrumbModeToggle` handler from the composition layer that owns `MappingEditorPage`.
- Update `ui/src/features/mappings/index.ts` barrel to remove GlobalToolbar export.
- Update all affected component tests.

### Out of Scope

- Deleting `BreadcrumbNav.tsx` file itself (may be retained for potential future use or deleted in cleanup).
- Resizable panels (T-02).
- Any changes to RuleList, InlinePreviewStrip, or auto-preview behavior.

## Change Requirements

**MappingEditorPage.tsx:**
- Remove `toolbarContent` from `MappingEditorPageProps`.
- Remove the toolbar row from the rendered layout (the element between EditorTopBar and the three-column area).
- Adjust vertical spacing so the three-column area sits directly below EditorTopBar.

**TargetWorklist.tsx:**
- Add props: `sort: TargetSort`, `onSortChange: (sort: TargetSort) => void`, `view: EditorView`, `onViewToggle: (view: EditorView) => void`.
- Render a toolbar row above the search input with:
  - Sort `<select>` (left-aligned, same options as current GlobalToolbar: schema / unmapped-first / required-first). Hidden when `view === 'rules'`.
  - Spacer.
  - Target View / Rules View toggle buttons (right-aligned). Use `aria-pressed` for accessibility.
- Remove `breadcrumbMode?: boolean`, `currentSubtreePath?: string | null`, `onSubtreeNavigate?: (path: string | null) => void` from props.
- Remove `BreadcrumbNav` import and conditional rendering.
- Remove `effectiveRootNodes` memo that filters by subtree path — always use full root nodes.
- Remove the click-to-drill-down behavior for object/array nodes when breadcrumb mode was active. Clicking always calls `onSelectNode`.

**EditorTopBar.tsx:**
- Add a disabled Auto-map button in the action area (after schema names, before save status). Style: `opacity-50`, tooltip "AI-powered auto-mapping — coming soon".
- Use `data-testid="automap-button"`.

**Composition layer:**
- Remove `breadcrumbMode` and `currentSubtreePath` state variables.
- Remove `onBreadcrumbModeToggle` handler.
- Stop passing `toolbarContent` to `MappingEditorPage`.
- Pass `sort`, `onSortChange`, `view`, `onViewToggle` to `TargetWorklist` (or the slot content that wraps it).

**Barrel / exports:**
- Remove `GlobalToolbar` from the mappings feature barrel.
