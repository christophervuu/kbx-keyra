## Summary

Remove the `autoPreview` toggle from the inline preview strip. Preview now always executes automatically when a rule is applied (via `lastApplyTimestamp`) and source data is present. This simplifies the UX by eliminating an opt-in toggle for what should be the default behavior.

---

## Scope

### In Scope

- Remove the `autoPreview` prop and `onAutoPreviewChange` prop from `InlinePreviewStripProps`.
- Remove the auto-preview checkbox UI from `InlinePreviewStrip.tsx`.
- Remove the `autoPreview` state from `ConnectedInlinePreviewStrip.tsx`.
- In `InlinePreviewStrip.tsx`, modify the `lastApplyTimestamp` effect to always trigger `onRun()` when `sourceData` is non-empty (remove the `autoPreview` condition check).
- Remove `data-testid="strip-auto-preview-label"` and `data-testid="strip-auto-preview-toggle"` elements.
- Update component tests.

### Out of Scope

- Changes to the Advanced Testing page's auto-run toggle (that page has its own independent toggle in its top bar).
- Changes to the Run button behavior (manual run is always available).
- Changes to `usePreviewExecution` hook.

---

## Relevant Areas

- `ui/src/features/mappings/components/InlinePreviewStrip.tsx`
- `ui/src/features/mappings/components/ConnectedInlinePreviewStrip.tsx`

## Change Requirements

**InlinePreviewStrip.tsx:**

Remove from `InlinePreviewStripProps`:
```ts
// Remove these:
autoPreview: boolean;
onAutoPreviewChange: (enabled: boolean) => void;
```

Remove the auto-preview checkbox UI from the status/controls section (the 25% right area in expanded mode). The area should still contain the status line and the "Open Advanced Testing" link.

Modify the `lastApplyTimestamp` `useEffect`:
```ts
// Before:
useEffect(() => {
  if (autoPreview && lastApplyTimestamp && lastApplyTimestamp !== prevTimestampRef.current && sourceData.trim()) {
    onRun();
  }
  prevTimestampRef.current = lastApplyTimestamp;
}, [lastApplyTimestamp, autoPreview, sourceData, onRun]);

// After:
useEffect(() => {
  if (lastApplyTimestamp && lastApplyTimestamp !== prevTimestampRef.current && sourceData.trim()) {
    onRun();
  }
  prevTimestampRef.current = lastApplyTimestamp;
}, [lastApplyTimestamp, sourceData, onRun]);
```

**ConnectedInlinePreviewStrip.tsx:**

Remove:
```ts
const [autoPreview, setAutoPreview] = useState(true);
```

Remove `autoPreview` and `onAutoPreviewChange` from the `InlinePreviewStrip` prop spread.

## Notes

- The 500ms debounce in `usePreviewExecution` still applies — the effect calls `onRun` which triggers the debounced execution. This prevents rapid-fire executions if the user applies multiple rules quickly.
- The Advanced Testing page has its own auto-run toggle (`autoRun` in its top bar). That toggle is independent and remains unchanged.
