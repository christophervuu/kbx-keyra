## Summary

Replace the current top `NavBar`-based shell with a fixed left sidebar workspace shell across primary routes, with collapsed state persisted in localStorage. Preserve focused workspace compatibility (e.g., Mapping Editor/Test Lab) and ensure no route renders both top nav and sidebar navigation simultaneously.

---

## Scope

### In Scope

- Update `AppLayout` to sidebar + content workspace structure for primary routes.
- Replace/refactor `NavBar` into sidebar navigation surface.
- Add sidebar collapse toggle and conditional nav label rendering.
- Persist sidebar collapsed/expanded preference in localStorage (client-only).
- Implement accessible icon-only collapsed navigation state.
- Remove top navigation rendering globally where practical, including primary routes.
- Preserve focused-route compatibility while avoiding dual navigation.

### Out of Scope

- Dashboard panel/content redesign details (handled in T-02).
- Non-shell feature logic changes unrelated to navigation/layout.
- Backend/data adapter changes.

- `ui/src/components/layout/AppLayout.tsx`
- `ui/src/components/layout/NavBar.tsx` (or replacement component[s])
- `ui/src/components/layout/index.ts` ?
- `ui/src/routes/paths.ts`
- `ui/src/components/layout/layout.test.tsx`

## Change Requirements

- App shell must render as full-height layout with fixed left sidebar and right content region.
- Sidebar must include KeyRa branding area, workspace section label, and large clickable nav rows.
- Expanded mode shows icons + labels; collapsed mode shows icons only.
- Sidebar state must persist across reloads via localStorage and degrade gracefully if storage is unavailable.
- Home active state must include non-color-only indicator.
- Hover and focus-visible styles must be implemented for nav rows and collapse toggle.
- Existing route targets (Home/Schemas/Templates/Settings/Project Overview and other standard pages) remain reachable.
- Focused routes (Mapping Editor/Test Lab) must remain functional and must not show top and side navigation together.

---

## Verification Requirements

- Update/add layout tests to verify:
  - no top nav region is rendered on primary routes (AE-01)
  - sidebar renders and toggles expanded/collapsed mode (AE-02)
  - active nav item includes non-color-only active indicator semantics (AE-03)
  - collapse preference restores on remount/reload via localStorage (AE-08)
  - focused route compatibility and absence of dual nav (AE-09)
- Manual verification for content expansion when collapsed and keyboard navigation in both states.

---

## Acceptance Checks

- App shell renders fixed left sidebar and right content area with no top nav on primary routes.
- Sidebar collapse toggle switches between icon+label and icon-only nav.
- Sidebar preference persists across reload using localStorage only.
- Home active nav row exposes a non-color-only active indicator.
- Focused workspace routes remain usable with no top+side dual-nav rendering.
- Sidebar nav controls are keyboard-focusable with visible focus states.
- Tests covering AE-01/AE-02/AE-03/AE-08/AE-09 pass.

- Focused route behavior may require nuanced layout branching to avoid UX regression.
